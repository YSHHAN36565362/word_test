脇
겨드랑이, 옆구리, 옆(わき)
[읽기] 脇=わき (훈독)
[한자1] 脇 (겨드랑이 협 / 겨드랑이, 옆)
· 음독: キョウ
· 훈독: ★わき
· 분해: 月(肉, 몸) + 劦(합할 협, 力 세 개가 힘을 모음)
· 어원: 몸(月)에서 힘(劦)이 모이는 팔과 몸통 사이 부분에서 겨드랑이, 옆을 나타냄
· 예시 단어: 脇士 (협시, きょう+じ)
[종합] 몸통 옆에 팔이 붙어 힘이 모이는 부위(脇)를 가리키는 글자로, 겨드랑이나 몸의 옆쪽을 뜻함
[치트키] "와키! 와, 키 큰 사람 옆구리" → 脇=와키→겨드랑이
[장면] 가방을 겨드랑이에 끼고 서둘러 걷는 장면
[예문] 荷物を脇に抱える(니모츠오 와키니 카카에루) = "짐을 옆구리에 끼다"

若人
젊은이, 청년(わこうど)
[읽기] 若=わか + 人=うど → わこうど (훈독, わかひと의 음편형)
[한자1] 若 (젊을 약 / 젊다, 만약)
· 음독: ★ジャク, ニャク
· 훈독: わか-い
· 분해: 艸(풀 초, 어린 새싹) + 右(오른손 우, 손으로 다룸)
· 어원: 손(右)으로 어린 새싹(艸)을 캐고 다루는 모습에서 어리다, 젊다를 나타냄
· 예시 단어: 若干 (약간, じゃっ+かん)
[한자2] 人 (사람 인 / 사람)
· 음독: ジン, ニン
· 훈독: ★ひと (이 단어에서는 わかひと→わこうど로 음편 변화)
· 분해: 사람이 서서 팔을 늘어뜨린 모습을 본뜬 상형자
· 어원: 두 다리로 서 있는 사람의 옆모습에서 사람을 나타냄
· 예시 단어: 人間 (인간, にん+げん)
[종합] 젊은(若) 사람(人)이라는 뜻이 합쳐져 젊은이, 청년을 가리키는 말이 됨
[치트키] "와코-도! 와, 코 오뚝한 도련님 청년" → 若人=와코-도→젊은이
[장면] 패기 넘치는 청년들이 힘차게 행진하는 장면
[예문] 若人よ、夢を持て(와코-도요, 유메오 모테) = "젊은이여, 꿈을 가져라"

綿
솜, 목화(わた)
[읽기] 綿=わた (훈독)
[한자1] 綿 (솜 면 / 솜, 목화, 이어지다)
· 음독: メン
· 훈독: ★わた
· 분해: 糸(실 사) + 帛(비단 백, 白+巾)
· 어원: 실(糸)처럼 가늘게 이어진 흰 비단천(帛)에서 부드러운 섬유, 솜을 나타냄
· 예시 단어: 綿密 (면밀, めん+みつ)
[종합] 부드러운 섬유 실이 이어져 뭉친 모습(綿)을 가리키는 글자로, 솜이나 목화를 뜻함
[치트키] "와타! 와, 타조 깃털처럼 부드러운 솜" → 綿=와타→솜
[장면] 하얀 솜뭉치가 폭신하게 쌓여있는 장면
[예문] 綿のように柔らかい(와타노 요-니 야와라카이) = "솜처럼 부드럽다"

和服
일본식 옷(わふく)
[읽기] 和=ワ + 服=フク → わふく (전부 음독)
[한자1] 和 (화할 화 / 화목하다, 일본의)
· 음독: ★ワ, オ
· 훈독: やわ-らぐ, なご-む, あ-える
· 분해: 禾(벼 화) + 口(입 구)
· 어원: 벼(禾)로 지은 곡식을 여럿이 입(口)으로 나눠 먹으며 화목해지는 모습에서 화하다를 나타냄
· 예시 단어: 平和 (평화, へい+わ)
[한자2] 服 (옷 복 / 옷, 복종하다)
· 음독: ★フク
· 훈독: 없음 (조요칸지 훈독 지정 없음)
· 분해: 月(肉, 몸) + 𠬝(다스릴 복, 사람을 굴복시킴)
· 어원: 몸(月)에 걸쳐 사람을 다스리듯(𠬝) 갖춰 입는 것에서 옷, 복종을 나타냄
· 예시 단어: 服装 (복장, ふく+そう)
[종합] 일본(和)에서 입는 옷(服)이라는 뜻이 합쳐져 일본식 옷을 가리키는 말이 됨
[치트키] "와후쿠! 와, 후크(옷고름) 채운 일본옷" → 和服=와후쿠→일본식 옷
[장면] 기모노를 곱게 차려입은 사람이 거리를 걷는 장면
[예문] 和服を着て出かける(와후쿠오 키테 데카케루) = "일본식 옷을 입고 외출하다"

打ち合わせる
사전에 협의하다, 의논하다(うちあわせる)
[읽기] 打=うち + 合わせる=あわせる → うちあわせる (훈독, 복합동사: 打つ+合わせる)
[한자1] 打 (칠 타 / 치다, 두드리다)
· 음독: ダ
· 훈독: ★う-つ, う-ち-
· 분해: 扌(손 수) + 丁(못 정, 두드리는 소리)
· 어원: 손(扌)으로 못(丁)을 두드리듯 내려치는 모습에서 치다를 나타냄
· 예시 단어: 打撃 (타격, だ+げき)
[한자2] 合 (합할 합 / 맞다, 합치다)
· 음독: ゴウ, ガッ, カッ
· 훈독: ★あ-わせる, あ-う
· 분해: 亼(모을 집) + 口(입 구)
· 어원: 뚜껑(亼)과 그릇(口)이 딱 맞물려 합쳐지는 모습에서 맞다, 합치다를 나타냄
· 예시 단어: 合計 (합계, ごう+けい)
[종합] 서로 치고(打) 의견을 맞추는(合) 행동이 합쳐져, 미리 의논해 맞추다=협의하다는 뜻이 됨
[치트키] "우치아와세루! 우리 치(팀) 아와서(맞춰서) 의논해" → 打ち合わせる=우치아와세루→협의하다
[장면] 회의실에서 팀원들이 일정을 맞춰보며 의논하는 장면
[예문] 明日の予定を打ち合わせる(아시타노 요테이오 우치아와세루) = "내일 일정을 사전에 협의하다"

繰り返す
반복하다(くりかえす)
[읽기] 繰=くり + 返す=かえす → くりかえす (훈독, 복합동사: 繰る+返す)
[한자1] 繰 (고치 켤 소 / 잇달아 감다, 되풀이하다)
· 음독: ソウ
· 훈독: ★く-る
· 분해: 糸(실 사) + 喿(울 소, 새 떼가 지저귐)
· 어원: 실(糸)을 계속해서 되풀이하며 감는 모습에서 잇달아, 되풀이하다를 나타냄
[한자2] 返 (돌이킬 반 / 돌아오다, 되돌리다)
· 음독: ★ヘン
· 훈독: かえ-す, かえ-る
· 분해: 辶(쉬엄쉬엄 갈 착) + 反(되돌릴 반, 손바닥을 뒤집는 모양)
· 어원: 손바닥을 뒤집듯(反) 왔던 길을 다시 가는(辶) 모습에서 되돌리다를 나타냄
· 예시 단어: 返却 (반각, へん+きゃく)
[종합] 실을 감듯(繰) 같은 동작을 계속 되돌리는(返) 것에서 반복하다는 뜻이 됨
[치트키] "쿠리카에스! 쿠리(밤)를 캐고 또 캐스(반복해)" → 繰り返す=쿠리카에스→반복하다
[장면] 같은 동작을 계속 되풀이하며 연습하는 장면
[예문] 同じミスを繰り返す(오나지 미스오 쿠리카에스) = "같은 실수를 반복하다"

着替える
옷을 갈아입다(きがえる)
[읽기] 着=き + 替える=かえる → きがえる (훈독, 복합동사: 着る+替える, 連濁으로 がえる)
[한자1] 着 (붙을 착 / 입다, 붙다, 도착하다)
· 음독: チャク, ジャク
· 훈독: ★き-る, つ-く, つ-ける
· 분해: 艹(풀 초, 원자 著의 변형) + 者(놈 자, 사람)
· 어원: 사람(者)의 몸에 옷이 드러나 붙는 모습에서 입다, 붙다를 나타냄
· 예시 단어: 着席 (착석, ちゃく+せき)
[한자2] 替 (바꿀 체 / 바꾸다, 교체하다)
· 음독: タイ
· 훈독: ★か-える, か-わる
· 분해: 夫(지아비 부) 두 개 + 曰(가로 왈, 말하다)
· 어원: 두 사람(夫夫)이 말(曰)을 주고받으며 자리를 서로 바꾸는 모습에서 바꾸다를 나타냄
· 예시 단어: 代替 (대체, だい+たい)
[종합] 입고(着) 있던 옷을 다른 것으로 바꾸는(替) 것에서 옷을 갈아입다는 뜻이 됨
[치트키] "키가에루! 키(옷) 갈아입고 가에루(바꿔)" → 着替える=키가에루→갈아입다
[장면] 퇴근 후 집에 와서 편한 옷으로 갈아입는 장면
[예문] 部屋着に着替える(헤야기니 키가에루) = "실내복으로 갈아입다"

付き合う
사귀다, 행동을 같이 하다(つきあう)
[읽기] 付き=つき + 合う=あう → つきあう (훈독, 복합동사: 付く+合う)

· 음독: フ
· 훈독: ★つ-く, つ-ける
· 분해: 亻(사람 인) + 寸(마디 촌, 손)
· 어원: 사람(亻)이 손(寸)으로 무언가를 건네주어 붙이는 모습에서 주다, 붙다를 나타냄
· 예시 단어: 交付 (교부, こう+ふ)
[한자2] 合 (합할 합 / 맞다, 함께하다)
· 음독: ゴウ, ガッ, カッ
· 훈독: ★あ-う, あ-わせる

· 예시 단어: 合体 (합체, がっ+たい)
[종합] 서로 붙어(付) 함께하는(合) 관계라는 뜻에서 사귀다, 행동을 같이 하다는 의미가 됨
[치트키] "츠키아우! 츠키(달)처럼 서로 붙어 아우르며 사귀다" → 付き合う=츠키아우→사귀다
[장면] 연인이 손을 꼭 붙잡고 나란히 걷는 장면
[예문] 二人は三年付き合っている(후타리와 산넨 츠키앗테이루) = "두 사람은 3년째 사귀고 있다"

幼稚な

· 훈독: おさな-い

· 예시 단어: 幼児 (유아, よう+じ)
[한자2] 稚 (어릴 치 / 어리다, 유치하다)
· 음독: ★チ
· 훈독: 없음 (조요칸지 훈독 지정 없음)

[예문] 幼稚な考え方だ(요-치나 캉가에카타다) = "유치한 사고방식이다"

乱暴な
난폭한(らんぼうな)
[읽기] 乱=ラン + 暴=ボウ → らんぼう (전부 음독)

· 예시 단어: 混乱 (혼란, こん+らん)

[종합] 어지럽고(乱) 사나운(暴) 성질이라는 뜻이 합쳐져 난폭한이라는 의미가 됨

[예문] 乱暴な運転はやめよう(란보-나 운텐와 야메요-) = "난폭한 운전은 그만두자"

それなのに
그런데도, 그럼에도(それなのに)
[종합] それ(그것)+な(단정)+のに(임에도)가 합쳐진 접속사로, 앞의 내용과 상반되거나 예상 밖의 결과가 이어질 때 쓰는 표현
[치트키] "소레나노니! 소레(그거)나노니(인데도) 그런데도" → それなのに=소레나노니→그런데도
[장면] 열심히 공부했는데도 시험을 망친 상황에서 한숨 쉬는 장면
[예문] 頑張ったのに、それなのに落ちた(간밧타노니, 소레나노니 오치타) = "열심히 했는데, 그런데도 떨어졌다"

· 예시 단어: 努力 (노력, ど+りょく)
[종합] 마음을 한가운데(中)로 모으는(集) 힘(力)이라는 뜻에서 집중력이 됨
[치트키] "슈-츄-료쿠! 슈-츄-(집중)의 료쿠(힘) 집중력" → 集中力=슈-츄-료쿠→집중력
[장면] 시험공부에 몰두해 주변 소리도 안 들리는 장면
[예문] 集中力が続かない(슈-츄-료쿠가 츠즈카나이) = "집중력이 지속되지 않는다"

財力
재력(ざいりょく)
[읽기] 財=ザイ + 力=リョク → ざいりょく (음독)
[한자1] 財 (재물 재 / 재물, 재산)
· 음독: ★ザイ, サイ
· 훈독: 없음
· 분해: 貝(조개 패, 재물) + 才(재주 재, 발음요소)
· 어원: 조개(재물)를 능숙한 재주로 다루는 모습에서 재물, 재산을 나타냄
· 예시 단어: 財産 (재산, ざい+さん)
[한자2] 力 (힘 력 / 힘)
· 음독: ★リョク, リキ
· 훈독: ちから
· 분해: 力 자체가 팔의 힘줄 모양을 본뜬 상형자
· 어원: 힘쓰는 팔의 모양을 본떠 힘을 나타냄
· 예시 단어: 実力 (실력, じつ+りょく)
[종합] 재물(財)이 많아 발휘되는 힘(力)이라는 뜻에서 재력이 됨
[치트키] "자이료쿠! 자이(재물)의 료쿠(힘) 재력" → 財力=자이료쿠→재력
[장면] 값비싼 미술품을 척척 사들이는 부호를 보는 장면
[예문] 財力がある家庭だ(자이료쿠가 아루 카테이다) = "재력이 있는 가정이다"

視力
시력(しりょく)
[읽기] 視=シ + 力=リョク → しりょく (음독)
[한자1] 視 (볼 시 / 보다)
· 음독: ★シ
· 훈독: み-る
· 분해: 礻(보일 시, 제단) + 見(볼 견)
· 어원: 제단을 바라보듯 눈여겨 보는 모습에서 보다를 나타냄
· 예시 단어: 重視 (중시, じゅう+し)
[한자2] 力 (힘 력 / 힘, 능력)
· 음독: ★リョク, リキ
· 훈독: ちから
· 분해: 力 자체가 팔의 힘줄 모양을 본뜬 상형자
· 어원: 팔의 힘줄 모양을 본떠 힘, 능력을 나타냄
· 예시 단어: 能力 (능력, のう+りょく)
[종합] 보는(視) 능력(力)이라는 뜻에서 시력이 됨
[치트키] "시료쿠! 시(봄)의 료쿠(힘) 시력" → 視力=시료쿠→시력
[장면] 안과에서 시력 검사표를 읽는 장면
[예문] 視力が落ちる(시료쿠가 오치루) = "시력이 떨어지다"

送別会
송별회(そうべつかい)
[읽기] 送=ソウ + 別=ベツ + 会=カイ → そうべつかい (음독)
[한자1] 送 (보낼 송 / 보내다)
· 음독: ★ソウ
· 훈독: おく-る
· 분해: 辶(쉬엄쉬엄갈 착) + 关(관계할 관의 변형, 두 손으로 물건을 드는 모습)
· 어원: 두 손으로 물건을 들어 길을 떠나보내는 모습에서 보내다를 나타냄
· 예시 단어: 送金 (송금, そう+きん)
[한자2] 別 (다를 별 / 다르다, 헤어지다)
· 음독: ★ベツ
· 훈독: わか-れる
· 분해: 冎(뼈 발라낼 과) + 刂(칼 도)
· 어원: 칼로 뼈와 살을 갈라내는 모습에서 나누다, 헤어지다를 나타냄
· 예시 단어: 別々 (각각, べつ+べつ)
[한자3] 会 (모일 회 / 모이다, 모임)
· 음독: ★カイ, エ
· 훈독: あ-う
· 분해: 亼(모을 집, 뚜껑) + 曰(가로 왈, 그릇)
· 어원: 뚜껑과 그릇이 맞물려 모이는 모습에서 모이다, 모임을 나타냄
· 예시 단어: 会議 (회의, かい+ぎ)
[종합] 떠나는(送) 사람과 헤어지며(別) 갖는 모임(会)이라는 뜻에서 송별회가 됨
[치트키] "소-베츠카이! 소-(보냄)베츠(헤어짐)카이(모임) 송별회" → 送別会=소-베츠카이→송별회
[장면] 전근 가는 동료를 위해 케이크와 꽃다발을 준비하는 장면
[예문] 送別会を開く(소-베츠카이오 히라쿠) = "송별회를 열다"

歓迎会
환영회(かんげいかい)
[읽기] 歓=カン + 迎=ゲイ + 会=カイ → かんげいかい (음독)
[한자1] 歓 (기뻐할 환 / 기뻐하다, 환영하다)
· 음독: ★カン
· 훈독: よろこ-ぶ
· 분해: 芇(풀 무성할 관, 발음요소) + 欠(하품 흠, 입을 벌린 사람)
· 어원: 입을 크게 벌리고 기뻐하는 모습에서 기뻐하다, 환영하다를 나타냄
· 예시 단어: 歓声 (환성, かん+せい)
[한자2] 迎 (맞이할 영 / 맞이하다)
· 음독: ★ゲイ
· 훈독: むか-える
· 분해: 辶(쉬엄쉬엄갈 착) + 卬(나 앙, 마주 보는 두 사람)
· 어원: 마주 보며 다가가 맞이하는 모습에서 맞이하다를 나타냄
· 예시 단어: 迎合 (영합, げい+ごう)
[한자3] 会 (모일 회 / 모이다, 모임)
· 음독: ★カイ, エ
· 훈독: あ-う
· 분해: 亼(모을 집, 뚜껑) + 曰(가로 왈, 그릇)
· 어원: 뚜껑과 그릇이 맞물려 모이는 모습에서 모임을 나타냄
· 예시 단어: 総会 (총회, そう+かい)
[종합] 기쁘게(歓) 맞이하는(迎) 모임(会)이라는 뜻에서 환영회가 됨
[치트키] "칸게이카이! 칸게이(환영)의 카이(모임) 환영회" → 歓迎会=칸게이카이→환영회
[장면] 새로 들어온 신입사원을 위해 박수치며 맞이하는 장면
[예문] 歓迎会に参加する(칸게이카이니 산카스루) = "환영회에 참가하다"
