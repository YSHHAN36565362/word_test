앙상블 기법 (보팅/배깅/부스팅/랜덤포레스트)
여러 예측 모형을 조합해 성능을 높이는 기법들 (암기: 혼자보다 같이가 낫다)
[구성] 보팅(Voting) / 배깅(Bagging) / 부스팅(Boosting) / 랜덤포레스트(Random Forest)
[의미]
· 보팅: 다수결 방식으로 결과 결합
· 배깅: 복원추출(붓스트랩)로 데이터를 무작위 추출해 병렬 학습 후 보팅으로 결합. 분산(Variance)을 줄이는 데 효과적
· 부스팅: 이전 모델이 틀린 데이터에 더 집중해서 순차적으로 학습. 편향(Bias)을 줄이는 데 효과적. 이상치에 민감, 병렬처리 불가
· 랜덤포레스트: 배깅+의사결정나무 결합. 성능 우수, 이상치에 강함
[구분] 기출 함정: "배깅은 모델의 편향을, 부스팅은 분산을 줄이는 데 효과적이다" → 반대로 됨! 배깅=분산 감소, 부스팅=편향 감소가 정답(4월 기출 44번)
[구분] 기출 함정: "배깅은 이전 모델의 오차를 보완하며 순차적으로 학습한다" → 틀림, 이건 부스팅 설명. 배깅은 "독립적으로 병렬 학습"(4월 기출 44번)
[구분] 기출 함정: "스태킹은 동일한 표본으로 다양한 유형의 모델을 학습" → 스태킹은 여러 모델의 "예측 결과"를 다시 메타모델에 학습시키는 방식(단순 동일표본 학습 아님, 4월 기출 74번)
[치트키] "배깅=병렬로 각자(분산↓), 부스팅=순차로 틀린 것 집중(편향↓), 랜덤포레스트=배깅+나무"
[예문] 랜덤포레스트는 배깅 기법에 의사결정나무를 결합해 이상치에 강하고 성능이 우수하다

부스팅 계열 (AdaBoost/GBM/XGBoost/LightGBM)
부스팅 기법의 대표적인 알고리즘 4가지
[구성] AdaBoost / GBM(Gradient Boosting Machine) / XGBoost / LightGBM
[의미]
· AdaBoost: 약한 모델(Weak Learner)의 오류 데이터에 가중치를 부여
· GBM: 예측 성능이 높은 욕심쟁이 알고리즘(Greedy Algorithm) 사용
· XGBoost: GBM을 개선한 방식, GBM보다 속도가 빠름
· LightGBM: 기존 트리 방식과 다르게 leaf(잎) 중심으로 분기
[구분] 기출 함정: "XGBoost는 GBM을 개선한 방식이지만 GBM보다 속도가 늦다" → 틀림! XGBoost는 GBM보다 "속도가 빠름"(8회 기출 59번)
[치트키] "AdaBoost(가중치 부여) → GBM(욕심쟁이 알고리즘) → XGBoost(GBM보다 빠름) → LightGBM(잎 중심 분기)"
[예문] XGBoost는 병렬처리와 최적화를 통해 GBM보다 빠른 학습 속도를 제공한다

시계열 분석 - 정상성과 자기상관
시간 흐름에 따라 관찰된 자료를 분석해 미래를 예측하는 기법의 핵심 개념
[구성] 정상성(Stationarity) / 자기상관(Autocorrelation) / 백색잡음(White Noise)
[의미]
· 정상성: 모든 시점에 일정한 평균과 분산을 가져야 함(시간에 따라 변하지 않음)
· 자기상관: 현재 상태가 과거·미래와 밀접한 관련이 있음(독립적이지 않음)
· 백색잡음: 시계열 모형의 오차항을 의미
[구분] 기출 함정: "비정상성(Non-stationarity)은 데이터의 평균과 분산이 시간에 따라 변하는 것을 의미한다" → 이게 정답(4월 기출 42번). 정상성의 "반대" 개념임을 정확히 구분
[구분] 차분: 현 시점의 자료를 이전 값으로 빼는 방법(비정상 시계열을 정상 시계열로 바꿀 때 사용)
[치트키] "정상성 = 시간이 지나도 평균·분산이 그대로, 비정상성 = 시간 따라 변함"
[예문] 주가처럼 시간에 따라 평균과 분산이 변하는 데이터는 비정상성을 가지므로 차분을 통해 정상화한다

시계열 모형 (AR/MA/ARIMA)
시간 흐름에 따른 데이터를 예측하는 대표적인 3가지 모형
[구성] 자기회귀(AR, AutoRegressive) / 이동평균(MA, Moving Average) / 자기회귀누적이동평균(ARIMA)
[의미]
· AR(p) 모형: 자신의 과거 값이 미래를 결정
· MA(q) 모형: 백색잡음들의 선형결합으로 표현(관측치에 모두 동일 가중치 부여). 지수평활법은 MA의 한 종류로, 최근 관측치에 더 높은 가중치 부여
· ARIMA(p,d,q): AR+MA, d는 차분 횟수를 의미
[구분] 기출 함정: "비정상성 시계열 데이터는 ARIMA 모델로 분석할 수 없다" → 틀림! ARIMA는 오히려 차분(d)을 통해 "비정상성 시계열을 정상화"해서 분석하는 모형(4월 기출 59번)
[구분] 계절성(Seasonality) 패턴을 반영하려면 확장된 SARIMA 모델 사용
[치트키] "AR=과거값 자체가 영향, MA=과거 오차(백색잡음)가 영향, ARIMA=둘 다+차분(d)"
[예문] ARIMA(1,1,1) 모형은 1차 차분 후 AR(1)과 MA(1)를 결합한 모형이다

분해시계열 (추세/계절/순환/불규칙 요인)
시계열에 영향을 주는 요인을 분리해 해석하는 방법
[구성] 추세 요인 / 계절 요인 / 순환(주기) 요인 / 불규칙 요인
[의미]
· 추세 요인: 장기적으로 증가하거나 감소
· 계절 요인: 특정 시기에 나타나는 고정된 주기
· 순환(주기, cycle) 요인: 알려지지 않은 주기, 중장기적
· 불규칙 요인: 설명 불가능한 요인
[구분] 계절 요인은 "고정된" 주기(예: 매년 12월), 순환 요인은 "고정되지 않은" 중장기 주기(예: 경기순환)라는 차이
[치트키] "추세(꾸준히 방향성) - 계절(정해진 시기마다) - 순환(불규칙한 큰 주기) - 불규칙(설명 불가)"
[예문] 매년 크리스마스 시즌 매출 증가는 계절 요인, 몇 년 주기의 경기 변동은 순환 요인에 해당한다

연관분석 (Association Rule Mining)
항목들 간 조건-결과로 이뤄지는 패턴을 발견하는 기법 (장바구니 분석)
[구성] Apriori 알고리즘 → 이거 사면 저것도 잘 사더라
[의미] 지지도, 신뢰도, 향상도 지표로 규칙의 유용성을 평가. 결과가 단순·분명하지만 품목 수가 많을수록 계산이 기하급수적으로 증가
[구분] 지지도(Support): A와 B를 동시에 살 확률 / 신뢰도(Confidence): A를 샀을 때 B도 샀을 확률 / 향상도(Lift): 우연이 아니고 진짜 관련 있는지(1보다 크면 양의 상관관계)
[구분] 기출 함정: "신뢰도가 높을수록 항상 유의미하고 흥미로운 규칙이라고 할 수 있다" → 틀림! 신뢰도가 높아도 우연히 자주 팔리는 상품일 수 있어 "향상도"까지 함께 봐야 진짜 의미 있는 규칙(4월 기출 60번)
[치트키] "지지도=동시에 살 확률, 신뢰도=A샀을때 B도 살 확률, 향상도=우연 아니고 진짜 관련있나"
[예문] 기저귀와 맥주를 함께 구매하는 경향이 우연이 아니라는 것을 확인하려면 향상도(Lift)를 봐야 한다

군집분석 (Clustering) - 계층적/비계층적
비지도 학습으로 데이터 간 거리·유사성을 기준으로 군집을 나누는 기법
[구성] 계층적 군집분석 / 비계층적 군집분석 → 비슷한 애들끼리 알아서 뭉치기(정답 없음)
[의미]
· 계층적 군집분석: 거리측정 방법(최단, 최장, 평균, 중심, 와드)을 이용, 덴드로그램(Tree 모양 그래프)으로 표현
· 비계층적 군집분석: K평균 군집화(K-means), DBSCAN, 기타(퍼지군집화, EM알고리즘, SOM)
[구분] K평균 군집화: 지정된 군집 개수에 따라 평균 기준으로 중심점 설정(중심점 변경 시 군집도 변할 수 있음), 이상치에 민감 → K-medoids로 대응
[구분] DBSCAN: 밀도기반, 군집수를 미리 정하지 않음, 노이즈·이상치에 강함(K-means와 정반대 특성)
[치트키] "계층적=나무모양(덴드로그램), 비계층적=K값 지정(K-means) 또는 밀도기반(DBSCAN)"
[예문] 군집 개수를 미리 알 수 없고 이상치가 많은 데이터에는 DBSCAN이 K-means보다 적합하다

덴드로그램 (Dendrogram) 해석
계층적 군집분석 결과를 시각화한 트리 형태 그래프
[구성] 덴드로(Dendro, 나무) + 그램(gram, 그림)
[의미] 특정 높이에서 수평으로 선을 그었을 때 교차하는 수직선의 개수가 그 지점에서의 군집 개수를 의미
[구분] "2개의 수직선과 교차" = 군집을 2개로 설정한 것(8회 기출 41번). 교차하는 선의 개수를 세는 문제가 자주 출제됨
[치트키] "덴드로그램에서 가로선 긋고 세로선과 만나는 개수 = 군집 개수"
[예문] 덴드로그램에서 특정 높이의 수평선이 3개의 수직선과 만나면 군집이 3개로 나뉜 것이다

차원 축소 목적
고차원 데이터를 저차원으로 줄이는 이유
[구성] 특징 추출 / 노이즈 제거 / 데이터 정제 (설명력 증가는 해당 없음)
[의미] 데이터의 핵심 특징만 추출하고 불필요한 노이즈를 제거해 분석을 효율화하는 것이 차원축소의 목적
[구분] 기출 함정: "설명력 증가"는 차원축소의 목적이 아님(오히려 정보 손실 위험) → 8회 기출 55번 정답
[치트키] "차원축소 목적 = 특징만 뽑고(추출), 노이즈 없애고, 데이터 깔끔하게(정제) - 설명력을 늘리려는 게 아님"
[예문] 차원축소는 데이터의 핵심 특징을 보존하면서 노이즈와 불필요한 정보를 줄이는 데 목적이 있다

다변량분산분석 (MANOVA)
다수의 독립변수와 다수의 종속변수를 함께 다루는 분산분석
[구성] Multivariate(다변량) + ANOVA(분산분석)
[의미] 다수의 독립변수와 다수의 종속변수인 경우 사용하는 통계 기법. 독립변수는 연속형·범주형 상관없이 사용 가능
[구분] 일반 ANOVA는 독립변수 1개·종속변수 1개 또는 그 조합에 사용, MANOVA는 "종속변수가 2개 이상"일 때 사용한다는 게 핵심 차이
[치트키] "MANOVA = 여러 개의 독립변수와 여러 개의 종속변수를 동시에(Multi) 분석"
[예문] 광고 채널(독립변수)이 매출액, 브랜드 인지도, 고객만족도(다수의 종속변수)에 미치는 영향을 분석할 때 MANOVA를 사용한다

텍스트 마이닝 (Text Mining)
문자 데이터를 분석하는 기법들
[구성] 불용어 제거(Stopword) / 어간추출(Stemming) / 토큰화(Tokenization) / 품사태깅(POS Tagging)
[의미]
· 불용어 제거: 분석에 필요 없는 단어(조사, 관사 등) 제거
· 어간추출: 단어의 어간을 추출
· 토큰화: 코퍼스(말뭉치)에서 토큰(단위) 단위로 나누는 것
· 품사태깅: 문장마다 품사를 태깅해서 의미를 찾음
[구분] 통계적 기반: TDM(단어-문서 행렬, 빈도를 행렬로 표현), TF-IDF(단어 등장 빈도를 특정 문서·전체 문서에서 비교)
[구분] 단어 수준 기반: Word2Vec(거리 기반 벡터화, CBOW/Skip-Gram), FastText(단어를 여러 개로 쪼개 벡터 계산), ELMo(양방향 언어모델)
[치트키] "불용어제거(필요없는말 빼기)-어간추출(어근만 남기기)-토큰화(단위로 쪼개기)-품사태깅(품사 붙이기)"
[예문] "달리다", "달렸다", "달릴 것이다"에서 공통 어간 "달리"를 추출하는 것이 어간추출(Stemming)이다

순환신경망 (RNN)과 LSTM/GRU
순차적 데이터(시계열 데이터) 학습에 특화된 신경망
[구성] RNN(Recurrent Neural Network) / LSTM(Long Short-Term Memory) / GRU(Gated Recurrent Unit)
[의미] 이전 입력을 기억하여 현재 입력과 함께 처리. 문장, 주가, 날씨, 음성, 필기체 등 순서가 중요한 데이터에 활용
[구분] RNN의 단점: 장기의존성(오래된 정보를 잘 기억하지 못함) → 이를 극복하기 위해 LSTM/GRU 모델(Reset, Update 게이트) 사용
[구분] 어텐션(Attention) 메커니즘: 인코더의 모든 정보를 하나의 고정 벡터에 압축할 때 발생하는 정보 손실을 보완, 디코더가 매 시점마다 인코더 전체를 다시 참고(단, RNN의 기울기 소실 문제를 "근본적으로" 해결하지는 못함 - 이 부분이 기출 함정)
[치트키] "RNN = 이전 걸 기억하며 순서대로 처리, 근데 오래된 건 잘 잊음(장기의존성), LSTM/GRU가 이걸 보완"
[예문] 문장의 앞부분 정보를 오래 기억해야 하는 번역 작업에는 RNN보다 LSTM이 유리하다

CNN vs DNN vs RNN vs 오토인코더
딥러닝의 대표적인 4가지 신경망 구조
[구성] DNN(Deep Neural Network) / CNN(Convolutional Neural Network) / RNN(Recurrent Neural Network) / 오토인코더(Autoencoder)
[의미]
· DNN: 은닉층 2개 이상으로 구성된 다층 퍼셉트론(MLP) 구조, 시계열·이미지 등 특수 구조에는 약함
· CNN: 이미지에서 패턴을 찾음(얼굴인식, 사진분류, 자율주행 카메라)
· RNN: 순차적 데이터 학습에 특화(시계열)
· 오토인코더: 입력 데이터를 인코더로 압축한 후 디코더로 재구성하는 "비지도 학습" 신경망
[구분] 오토인코더는 라벨(정답)이 필요 없는 비지도학습이라는 점이 다른 신경망들과 결정적으로 다름
[치트키] "DNN(범용, 깊은층)-CNN(이미지 특화)-RNN(순서 데이터 특화)-오토인코더(압축·복원, 비지도)"
[예문] 오토인코더는 입력을 압축했다가 다시 복원하는 과정에서 이상치 탐지나 노이즈 제거에 활용된다

트랜스포머 (Transformer)
RNN의 한계를 개선한 병렬 처리 기반 모델
[구성] 트랜스포머 = RNN의 느린 속도 + 병렬처리 불가 단점을 개선한 모델
[의미] BERT, GPT의 기반이 되는 모델 구조. 순차 처리가 아닌 병렬 처리로 학습 속도를 크게 개선
[구분] RNN은 이전 시점 결과를 기다려야 다음 시점을 계산할 수 있어 순차적(느림), 트랜스포머는 어텐션 메커니즘으로 전체 문장을 한번에 병렬 처리 가능
[치트키] "트랜스포머 = RNN의 느림(순차처리)을 어텐션으로 극복해서 한번에 병렬 처리"
[예문] BERT와 GPT는 모두 트랜스포머 구조를 기반으로 하여 대규모 언어 데이터를 병렬로 학습한다

비모수검정 (Non-parametric Test)
모집단의 분포를 가정하지 않고 순위·차이로 비교하는 검정 방법
[구성] 비모수(非母數) 검정 → 분포 모르니까 그냥 순서나 차이로 비교하자
[의미] 모집단에 대한 정보가 없을 때, 관측 자료의 분포 가정이 불가능한 상태에서 두 관측 간 순위나 차이로 검정하는 방법
[구분] 기출 함정: "비모수통계는 모수통계보다 검정력이 높다" → 틀림! 일반적으로 모수통계가 분포 가정을 충족할 때 "검정력이 더 높음"(4월 기출 61번 정답은 이 지문이 틀린 것)
[구분] 종류: 부호검정, 순위합검정, 만-휘트니 U검정, 크러스컬-월리스 검정. 순위(Rank)나 부호(Sign)에 기초해 이상치의 영향을 덜 받음
[치트키] "비모수 = 분포를 모르니까 순위로만 비교, 대신 모수검정보다 힘(검정력)은 약함"
[예문] 표본 수가 적고 정규분포를 가정할 수 없을 때는 만-휘트니 U검정 같은 비모수검정을 사용한다
