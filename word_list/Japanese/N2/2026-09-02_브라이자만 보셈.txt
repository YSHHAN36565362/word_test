半導体
반도체(はんどうたい)
[읽기] 半=ハン + 導=ドウ + 体=タイ → はんどうたい (음독)
[악센트] 3형(중고형)
[한자1] 半 (반 반 / 절반, 반)
· 음독: ★ハン
· 훈독: なか-ば
· 분해: 八(나눌 팔) + 牛(소 우)
· 어원: 소(牛)를 둘로 나눈(八) 것에서 절반을 뜻함
· 예시 단어: 半分 (절반, はん+ぶん)
[한자2] 導 (이끌 도 / 인도하다, 통하다)
· 음독: ★ドウ
· 훈독: みちび-く
· 분해: 道(길 도) + 寸(마디 촌/손)
· 어원: 손(寸)으로 길(道)을 가리키며 인도하는 모습에서 전도하다, 이끌다를 뜻함
· 예시 단어: 指導 (지도, し+どう)
[한자3] 体 (몸 체 / 물체, 형체)
· 음독: ★タイ, テイ
· 훈독: からだ, かたち
· 분해: 亻(사람인변) + 本(밑 본/뿌리)
· 어원: 사람(亻)의 근본(本)이 되는 몸 또는 물체를 뜻함
· 예시 단어: 物質 (물질, ぶっ+しつ)
[종합] 전기를 통하게 하는 도체(導体)의 성질을 절반(半)만 띠어 제어가 가능한 물질(体)을 뜻함
[치트키] "한도-타이! 반도체 생산 한도 타이트하네" → 半導体=한도-타이→반도체
[장면] 초미세 회로가 빼곡하게 새겨진 실리콘 반도체 칩
[예문] 半導体の需要が高まる(한도-타이노 주요-가 타카마루) = "반도체의 수요가 높아지다"

電子部品
전자부품(でんしぶひん)
[읽기] 電=デン + 子=シ + 部=ブ + 品=ヒン → でんしぶひん (음독)
[악센트] 4형(중고형)
[한자1] 電 (번개 전 / 전기, 전자)
· 음독: ★デン
· 훈독: いなづま
· 분해: 雨(비 우) + 申(펼 신/번개 모양)
· 어원: 비(雨)가 올 때 하늘에서 번쩍이며 뻗어 나오는 번개(申) 모양에서 전기를 뜻함
· 예시 단어: 電池 (전지, でん+ち)
[한자2] 子 (아들 자 / 입자, 작은 알갱이)
· 음독: ★シ, ス
· 훈독: こ, ね
· 분해: 어린아이가 팔을 벌리고 있는 모습을 본뜬 상형자
· 어원: 어린아이(子)에서 유래해 물질을 구성하는 미세한 입자를 뜻함
· 예시 단어: 原子 (원자, げん+し)
[한자3] 部 (나눌 부 / 부분, 파트)
· 음독: ★ブ
· 훈독: とべ
· 분해: 咅(침 부) + 阝(고을 읍)
· 어원: 구역(阝)을 나누어(咅) 일정 부분을 맡긴다는 데서 부분을 뜻함
· 예시 단어: 部分 (부분, ぶ+ぶん)
[한자4] 品 (물건 품 / 물품, 부품)
· 음독: ★ヒン, ホン
· 훈독: しな
· 분해: 口(입 구)×3
· 어원: 여러 개의 그릇이나 물건(口)을 쌓아 놓은 모습에서 물품을 뜻함
· 예시 단어: 商品 (상품, しょう+ひん)
[종합] 전자(電子) 신호를 제어하고 회로를 구성하는 낱개의 부품(部品)을 뜻함
[치트키] "덴시부힌! 전자부품은 댄 시(대신) 부품을 써라" → 電子部品=덴시부힌→전자부품
[장면] 초소형 저항, 콘덴서 등 회로 기판에 꽂히는 정밀 부품들
[예문] 電子部品を基板に実装する(덴시부힌오 키반니 짓소-스루) = "전자부품을 기판에 실장하다"

電子機器
전자기기(でんしきき)
[읽기] 電=デン + 子=シ + 機=キ + 器=キ → でんしきき (음독)
[악센트] 4형(중고형)
[한자1] 電 (번개 전 / 전기, 전자)
· 음독: ★デン
· 훈독: いなづま
· 분해: 雨(비 우) + 申(펼 신/번개)
· 어원: 비구름(雨) 사이로 번개(申)가 치는 현상에서 전기를 뜻함
· 예시 단어: 電車 (전차, でん+しゃ)
[한자2] 子 (아들 자 / 작은 것, 입자)
· 음독: ★シ, ス
· 훈독: こ, ね
· 분해: 머리가 크고 양팔을 벌린 아이의 모양을 본뜸
· 어원: 미세한 구성 단위를 가리켜 전자를 뜻함
· 예시 단어: 粒子 (입자, りゅう+し)
[한자3] 機 (틀 기 / 기계, 틀)
· 음독: ★キ
· 훈독: はた, からくり
· 분해: 木(나무 목) + 幾(기미 기, 미세한 장치)
· 어원: 나무(木)로 정교하게 짠 베틀(幾)에서 유래해 정밀 기계를 뜻함
· 예시 단어: 機械 (기계, き+かい)
[한자4] 器 (그릇 기 / 도구, 기구)
· 음독: ★キ
· 훈독: うつわ
· 분해: 口(입 구)×4 + 犬(개 견)
· 어원: 여러 개의 그릇(口)을 개(犬)가 지키는 모습에서 도구와 기구를 뜻함
· 예시 단어: 器具 (기구, き+ぐ)
[종합] 전자(電子)의 움직임을 응용해 다양한 동작을 수행하는 정밀 기구 및 기계(機器)를 의미함
[치트키] "덴시키키! 전자기기 켜니 삑 소리가 킥킥 난다" → 電子機器=덴시키키→전자기기
[장면] 스마트폰, 컴퓨터, 측정기 등 복잡한 내부 회로를 가진 기기들
[예문] 最新の電子機器を導入する(사이신노 덴시키키오 도-뉴-스루) = "최신 전자기기를 도입하다"

集積回路
집적회로(しゅうせきかいろ)
[읽기] 集=シュウ + 積=セキ + 回=カイ + 路=ロ → しゅうせきかいろ (음독)
[악센트] 5형(중고형)
[한자1] 集 (모을 집 / 모으다, 집중하다)
· 음독: ★シュウ
· 훈독: あつ-まる, あつ-める, つど-う
· 분해: 隹(새 추) + 木(나무 목)
· 어원: 나무(木) 위에 새들(隹)이 옹기종기 모여 앉아 있는 모습
· 예시 단어: 集合 (집합, しゅう+ごう)
[한자2] 積 (쌓을 적 / 쌓다, 모으다)
· 음독: ★セキ
· 훈독: つ-む, つ-もる
· 분해: 禾(벼 화) + 責(맡을 책/조개 패)
· 어원: 수확한 곡식(禾)을 창고에 차곡차곡 쌓아(責) 두는 모습
· 예시 단어: 蓄積 (축적, ちく+せき)
[한자3] 回 (돌 회 / 돌다, 둘레)
· 음독: ★カイ, エ
· 훈독: まわ-る, まわ-す
· 분해: 안팎으로 빙빙 도는 소용돌이 모양을 본뜬 상형자
· 어원: 둥글게 원을 그리며 빙빙 돌아 제자리로 오는 모습
· 예시 단어: 回転 (회전, かい+てん)
[한자4] 路 (길 로 / 도로, 길)
· 음독: ★ロ, ル
· 훈독: じ, みち
· 분해: 足(발 족) + 各(각각 각)
· 어원: 각자(各) 발(足)로 밟고 지나다니며 만들어진 길
· 예시 단어: 道路 (도로, どう+ろ)
[종합] 다수의 전자 소자와 도선 회로(回路)를 좁은 반도체 판 위에 집결해 쌓아 올린(集積) 집적회로(IC)
[치트키] "슈-세키카이로! 집적회로 수색하러 카이로까지 가네" → 集積回路=슈-세키카이로→집적회로
[장면] 검은색 몰딩 아래 미세한 금선과 트랜지스터가 빽빽하게 모여 있는 IC 칩
[예문] 集積回路の微細化が進む(슈-세키카이로노 비사이카가 수스무) = "집적회로의 미세화가 진행되다"

回路

[악센트] 1형(두고형)
[한자1] 回 (돌 회 / 돌다, 회전)
· 음독: ★カイ, エ
· 훈독: まわ-る, まわ-す
· 분해: 소용돌이치며 둥글게 도는 모양의 상형자
· 어원: 시작점에서 돌아 다시 원래 자리로 이어지는 닫힌 고리 모양
· 예시 단어: 回線 (회선, かい+せん)
[한자2] 路 (길 로 / 길, 통로)
· 음독: ★ロ, ル
· 훈독: じ, みち

· 예시 단어: 通路 (통로, つう+ろ)
[종합] 전류가 한 바퀴 빙 돌아서(回) 흐를 수 있도록 이어진 전기적 통로(路)
[치트키] "카이로! 전기 회로 손보다가 카이로(핫팩)처럼 뜨거워졌네" → 回路=카이로→회로

[예문] 回路を設計する(카이로오 셋케이Validateス루) = "회로를 설계하다"

[한자2] 良 (어질 량 / 좋다, 우수하다)

[한자4] 置 (둘 치 / 자리잡다)

· 예시 단어: 放置 (방치, ほう+ち)
[종합] 대형 생산 장치(装置)를 정해진 공장 위치에 수평을 맞추어 들여놓고 세움(設置)
[치트키] "소-치노셋치! 장치 설치는 소치(탓)하지 말고 셋이 치워가며 해라" → 装置の設置=소-치노셋치→장치 설치

問題を解決する
문제를 해결하다(もんだいをかいけつする)
[읽기] 問=モン + 題=ダイ + を + 解=カイ + 決=ケツ + する → もんだいをかいけつする (음독)
[악센트] 1형(두고형)
[한자1] 問 (물을 문 / 묻다, 질문)
· 음독: ★モン
· 훈독: と-う, と-い, とん
· 분해: 門(문 문) + 口(입 구)
· 어원: 문(門) 앞에서 입(口)을 열어 길을 물어봄
· 예시 단어: 質問 (질문, しつ+もん)
[한자2] 題 (제목 제 / 주제, 문제)
· 음독: ★ダイ
· 훈독: なし
· 분해: 是(바를 시) + 頁(머리 혈)
· 어원: 글의 머리(頁)에 바르게(是) 적어 놓은 핵심 제목이나 과제
· 예시 단어: 課題 (과제, か+だい)
[한자3] 解 (풀 해 / 풀다, 흩어지다)
· 음독: ★カイ, ゲ
· 훈독: と-く, と-かす, と-ける, ほど-く, ほど-ける, わかり, わた-る
· 분해: 角(뿔 각) + 刀(칼 도) + 牛(소 우)
· 어원: 칼(刀)로 소(牛)의 뿔(角)과 뼈마디를 분해하여 얽힌 것을 매끄럽게 풂
· 예시 단어: 解答 (해답, かい+とう)
[한자4] 決 (결단할 결 / 결정하다, 트다)
· 음독: ★ケツ
· 훈독: き-める, き-まる, さ-く
· 분해: 氵(물 수) + 夬(터놓을 쾌)
· 어원: 둑(氵)을 터서(夬) 물이 쏟아져 나가듯 시원하게 매듭짓고 결단을 내림
· 예시 단어: 決断 (결단, けつ+だん)
[종합] 얽혀서 답답했던 문제(問題)를 싹 풀어서(解) 명쾌하게 매듭지어 결말을 냄(解決する)
[치트키] "몬다이오카이케츠스루! 문제를 해결하고 몸 대(몬다이) 카이(가서) 결(케츠)정짓자" → 問題を解決する=몬다이오카이케츠스루→문제를 해결하다
[장면] 장비 에러가 완전히 해소되고 모니터에 정상 가동률 100%가 뜨는 화면
[예문] チーム一丸となって問題を解決する(치-무이치간토 낫테 몬다이오 카이케츠스루) = "팀이 하나가 되어 문제를 해결하다"
[활용] ます형: 問題を解決します · ない형: 問題を解決しない · て형: 問題を解決して · た형: 問題を解決した

動作を確認する
작동을 확인하다(どうさをかくにんする)
[읽기] 動=ドウ + 作=サ + を + 確=カク + 認=ニン + する → どうさをかくにんする (음독)
[악센트] 1형(두고형)
[한자1] 動 (움직일 동 / 움직이다, 작동)
· 음독: ★ドウ
· 훈독: うご-く, うご-かす
· 분해: 重(무거울 중) + 力(힘 력)
· 어원: 무거운(重) 물건을 힘(力)을 주어 실제로 움직이게 함
· 예시 단어: 稼働 (가동, か+どう)
[한자2] 作 (지을 작 / 짓다, 동작)
· 음독: ★サ, サク
· 훈독: つく-る
· 분해: 亻(사람인변) + 乍(잠깐 사)
· 어원: 사람이 몸을 움직여 어떤 거동이나 물건을 만듦
· 예시 단어: 動作 (동작, どう+さ)
[한자3] 確 (굳을 확 / 확실하다)
· 음독: ★カク
· 훈독: たし-か, たし-かめる
· 분해: 石(돌 석) + 隺(높이 날 학)
· 어원: 바위처럼 단단하고 확실함
· 예시 단어: 確証 (확증, かく+しょう)
[한자4] 認 (인정할 인 / 알아보다)
· 음독: ★ニン
· 훈독: みと-める
· 분해: 言(말씀 언) + 忍(참을 인)
· 어원: 마음으로 이해하고 확인하여 인정함
· 예시 단어: 公認 (공인, こう+にん)
[종합] 기계나 센서의 움직임과 작동(動作)이 정상적으로 이루어지는지 확실히 눈으로 점검함(確認する)
[치트키] "도-사오카쿠닌스루! 동작을 확인하러 도사(도-사)가 각(카쿠) 잡고 인정(닌)하네" → 動作を確認する=도-사오카쿠닌스루→작동을 확인하다
[장면] 티칭 펜던트로 로봇 팔을 한 스텝 움직인 뒤 정위치에 도달했는지 눈으로 체크하는 모습
[예문] 修理完了後に全体の動作を確認する(슈-리칸료-고니 젠타이노 도-사오 카쿠닌스루) = "수리 완료 후 전체 작동을 확인하다"
[활용] ます형: 動作を確認します · ない형: 動作を確認しない · て형: 動作を確認して · た형: 動作を確認した

結果を報告する
결과를 보고하다(けっかをほうこくする)
[읽기] 結=ケツ + 果=カ + を + 報=ホウ + 告=コク + する → けっかをほうこくする (음독, 結의 ツ가 촉음화되어 けっ이 됨)
[악센트] 1형(두고형)
[한자1] 結 (맺을 결 / 맺다, 묶다)
· 음독: ★ケツ, ケチ
· 훈독: むす-ぶ, ゆ-う, ゆ-わえる
· 분해: 糸(실 사) + 吉(길할 길)
· 어원: 실(糸)을 단단하게 매듭지어(吉) 끝을 맺음
· 예시 단어: 結合 (결합, けつ+ごう)
[한자2] 果 (열매 과 / 열매, 성과)
· 음독: ★カ
· 훈독: は-たす, は-てる, は-て
· 분해: 木(나무 목) + 田(열매 모양)
· 어원: 나무(木) 위에 탐스럽게 맺힌 결실의 열매(田)
· 예시 단어: 成果 (성과, せい+か)
[한자3] 報 (갚을 보 / 알리다, 보고하다)
· 음독: ★ホウ
· 훈독: むく-いる
· 분해: 幸(수갑 형틀) + 卩(무릎 꿇은 사람) + 又(손)
· 어원: 죄수를 다스린 결과를 윗사람에게 사실대로 낱낱이 알림
· 예시 단어: 情報 (정보, じょう+ほう)
[한자4] 告 (알릴 고 / 고하다, 알리다)
· 음독: ★コク
· 훈독: つ-げる
· 분해: 牛(소 우) + 口(입 구)
· 어원: 제사용 소(牛)를 바치며 신이나 웃어른에게 말(口)로 널리 알림
· 예시 단어: 告知 (고지, こく+ち)
[종합] 일이나 조치의 최종 매듭으로 맺어진 결실(結果)을 상사나 고객에게 정확히 알려 올림(報告する)
[치트키] "켓카오호-코쿠스루! 결과를 보고하러 캐까(켓카)짓 보고 포효(호-코쿠)한다" → 結果を報告する=켓카오호-코쿠스루→결과를 보고하다
[장면] 테스트 데이터 그래프가 첨부된 완성된 보고서를 팀장에게 제출하며 브리핑하는 모습
[예문] 検査の結果を上司に報告する(켄사노 켓카오 조-시니 호-코쿠스루) = "검사 결과를 상사에게 보고하다"
[활용] ます형: 結果を報告します · ない형: 結果を報告しない · て형: 結果を報告して · た형: 結果を報告した
