記憶
기억(きおく)
記 (기록할 기/적을 기) = 言 (말씀 언) + 己 (몸 기/자기 기) : 말을 통해 자신의 경험이나 사실을 몸에 새기고 남긴다는 뜻에서 “기록하다, 적다”의 의미가 생겼습니다.
憶 (생각할 억/기억할 억) = 忄 (마음 심) + 意 (뜻 의) : 마음(忄)속에 뜻과 인상(意)을 되새기며 떠올리는 모습을 나타내어 “기억하다”의 뜻이 되었습니다.
과거의 일을 마음에 새겨 두는 것, 즉 “기억”을 뜻하는 단어입니다.

機会
기회(きかい)
機 (틀 기/기계 기) = 木 (나무 목) + 幾 (거의 기/몇 기) : 원래는 베틀 같은 정교한 나무틀을 가리켰고, 나중에 복잡한 장치나 “기계”의 뜻으로도 넓어졌습니다.
会 (모일 회/만날 회) = 亼 (모을 집) + 云 (이를 운/말할 운) : 사람과 일이 모여 만나고 성립하는 자리를 뜻하는 글자입니다.
무언가를 할 수 있는 적절한 때나 상황이 우연히 모여 생기는 “기회”를 의미합니다.

機械
기계(きかい)
機 (틀 기/기계 기) = 木 (나무 목) + 幾 (거의 기/몇 기) : 원래는 정교한 베틀의 구조를 가리켰고, 이후 여러 부품이 맞물려 움직이는 장치를 뜻하게 되었습니다.
械 (기계 계/도구 계) = 木 (나무 목) + 戒 (경계할 계) : 나무로 만든 도구·장치의 뜻에서 출발해, 사람의 손을 대신해 작동하는 물건을 가리키게 되었습니다.
여러 부품이 맞물려 일정한 기능을 수행하는 장치, 즉 “기계”를 뜻합니다.

季節
계절(きせつ)
季 (끝 계/철 계) = 禾 (벼 화) + 子 (아들 자) : 곡식의 생장과 이어지는 시기 단위를 나타내어, 계절이나 한철을 뜻하게 되었습니다.
節 (마디 절/절기 절) = 竹 (대 죽) + 即/卩 계열 : 대나무의 마디처럼 끊어져 구분되는 부분을 본뜬 글자로, 시기와 구분의 뜻이 있습니다.
자연의 흐름이 일정한 단위로 나뉘는 때, 즉 봄·여름·가을·겨울 같은 “계절”을 의미합니다.

規則
규칙(きそく)
規 (법 규/바르게 할 규) = 見 (볼 견) + 夫 (사내 부) : 바르게 보아 기준을 세운다는 뜻에서 “법도, 규정”의 의미가 생겼습니다.
則 (법 칙/곧 칙) = 貝 (조개 패/재물 패) + 刂 (칼 도) : 옛날에 판결·판정의 기준을 새기거나 나누는 모습에서 “법칙, 규정”의 뜻이 되었습니다.
행동이나 판단의 기준이 되는 정해진 약속이나 법도, 즉 “규칙”입니다.

期待
기대(きたい)
期 (기약할 기/기일 기) = 其 (그 기) + 月 (달 월) : 정해진 때를 기다린다는 뜻에서 “기일, 기한”의 의미가 생겼습니다.
待 (기다릴 대/기다리다) = 彳 (조금 걸을 척) + 寺 (절 사) : 서서 기다리며 시간을 두고 맞이하는 모습을 나타냅니다.
어떤 일이 이루어지기를 마음속으로 바라며 기다리는 뜻입니다.

帰宅
귀가(きたく)
帰 (돌아갈 귀/돌아오다) = 帚 (비 추/빗자루) + 止 (그칠 지) : 원래는 집안일을 마치고 돌아감, 또는 원래 자리로 돌아감을 뜻했습니다.
宅 (집 택/집) = 宀 (집 면) + 乇 (싹 트다/맡기다 계열) : 지붕 아래 거처를 나타내는 글자로, 살림하는 집을 뜻합니다.
밖에서 하던 일을 마치고 집으로 돌아가는 것을 뜻합니다.

喫茶店
다방, 찻집(きっさてん)
喫 (먹을 끽/마실 끽) = 口 (입 구) + 契 (맺을 계) : 입으로 받아들이고 들이킨다는 뜻이 강해, 차나 음료를 마시다의 느낌을 가집니다.
茶 (차 다/차) = 艹 (풀 초) + 人/木 계열 구성 : 차나무에서 얻는 잎을 뜻하는 글자입니다.
店 (가게 점) = 广 (집 엄호) + 占 (점칠 점) : 처마 아래 자리 잡은 상점을 뜻합니다.
차를 마시는 가게, 즉 현대적으로는 커피·음료도 함께 파는 “찻집/다방”을 의미합니다.

逆
역, 반대(ぎゃく)
逆 (거스를 역/반대 역) = 之 계열 + 卩/攴 계열 : 원래 흐름이나 방향에 거슬러 올라간다는 뜻에서 “거스르다, 반대”의 의미가 생겼습니다.
방향이나 순서, 입장 따위가 서로 맞지 않고 반대되는 상태를 뜻합니다.

急行
급행(きゅうこう)
急 (급할 급/급하다) = 及 (미칠 급) + 心 (마음 심) 계열 : 마음이 다급하게 닿아 조급해지는 모습을 나타냅니다.
行 (갈 행/행하다) = 사람의 걸음과 길을 본뜬 글자 : 이동하다, 나아가다의 뜻입니다.
보통보다 빨리 달리거나 빠르게 진행하는 것을 뜻하며, 교통에서는 “급행” 열차를 가리킵니다.

休日
휴일(きゅうじつ)
休 (쉴 휴/쉬다) = 亻 (사람 인) + 木 (나무 목) : 사람이 나무에 기대어 쉬는 모습에서 “쉬다”의 뜻이 생겼습니다.
日 (날 일/해 일) = 태양을 본뜬 상형자 : 날, 하루를 뜻합니다.
일이나 수업을 쉬는 날, 즉 “휴일”을 의미합니다.

教師
교사(きょうし)
教 (가르칠 교/가르치다) = 孝 (효도 효) + 攴 (칠 복) : 옛 교육이 아이를 바르게 이끄는 행위였음을 반영해 “가르치다”의 뜻이 생겼습니다.
師 (스승 사/스승) = 帀/帚 계열 + 여러 사람을 이끄는 뜻 : 무리를 이끄는 사람, 곧 스승이나 전문적인 지도자를 뜻합니다.
지식이나 기술을 가르치는 사람, 즉 “교사”입니다.

教室
교실(きょうしつ)
教 (가르칠 교/가르치다) = 孝 (효도 효) + 攴 (칠 복) : 배우고 익히게 하는 교육 행위를 나타냅니다.
室 (집 실/방 실) = 宀 (집 면) + 至 (이를 지) : 집 안에 사람들이 모이는 방을 뜻합니다.
가르치고 배우는 방, 즉 “교실”을 뜻합니다.

競争
경쟁(きょうそう)
競 (다툴 경/겨루다) = 立 (설 립) + 兄 계열 : 서로 앞서려고 마주 서서 겨루는 모습을 담고 있습니다.
争 (다툴 쟁/다툴 정) = 爪 (손톱 조) + 亅/又 계열 : 손으로 서로 움켜쥐며 다투는 모습을 나타냅니다.
서로 이기려고 겨루는 것을 의미합니다.

兄弟
형제(きょうだい)
兄 (맏 형/형) = 口 (입 구) + 儿 (사람 인) : 입으로 말을 주도하는 맏사람의 이미지에서 “형, 오빠” 뜻이 생겼습니다.
弟 (아우 제/아우) = 丿 + 弓 + ㅅ 계열 : 아래로 순종하는 동생의 위치를 나타내어 “아우, 남동생”을 뜻합니다.
같은 부모에게서 난 형과 아우를 함께 이르는 말입니다.

共通
공통(きょうつう)
共 (함께 공/함께) = 廿 (스물 입) + 廾 (두 손 맞잡을 공) 계열 : 여러 사람이 함께 손을 모으는 모습에서 “함께”의 뜻이 생겼습니다.
通 (통할 통/다니게 하다) = 辶 (쉬엄쉬엄 갈 착) + 甬 (길 용) : 길이 서로 이어져 오가고 통하는 상태를 뜻합니다.
여러 대상에 함께 들어 있거나 모두에게 해당되는 성질을 의미합니다.

共同
공동(きょうどう)
共 (함께 공/함께) = 廿 + 廾 계열 : 함께 손을 맞대는 모습에서 “함께”를 뜻합니다.
同 (같을 동/같다) = 口 (입 구) + 冖 (덮을 멱) : 하나의 틀 안에서 같아짐을 나타냅니다.
여러 사람이 한마음으로 같이 하는 상태, 즉 “공동”을 뜻합니다.

興味
흥미(きょうみ)
興 (일으킬 흥/흥성할 흥) = 臼 (절구 구) + 同 계열 : 힘을 모아 어떤 일을 일으키는 모습을 나타냅니다.
味 (맛 미/맛) = 口 (입 구) + 未 (아닐 미/아직 미) : 입으로 처음 느끼는 감각에서 “맛”의 뜻이 생겼고, 나아가 느낌과 취향의 의미도 가집니다.
어떤 대상에 마음이 끌려 관심이 생기는 것을 뜻합니다.

協力
협력(きょうりょく)
協 (화할 협/협력할 협) = 十 (열 십) + 力 (힘 력) 계열 : 여러 힘이 모여 하나로 맞춰지는 모습을 나타냅니다.
力 (힘 력/힘) = 사람의 팔이나 도구의 힘을 본뜬 상형자입니다.
힘을 합쳐 함께 돕는다는 뜻입니다.

去年
작년(きょねん)
去 (갈 거/지나다) = 土 (흙 토) + 口/厶 계열 : 떠나가고 지나간다는 뜻을 담습니다.
年 (해 년/해) = 사람이 곡식을 이고 서 있는 모습에서 비롯되어 한 해의 주기를 뜻합니다.
지나가 버린 한 해, 즉 “작년”을 뜻합니다.

距離
거리(きょり)
距 (멀 거/간격 거) = 足 (발 족) + 巨 (클 거) : 발로 재는 큰 간격에서 “멀다, 거리”의 뜻이 생겼습니다.
離 (떠날 리/떨어질 리) = 隹 (새 추) + 离 계열 : 서로 떨어져 갈라지는 모습을 나타냅니다.
사이의 떨어진 길이, 즉 “거리”를 의미합니다.

記録
기록(きろく)
記 (기록할 기/적을 기) = 言 (말씀 언) + 己 (몸 기/자기 기) : 말이나 사실을 글로 새긴다는 뜻입니다.
録 (기록할 록/기록) = 金 (쇠 금) + 彔 (새길 록 계열) : 금속에 새기듯 남긴다는 뜻에서 “적다, 기록하다”의 의미가 생겼습니다.
사실이나 일을 남겨 두는 것을 뜻합니다.

禁煙
금연(きんえん)
禁 (금할 금/금지할 금) = 林 (수풀 림) + 示 (보일 시/제단) : 신성한 곳에서 함부로 하지 못하게 금지하는 뜻이 있습니다.
煙 (연기 연/연기) = 火 (불 화) + 垔/因 계열 : 불에서 피어오르는 연기를 나타냅니다.
담배 연기나 흡연을 금하는 것을 의미합니다.

銀行
은행(ぎんこう)
銀 (은 은/은) = 金 (쇠 금) + 艮 (그칠 간) : 금속 광물 중 은을 뜻하는 글자입니다.
行 (갈 행/은행 행) = 길을 따라 움직이는 모습 : 이 글자 자체보다, 여기서는 ‘금융기관’의 고유 명사형 일부로 사용됩니다.
원래 금전 거래와 관련된 기관을 가리키며, 현대에는 예금을 맡고 대출을 해 주는 “은행”을 뜻합니다.

禁止
금지(きんし)
禁 (금할 금/금지할 금) = 林 + 示 계열 : 신성하거나 정해진 규범 아래에서 하지 못하게 막는다는 뜻입니다.
止 (그칠 지/그치다) = 발자국을 본뜬 글자 : 멈추다, 그치다의 뜻입니다.
어떤 행동을 하지 못하게 막는 것을 의미합니다.

近所
근처(きんじょ)
近 (가까울 근/가깝다) = 辶 (쉬엄쉬엄 갈 착) + 斤 (도끼 근) : 가까이 다가간다는 뜻에서 “가깝다”의 의미가 생겼습니다.
所 (바 소/곳) = 戶 (문 호) + 斤 (도끼 근) : 문 가까이에서 일어나는 장소를 뜻해 “장소, 곳”이 되었습니다.
가까운 곳이나 이웃한 장소를 의미합니다.

区域
구역(くいき)
区 (구분할 구/구역) = 匚 (상자 방) + 乂 (벨 예) 계열 : 칸을 나누어 구분한다는 뜻에서 “구역”의 의미가 생겼습니다.
域 (지경 역/영역) = 土 (흙 토) + 或 (혹 혹/나라 국 계열) : 땅의 경계로 나뉜 범위를 뜻합니다.
어떤 기준으로 나누어진 일정한 범위를 말합니다.

空気
공기(くうき)
空 (빌 공/비다) = 穴 (굴 혈) + 工 (장인 공) : 텅 빈 구멍 속 공간을 나타내어 “비다”의 뜻이 생겼습니다.
気 (기운 기/기운) = 气 (기운 기) + 米 (쌀 미) 계열 : 눈에 보이지 않지만 몸과 주변에 퍼지는 기운을 뜻합니다.
우리 주변을 채우는 공기, 또는 분위기와 기운을 뜻합니다.

空港
공항(くうこう)
空 (빌 공/비다) = 穴 + 工 : 하늘로 텅 뚫린 공간이라는 느낌에서 비행장과 연결되었습니다.
港 (항구 항/항구) = 氵 (물 수) + 巷 (거리 항) : 배가 드나드는 물가의 장소를 뜻합니다.
비행기가 드나드는 항공의 항구, 즉 “공항”을 의미합니다.

区別
구별(くべつ)
区 (구분할 구/구역) = 匚 + 乂 계열 : 나누어 구분한다는 뜻입니다.
別 (나눌 별/다를 별) = 刀 (칼 도) + 刂/冎 계열 : 칼로 갈라 놓는 모습에서 “나누다, 다르다”의 뜻이 생겼습니다.
서로 다른 것들을 가르고 구분하는 것을 뜻합니다.

苦労
고생(くろう)
苦 (쓸 고/괴로울 고) = 艹 (풀 초) + 古 (옛 고) : 쓴 풀처럼 입에 쓰고 삶도 고통스럽다는 이미지에서 “괴롭다, 쓰다”의 뜻이 생겼습니다.
労 (일할 로/수고할 로) = 力 (힘 력) + 冖/炏 계열 : 힘을 들여 애쓰는 수고를 뜻합니다.
어렵고 힘든 일을 겪으며 애쓰는 것을 의미합니다.

訓練
훈련(くんれん)
訓 (가르칠 훈/가르치다) = 言 (말씀 언) + 川 (내 천) : 말을 흘러가게 전해 가르친다는 뜻에서 교육의 의미가 생겼습니다.
練 (익힐 련/익힐) = 糸 (실 사) + 柬 (가릴 간) : 실을 여러 번 다듬고 고르게 하듯, 반복해서 익힌다는 뜻입니다.
반복적으로 배우고 몸에 익히는 것을 뜻합니다.

経営
경영(けいえい)
経 (지날 경/경영할 경) = 糸 (실 사) + 巠 (물줄기 경) : 실을 곧게 이끌어 관리한다는 뜻에서 “다스리다, 경영하다”의 의미가 생겼습니다.
営 (경영할 영/경영하다) = 冖 (덮을 멱) + 呂/熒 계열 : 안을 정리하고 꾸려 나간다는 뜻에서 “운영하다”의 의미가 있습니다.
조직이나 사업을 맡아 운영하고 이끌어 가는 것을 뜻합니다.

計画
계획(けいかく)
計 (셀 계/헤아리다) = 言 (말씀 언) + 十 (열 십) : 말과 수를 놓고 헤아려 판단한다는 뜻입니다.
画 (그릴 화/그림) = 一 (한 일) + 由/田 계열 : 선을 그어 구획을 나누는 모습에서 “그리다, 계획하다”의 뜻이 생겼습니다.
미리 생각하여 일의 순서와 방법을 정하는 것을 의미합니다.

警官
경관, 경찰관(けいかん)
警 (경계할 경/경계하다) = 敬 (공경할 경) + 言 (말씀 언) : 경계와 주의를 말로 알린다는 뜻에서 “경계하다”가 되었습니다.
官 (벼슬 관/관청) = 宀 (집 면) + 㠯/人 계열 : 지붕 아래의 공적 자리를 뜻해 관직, 관청을 의미합니다.
공공의 안전을 지키는 경찰관을 뜻합니다.

経験
경험(けいけん)
経 (지날 경/경험 경) = 糸 + 巠 : 시간을 따라 지나가며 익힌다는 의미가 담겨 있습니다.
験 (시험 험/경험 험) = 馬 (말 마) + 僉 (다 첨) : 여러 차례 확인하여 증명한다는 뜻에서 “시험, 경험”의 의미가 생겼습니다.
직접 겪어 보아 알게 된 일이나 체험을 의미합니다.

経済
경제(けいざい)
経 (지날 경/경세할 경) = 糸 + 巠 : 세상을 다스리고 지나가게 한다는 뜻에서 정치·경세의 의미가 확장되었습니다.
済 (건널 제/구제할 제) = 氵 (물 수) + 齊 (가지런할 제) : 물을 건너 무사히 마친다는 뜻에서 “돕다, 이루다”의 뜻이 생겼습니다.
재화와 자원의 흐름을 관리하고 사회를 운영하는 것을 뜻합니다.

警察
경찰(けいさつ)
警 (경계할 경/경계하다) = 敬 + 言 : 위험이나 위법을 경계하도록 알린다는 뜻입니다.
察 (살필 찰/살피다) = 宀 (집 면) + 祭 (제사 제) : 신중히 들여다보고 살핀다는 뜻이 있습니다.
사회 질서를 지키기 위해 살피고 단속하는 기관이나 사람을 뜻합니다.

計算
계산(けいさん)
計 (셀 계/헤아리다) = 言 + 十 : 수를 헤아리며 따진다는 뜻입니다.
算 (셀 산/계산) = 竹 (대 죽) + 具 (갖출 구) : 대나무 산가지로 셈하던 방식에서 나온 글자입니다.
숫자를 헤아려 더하거나 빼고 따지는 것을 의미합니다.

経由
경유(けいゆ)
経 (지날 경/지나다) = 糸 + 巠 : 어떤 길이나 과정을 거쳐 지나간다는 뜻입니다.
由 (말미암을 유/말미암아) = 田 (밭 전) + 由 계열 : 어떤 근거와 경로를 통해 나온다는 뜻이 있습니다.
어떤 장소나 절차를 거쳐 다른 곳으로 가는 것을 뜻합니다.

けが
부상, 다침(けが)
다친 상태를 뜻하는 일본어 관용 표현입니다.
외부의 충격이나 사고로 몸에 상처를 입은 상태를 의미합니다.

外科
외과(げか)
外 (바깥 외/밖) = 夕 (저녁 석) + 卜 (점 복) 계열 : 안이 아닌 바깥을 뜻합니다.
科 (과목 과/과) = 禾 (벼 화) + 斗 (말 두) : 곡식의 분량을 나누는 데서 “분과, 과목”의 뜻이 생겼습니다.
몸의 바깥부분을 수술로 치료하는 의학 분야를 뜻합니다.

景色
경치(けいしょく)
景 (볕 경/경치 경) = 日 (해 일) + 京 (서울 경) : 해가 비추는 높고 넓은 곳의 모습에서 “경치” 의미가 생겼습니다.
色 (빛 색/색) = 사람의 얼굴과 분위기를 본뜬 글자입니다.
눈에 보이는 풍경과 분위기를 함께 이르는 말입니다.

血液型
혈액형(けつえきがた)
血 (피 혈/피) = 피가 담긴 그릇 모양을 본뜬 상형자입니다.
液 (물 젖을 액/액체) = 氵 (물 수) + 夜 (밤 야) : 흐르는 액체를 뜻합니다.
型 (모형 형/틀) = 土 (흙 토) + 䒑/刑 계열 : 어떤 모양을 찍어내는 틀을 뜻합니다.
피의 종류와 분류를 나타내는 말입니다.

結果
결과(けっか)
結 (맺을 결/맺다) = 糸 (실 사) + 吉 (길할 길) : 실을 단단히 묶어 매듭지은 모습에서 “맺다”의 뜻이 생겼습니다.
果 (과실 과/열매) = 木 (나무 목) + 田 (밭 전) : 나무에 맺힌 열매를 뜻합니다.
일의 끝에 맺어진 상태나 나온 성과를 의미합니다.

結婚
결혼(けっこん)
結 (맺을 결/맺다) = 糸 + 吉 : 두 관계를 매듭짓는다는 뜻이 있습니다.
婚 (혼인할 혼/혼인) = 女 (여자 녀) + 昏 (저물 혼) : 예부터 혼례가 해질 무렵 거행되던 관습과 관련 있습니다.
남녀가 법적으로나 사회적으로 한 가정을 이루는 것을 뜻합니다.

欠点
결점(けってん)
欠 (이지러질 결/부족할 결) = 人 (사람 인) + 乙/气 계열 : 입을 벌린 모습에서 비어 있거나 모자라는 상태를 뜻합니다.
点 (점 점/점) = 火 (불 화) + 占 (점칠 점) : 작은 불씨처럼 찍히는 점을 뜻합니다.
부족하거나 흠이 되는 부분을 의미합니다.

結論
결론(けつろん)
結 (맺을 결/맺다) = 糸 + 吉 : 여러 논의를 묶어 맺는다는 뜻입니다.
論 (논할 론/말할 론) = 言 (말씀 언) + 侖 (차례 로) : 말을 질서 있게 차례로 세운다는 뜻에서 “논하다”가 되었습니다.
여러 의견이나 과정을 정리해 마지막으로 내리는 판단이나 결과를 뜻합니다.

県
현(けん)
県 (고을 현/현) = 본래 머리카락과 줄을 묶은 모양에서 유래해, 후에는 행정 구역을 뜻하게 되었습니다.
일본의 행정구역 단위인 “현”을 뜻합니다.

原因
원인(げんいん)
原 (근원 원/언덕 원) = 厂 (언덕 엄) + 泉 (샘 천) : 샘이 솟는 언덕에서 “근원, 근본”의 뜻이 생겼습니다.
因 (말미암을 인/인할 인) = 囗 (에울 위) + 大 (큰 대) : 안에 기대고 의지하는 모습에서 “원인, 인하다”의 뜻이 생겼습니다.
어떤 일이 생겨나게 한 근본 사유를 뜻합니다.

玄関
현관(げんかん)
玄 (검을 현/깊을 현) = 실이 감겨 있는 모습을 본뜬 글자에서 “깊고 아득함”의 뜻이 나왔습니다.
関 (관계할 관/관문 관) = 門 (문 문) + 𢇁/丱 계열 : 문을 걸어 잠그는 관문을 뜻합니다.
집이나 건물의 출입문 가까이에 있는 입구 공간을 의미합니다.

研究
연구(けんきゅう)
研 (갈 연/연구할 연) = 石 (돌 석) + 开 계열 : 돌을 갈아 다듬는 모습에서 “갈다, 연구하다”의 뜻이 생겼습니다.
究 (궁구할 구/연구할 구) = 穴 (굴 혈) + 九 (아홉 구) : 구멍을 깊이 파고 끝까지 파고든다는 뜻에서 “깊이 캐묻다”의 의미가 생겼습니다.
어떤 문제를 깊이 파고들어 살펴보는 것을 뜻합니다.

健康
건강(けんこう)
健 (굳셀 건/건강할 건) = 亻 (사람 인) + 建 (세울 건) : 사람이 바르게 서고 힘이 있다는 뜻에서 “건강하다”의 의미가 생겼습니다.
康 (편안할 강/편안하다) = 广 (집 엄) + 米 (쌀 미) + 隶 계열 : 넉넉하고 편안한 상태를 뜻합니다.
몸과 마음이 병 없이 튼튼하고 편안한 상태를 의미합니다.

検査
검사(けんさ)
検 (검사할 검/살필 검) = 木 (나무 목) + 㑒/僉 계열 : 물건이나 상황을 하나하나 대조해 살핀다는 뜻이 있습니다.
査 (조사할 사/살피다) = 木 (나무 목) + 且 (또 차) : 대상을 위에서 아래로 다시 살핀다는 뜻에서 “조사하다”가 되었습니다.
상태나 사실을 자세히 살펴 확인하는 것을 뜻합니다.

現在
현재(げんざい)
現 (나타날 현/현재) = 玉 (구슬 옥) + 見 (볼 견) : 눈에 보이듯 드러난다는 뜻에서 “현재, 나타나다”의 의미가 생겼습니다.
在 (있을 재/있다) = 土 (흙 토) + 才 (재주 재/있다 계열) : 어떤 자리에 존재한다는 뜻입니다.
지금 이 순간의 상태나 시점을 의미합니다.

研修
연수(けんしゅう)
研 (갈 연/익힐 연) = 石 + 开 계열 : 갈고 닦는다는 뜻에서 배움을 심화하는 의미가 있습니다.
修 (닦을 수/닦다) = 亻 (사람 인) + 彡 (터럭 삼) + 攸 계열 : 몸과 태도를 단정히 가다듬고 닦는 모습을 뜻합니다.
지식이나 기술을 더 익히고 닦는 교육이나 훈련을 의미합니다.

減少
감소(げんしょう)
減 (덜 감/줄다) = 氵 (물 수) + 咸 (다 함) : 물이 줄어드는 모습에서 “줄다, 덜다”의 뜻이 생겼습니다.
少 (적을 소/적다) = 점이 적게 흩어진 모양 : 양이 적음을 뜻합니다.
양이나 정도가 적어지는 것을 의미합니다.

原料
원료(げんりょう)
原 (근원 원/근본) = 厂 + 泉 : 근본이 되는 샘과 언덕의 이미지에서 출발했습니다.
料 (헤아릴 료/재료 료) = 米 (쌀 미) + 斗 (말 두) : 재료의 분량을 헤아린다는 뜻에서 “재료, 원료”의 의미가 생겼습니다.
어떤 물건을 만드는 데 바탕이 되는 재료를 뜻합니다.

おしい
아깝다(おしい)
아쉬움과 아까움이 섞인 감탄 표현입니다.
어떤 대상이 거의 맞았거나 가치가 큰데 놓쳐서 아쉽고 아깝다는 뜻으로 쓰입니다.

多い
많다(おおい)
多 (많을 다/많다) = 夕 (저녁 석) + 夕 (저녁 석) : 같은 모양을 겹쳐 많이 있음을 나타냅니다.
수나 양이 많음을 뜻합니다.

おかしい
이상하다(おかしい)
‘정상과 다르다, 우습다, 이상하다’의 뜻을 가진 형용사입니다.
상황이나 모양이 보통과 다를 때 쓰입니다.

重い
무겁다(おもい)
重 (무거울 중/무겁다) = 사람/짐이 겹쳐 있는 모양에서 유래했습니다.
무게가 크거나 심각하다는 뜻을 가집니다.

大人しい
점잖다, 얌전하다(おとなしい)
大 (큰 대/크다) = 사람의 팔과 다리를 펼친 모습에서 사람의 큰 형상을 나타냅니다.
人 (사람 인) = 사람의 서 있는 모습을 본뜬 상형자입니다.
어른처럼 조용하고 차분한 성격이나 태도를 뜻합니다.

悲しい
슬프다(かなしい)
悲 (슬플 비/슬프다) = 非 (아닐 비) + 心 (마음 심) 계열 : 마음이 어긋나고 아픈 상태를 나타냅니다.
마음이 아프고 안타까운 감정을 의미합니다.

うらやましい
부럽다(うらやましい)
일본어 고유어 형용사로, 남의 좋은 처지나 것을 보고 갖고 싶고 부러운 감정을 뜻합니다.

うるさい
시끄럽다(うるさい)
원래는 말이 많아 성가시거나 귀찮다는 뜻에서 출발해, 소리가 지나치게 커서 거슬리는 의미로 쓰입니다.

嬉しい
기쁘다(うれしい)
嬉 (기쁠 희/기쁘다) = 女 (여자 녀) + 喜 (기쁠 희) 계열 : 기쁨과 즐거움이 겹쳐 나타나는 글자입니다.
마음이 즐겁고 반가운 감정을 뜻합니다.

危険だ
위험하다(きけんだ)
危 (위태할 위/위험하다) = 厂 (언덕 엄) + 𠂊/人 계열 : 높은 곳에서 불안하게 서 있는 모습에서 “위태롭다”의 뜻이 생겼습니다.
険 (험할 험/험하다) = 阝 (언덕 부) + 僉 계열 : 가파르고 거친 지세를 뜻합니다.
위협이나 해가 생길 가능성이 큰 상태를 의미합니다.

貴重だ
귀중하다(きちょうだ)
貴 (귀할 귀/귀하다) = 貝 (조개 패/재물 패) + 中 계열 : 값비싼 귀한 것을 뜻합니다.
重 (무거울 중/귀중할 중) = 사람이 겹쳐 묵직함을 나타냄 : 값이 무겁고 소중하다는 뜻으로 확장됩니다.
매우 값지고 소중하다는 의미입니다.

器用だ
기용하다, 솜씨가 좋다(きようだ)
器 (그릇 기/그릇) = 口가 여러 개 모여 있는 모습 : 여러 용도로 쓰이는 그릇을 뜻합니다.
用 (쓸 용/쓰다) = 凵/冂 계열 + 中 : 실제로 쓰이는 기능과 쓰임새를 뜻합니다.
손재주가 있고 일을 능숙하게 해내는 상태를 의미합니다.

嫌いだ
싫어하다(きらいだ)
嫌 (싫어할 혐/싫어하다) = 女 (여자 녀) + 兼 (겸할 겸) : 마음에 들지 않고 꺼리는 감정을 나타냅니다.
어떤 대상에 대해 불쾌하거나 좋아하지 않는 감정을 뜻합니다.

結構だ
훌륭하다, 괜찮다(けっこうだ)
結 (맺을 결/맺다) = 糸 + 吉 : 단단히 맺고 정리한다는 뜻입니다.
構 (얽을 구/구조할 구) = 木 (나무 목) + 句 (글귀 구) : 여러 재료를 짜 맞춰 구조를 만든다는 뜻입니다.
잘 갖추어져 있어서 훌륭하거나, 상황에 따라 “괜찮다”는 뜻으로 쓰입니다.

元気だ
건강하다, 활기차다(げんきだ)
元 (으뜸 원/처음 원) = 二 (둘 이) + 儿 (사람 인) : 가장 기본이 되는 시작을 뜻합니다.
気 (기운 기/기운) = 气 + 米 계열 : 몸과 마음에 흐르는 기운을 뜻합니다.
몸과 마음에 생기가 넘치는 상태를 의미합니다.

きちんと
깔끔히, 정확히
단정하고 빈틈없게 행동하거나 정리한다는 뜻의 부사입니다.

ぎっしり
빽빽이
빈틈이 없이 가득 차 있는 상태를 나타내는 부사입니다.

きっと
꼭, 염원, 확실히, 분명히, 틀림없이
확신이나 강한 추정을 나타내는 부사입니다.

急に
갑자기
예고 없이 빠르게 변하거나 일어나는 상황을 뜻합니다.

ぐっすり
푹
깊고 편안하게 잠드는 상태를 나타내는 부사입니다.

ぐったり
녹초가 됨
기운이 빠져 축 늘어진 상태를 뜻하는 부사입니다.

けっして
결코
부정을 강조하여 “절대로”라는 뜻을 나타내는 부사입니다.

こっそり
남몰래, 살짝
남이 모르게 조용히 행동하는 상태를 나타내는 부사입니다.

カロリー
칼로리
Calorie(칼로리) = 에너지의 단위인 영어/국제어에서 온 외래어입니다.
음식이나 운동에서 에너지 양을 나타내는 말입니다.

カレンダー
캘린더, 달력
Calendar(캘린더) = 날짜를 적는 달력을 뜻하는 영어에서 온 외래어입니다.
날짜와 요일을 보기 쉽게 정리한 도구를 뜻합니다.

キャンセル
취소
Cancel(캔슬) = 계약·예약 등을 없던 일로 하는 영어에서 온 외래어입니다.
이미 하기로 한 일을 중단하거나 없던 일로 만드는 것을 뜻합니다.

キロ(グラム)
킬로그램
Kilo(킬로) + gram(그램) = 무게 단위인 국제어/영어 계열 외래어입니다.
질량을 나타내는 단위입니다.

キロ(メートル)
킬로미터
Kilo(킬로) + meter(미터) = 길이 단위인 국제어/영어 계열 외래어입니다.
거리를 나타내는 단위입니다.

ケーキ
케이크
Cake(케이크) = 서양식 과자·빵류를 뜻하는 영어에서 온 외래어입니다.
빵반죽이나 크림으로 만든 달콤한 디저트를 뜻합니다.

クーラー
쿨러, 냉방 장치
Cooler(쿨러) = 식히는 장치라는 영어에서 온 외래어입니다.
방이나 기계를 식혀 주는 냉방·냉각 장치를 뜻합니다.

クラス
클래스, 학급
Class(클래스) = 영어에서 온 외래어입니다.
학생이 함께 배우는 반이나 분류를 뜻합니다.

グループ
그룹, 모둠
Group(그룹) = 여러 사람이나 사물을 묶은 집단을 뜻하는 영어에서 온 외래어입니다.
공통된 목적이나 성격으로 묶인 무리를 뜻합니다.

おいしい
맛있다(おいしい)
おいしい (맛있다) = 일본어 형용사로, 음식의 맛이 좋다는 뜻입니다.
음식이나 상태가 입맛에 맞고 즐겁게 느껴질 때 쓰는 표현입니다.

多い
많다(おおい)
多 (많을 다/많다) = 夕 (저녁 석) + 夕 (저녁 석) : 같은 모양을 겹쳐 많이 있음을 나타냅니다.
수나 양이 많음을 뜻합니다.

おかしい
이상하다(おかしい)
おかしい (이상하다) = 일본어 형용사로, 정상적이지 않거나 우스운 상태를 뜻합니다.
상황, 모양, 말이 보통과 다를 때 쓰이며, “이상하다”와 “우습다”의 뜻을 함께 가집니다.

重い
무겁다(おもい)
重 (무거울 중/무겁다) = 사람이 짐을 지고 겹쳐 있는 모습에서 유래한 글자입니다.
무게가 크거나, 심리적으로도 부담이 큰 상태를 뜻합니다.

大人しい
점잖다, 얌전하다(おとなしい)
大 (큰 대/크다) = 사람의 팔과 다리를 펼친 모습에서 사람의 큰 형상을 나타냅니다.
人 (사람 인) = 사람의 서 있는 모습을 본뜬 상형자입니다.
어른처럼 조용하고 차분하며 얌전한 성격이나 태도를 뜻합니다.

面白い
재미있다(おもしろい)
面 (낯 면/면) = 얼굴이나 앞면을 뜻하는 글자입니다.
白 (흰 백/희다) = 빛나는 흰색을 나타내는 상형자입니다.
원래는 “얼굴이 밝아 보일 만큼 흥미롭다”는 느낌에서 발전해, 지금은 “재미있다”의 뜻으로 쓰입니다.

固い
딱딱하다, 단단하다(かたい)
固 (굳을 고/굳다) = 囗 (에울 위) + 古 (옛 고) : 안이 단단히 둘러싸여 굳어진 모습에서 나온 글자입니다.
물건이나 마음이 쉽게 흔들리지 않고 단단한 상태를 뜻합니다.

結構だ
훌륭하다, 괜찮다(けっこうだ)
結 (맺을 결/맺다) = 糸 (실 사) + 吉 (길할 길) : 실을 단단히 묶어 매듭짓는 모습에서 “맺다”의 뜻이 생겼습니다.
構 (얽을 구/구조할 구) = 木 (나무 목) + 句 (글귀 구) : 여러 재료를 짜 맞춰 구조를 만든다는 뜻입니다.
잘 갖추어져 있어 훌륭하거나, 상황에 따라 “괜찮다”는 뜻으로도 쓰입니다.
