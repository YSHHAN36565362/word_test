OSI 7계층
데이터 통신 과정을 7개 계층으로 표준화한 참조 모델 (암기: 물데네전세표응)
[구성] 7단계: 물리 → 데이터링크 → 네트워크 → 전송 → 세션 → 표현 → 응용
[의미] 통신 기능을 계층별로 나누어 서로 다른 시스템 간 호환과 표준화를 돕는 모델
[구분] 계층별 전송 단위와 장비
· 7 응용: 데이터, HTTP·FTP
· 6 표현: 데이터, JPEG·MPEG, 암호화·압축
· 5 세션: 데이터, RPC·NETBIOS
· 4 전송: 세그먼트, TCP·UDP, L4 스위치
· 3 네트워크: 패킷, IP·ICMP, 라우터
· 2 데이터링크: 프레임, HDLC·PPP, 브리지·스위치
· 1 물리: 비트, RS-232C, 허브·리피터
[치트키] "물데네전세표응 (1→7), 영어는 아파서티내다피나다 (7→1)"
[예문] 패킷 단위로 경로 선택을 담당하며 라우터를 사용하는 계층은 네트워크 계층이다

포트 번호
상위 계층의 응용 프로그램으로 데이터를 전달하기 위한 통로
[구성] FTP 20, 21 + TELNET 23 + SMTP 25 + DNS 53 + HTTP 80 + HTTPS 443
[의미] 같은 IP 안에서 서비스를 구분하는 번호
[구분] 주요 포트
· FTP 데이터: 20번
· FTP 제어: 21번
· TELNET: 23번
· SMTP: 25번
· DNS: 53번
· HTTP: 80번
· HTTPS: 443번
· SSH: 22번
[치트키] "FTP 20·21, 텔넷 23, 메일 25, DNS 53, 웹 80, 보안웹 443"
[예문] 웹 서버의 기본 HTTP 포트 번호는 80이다

프로토콜 기본요소
서로 다른 시스템 간 데이터 교환을 원활하게 하기 위한 통신 규약의 기본 요소 (암기: 구의타)
[구성] 구문 + 의미 + 타이밍
[의미] 프로토콜이 규정해야 하는 세 가지 핵심 요소
[구분] 요소별 의미
· 구문: 데이터 형식, 코딩, 신호 레벨 등의 규정
· 의미: 제어 정보로 조정과 에러 처리를 위한 규정
· 타이밍: 속도 조절과 순서 관리 규정
[치트키] "구(구문) 의(의미) 타(타이밍) = 구의타"
[예문] 속도 조절과 순서 관리를 규정하는 프로토콜 요소는 타이밍이다

라우팅 프로토콜
네트워크에서 경로 정보를 교환하여 최적의 경로를 결정하는 프로토콜
[구성] IGP(RIP + OSPF) + EGP(BGP)
[의미] 같은 조직 내부(IGP)와 서로 다른 조직 간(EGP)으로 나뉨
[구분] 프로토콜별 특징
· IGP: 동일 그룹 내부에서 라우팅 정보를 교환
· EGP: 다른 그룹과 라우팅 정보를 교환
· RIP: 최초의 라우팅 프로토콜, 거리 벡터 알고리즘, 최대 15홉
· OSPF: 링크 상태 알고리즘, 변경 정보를 RIP보다 빠르게 업데이트
· BGP: 규모가 큰 네트워크의 상호 연결, 서로 다른 AS를 연결하는 경계 게이트웨이 프로토콜
[치트키] "RIP은 15홉 한계, OSPF는 링크 상태로 빠르게, BGP는 AS 사이를 이어준다"
[예문] 최대 15홉까지만 이동하며 거리 벡터 알고리즘을 사용하는 라우팅 프로토콜은 RIP이다

ARP
IP 네트워크에서 IP 주소를 MAC 주소로 변환하는 프로토콜
[구성] IP 주소 → MAC 주소
[의미] 같은 네트워크 안에서 IP 주소만 알 때 상대의 물리 주소(MAC)를 알아내기 위해 사용
[치트키] "ARP = IP를 주면 MAC을 찾아 주는 안내원 (A→R 방향 정방향)"
[예문] IP 주소로부터 MAC 주소를 알아내는 프로토콜은 ARP이다
[헷갈리는 단어] RARP - ARP는 IP에서 MAC, RARP는 MAC에서 IP

RARP
네트워크 MAC 주소를 IP 주소로 변환하는 프로토콜
[구성] MAC 주소 → IP 주소
[의미] 자신의 MAC 주소는 알지만 IP 주소를 모르는 장치가 IP를 얻기 위해 사용
[치트키] "R(Reverse) = 거꾸로, MAC을 주면 IP를 알려 준다"
[예문] MAC 주소로부터 IP 주소를 알아내는 프로토콜은 RARP이다
[헷갈리는 단어] ARP - RARP는 MAC에서 IP, ARP는 IP에서 MAC

ICMP
IP 패킷 전송 중 에러가 발생하면 에러 발생 메시지를 보내 주는 프로토콜 (인터넷 제어 메시지 프로토콜)
[구성] IP 오류 보고 + 제어 메시지
[의미] 네트워크 상태 진단과 오류 통보에 사용되는 프로토콜 (ping에 사용)
[치트키] "ICMP = 인터넷 제어 메시지, 에러가 나면 알려 준다"
[예문] IP 패킷 전송 중 발생한 오류를 알려 주는 프로토콜은 ICMP이다
[헷갈리는 단어] IGMP - ICMP는 오류·제어 메시지, IGMP는 멀티캐스트 그룹 관리

IGMP
컴퓨터가 멀티캐스트 그룹 구성원을 인접한 라우터에게 알리는 프로토콜 (인터넷 그룹 관리 프로토콜)
[구성] 호스트 → 인접 라우터 / 멀티캐스트 그룹 가입·탈퇴 알림
[의미] 멀티캐스트 통신에서 그룹 구성원을 관리
[치트키] "IGMP의 G = Group, 그룹 가입 신고서"
[예문] 호스트가 멀티캐스트 그룹 가입을 라우터에 알릴 때 사용하는 프로토콜은 IGMP이다
[헷갈리는 단어] ICMP - IGMP는 그룹 관리, ICMP는 오류·제어 메시지

이더넷(Ethernet)
LAN을 위해 개발된 근거리 유선 네트워크 통신 기술로 IEEE 802.3으로 표준화
[구성] 유선 LAN + IEEE 802.3 + CSMA/CD
[의미] 근거리 유선 네트워크에서 가장 널리 쓰이는 통신 방식
[치트키] "이더넷 = 802.3 = 유선 LAN"
[예문] IEEE 802.3으로 정의된 근거리 유선 네트워크 기술은 이더넷이다

CSMA/CD
버스에 연결된 여러 통신 주체가 동시에 통신하며 발생하는 충돌을 막기 위해 충돌을 탐지하는 프로토콜 (유선)
[구성] 반송파 감지 + 다중 접근 + 충돌 탐지(Collision Detection)
[의미] 유선 LAN(이더넷)에서 충돌 발생 시 이를 탐지하고 재전송하는 방식
[치트키] "CD = Detection(탐지), 유선은 부딪힌 걸 알아낸다"
[예문] 이더넷에서 충돌을 탐지하는 접근 제어 방식은 CSMA/CD이다
[헷갈리는 단어] CSMA/CA - CD는 충돌 탐지(유선), CA는 충돌 회피(무선)

CSMA/CA
네트워크가 빌 때까지 기다렸다가 정해진 시간 후 데이터를 전송해 충돌을 회피하는 프로토콜 (무선)
[구성] 반송파 감지 + 다중 접근 + 충돌 회피(Collision Avoidance)
[의미] 무선 LAN에서 충돌 탐지가 어려워 미리 충돌을 피하도록 하는 방식
[치트키] "CA = Avoidance(회피), 무선은 부딪히기 전에 피한다"
[예문] 무선 LAN(IEEE 802.11)에서 충돌을 회피하는 방식은 CSMA/CA이다
[헷갈리는 단어] CSMA/CD - CA는 회피(무선), CD는 탐지(유선)

IPv4
32bit 주소 체계를 갖는 네트워크 계층의 프로토콜
[구성] 32bit + 8bit씩 4부분
[의미] 현재 널리 쓰이지만 주소 고갈 문제가 있음
[치트키] "IPv4 = 32bit (4×8)"
[예문] 32bit 주소 체계를 갖는 IP 버전은 IPv4이다
[헷갈리는 단어] IPv6 - IPv4는 32bit, IPv6는 128bit

IPv6
128bit 주소 체계를 갖는 차세대 인터넷 프로토콜
[구성] 128bit + 16bit씩 8부분
[의미] 주소 고갈 문제를 해결하고 헤더 단순화, 보안 강화(IPSec), QoS 지원
[치트키] "IPv6 = 128bit (16×8)"
[예문] 128bit 주소 체계를 갖는 인터넷 프로토콜은 IPv6이다
[헷갈리는 단어] IPv4 - IPv6는 128bit, IPv4는 32bit

IPv4/IPv6 전환 기술
IPv4에서 IPv6로 넘어가는 과도기에 두 버전을 함께 운용하기 위한 3가지 기술
[구성] 듀얼 스택 + 터널링 + 주소 변환
[의미] 두 프로토콜이 공존하는 환경에서 통신을 가능하게 하는 방법
[구분] 기술별 의미
· 듀얼 스택: IPv4와 IPv6를 동시에 지원
· 터널링: IPv4 패킷으로 캡슐화하여 전송, 두 IPv6 네트워크 간에 터널을 이용
· 주소 변환: IPv4와 IPv6 간에 주소를 변환해 두 버전을 연동
[치트키] "둘 다 쓰면 듀얼, 포장해서 지나가면 터널, 번역하면 주소 변환"
[예문] IPv4와 IPv6를 동시에 지원하는 전환 기술은 듀얼 스택이다

IPv4/IPv6 전송 방식
데이터를 전송하는 대상의 범위에 따른 4가지 방식
[구성] 유니캐스트 + 멀티캐스트 + 브로드캐스트 + 애니캐스트
[의미] 전송 대상이 1:1, 1:다, 1:전체, 가장 가까운 노드인지로 구분
[구분] 방식별 의미
· 유니캐스트: 고유 주소로 식별된 하나의 목적지와 1:1 통신 (IPv4, IPv6 사용)
· 멀티캐스트: 한 번의 송신으로 여러 컴퓨터에 동시 전송, 1:다 (IPv4, IPv6 사용)
· 브로드캐스트: 네트워크에 연결된 모든 호스트에 전송, 1:전체 (IPv4만 사용)
· 애니캐스트: 브로드캐스트 단점을 보완해 가장 가까운 노드와 통신 (IPv6만 사용)
[치트키] "브로드캐스트는 IPv4만, 애니캐스트는 IPv6만, 유니·멀티는 둘 다"
[예문] IPv6에서 브로드캐스트를 대체하여 가장 가까운 노드와 통신하는 방식은 애니캐스트이다

소켓(Socket)
컴퓨터 네트워크를 경유하는 프로세스 간 통신의 종착점
[구성] 응용 계층 프로그램 → 소켓 → 전송 계층 통신망
[의미] 응용 프로그램이 데이터를 송수신하기 위해 소켓을 거쳐 전송 계층으로 데이터를 전달
[치트키] "소켓 = 콘센트, 응용 프로그램이 통신망에 꽂는 구멍"
[예문] 응용 프로그램이 네트워크로 데이터를 주고받는 통신의 종착점은 소켓이다

NAT(Network Address Translation)
한정된 공인 IP를 여러 개의 내부 사설 IP로 변환하기 위해 사용하는 기술
[구성] 사설 IP ↔ 공인 IP 변환
[의미] 공인 IP 부족 문제를 완화하고 내부 네트워크를 보호
[치트키] "NAT = 사설 IP를 공인 IP 옷으로 갈아입힌다"
[예문] 공인 IP 하나로 여러 사설 IP 장비가 인터넷을 쓰게 하는 기술은 NAT이다

Ad-Hoc 네트워크
특정 기지국에 의존하지 않고 무선 이동 단말로만 구성된 분산형 무선 통신 네트워크
[구성] 무선 단말 + 분산형 + 기지국 없음
[의미] 긴급 구조, 긴급 회의 등 인프라가 없는 환경에서 임시로 구성하는 네트워크
[치트키] "애드혹 = 그때그때(Ad hoc) 즉석에서 만드는 무선망"
[예문] 기지국 없이 단말끼리 구성하는 무선 네트워크는 Ad-Hoc 네트워크이다

TCP
신뢰성이 보장되는 연결 지향형 전송 계층 프로토콜
[구성] 연결 지향 + 흐름 제어 + 에러 제어 + 혼잡 제어 + 패킷 다중화
[의미] IP와 함께 TCP/IP로 사용되며 데이터의 정확한 전달을 보장
[치트키] "TCP = 믿을 수 있고(신뢰) 연결부터 하고 보낸다"
[예문] 흐름 제어와 혼잡 제어를 제공하는 연결 지향형 프로토콜은 TCP이다
[헷갈리는 단어] UDP - TCP는 연결형·신뢰성, UDP는 비연결형·고속

UDP
신뢰성은 없지만 데이터그램 단위로 고속 전송이 가능한 비연결 지향형 전송 계층 프로토콜
[구성] 비연결 지향 + 데이터그램 + 고속
[의미] 스트리밍·DNS처럼 속도가 중요한 서비스에 사용
[치트키] "UDP = 연결 없이 휙 던지는 빠른 우편"
[예문] 연결 설정 없이 데이터그램을 빠르게 전송하는 프로토콜은 UDP이다
[헷갈리는 단어] TCP - UDP는 비연결형·고속, TCP는 연결형·신뢰성

네트워크 연결 장비
OSI 계층에 따라 구분되는 네트워크 연결 장비
[구성] 1계층: 허브, 리피터 → 2계층: 브리지, 스위치 → 3계층: 라우터
[의미] 계층별로 처리하는 단위(비트, 프레임, 패킷)와 기능이 다름
[구분] 장비별 의미
· 허브: 1계층, 여러 컴퓨터를 연결하고 수신 정보를 여러 대로 송신
· 리피터: 1계층, 디지털 신호를 증폭
· 브리지: 2계층, 두 개의 LAN을 서로 연결
· 라우터: 3계층, LAN과 LAN 또는 LAN과 WAN을 연결하고 최적 경로를 판단
[치트키] "1층은 허브·리피터, 2층은 브리지·스위치, 3층은 라우터"
[예문] 최적의 경로를 판단하여 LAN과 WAN을 연결하는 3계층 장비는 라우터이다

SSH
원격 호스트에 접속하기 위해 사용되는 보안 프로토콜로 22번 포트를 사용
[구성] 원격 접속 + 암호화 통신 + 22번 포트
[의미] 텔넷의 평문 전송 단점을 보완한 안전한 원격 접속 방식
[치트키] "SSH = 22번 포트의 안전한 원격 접속"
[예문] 22번 포트를 사용하는 보안 원격 접속 프로토콜은 SSH이다

VPN
공중 네트워크에 암호화 기술을 이용해 자신의 전용 회선을 사용하는 것처럼 해 주는 보안 솔루션
[구성] 공중망 + 터널링 + 암호화
[의미] 저렴하게 안전한 사설망 통신을 구현
[치트키] "VPN = 가상(Virtual) 사설(Private) 망, 공중망 속의 전용 터널"
[예문] 인터넷에서 암호화된 가상의 전용 회선을 제공하는 보안 솔루션은 VPN이다

LAN 802.xx 시리즈 규약
IEEE 802 위원회에서 정한 LAN 표준 규약
[구성] 802.3 + 802.4 + 802.5 + 802.11 + 802.15
[의미] 번호에 따라 접속 방식과 매체가 다름
[구분] 번호별 의미
· 802.3: CSMA/CD (유선)
· 802.4: 토큰 버스
· 802.5: 토큰 링
· 802.11: CSMA/CA (무선)
· 802.15: 블루투스
[치트키] "3 유선 CD, 4 토큰 버스, 5 토큰 링, 11 무선 CA, 15 블루투스"
[예문] 무선 LAN의 표준 규약은 IEEE 802.11이다

3-way handshake
TCP 연결을 설정하기 위해 3번 메시지를 주고받는 과정
[구성] SYN → SYN/ACK → ACK
[의미] 양쪽이 통신 준비가 되었음을 확인하고 연결을 수립
[구분] 단계별 의미
· SYN: 클라이언트가 연결 요청
· SYN/ACK: 서버가 요청을 수락하고 자신의 연결 요청 전송
· ACK: 클라이언트가 확인 응답
[치트키] "요청(SYN) → 요청과 승낙(SYN/ACK) → 승낙(ACK)"
[예문] TCP 연결 설정 과정은 SYN, SYN/ACK, ACK의 3단계로 이루어진다

TCP/IP 4계층
인터넷 통신에 사용되는 4계층 모델
[구성] 응용 → 전송 → 인터넷 → 네트워크 액세스
[의미] OSI 7계층을 4계층으로 단순화
[구분] OSI와의 대응
· 응용 = OSI 5·6·7계층
· 전송 = OSI 4계층
· 인터넷 = OSI 3계층
· 네트워크 액세스 = OSI 1·2계층
[치트키] "응전인네 = 응용 전송 인터넷 네트워크"
[예문] TCP/IP 모델에서 OSI의 3계층에 해당하는 계층은 인터넷 계층이다

VLAN
물리적 구성과 관계없이 논리적으로 네트워크를 분리하는 가상 LAN
[구성] 스위치 설정 + 논리적 분리
[의미] 같은 장비에서도 네트워크를 나눠 보안과 관리 효율을 높임
[치트키] "VLAN = 선은 하나, 네트워크는 여러 개"
[예문] 물리적 연결과 상관없이 논리적으로 네트워크를 분리하는 기술은 VLAN이다

AAL
ATM 계층 중 패킷을 작은 조각인 셀로 전송하고 다시 조립하여 원래 데이터로 복원하는 역할을 담당하는 계층
[구성] 분할 + 셀 전송 + 재조립
[의미] 상위 계층 데이터를 ATM 셀 단위로 적응시키는 계층
[치트키] "AAL = ATM 적응(Adaptation) 계층, 쪼갰다 다시 붙이기"
[예문] 패킷을 셀로 분할하고 다시 조립하는 ATM 계층은 AAL이다

서브넷 마스크(서브넷팅 계산)
IP 주소에서 네트워크부와 호스트부를 구분하는 값으로, 네트워크 주소는 IP와 서브넷 마스크를 AND 연산해 구함
[구성] 네트워크 주소 = IP 주소 AND 서브넷 마스크 → CIDR 표기 = 주소/마스크의 1의 개수
[의미] 네트워크를 쪼개 사용(서브넷팅)하며, 실기에서는 호스트가 속한 네트워크 주소를 CIDR로 쓰는 계산 문제가 출제됨
[구분] 계산 방법
· 255.255.255.0 = /24, 255.255.254.0 = /23, 255.255.252.0 = /22, 255.255.255.128 = /25
· 마스크가 변하는 옥텟의 블록 크기 = 256 - 마스크 값 (254이면 블록 크기 2)
· 해당 옥텟을 블록 크기의 배수로 내림하면 네트워크 주소
· 2026년 1회 기출: 255.255.254.0(/23)에서 192.168.11.20은 11을 2의 배수로 내려 10 → 192.168.10.0/23
· 같은 문제의 192.168.12.200은 12가 2의 배수이므로 192.168.12.0/23
· 호스트 수 = 2의 호스트비트 수 제곱 - 2 (네트워크 주소와 브로드캐스트 제외)
· 사설 IP 대역: 10.x, 172.16~31.x, 192.168.x (NAT로 공인 IP 변환)
[치트키] "마스크가 254면 2칸씩 묶는다: 홀수는 내려서 짝수 시작"
[예문] IP 192.168.11.20과 서브넷 마스크 255.255.254.0이 주어졌을 때 네트워크 주소는 192.168.10.0/23이다
[헷갈리는 단어] 브로드캐스트 주소 - 네트워크 주소는 호스트비트가 전부 0, 브로드캐스트 주소는 전부 1

HDLC
비트 중심의 데이터 링크 제어 프로토콜로 프레임 단위로 전송하며 흐름 제어와 오류 복구 기능을 제공
[구성] 프레임 3종(I, S, U) + 동작 모드 3종(NRM, ARM, ABM)
[의미] 2계층(데이터 링크 계층)의 대표 프로토콜로, 2026년 1회에 프레임·모드를 묻는 문제가 출제
[구분] 프레임 종류
· 정보 프레임(I-Frame): 실제 사용자 데이터를 전송
· 감시 프레임(S-Frame): 흐름 관리, 오류 제어, 통신 상태 감시
· 비번호 프레임(U-Frame): 순서 번호 없이 링크 설정·해제, 모드 설정 등 제어
· 동작 모드
· 정규 응답 모드(NRM): 종국이 주국의 허가(폴링)를 받아야 응답 전송
· 비동기 응답 모드(ARM): 종국이 주국의 허가 없이 자발적으로 응답 전송
· 비동기 균형 모드(ABM): 두 국이 동등한 위치에서 서로 명령과 응답을 주고받음
[치트키] "I는 데이터(Information), S는 감시(Supervisory), U는 번호 없음(Unnumbered) / 동등하면 균형(ABM), 알아서 응답하면 비동기 응답(ARM)"
[예문] 두 국이 동등한 위치에서 명령과 응답을 주고받는 HDLC 모드는 비동기 균형 모드(ABM)이다
[헷갈리는 단어] 비동기 응답 모드 - ARM은 종국의 자발 응답, ABM은 두 국이 동등

오류 검출 방식
전송된 데이터에 오류가 있는지 확인하는 방식
[구성] 패리티 검사 + 블록 합 + CRC(순환 중복 검사) + 해밍 코드
[의미] 데이터 링크 계층에서 신뢰성 있는 전송을 위해 사용하며, 정정 가능 여부에 따라 구분
[구분] 방식별 의미
· 패리티 검사: 짝수/홀수 패리티 비트를 추가해 1비트 오류를 검출
· 블록 합: 데이터 블록의 합을 검사 비트로 전송
· CRC: 다항식 코드를 사용해 오류 발생 유무만 판별 (집단 오류에 강함, 2025년 1회 출제)
· 해밍 코드: 데이터 비트 사이에 패리티 비트를 삽입해 1비트 오류를 검출하고 정정
[치트키] "패리티는 1비트 확인, CRC는 다항식으로 확인만, 해밍은 확인하고 고친다"
[예문] 다항식 코드를 이용해 전송 오류 발생 유무를 판별하는 방식은 CRC이다
[헷갈리는 단어] 해밍 코드 - CRC는 검출만 가능하고, 해밍 코드는 1비트 오류를 정정까지 가능

오류 제어 방식(FEC, BEC)
오류를 검출한 뒤 처리하는 방법에 따라 나눈 두 가지 오류 제어 방식
[구성] FEC(전진 오류 수정) + BEC(후진 오류 수정, ARQ)
[의미] 수신 측이 스스로 고치는지, 송신 측에 재전송을 요구하는지의 차이
[구분] 방식별 의미
· FEC: 수신 측이 오류를 검출하고 정정까지 수행 (해밍 코드 등)
· BEC: 오류를 검출하면 송신 측에 재전송을 요구 (자동 반복 요청 ARQ)
[치트키] "FEC는 앞에서 고치고(Forward), BEC는 뒤로 되돌려 다시 받는다(Backward)"
[예문] 수신 측이 오류를 정정하는 방식이 아니라 재전송을 요구하는 방식은 BEC(ARQ)이다

ARQ(자동 반복 요청)
수신 측이 오류를 발견하면 송신 측에 재전송을 요구하는 오류 제어 방식
[구성] Stop-and-Wait ARQ + Go-Back-N ARQ + Selective Repeat ARQ + Adaptive ARQ
[의미] 재전송 범위와 대기 방식에 따라 효율이 달라짐
[구분] 종류별 의미
· Stop-and-Wait: 한 프레임을 보내고 응답(ACK)을 받은 뒤 다음 프레임 전송
· Go-Back-N: 오류 발생 프레임부터 이후 프레임 전체를 재전송
· Selective Repeat: 오류가 난 프레임만 선택적으로 재전송
· Adaptive: 채널 상태에 따라 프레임 길이를 동적으로 조정
[치트키] "멈추고 기다리기 / 되돌아가서 전부 / 틀린 것만 골라서 / 상황 보며 적응"
[예문] 오류가 발생한 프레임만 골라서 재전송하는 ARQ 방식은 Selective Repeat이다

패킷 교환 방식
데이터를 패킷 단위로 나누어 전송하는 두 가지 방식
[구성] 가상 회선 방식 + 데이터그램 방식
[의미] 전송 전에 경로를 설정하느냐에 따라 구분
[구분] 방식별 특징
· 가상 회선: 연결형, 논리적 경로를 미리 설정, 패킷 순서가 보장되고 오류·흐름 제어가 쉬움
· 데이터그램: 비연결형, 패킷마다 독립적으로 경로 선택, 순서가 바뀔 수 있어 수신 측에서 재조립
[치트키] "가상 회선은 길을 미리 닦고, 데이터그램은 각자 알아서 간다"
[예문] 경로를 미리 설정하고 패킷 순서를 보장하는 패킷 교환 방식은 가상 회선이다

원거리 통신망 연결 기술
멀리 떨어진 네트워크를 연결하는 세 가지 회선 방식
[구성] 전용 회선 방식 + 회선 교환 방식 + 패킷 교환 방식
[의미] 회선 점유 방식에 따라 비용과 효율이 다름
[구분] 방식별 특징
· 전용 회선: 특정 두 지점을 고정적으로 연결
· 회선 교환: 통신 시 회선을 전용으로 설정해 사용 (전화망)
· 패킷 교환: 데이터를 패킷으로 나눠 회선을 공유하며 전송
[치트키] "전용은 독점 전세, 회선교환은 통화 중 점유, 패킷교환은 공유"
[예문] 데이터를 패킷으로 나누어 회선을 공유하는 방식은 패킷 교환이다

OSPF의 특징
대규모 네트워크에 적합한 대표적인 내부 라우팅 프로토콜 (Open Shortest Path First)
[구성] 다익스트라 알고리즘 + 라우팅 메트릭 지정 + AS 분할 + 홉 카운트 무제한
[의미] 링크 상태 알고리즘으로 변경 정보를 RIP보다 빠르게 갱신
[구분] 특징별 의미
· 다익스트라 알고리즘을 사용하는 내부 라우팅 프로토콜
· 지연, 최대 처리량 등 관리자가 라우팅 메트릭을 지정
· 자치 시스템(AS)을 지역(영역)으로 나눠 효율적으로 관리
· 홉 카운트에 제한이 없음 (RIP은 최대 15홉)
[치트키] "OSPF = 다익스트라, 메트릭, 영역 분할, 홉 무제한"
[예문] 다익스트라 알고리즘과 링크 상태 방식을 사용하는 라우팅 프로토콜은 OSPF이다
[헷갈리는 단어] RIP - OSPF는 링크 상태·홉 무제한, RIP은 거리 벡터·최대 15홉

라우팅 알고리즘 유형
라우터가 최적 경로를 계산하는 방식
[구성] 거리 벡터 알고리즘 + 링크 상태 알고리즘
[의미] 이웃과 정보를 교환하는 범위에 따라 구분
[구분] 유형별 의미
· 거리 벡터: 이웃 라우터와 경로 비용(거리) 정보를 주기적으로 교환 (RIP)
· 링크 상태: 네트워크 전체의 링크 상태를 파악해 최단 경로를 계산 (OSPF)
[치트키] "RIP은 거리 벡터, OSPF는 링크 상태"
[예문] 전체 네트워크의 링크 상태를 이용해 최단 경로를 계산하는 알고리즘은 링크 상태 알고리즘이다

NAT 유형
사설 IP를 공인 IP로 변환하는 NAT의 방식
[구성] Static NAT + Dynamic NAT (+ PAT)
[의미] 변환 대응 방식에 따라 구분
[구분] 유형별 의미
· Static NAT: 사설 IP와 공인 IP를 1:1로 고정 연결
· Dynamic NAT: 공인 IP 풀에서 동적으로 할당하는 N:1 또는 N:M 방식
· PAT: 포트 번호까지 변환해 하나의 공인 IP를 여러 사설 IP가 공유
[치트키] "정적은 일대일 고정, 동적은 풀에서 빌려 쓴다"
[예문] 사설 IP와 공인 IP를 1:1로 연결하는 NAT 방식은 Static NAT이다

응용 계층 프로토콜
OSI 7계층 최상위인 응용 계층에서 사용자에게 서비스를 제공하는 프로토콜
[구성] HTTP + FTP + SMTP + POP3 + IMAP + Telnet (+ DNS, DHCP, SNMP, SSH)
[의미] 웹, 파일 전송, 메일, 원격 접속 같은 서비스를 담당
[구분] 프로토콜별 의미
· HTTP: 웹 문서 전송 (80), HTTPS는 443
· FTP: 파일 전송 (20, 21)
· SMTP: 메일 송신 (25)
· POP3, IMAP: 메일 수신
· Telnet: 원격 접속 (23, 평문), SSH는 22번 포트의 보안 원격 접속
· DNS: 도메인을 IP로 변환 (53), DHCP: IP 자동 할당, SNMP: 망 관리
[치트키] "보낼 땐 SMTP, 받을 땐 POP3·IMAP"
[예문] 메일 서버에서 메일을 수신할 때 사용하는 프로토콜은 POP3 또는 IMAP이다

데이터 링크 계층 기법
OSI 2계층에서 인접 노드 간 신뢰성 있는 전송을 위한 기능
[구성] 회선 제어 + 흐름 제어 + 오류 제어
[의미] 물리 계층에서 올라온 비트를 프레임으로 구성해 오류 없이 전달
[구분] 기법별 의미
· 회선 제어: 송수신 권한과 회선 사용을 제어
· 흐름 제어: 송신 속도를 수신 측 처리 속도에 맞춤
· 오류 제어: 오류를 검출하고 정정·재전송
[치트키] "회선·흐름·오류 제어 = 2계층의 3가지 일"
[예문] 송신 속도를 수신 측 처리 속도에 맞춰 조절하는 기법은 흐름 제어이다

다중화(Multiplexing) 기법
하나의 전송 매체를 여러 신호가 함께 사용하게 하는 기술
[구성] 시분할 다중화(TDM) + 주파수 분할 다중화(FDM) + 코드 분할 다중화(CDM)
[의미] 회선 이용 효율을 높임
[구분] 기법별 의미
· TDM: 시간을 쪼개어 번갈아 사용
· FDM: 주파수 대역을 나누어 사용
· CDM: 서로 다른 코드를 부여해 같은 시간·주파수에서 구분
[치트키] "시간 쪼개기, 주파수 쪼개기, 코드 구분"
[예문] 주파수 대역을 나누어 여러 신호를 동시에 전송하는 방식은 FDM이다

무선 LAN 보안
무선 네트워크의 접속과 데이터를 보호하기 위한 용어와 기술
[구성] SSID + WEP + WPA/WPA2 + TKIP + AES-CCMP
[의미] 무선 구간의 도청과 무단 접속을 막기 위한 인증·암호화 방식
[구분] 용어별 의미
· SSID: 무선 네트워크를 식별하는 이름
· WEP: 초기 무선 보안 방식 (취약)
· WPA: WEP의 취약점을 보완한 보안 방식
· TKIP: WPA에서 패킷마다 키를 바꾸는 임시 키 무결성 프로토콜
· WPA2: AES 기반 CCMP 사용
[치트키] "WEP은 약하고 WPA는 TKIP, WPA2는 AES"
[예문] WPA에서 패킷마다 암호키를 바꾸는 프로토콜은 TKIP이다

L2TP와 PPTP
VPN에서 사용하는 2계층 터널링 프로토콜
[구성] PPTP + L2F → L2TP (IPSec과 함께 사용하는 경우가 많음)
[의미] 원격 사용자가 공중망을 통해 사설망에 안전하게 접속하도록 터널을 구성
[구분] 특징
· PPTP: 마이크로소프트가 주도한 2계층 터널링 프로토콜
· L2TP: PPTP와 L2F의 장점을 결합한 2계층 터널링 프로토콜, 암호화는 IPSec을 병행
[치트키] "L2 = 2계층(Layer 2) 터널링 프로토콜"
[예문] 2계층에서 터널링을 제공하며 IPSec과 함께 쓰이는 VPN 프로토콜은 L2TP이다
[헷갈리는 단어] IPSec - IPSec은 3계층 보안 프로토콜, L2TP는 2계층 터널링
