혼동행렬 (Confusion Matrix)
이진 분류 모델의 예측 성능을 평가하는 표
[구성] TP(True Positive) / FP(False Positive) / FN(False Negative) / TN(True Negative)
[의미] 실제값과 예측값을 교차한 표. 재현율(Recall)=민감도(Sensitivity)=TP Rate=Hit Rate로 모두 같은 의미. F1-Score는 정밀도(Precision)와 재현율(Recall)의 조화평균. 특이도(Specificity)는 실제 False인 것 중 맞춘 것
[구분] 정밀도(Precision)와 재현율(Recall)은 Trade-off 관계(하나를 올리면 다른 하나가 내려가는 경향)
[구분] 혼동행렬 계산 예시: 정확도=(TP+TN)/전체, 재현율=TP/(TP+FN), 정밀도=TP/(TP+FP), 특이도=TN/(TN+FP)
[치트키] "재현율=민감도=TPR=히트레이트(다 같은 말!), 정밀도-재현율은 시소처럼 반대로 움직임"
[예문] 실제 참 48, 예측 참 50인 표에서 정밀도는 TP/(TP+FP)로 계산한다(4월 기출 63번 유형)

정확도/정밀도/재현율/특이도 계산
혼동행렬에서 도출하는 4가지 핵심 평가지표
[구성] 정확도(Accuracy) / 정밀도(Precision) / 재현율(Recall) / 특이도(Specificity)
[의미]
· 정확도: 전체 중 맞게 예측한 비율 = (TP+TN)/전체
· 정밀도: Positive로 예측한 것 중 실제 Positive 비율 = TP/(TP+FP)
· 재현율(민감도): 실제 Positive 중 Positive로 맞춘 비율 = TP/(TP+FN)
· 특이도: 실제 Negative 중 Negative로 맞춘 비율 = TN/(TN+FP)
[구분] 기출 함정: "실제 Positive인 경우에 Positive로 예측한 것"을 묻는 질문의 정답은 재현율(Recall)이지 정밀도가 아님(8회 기출 64번) - "실제 기준"이면 재현율, "예측 기준"이면 정밀도
[치트키] "재현율=실제 P 중에서 맞춘 비율(실제 기준), 정밀도=예측 P 중에서 맞춘 비율(예측 기준)"
[예문] 암 환자를 놓치면 안 되는 상황(FN 최소화)에서는 재현율(Recall)을 가장 우선적으로 고려해야 한다

F1 Score
정밀도와 재현율의 균형을 나타내는 조화평균 지표
[구성] F1 = 2×(Precision×Recall)/(Precision+Recall)
[의미] 정밀도(Precision)와 재현율(Recall)의 조화평균으로 계산되는 지표. 두 지표가 Trade-off 관계일 때 균형점을 보여줌
[구분] 기출 함정: F1 Score가 "정확도와 재현율의 조화평균"이라거나 "정밀도와 특이도의 조화평균"이라는 지문은 틀림 → 정확히 "정밀도(Precision)와 재현율(Recall)"의 조화평균이 정답(4월 기출 72번)
[치트키] "F1 = 정밀도와 재현율 둘 다 챙기는 균형잡힌 점수"
[예문] 클래스 불균형 데이터에서는 정확도보다 F1 Score로 모델 성능을 평가하는 것이 더 적절하다

ROC 커브 & AUC
이진 분류 모델의 성능을 시각화하는 그래프와 그 아래 면적
[구성] ROC(Receiver Operating Characteristic) Curve + AUC(Area Under the Curve)
[의미] 모든 분류 임계값(threshold)에 대해 모델 성능 변화를 시각화. 가로축=FPR(1-특이도), 세로축=TPR(민감도, 재현율)
[구분] 기출 함정: "AUC가 작을수록 모델 성능이 좋다" 또는 "AUC 값은 0.5에 가까울수록 성능이 우수하다" → 둘 다 틀림! 실제로는 "AUC가 1에 가까울수록(면적이 클수록)" 성능이 좋음(8회 기출 66번, 4월 기출 67번)
[구분] 기출 함정: "무작위의 경우 TPR과 FPR은 같은 곳으로 수렴한다" → 옳은 설명(무작위 분류기는 대각선을 그림, AUC=0.5)
[구분] 클래스 분포가 불균일할 때도 객관적으로 성능을 평가할 수 있는 지표
[치트키] "ROC 커브 면적(AUC)이 1에 가까울수록 굿, 0.5면 찍기랑 다를바 없음(대각선)"
[예문] AUC가 0.9인 모델은 AUC가 0.6인 모델보다 분류 성능이 우수하다고 평가된다

이익 도표 (Lift Table) & 향상도 곡선
불균형 데이터에서 성과 향상도를 등급별로 파악하는 도표
[구성] 이익 도표(Lift Table) / 향상도 곡선(Lift Curve)
[의미] 불균형 데이터 집합에서 성과 향상도를 각 등급별로 파악할 수 있는 도표. 향상도 곡선은 이 이익도표를 시각화한 곡선
[구분] ROC/AUC와 마찬가지로 분류모델 평가에 쓰이지만, Lift Table은 특히 "불균형 데이터"에 특화되어 각 등급(구간)별 향상 정도를 볼 수 있다는 점이 특징
[치트키] "이익도표 = 상위 몇 %를 타겟팅했을 때 얼마나 이득을 보는지 등급별로 보여줌"
[예문] 마케팅 캠페인에서 상위 10% 고객만 타겟팅했을 때의 반응률 향상도를 이익도표로 확인할 수 있다

회귀모델 평가지표 (MSE/MAE/RMSE/결정계수)
회귀모델의 예측 성능을 측정하는 손실함수와 지표들
[구성] MSE / MAE / RMSE / MPE / MAPE / 결정계수(R²)
[의미]
· MSE(평균제곱오차): (1/n)Σ(yi-ŷi)²
· MAE(평균절대오차): (1/n)Σ|yi-ŷi|
· RMSE: MSE에 제곱근
· MPE(평균백분율오차): (100%/n)Σ((yi-ŷi)/yi) - 부호가 있어 양수·음수 오차가 상쇄될 수 있음
· MAPE(평균절대백분율오차): (1/n)Σ|(yi-ŷi)/yi|
[구분] 기출 함정: 수식 중 옳지 않은 것 찾기 문제에서 MPE 공식의 분자가 (yi-ŷi)가 아니라 (ŷi-yi)순서 등으로 뒤바뀌어 출제됨 → 각 공식의 분자·분모 순서를 정확히 암기(4월 기출 65번)
[치트키] "MSE(제곱오차평균)-MAE(절대오차평균)-RMSE(MSE에 루트)-MAPE(절대오차를 %로)"
[예문] 이상치에 민감한 MSE와 달리, MAE는 절댓값을 사용해 이상치의 영향을 상대적으로 덜 받는다

군집분석 평가지표 (실루엣 계수 & Dunn Index)
군집화 결과가 얼마나 잘 되었는지 평가하는 지표 (암기: 군집 내 유사, 군집 간 분리)
[구성] 실루엣 계수(Silhouette Coefficient) / Dunn Index(DI)
[의미]
· 실루엣 계수: -1~1 사이 값, 1에 가까울수록 잘 된 군집화(보통 0.5보다 크면 타당한 것으로 평가)
· Dunn Index: 값이 클수록 군집화가 잘 되었다고 평가(군집 간 거리는 크게, 군집 내 거리는 작게)
[구분] 두 지표 모두 "군집 내부는 가깝게(유사), 군집 간에는 멀게(분리)" 되었는지를 평가한다는 공통 원리
[치트키] "실루엣계수=1에 가까울수록 굿(0.5 넘으면 합격), Dunn Index=클수록 굿"
[예문] 실루엣 계수가 0.7로 나왔다면 군집화가 잘 되었다고 평가할 수 있다

교차 검증 (Cross Validation) 4종
모델의 일반화 성능을 평가하는 4가지 검증 방법
[구성] 홀드아웃(Hold-out) / K-fold 교차검증 / LOOCV / 붓스트랩(Bootstrap)
[의미]
· 홀드아웃: 훈련용, 평가용(테스트) 데이터셋으로 단순 분리
· K-fold 교차검증: 데이터를 K개 집단으로 구분하여 K-1개는 학습용, 나머지 1개는 평가용으로 사용하는 과정을 K번 반복(각 폴드가 딱 한번씩 검증용으로 사용됨)
· LOOCV(Leave-One-Out): 1개의 데이터만 평가용, 나머지 전부로 학습(K-fold의 극단적인 형태, K=n인 경우)
· 붓스트랩: 복원추출(데이터 부족과 불균형 문제 해소)
[구분] 기출 함정: "데이터셋은 행으로만 나눈다"는 K-fold 관련 지문에서 오답으로 나올 수 있음(4월 기출 68번), "각각 한 번씩만 검증용으로 사용된다"가 K-fold의 핵심 특징
[치트키] "홀드아웃(딱 한번 나눔)-K폴드(K번 나눠서 돌아가며 검증)-LOOCV(1개씩만 검증, K폴드의 끝판왕)-붓스트랩(복원추출로 여러 세트 생성)"
[예문] 데이터가 적을 때 LOOCV를 사용하면 거의 모든 데이터를 학습에 활용할 수 있지만 계산 비용이 크다

적합도 검정 (정규성 검정 4종)
데이터가 특정 분포(주로 정규분포)를 따르는지 확인하는 검정
[구성] Q-Q plot / 카이제곱 검정 / 샤피로-윌크 검정 / 콜모고로프-스미르노프 검정
[의미]
· Q-Q plot: 데이터 정규성을 시각적으로 파악(대각선을 따라 값들이 분포하면 정규성 만족)
· 샤피로-윌크 검정: p-value가 0.05보다 크면 정규성 가정 충족
· 콜모고로프-스미르노프 검정: 누적분포함수를 비교한 연속형 데이터 검정, p-value가 0.05보다 크면 정규성 가정
[구분] 기출 함정: "t-test"는 정규성 검정 방법에 해당하지 않음(4월 기출 50번 정답) → t-test는 "평균 비교" 검정이지 "분포 확인" 검정이 아님
[구분] 지도학습 모델의 적합도 검정에서 "자기상관성"도 함께 확인할 항목(4월 기출 69번)
[치트키] "정규성 검정 = Q-Q플롯(그림으로), 샤피로윌크·콜모고로프스미르노프(p-value로 판단), t-test는 정규성 검정이 아님!"
[예문] Shapiro-Wilk 검정에서 p-value가 0.05보다 크면 데이터가 정규분포를 따른다고 가정할 수 있다

하이퍼파라미터 튜닝 (그리드/랜덤/베이지안 서치)
최적 하이퍼파라미터를 찾는 탐색 방법들
[구성] 메뉴얼 서치(경험/감으로 설정) / 그리드 서치 / 랜덤 서치 / 베이지안 최적화
[의미]
· 그리드 서치: 사용자가 지정한 하이퍼파라미터 값들의 "모든 조합"을 체계적으로 탐색
· 랜덤 서치: 탐색 공간에서 무작위로 하이퍼파라미터 조합을 선택해 검증
· 베이지안 최적화: 베이즈 정리를 기반으로 이전 탐색 결과(기존 평가 결과)를 활용해 다음 탐색 지점을 결정
[구분] 기출 함정: "그리드 서치는 항상 가장 짧은 시간 안에 최적의 하이퍼파라미터를 찾을 수 있다" → 틀림! 그리드 서치는 모든 조합을 다 탐색하므로 오히려 "시간이 오래 걸림"(4월 기출 62번)
[치트키] "그리드=다 해봄(전수조사), 랜덤=무작위로 찍어봄, 베이지안=이전 결과 보고 똑똑하게 다음 지점 선택"
[예문] 하이퍼파라미터 조합이 매우 많을 때는 그리드 서치보다 랜덤 서치나 베이지안 최적화가 시간상 효율적이다

Batch Size / Epoch / Iteration
딥러닝 학습에서 데이터를 나누고 반복하는 단위 개념
[구성] Batch Size / Epoch / Iteration
[의미]
· Batch Size: 하나의 소그룹(배치)에 속하는 데이터 수
· Epoch: 모든 데이터셋을 학습하는 횟수(전체 데이터를 한 번 다 훑으면 1 Epoch)
· Iteration: 1 Epoch를 마치기 위해 필요한 배치(Batch) 수
[구분] 관계식: Iteration = 전체 데이터 수 / Batch Size (한 Epoch 안에 몇 번의 파라미터 업데이트가 일어나는지)
[치트키] "배치사이즈(한 묶음 크기)-에폭(전체 한바퀴 도는 횟수)-이터레이션(한바퀴 돌 때 몇 번 나눠 도나)"
[예문] 데이터가 1000개이고 배치 크기가 100이면, 1 Epoch를 마치기 위한 Iteration은 10번이다

과대적합 vs 과소적합
모델이 데이터를 학습하는 정도에 따른 두 가지 문제
[구성] 과대적합(Overfitting) / 과소적합(Underfitting)
[의미]
· 과대적합: 모델이 훈련 데이터를 지나치게 학습해 매우 복잡해진 모형(훈련 오차는 낮지만 검증 오차는 높음)
· 과소적합: 데이터를 충분히 설명하지 못하는 단순한 모델(훈련 오차, 검증 오차 모두 높음)
[구분] 기출 함정: "학습 곡선에서 훈련 오차와 검증 오차가 모두 높은 수준에서 수렴"하면 → 과소적합(Underfitting)을 의미(모델 표현력 부족), 과대적합이 아님(4월 기출 63번)
[구분] 기출 함정: "훈련 데이터의 수가 많을수록 과적합이 발생하기 쉽다"는 틀림 → 반대로 데이터가 "적고" 모델이 복잡할 때 과적합 발생 쉬움(4월 기출 75번)
[치트키] "과대적합=너무 외워서 실전에 약함(훈련↓검증↑), 과소적합=아예 못 배움(둘 다 높음)"
[예문] 훈련 오차는 계속 감소하는데 검증 오차가 특정 시점부터 증가하기 시작하면 과적합이 발생한 것이다

과적합 방지 방안
모델의 과적합을 완화하는 일반적인 방법들
[구성] 훈련 데이터 증가 / 규제(Regularization) / 드롭아웃(Dropout) / 조기종료 / 매개변수 감소
[의미] 훈련 데이터의 양을 늘리거나, 모델에 규제를 적용해 복잡도를 낮추거나, 학습 시 일부 뉴런을 비활성화(드롭아웃)하는 등의 방법으로 과적합을 완화
[구분] 기출 함정: "매개변수를 늘린다"는 과적합 방지 방안이 아님(오히려 모델을 더 복잡하게 만들어 과적합을 유발) → "매개변수를 줄이는 것"이 방지 방안(4월 기출 71번)
[구분] "ReLU를 사용하여 학습 속도를 높인다"는 과적합 방지와 직접 관련 없는 설명(4월 기출 43번, 활성화함수는 속도/기울기소실 문제와 관련)
[치트키] "과적합 방지 = 데이터 늘리기, 규제 걸기, 일부 꺼두기(드롭아웃), 일찍 멈추기(조기종료), 모델 단순화(매개변수 감소)"
[예문] 훈련 데이터가 부족한 상황에서는 데이터 증강을 통해 과적합을 완화할 수 있다

파라미터 vs 하이퍼파라미터
모델이 스스로 학습하는 값과 사용자가 직접 설정하는 값의 구분
[구성] 파라미터(Parameter) / 하이퍼파라미터(Hyperparameter)
[의미]
· 파라미터: 모델이 훈련 데이터를 통해 스스로 학습하여 찾아내는 값(예: 회귀계수, 신경망 가중치), 경사하강법으로 추정 가능
· 하이퍼파라미터: 학습 전에 사용자가 직접 설정하는 값(예: 학습률, 은닉층 수, K값), 학습 중에 변하지 않음
[구분] 기출 함정: "인공신경망의 가중치(weights)와 KNN의 k값은 모두 대표적인 하이퍼파라미터이다" → 틀림! 가중치(weights)는 파라미터, K값이 하이퍼파라미터(4월 기출 47번)
[치트키] "파라미터=모델이 스스로 찾는 값(가중치), 하이퍼파라미터=사람이 미리 정해주는 값(K값, 학습률)"
[예문] 선형 회귀 모델의 회귀 계수는 파라미터에, 의사결정나무의 최대 깊이는 하이퍼파라미터에 해당한다

주성분 분석 결과 해석 (스크리플롯)
PCA 결과를 해석하고 주성분 개수를 선택하는 방법
[구성] Standard Deviation / Proportion of Variance / Cumulative Proportion + 스크리플롯(Scree Plot)
[의미] 첫번째 주성분(PC1)의 분산이 가장 크며, 여러 주성분을 누적하면 전체 데이터의 분산을 몇 %까지 설명하는지 확인 가능
[구분] 스크리플롯: 주성분 개수 선택에 도움 되는 그래프(팔꿈치 기법 이용) - 그래프가 완만해지기 직전 단계의 개수로 선택
[구분] Cumulative Proportion 표에서 특정 PC까지의 누적 분산비율을 읽어 "전체분산의 몇 %를 설명하는지" 계산하는 문제가 자주 출제됨
[치트키] "스크리플롯 = 팔꿈치처럼 꺾이는 지점 직전까지가 적정 주성분 개수"
[예문] 누적 분산 비율표에서 PC3까지의 값이 0.938이면, 3개의 주성분으로 전체 데이터의 93.8%를 설명할 수 있다는 의미다

회귀모형 검정결과 해석 (F통계량 & t통계량)
회귀분석 결과표를 해석하는 핵심 절차
[구성] F통계량(모형 전체 유의성) + t통계량(개별 회귀계수 유의성)
[의미]
① 모형이 통계적으로 유의미한가: F통계량, p-value로 판단(귀무가설: '모든 회귀계수는 0이다')
② 회귀계수들이 유의미한가: t통계량, p-value로 판단(귀무가설: '회귀계수는 0이다')
③ 1번과 2번 모두 귀무가설이 기각되면 해당 모델을 활용
④ 모형이 설명력을 갖는가 = 결정계수(R square) 값으로 판단
[구분] p-value가 유의수준(보통 0.05)보다 "작으면" 귀무가설 기각(유의미함), "크면" 귀무가설 채택(유의하지 않음 → 해당 변수는 재검토 필요)
[치트키] "F통계량=모형 전체가 쓸모있나, t통계량=각 변수가 쓸모있나, 둘다 p-value<0.05면 통과"
[예문] age 변수의 p-value가 0.05보다 작아 회귀계수가 유의미하지만, no_siblings의 p-value가 0.851로 크므로 이 변수는 제외하고 재분석하는 것이 좋다

시각화 유형 4분류 (시간/공간/관계/비교)
데이터 시각화를 목적에 따라 나눈 4가지 분류
[구성] 시간 시각화 / 공간 시각화 / 관계 시각화 / 비교 시각화
[의미]
· 시간 시각화: 막대, 점, 선, 계단식(시간 흐름에 따른 변화)
· 공간 시각화: 등치지역도, 카토그램, 등치선도, 버블 플롯(지리적 위치와 관련된 데이터)
· 관계 시각화: 산점도, 버블차트, 히트맵, 히스토그램, 파이플롯, 트리맵(데이터 사이 관계·분포·패턴 표현)
· 비교 시각화: 히트맵, 체르노프 페이스, 스타차트, 평행좌표계(여러 변수 간 차이·유사성 비교)
[구분] 히트맵은 "관계 시각화"와 "비교 시각화" 둘 다에 해당될 수 있다는 점에 주의(맥락에 따라 다름)
[치트키] "시간(흐름)-공간(지도)-관계(산점도류)-비교(여러 변수 한눈에)"
[예문] 여러 나라의 GDP, 인구, 교육수준을 한눈에 비교하려면 평행좌표계나 스타차트 같은 비교 시각화가 적합하다

카토그램 vs 등치지역도 vs 등치선도
공간 데이터를 표현하는 지도 기반 시각화 기법들
[구성] 카토그램(Cartogram) / 등치지역도(Choropleth Map) / 등치선도(Isarithmic Map)
[의미]
· 카토그램: 실제 면적이 아니라 특정 값(예: 인구, 선거 결과)의 크기에 비례해 지역 크기를 왜곡해서 표현
· 등치지역도: 지역을 색상 농도로 구분해 값의 크기를 표현(예: 인구밀도 지도)
· 등치선도: 동일한 값을 가진 지점을 선으로 연결(예: 등고선, 기온선)
[구분] 기출 함정: "국회의원 선거에서 지역 면적이 아니라 지역구에 당선된 국회의원 수에 따라 시각화" → 정답은 격자 카토그램(실제 면적이 아닌 다른 값 기준으로 크기 왜곡, 4월 기출 76번)
[치트키] "카토그램=면적을 값에 맞게 왜곡, 등치지역도=색깔 농도로 표현, 등치선도=같은 값끼리 선으로 연결"
[예문] 각 지역의 실제 면적 대신 인구수에 비례해 지역을 확대·축소해 그리는 지도는 카토그램이다

인포그래픽 (Infographic)
정보와 시각적 형상을 결합해 설득형 메시지를 전달하는 콘텐츠
[구성] 인포(Information, 정보) + 그래픽(Graphic, 시각적 형상)
[의미] 데이터, 정보, 지식을 시각적으로 표현해 독자의 빠르고 쉬운 이해를 돕는 콘텐츠. 패턴 발견보다 "일반인에게 설득형 메시지 전달"이 목적. 유형: 타임라인(시간순 나열), 컨셉맵(주제-내용 간 연관성)
[구분] 기출 함정: "데이터 시각화와 완전히 동일한 개념으로, 어떤 데이터 시각화든 인포그래픽이라고 할 수 있다" → 틀림! 인포그래픽은 데이터 시각화의 "부분집합"에 가까우며, 목적(설득·전달)에서 일반 시각화와 결이 다름(4월 기출 79번)
[구분] 지역별 코로나 발생률 = 지도형(카토그램 등) / 월별 코로나 발생률 = 타임라인형(시간 순 나열)
[치트키] "인포그래픽 = 정보(Info)+그림(Graphic), 목적은 '설득·전달'이지 '패턴 발견'이 아님"
[예문] 회사 연혁을 시각적으로 정리한 타임라인형 인포그래픽은 정보 전달과 마케팅 목적으로 함께 활용된다

관계형 시각화에 해당하지 않는 것 (히스토그램 예외 함정)
두 변수 간의 관계를 파악하는 관계형 시각화 vs 단일 변수 분포를 보는 시각화
[구성] 관계형 시각화: 산점도(Scatter Plot), 버블차트(Bubble Chart), 히트맵(Heatmap) / 분포 시각화: 히스토그램(Histogram)
[의미] 관계형 시각화는 "두 개 이상 변수 간의 관계"를 파악하는 것이 목적, 히스토그램은 "하나의 변수의 분포"를 보는 것이 목적이라는 차이
[구분] 기출 함정: 관계형 시각화에 해당하지 않는 것을 고르는 문제에서 정답은 히스토그램(4월 기출 80번) - 산점도/버블차트/히트맵은 관계형, 히스토그램은 분포형이라는 차이를 명확히 구분
[치트키] "관계형=두 변수 사이 관계(산점도,버블,히트맵), 분포형=한 변수의 분포(히스토그램)"
[예문] 키와 몸무게의 관계를 보려면 산점도, 나이 분포만 보려면 히스토그램을 사용한다
