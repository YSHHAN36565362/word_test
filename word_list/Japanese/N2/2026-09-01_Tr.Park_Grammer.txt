のに
~는데(도)(のに)
[종합] 역접·불만·의외를 나타내는 조사. 앞의 내용에서 당연히 예상되는 결과와 다른 결과가 나왔을 때, 아쉬움이나 불만의 뉘앙스를 담아 사용함
[치트키] "노니! 노력했는데도 니(너무해) 결과가 안 좋다" → のに=노니→~는데도
[장면] 우산을 챙겼는데도 비를 쫄딱 맞고 투덜대는 장면
[예문] 頑張ったのに、失敗した(간밧타노니, 싯파이시타) = "열심히 했는데도 실패했다"

〜さえ
~조차, ~마저(さえ)
[종합] 극단적인 예를 들어 "그것마저도 그러하니 다른 것은 말할 것도 없다"는 뉘앙스를 강조하는 조사. 명사·동사 등에 접속하여 "~조차, ~마저"의 의미를 더함
[치트키] "사에! 사소한 것사에 놓쳤다" → さえ=사에→~조차
[장면] 전문가조차 풀지 못하는 어려운 문제를 마주한 장면
[예문] 子供さえ知っている(코도모사에 싯테이루) = "아이조차 알고 있다"

〜さえ〜ば
~하기만 하면(さえば)
[종합] 「さえ」와 가정형 「〜ば」가 결합한 문형으로, 다른 조건은 다 필요 없고 오직 그 한 가지 조건만 충족되면 됨을 강조하는 표현
[치트키] "사에바! 사(이것)사에 있으바(있으면) 충분해" → さえば=사에바→~하기만 하면
[장면] 딱 하나의 재료만 있으면 요리가 완성되는 상황
[예문] 時間さえあれば行ける(지칸사에 아레바 이케루) = "시간만 있으면 갈 수 있다"

〜次第だ
~에 달려있다(しだいだ)
[읽기] 次=シ + 第=ダイ → しだい (음독) + だ(단정 조동사)
[한자1] 次 (버금 차 / 다음, 순서)
· 음독: ★シ, ジ
· 훈독: つぎ, つ-ぐ
· 분해: 二(둘, 벌린 입김) + 欠(하품하듯 입을 벌린 사람)
· 어원: 사람이 숨을 내쉬며(欠) 차례로 이어지는(二) 모습에서 버금, 순서를 나타냄
· 예시 단어: 次回 (다음번, じ+かい)
[한자2] 第 (차례 제 / 차례, 등급)
· 음독: ★ダイ
· 훈독: 없음
· 분해: 竹(대나무) + 弟(아우 제, 위에서 아래로 차례로 감긴 줄)
· 어원: 대나무(竹) 마디처럼 순서대로(弟) 매겨진 것에서 차례, 등급을 나타냄
· 예시 단어: 第一 (제일, だい+いち)
[종합] 순서(次)와 등급(第)이 합쳐진 「次第」에 だ가 붙어, 어떤 결과가 앞의 조건이나 상황의 흐름에 따라 정해짐을 뜻하는 문형이 됨
[치트키] "시다이다! 시(시험)는 다이(그대)의 노력 시다이다" → 次第だ=시다이다→~에 달려있다
[장면] 노력한 만큼 결과가 달라지는 시험 성적표를 받는 장면
[예문] 結果は君の努力次第だ(켓카와 키미노 도료쿠 시다이다) = "결과는 너의 노력에 달려있다"

〜せずに
~하지 않고(せずに)
[종합] 「する」의 부정형 「せず」에 「に」가 붙은 형태로, 어떤 행동을 하지 않은 채 다음 동작으로 이어짐을 나타내는 다소 문어체적인 표현
[치트키] "세즈니! 세(하지) 즈니(않고) 그냥 간다" → せずに=세즈니→하지 않고
[장면] 우산을 쓰지 않고 그대로 비를 맞으며 걷는 장면
[예문] 何も言わずに帰った(나니모 이와즈니 카엣타) = "아무 말도 하지 않고 돌아갔다"

〜たとたん（に）
~하자마자(とたんに)
[읽기] 途=と + 端=たん + に → とたんに (음독, 途端の「途」+「端」)
[한자1] 途 (길 도 / 길, 도중)
· 음독: ★ト
· 훈독: 없음
· 분해: 辶(가다) + 余(남을 여, 나머지 — 지붕 아래 사람이 여유롭게 쉬는 모습)
· 어원: 여유를 두고 나아가는(辶) 길의 모습에서 도중, 길을 나타냄
· 예시 단어: 途中 (도중, と+ちゅう)
[한자2] 端 (끝 단 / 끝, 처음)
· 음독: ★タン
· 훈독: はし, はた, は
· 분해: 立(설 립) + 耑(뿌리와 싹, 식물이 뻗어난 모습)
· 어원: 식물이 뿌리내려 서 있는(立) 시작점과 끝(耑)에서 끝, 처음을 나타냄
· 예시 단어: 端末 (단말, たん+まつ)
[종합] 途(길, 과정)의 端(끝)이라는 뜻의 명사 「途端」에 「〜た」가 붙어, 어떤 동작이 끝난 바로 그 순간 다음 일이 일어남을 나타내는 문형이 됨
[치트키] "토탄니! 토(길)의 탄(끝)에 니(바로) 일어난다" → たとたん(に)=토탄니→하자마자
[장면] 문을 연 순간 갑자기 비가 쏟아지기 시작하는 장면
[예문] 家を出たとたんに雨が降り出した(이에오 데타 토탄니 아메가 후리다시타) = "집을 나서자마자 비가 내리기 시작했다"

たまらない
견딜 수 없다(たまらない)
[읽기] 堪る(たまる)의 부정형 → たまらない (훈독) ※한자 堪는 일상적으로 가나로 표기
[한자1] 堪 (견딜 감 / 견디다)
· 음독: カン
· 훈독: た-える, たま-る
· 분해: 土(흙) + 甚(심할 심 — 甘(달 감) + 匹(짝, 발음요소))
· 어원: 흙(土)이 심하게(甚) 짓눌려도 버텨내는 모습에서 견디다를 나타냄
· 예시 단어: 堪忍 (감인, かん+にん)
[종합] 堪る(견디다)의 부정형에 강조 뉘앙스가 더해져, 감정이나 감각이 정도를 넘어서 도저히 참을 수 없을 만큼 강함을 나타내는 표현이 됨
[치트키] "타마라나이! 타마(구슬)처럼 라나이(굴러떨어질 만큼) 못 참겠다" → たまらない=타마라나이→견딜 수 없다
[장면] 너무 맛있는 냄새에 참지 못하고 침을 삼키는 장면
[예문] 眠くてたまらない(네무쿠테 타마라나이) = "졸려서 견딜 수 없다"

仕様がない
어쩔 수 없다(しょうがない)
[읽기] 仕=し + 様=よう → しよう → しょう(음편/축약) + が + ない → しょうがない
[한자1] 仕 (섬길 사 / 섬기다, 일하다)
· 음독: ★シ, ジ
· 훈독: つか-える
· 분해: 亻(사람) + 士(선비)
· 어원: 사람(亻)이 윗사람인 선비(士)를 섬기는 모습에서 섬기다, 일하다를 나타냄
· 예시 단어: 仕事 (일, し+ごと)
[한자2] 様 (모양 양 / 모습, 방법)
· 음독: ヨウ
· 훈독: ★よう, さま
· 분해: 木(나무) + 羊(양) + 永(길 영, 흐름)
· 어원: 나무(木)가 자라나는 여러 모양에서 모습, 방법을 나타냄
· 예시 단어: 様子 (모습, よう+す)
[종합] 仕(할) 様(방법)이 없다는 뜻의 「仕様がない」가 음편으로 축약되어 「しょうがない」가 되었으며, 더 이상 손쓸 방법이 없어 체념함을 나타냄
[치트키] "쇼-가나이! 쇼(할) 방법이 나이(없다)" → 仕様がない=쇼-가나이→어쩔 수 없다
[장면] 버스를 놓치고 어깨를 으쓱하며 체념하는 장면
[예문] 遅れても仕様がない(오쿠레테모 쇼-가나이) = "늦어도 어쩔 수 없다"

しかない
~할 수밖에 없다(しかない)
[종합] 조사 「しか」(~밖에)에 부정 「ない」가 결합한 문형으로, 다른 선택지가 전혀 없이 오직 그 하나의 방법·상태뿐임을 강조함
[치트키] "시카나이! 시카(사슴)나이(밖에 없어) 이것뿐" → しかない=시카나이→~할 수밖에 없다
[장면] 막차를 놓쳐 걸어가는 방법밖에 남지 않은 상황
[예문] 歩くしかない(아루쿠시카나이) = "걸을 수밖에 없다"

ならない
안 된다, 되지 않는다(ならない)
[읽기] 成る(なる)의 부정형 → ならない (훈독)
[한자1] 成 (이룰 성 / 이루다, 되다)
· 음독: セイ, ジョウ
· 훈독: ★な-る
· 분해: 戊(도끼, 무기) + 丁(못, 완성)
· 어원: 도끼(戊)로 다듬어 완성해(丁) 내는 모습에서 이루다, 되다를 나타냄
· 예시 단어: 成功 (성공, せい+こう)
[종합] 成る(되다)의 부정형으로, 단독으로는 "되지 않는다"는 뜻이지만 「〜てはならない」「〜なければならない」같은 문형에 쓰여 금지·의무를 나타내는 문법 요소로 널리 쓰임
[치트키] "나라나이! 나라(그렇게) 나이(되면 안 돼)" → ならない=나라나이→안 된다
[장면] 표지판에 "출입금지"라고 쓰여 문을 막는 장면
[예문] 遅刻してはならない(치코쿠시테와 나라나이) = "지각해서는 안 된다"

おかげで
덕분에(おかげで)
[읽기] ※원문 표기 "おかげて"는 오기로 판단하여 「おかげで」로 처리. 御(お) + 陰(かげ) + で (한자 御陰로도 표기 가능하나 관용적으로 가나 표기)
[한자1] 陰 (그늘 음 / 그늘, 보이지 않는 도움)
· 음독: イン
· 훈독: ★かげ
· 분해: 阝(언덕) + 侌(그늘질 음 — 今(이제) + 云(구름))
· 어원: 언덕(阝)에 구름(云)이 낀 지금(今)의 날씨가 그늘진 모습에서 그늘, 보이지 않는 도움을 나타냄
· 예시 단어: 陰口 (뒷담화, かげ+ぐち)
[종합] 「御(존경 접두사)+陰(그늘, 보이지 않는 도움)+で」가 결합해, 남이 눈에 띄지 않게 베푼 도움이나 배려 덕분임을 겸손하게 나타내는 표현이 됨
[치트키] "오카게데! 오(오, 이) 카게(그늘)데 덕분에" → おかげで=오카게데→덕분에
[장면] 도와준 친구에게 고개 숙여 진심으로 감사 인사를 하는 장면
[예문] 先生のおかげで合格した(센세-노 오카게데 고-카쿠시타) = "선생님 덕분에 합격했다"

〜ということだ
~라고 한다, ~라는 것이다(ということだ)
[읽기] という + こと(事) + だ → ということだ (훈독)
[한자1] 事 (일 사 / 일, 것)
· 음독: ジ, ズ
· 훈독: ★こと
· 분해: 손에 붓이나 깃발을 든 모습을 본뜬 상형자
· 어원: 손에 문서를 들고 관청의 일을 처리하는 모습에서 일, 사물을 나타냄
· 예시 단어: 仕事 (일, し+ごと)
[종합] 「という(~라고 하는)」에 「こと(것)+だ(단정)」이 결합해, 전해 들은 정보나 소문을 인용하여 전달할 때 쓰는 문형이 됨
[치트키] "토이우코토다! 토(그렇다) 이우(말하는) 코토다(것이다)" → ということだ=토이우코토다→~라고 한다
[장면] 뉴스에서 들은 소식을 친구에게 그대로 전해주는 장면
[예문] 明日は雨だということだ(아시타와 아메다토 이우 코토다) = "내일은 비가 온다고 한다"

〜といった
~와 같은, ~라고 하는(といった)
[읽기] と + 言った(いった) → といった (훈독)
[한자1] 言 (말씀 언 / 말하다)
· 음독: ゲン, ゴン
· 훈독: ★い-う
· 분해: 辛(매울 신, 형벌 도구) + 口(입)
· 어원: 입(口)으로 죄를 자백하는 모습에서 말하다를 나타냄
· 예시 단어: 言葉 (말, こと+ば)
[종합] 「〜と言った(~라고 말한)」에서 유래하여, 구체적인 예를 몇 가지 들며 "~와 같은, ~라고 하는" 것들을 예시로 나열할 때 쓰는 문형이 됨
[치트키] "토잇타! 토(그) 잇타(말한) 것과 같은" → といった=토잇타→~와 같은
[장면] 사과, 배와 같은 과일들을 손으로 가리키며 소개하는 장면
[예문] りんごやみかんといった果物(링고야 미칸토 잇타 쿠다모노) = "사과나 귤과 같은 과일"

〜ないことはない
~하지 않는 것은 아니다(ないことはない)
[읽기] ない + こと(事) + は + ない → ないことはない (훈독)
[한자1] 事 (일 사 / 일, 것)
· 음독: ジ, ズ
· 훈독: ★こと
· 분해: 손에 붓이나 깃발을 든 모습을 본뜬 상형자
· 어원: 손에 문서를 들고 관청의 일을 처리하는 모습에서 일, 것을 나타냄
· 예시 단어: 大事 (중요, だい+じ)
[종합] 부정(〜ない)을 두 번 겹쳐 「〜ない+こと+は+ない」의 이중부정 구조로, 완전히 그렇다고 할 수는 없지만 가능성이나 여지가 어느 정도 있음을 완곡하게 나타내는 문형
[치트키] "나이코토와나이! 나이(없는) 코토와(것은) 나이(아니다)" → ないことはない=나이코토와나이→하지 않는 것은 아니다
[장면] 어렵지만 시간을 들이면 할 수도 있다며 고민하는 장면
[예문] 忙しいが、行けないことはない(이소가시이가, 이케나이 코토와 나이) = "바쁘지만 못 갈 것도 없다"

〜に違いない
~임에 틀림없다(にちがいない)
[읽기] に + 違い(ちがい, 훈독) + ない → にちがいない
[한자1] 違 (어긋날 위 / 어긋나다, 다르다)
· 음독: イ
· 훈독: ★ちが-う
· 분해: 辶(가다) + 韋(어긋날 위 — 큰 성(囗) 둘레를 서로 반대 방향으로 도는 발자국(舛의 변형))
· 어원: 방향이 어긋나게(韋) 가는(辶) 모습에서 어긋나다, 다르다를 나타냄
· 예시 단어: 相違 (상위, そう+이)
[종합] 違い(다름, 어긋남)에 강한 부정 ない가 붙어, 다를 가능성이 없다는 뜻에서 강한 확신을 나타내는 "~임에 틀림없다"는 문형이 됨
[치트키] "니 치가이나이! 니(너는) 치가이(다름이) 나이(없어) 틀림없어" → に違いない=니치가이나이→~임에 틀림없다
[장면] 범인의 정황증거를 보고 확신에 찬 표정으로 단정 짓는 탐정
[예문] 彼が犯人に違いない(카레가 한닌니 치가이나이) = "그가 범인임에 틀림없다"

次第で
~에 따라(しだいで)
[읽기] 次=シ + 第=ダイ → しだい (음독) + で(조사)
[한자1] 次 (버금 차 / 다음, 순서)
· 음독: ★シ, ジ
· 훈독: つぎ, つ-ぐ
· 분해: 二(둘, 벌린 입김) + 欠(하품하듯 입을 벌린 사람)
· 어원: 사람이 숨을 내쉬며(欠) 차례로 이어지는(二) 모습에서 버금, 순서를 나타냄
· 예시 단어: 目次 (목차, もく+じ)
[한자2] 第 (차례 제 / 차례, 등급)
· 음독: ★ダイ
· 훈독: 없음
· 분해: 竹(대나무) + 弟(아우 제, 위에서 아래로 차례로 감긴 줄)
· 어원: 대나무(竹) 마디처럼 순서대로(弟) 매겨진 것에서 차례, 등급을 나타냄
· 예시 단어: 及第 (급제, きゅう+だい)
[종합] 순서(次)와 등급(第)이 결합한 「次第」에 で가 붙어, 상황이나 조건의 흐름에 따라 결과가 달라짐을 나타내는 문형이 됨
[치트키] "시다이데! 시다이(형편)데(따라) 달라진다" → 次第で=시다이데→~에 따라
[장면] 날씨에 따라 소풍 일정이 바뀌는 상황
[예문] 天気次第で中止になる(텐키 시다이데 츄-시니 나루) = "날씨에 따라 중지된다"

わけがない
~할 리가 없다(わけがない)
[읽기] 訳(わけ, 훈독) + が + ない → わけがない
[한자1] 訳 (번역할 역 / 이유, 사정)
· 음독: ヤク
· 훈독: ★わけ
· 분해: 訁(言, 말씀) + 尺(자 척, 재다)
· 어원: 말(訁)을 자로 재듯(尺) 정확히 옮기는 모습에서 번역하다, 나아가 이유, 사정을 나타내는 わけ로 쓰임
· 예시 단어: 通訳 (통역, つう+やく)
[종합] 訳(이유, 사정)에 が+ない가 붙어, 논리적으로 그럴 이유나 가능성이 전혀 없다는 강한 부정을 나타내는 문형이 됨
[치트키] "와케가나이! 와케(이유)가 나이(없다) 그럴 리 없어" → わけがない=와케가나이→~할 리가 없다
[장면] 말도 안 되는 소문에 손사래를 치며 부정하는 장면
[예문] そんなことがあるわけがない(손나 코토가 아루 와케가나이) = "그런 일이 있을 리가 없다"

はずがない
~할 리가 없다(はずがない)
[읽기] 筈(はず, 훈독) + が + ない → はずがない
[한자1] 筈 (오늬 괄 / 화살 끝, 당연히 그럴 예정)
· 음독: カツ
· 훈독: ★はず
· 분해: 竹(대나무) + 舌(혀 설, 좁게 갈라진 모양)
· 어원: 화살대(竹) 끝이 시위에 걸리도록 좁게 갈라진(舌) 부분에서, 당연히 맞아 들어가야 할 예정, 당연함을 나타내는 はず로 쓰임
· 예시 단어: 筈が合う (앞뒤가 맞다, はずがあう)
[종합] 筈(당연함, 예정)에 が+ない가 붙어, 논리적·상식적으로 당연히 그럴 리가 없다는 확신에 찬 부정을 나타내는 문형이 됨
[치트키] "하즈가나이! 하즈(당연)가 나이(없어) 그럴 리 없다" → はずがない=하즈가나이→~할 리가 없다
[장면] 100점 만점에 200점이 나올 리 없다며 놀라는 장면
[예문] 彼が知らないはずがない(카레가 시라나이 하즈가나이) = "그가 모를 리가 없다"

ず에는いられない
~하지 않을 수 없다(ずにはいられない)
[읽기] ※79번과 동일한 문형. ~ず + には + 居られない → ずにはいられない
[한자1] 居 (있을 거 / 있다, 머무르다)
· 음독: キョ
· 훈독: ★い-る
· 분해: 尸(주검, 사람이 몸을 기대고 걸터앉은 모습) + 古(오래됨, 十+口)
· 어원: 사람이 한 자리에 오래도록(古) 몸을 기대고 앉아 있는 모습(尸)에서 있다, 머무르다를 나타냄
· 예시 단어: 居場所 (있을 곳, い+ばしょ)
[종합] 「〜ず(부정)+에는+居られない(있을 수 없다)」가 결합해, 감정이나 충동을 억누르지 못하고 반드시 그 행동을 하게 됨을 강조하는 문형(앞서 나온 「〜ずにはいられにい」의 올바른 표기)
[치트키] "즈니와 이라레나이! 참지 못하고 즈니와 이라레나이(하게 된다)" → ずにはいられない=즈니와이라레나이→하지 않을 수 없다
[장면] 재미있는 이야기를 듣고 웃음을 참지 못하는 장면
[예문] 応援せずにはいられない(오-엔세즈니와 이라레나이) = "응원하지 않을 수 없다"

わけだ
~인 것이다(わけだ)
[읽기] 訳(わけ, 훈독) + だ → わけだ
[한자1] 訳 (번역할 역 / 이유, 도리)
· 음독: ヤク
· 훈독: ★わけ
· 분해: 訁(言, 말씀) + 尺(자 척, 재다)
· 어원: 말(訁)을 자로 재듯(尺) 옮기는 모습에서 이유, 사정을 나타내는 わけ로 쓰임
· 예시 단어: 訳文 (역문, やく+ぶん)
[종합] 訳(이치, 사정)에 だ가 붙어, 앞서 말한 내용을 근거로 논리적으로 당연히 그렇게 된다는 결론을 나타내는 문형이 됨
[치트키] "와케다! 와케(사정이 그런) 것이다" → わけだ=와케다→~인 것이다
[장면] 이유를 듣고 "아, 그래서 그랬구나"하며 고개를 끄덕이는 장면
[예문] だから遅れたわけだ(다카라 오쿠레타 와케다) = "그래서 늦은 것이다"

わけにはいかない
~할 수는 없다(わけにはいかない)
[읽기] 訳(わけ, 훈독) + には + 行かない → わけにはいかない
[한자1] 訳 (번역할 역 / 이유, 도리)
· 음독: ヤク
· 훈독: ★わけ
· 분해: 訁(言, 말씀) + 尺(자 척, 재다)
· 어원: 말(訁)을 자로 재듯(尺) 옮기는 모습에서 이유, 도리를 나타내는 わけ로 쓰임
· 예시 단어: 内訳 (내역, うち+わけ)
[종합] 訳(사정, 도리)에 「에는行かない(그렇게는 갈 수 없다)」가 붙어, 사회통념이나 도리상 그렇게 할 수 없음을 나타내는 문형이 됨
[치트키] "와케니와 이카나이! 와케(도리)니와 이카나이(할 수 없다)" → わけにはいかない=와케니와이카나이→~할 수는 없다
[장면] 아무리 피곤해도 약속을 어길 수는 없어 억지로 나가는 장면
[예문] 約束を破るわけにはいかない(야쿠소쿠오 야부루 와케니와 이카나이) = "약속을 어길 수는 없다"

〜ます+かねる
~하기 어렵다, 할 수 없다(かねる)
[읽기] ます(동사 연용형) + 兼ねる(かねる, 훈독) → 〜かねる
[한자1] 兼 (겸할 겸 / 겸하다)
· 음독: ケン
· 훈독: ★か-ねる
· 분해: 秝(벼 두 포기) + 又(손)
· 어원: 손(又)으로 두 포기 벼(秝)를 한꺼번에 쥐는 모습에서 겸하다, 나아가 동사 뒤에 붙어 "~하기 어렵다"는 뜻을 나타냄
· 예시 단어: 兼業 (겸업, けん+ぎょう)
[종합] 동사의 ます형에 兼ねる(겸하다)가 붙어, 입장이나 감정상 그 행동을 하기가 곤란하고 어려움을 완곡하게 나타내는 문형이 됨
[치트키] "카네루! 카네(겸)해서 하기 카네루(어렵다)" → かねる=카네루→하기 어렵다
[장면] 곤란한 부탁에 난처한 표정으로 말끝을 흐리는 장면
[예문] その要求には応じかねる(소노 요-큐-니와 오-지카네루) = "그 요구에는 응하기 어렵다"

〜ます+かねない
~할지도 모른다(かねない)
[읽기] ます(동사 연용형) + 兼ねない(かねない, 훈독) → 〜かねない
[한자1] 兼 (겸할 겸 / 겸하다)
· 음독: ケン
· 훈독: ★か-ねる
· 분해: 秝(벼 두 포기) + 又(손)
· 어원: 손(又)으로 두 포기 벼(秝)를 한꺼번에 쥐는 모습에서 겸하다를 나타냄
· 예시 단어: 兼任 (겸임, けん+にん)
[종합] かねる(하기 어렵다)의 부정형 「かねない」는 이중부정으로, "~하지 않는다고 할 수 없다" 즉 부정적인 일이 일어날 가능성이 충분히 있음을 우려하는 문형이 됨
[치트키] "카네나이! 카네(할 수도) 나이(없지 않다) 그럴지도" → かねない=카네나이→~할지도 모른다
[장면] 무리하게 운전하면 사고가 날 수도 있다며 걱정하는 장면
[예문] 無理をすると事故になりかねない(무리오 스루토 지코니 나리카네나이) = "무리하면 사고가 날지도 모른다"

どころではない
~할 상황이 아니다(どころではない)
[읽기] 所(どころ, 훈독) + では + ない → どころではない
[한자1] 所 (바 소 / 곳, 장소)
· 음독: ショ
· 훈독: ★ところ
· 분해: 戸(문) + 斤(도끼)
· 어원: 도끼(斤)로 나무를 베어 문(戸)을 내고 자리 잡은 곳에서 장소, 곳을 나타냄
· 예시 단어: 場所 (장소, ば+しょ)
[종합] 所(곳, 상황)에 では+ない가 붙어, 지금은 그런 것을 할 만한 여유나 상황이 전혀 아님을 강하게 부정하는 문형이 됨
[치트키] "도코로데와나이! 도코로(그럴 상황)데와 나이(아니다)" → どころではない=도코로데와나이→~할 상황이 아니다
[장면] 마감에 쫓겨 밥 먹을 정신조차 없는 장면
[예문] 今は旅行どころではない(이마와 료코- 도코로데와 나이) = "지금은 여행할 상황이 아니다"

すぎない
~에 지나지 않다(すぎない)
[읽기] 過ぎる(すぎる, 훈독)의 부정형 → すぎない
[한자1] 過 (지날 과 / 지나다, 초과하다)
· 음독: カ
· 훈독: ★す-ぎる, す-ごす
· 분해: 辶(가다) + 咼(입 비뚤어질 괘, 뼈가 어긋난 모양)
· 어원: 어긋난(咼) 채로 지나가는(辶) 모습에서 정해진 범위를 벗어나 지나치다, 초과하다를 나타냄
· 예시 단어: 通過 (통과, つう+か)
[종합] 過ぎる(지나치다, 초과하다)의 부정형으로, 정도가 딱 그것뿐이며 그 이상은 아니라는 겸손하거나 축소하는 뉘앙스를 나타내는 문형이 됨
[치트키] "스기나이! 스기(지나)나이(지 않다) 딱 그뿐" → すぎない=스기나이→~에 지나지 않다
[장면] 대단한 성과가 아니라 그저 운이 좋았을 뿐이라며 겸손해하는 장면
[예문] これは一例にすぎない(코레와 이치레이니 스기나이) = "이것은 한 예에 지나지 않는다"

がちだ
~하기 십상이다, 자주 ~하다(がちだ)
[읽기] 勝ち(かち, 훈독)가 탁음화되어 がち + だ → がちだ (탁음화/연탁)
[한자1] 勝 (이길 승 / 이기다, 우세하다)
· 음독: ショウ
· 훈독: ★か-つ, ま-さる (「勝ち」가 탁음화되어 ★がち로 쓰임)
· 분해: 月(肉, 몸) + 关(짐 꾸러미, 두 손으로 드는 모습) + 力(힘)
· 어원: 몸(月)과 힘(力)을 다해 짐(关)을 짊어지고 남을 능가하는 모습에서 이기다를 나타내며, 명사형 「勝ち(かち)」가 탁음화되어 접미사 「がち」가 됨
· 예시 단어: 勝ち (승리, かち)
[종합] 원래 「勝ち(우세함, 그런 경향이 두드러짐)」에서 온 접미사로, 어떤 좋지 않은 경향이나 상태가 자주, 쉽게 일어남을 나타내는 「がちだ」가 됨
[치트키] "가치다! 가치(승세)가 그쪽으로 기울어 자주 그런다" → がちだ=가치다→~하기 십상이다
[장면] 바쁘면 아침을 자주 거르게 되는 습관을 반성하는 장면
[예문] 忙しいと朝食を抜きがちだ(이소가시이토 초-쇼쿠오 누키가치다) = "바쁘면 아침을 자주 거르기 십상이다"

のみ
~뿐, ~만(のみ)
[종합] 「だけ」와 같은 뜻의 문어체적인 한정 조사로, 오직 그것 하나뿐임을 격식 있고 딱딱하게 강조할 때 씀. 「飲み」(마심)와 발음이 같지만 전혀 다른 조사임에 유의
[치트키] "노미! 노(오직) 미(이것)만 뿐" → のみ=노미→~뿐
[장면] 규정에 "회원만 입장 가능"이라고 딱딱하게 적힌 안내문
[예문] 会員のみ入場可能(카이인노미 뉴-죠-카노-) = "회원만 입장 가능"
[헷갈리는 단어] 飲み(のみ) - 발음이 완전히 같으나 飲む(마시다)의 명사형으로 전혀 다른 뜻

〜において
~에 있어서, ~에서(において)
[읽기] に + 於いて(おいて, 훈독) → において
[한자1] 於 (어조사 어 / ~에, ~에서 — 현대어에서는 주로 가나로 표기)
· 음독: オ, ヨ
· 훈독: ★お-いて
· 분해: 方(모 방) + 仒(깃발이 나부끼는 모습)
· 어원: 깃발(仒)이 특정 방향(方)을 가리키는 모습에서 어조사 "~에서"를 나타냄
· 예시 단어: 於: 현대 일본어에서는 단독 사용 예가 드묾(고문 어휘)
[종합] 「〜に+於いて」가 결합해, 격식 있는 문어체로 장소·상황·분야 등을 한정하여 "~에 있어서"를 나타내는 조사구가 됨
[치트키] "니오이테! 니(에) 오이테(놓고 보면) ~에 있어서" → において=니오이테→~에 있어서
[장면] 학회 발표에서 "본 연구에 있어서"라고 격식 있게 말을 시작하는 장면
[예문] 現代社会において重要だ(겐다이샤카이니 오이테 쥬-요-다) = "현대사회에 있어서 중요하다"

〜によって
~에 의해, ~에 따라(によって)
[읽기] に + 因って(よって, 훈독) → によって
[한자1] 因 (인할 인 / 인하다, 말미암다)
· 음독: イン
· 훈독: ★よ-る
· 분해: 囗(자리, 돗자리) + 大(사람)
· 어원: 사람(大)이 돗자리(囗) 위에 몸을 기대는 모습에서 인하다, 말미암다, 의지하다를 나타냄
· 예시 단어: 原因 (원인, げん+いん)
[종합] 「〜に+因って(말미암아)」가 결합해, 어떤 것을 근거·수단·원인으로 삼아 "~에 의해, ~에 따라"를 나타내는 조사구가 됨
[치트키] "니욧테! 니(에) 욧테(의해서) ~에 의해" → によって=니욧테→~에 의해
[장면] 지역에 따라 날씨가 크게 다른 일기예보 화면
[예문] 地域によって気候が違う(치이키니욧테 키코-가 치가우) = "지역에 따라 기후가 다르다"

〜に当たって
~에 즈음하여, ~에 임하여(にあたって)
[읽기] に + 当たって(あたって, 훈독) → にあたって
[한자1] 当 (마땅할 당 / 마땅하다, 부딪히다, 임하다)
· 음독: トウ
· 훈독: ★あ-たる, あ-てる
· 분해: 尚(오히려 상, 집 위로 연기가 퍼짐) + 田(밭)
· 어원: 밭(田)에 걸맞게(尚) 마땅히 들어맞는 모습에서 마땅하다, 부딪히다, 임하다를 나타냄
· 예시 단어: 当日 (당일, とう+じつ)
[종합] 「〜に+当たって(부딪혀, 임하여)」가 결합해, 중요한 일을 시작하거나 마주하는 바로 그 시점에서 "~에 즈음하여, ~에 임하여"를 나타내는 격식체 조사구가 됨
[치트키] "니아탓테! 니(에) 아탓테(임하여) 즈음하여" → に当たって=니아탓테→~에 즈음하여
[장면] 신년사에서 새해를 맞이하며 각오를 다지는 장면
[예문] 開会に当たって挨拶する(카이카이니 아탓테 아이사츠스루) = "개회에 즈음하여 인사하다"

をきっかけに
~을 계기로(をきっかけに)
[읽기] を + 掛け(かけ, 훈독)의 촉음화형 「きっかけ」 + に → をきっかけに
[한자1] 掛 (걸 괘 / 걸다, 계기)
· 음독: カイ
· 훈독: ★きっかけ (촉음화된 형태), か-ける
· 분해: 扌(손) + 卦(걸 괘, 점괘를 거는 모습)
· 어원: 손(扌)으로 점괘(卦)를 걸듯 어떤 일을 시작하는 계기가 되는 모습에서 계기, 실마리를 나타냄
· 예시 단어: 出掛け (외출하는 김에, で+かけ)
[종합] 掛け(계기, 실마리)가 촉음화된 「きっかけ」에 「を〜に」가 붙어, 어떤 일이 시작된 원인이나 동기를 "~을 계기로"라는 뜻으로 나타내는 문형이 됨
[치트키] "오 킷카케니! 오(그것을) 킷카케(계기)니 삼아" → をきっかけに=오킷카케니→~을 계기로
[장면] 작은 사고를 계기로 안전 규정을 전면 개정하는 장면
[예문] 事故をきっかけに規則が変わった(지코오 킷카케니 키소쿠가 카왓타) = "사고를 계기로 규칙이 바뀌었다"

を元にして
~을 바탕으로(をもとにして)
[읽기] を + 元=もと(훈독) + にして → をもとにして
[한자1] 元 (으뜸 원 / 근원, 처음)
· 음독: ゲン, ガン
· 훈독: ★もと
· 분해: 二(위, 하늘) + 儿(사람)
· 어원: 사람(儿)의 머리 위(二)를 가리키는 모습에서 맨 처음, 근본을 나타냄
· 예시 단어: 元来 (원래, がん+らい)
[종합] 근본(元)으로 삼아(にして) 무언가를 만들거나 판단한다는 뜻에서 "~을 바탕으로"를 나타내는 문형이 됨
[치트키] "오 모토니시테! 오(그것을) 모토(바탕)니시테 삼아" → を元にして=오모토니시테→~을 바탕으로
[장면] 실화를 바탕으로 만든 영화의 오프닝 자막이 나오는 장면
[예문] 実話を元にして作られた(지츠와오 모토니시테 츠쿠라레타) = "실화를 바탕으로 만들어졌다"

を巡って
~을 둘러싸고(をめぐって)
[읽기] を + 巡って(めぐって, 훈독) → をめぐって
[한자1] 巡 (돌 순 / 돌다, 순회하다)
· 음독: ジュン
· 훈독: ★めぐ-る
· 분해: 辶(가다) + 巛(내 천, 물이 굽이쳐 흐름)
· 어원: 물줄기(巛)처럼 굽이쳐 돌아가는(辶) 모습에서 돌다, 순회하다를 나타냄
· 예시 단어: 巡回 (순회, じゅん+かい)
[종합] 「〜を+巡って(돌아서, 둘러싸고)」가 결합해, 어떤 화제나 문제를 중심에 두고 여러 의견이 오가는 상황을 "~을 둘러싸고"로 나타내는 문형이 됨
[치트키] "오 메굿테! 오(그것을) 메굿테(둘러싸고) 논쟁" → を巡って=오메굿테→~을 둘러싸고
[장면] 회의 탁자에 둘러앉아 하나의 안건을 두고 열띤 토론을 벌이는 장면
[예문] 予算を巡って議論する(요산오 메굿테 기론스루) = "예산을 둘러싸고 논의하다"

を通じて
~을 통해(をつうじて)
[읽기] を + 通じて(つうじて, 음독+훈독 혼합) → をつうじて
[한자1] 通 (통할 통 / 통하다)
· 음독: ★ツウ, ツ
· 훈독: とお-る, かよ-う
· 분해: 辶(가다) + 甬(길 용, 대롱처럼 뚫린 통로)
· 어원: 뚫린 통로(甬)를 따라 가는(辶) 모습에서 통하다를 나타냄
· 예시 단어: 通勤 (통근, つう+きん)
[종합] 「〜を+通じて(통하여)」가 결합해, 어떤 수단이나 기간 전체를 매개로 하여 "~을 통해, ~내내"를 나타내는 문형이 됨
[치트키] "오 츠-지테! 오(그것을) 츠-지테(통해서)" → を通じて=오츠-지테→~을 통해
[장면] 통역사를 통해 외국 손님과 대화를 나누는 장면
[예문] 通訳を通じて話す(츠-야쿠오 츠-지테 하나스) = "통역을 통해 이야기하다"

どころか
~는커녕(どころか)
[읽기] 所(ところ, 훈독)의 탁음화형「どころ」+ か → どころか (탁음화/연탁)
[한자1] 所 (바 소 / 곳, 것)
· 음독: ショ
· 훈독: ★ところ (탁음화되어 ★どころ로도 쓰임)
· 분해: 戸(문) + 斤(도끼)
· 어원: 도끼(斤)로 나무를 베어 문(戸)을 내고 자리 잡은 곳에서 장소, 곳을 나타냄
· 예시 단어: 台所 (부엌, だい+どころ)
[종합] 所(곳, 것)가 탁음화된 「どころ」에 「か」가 붙어, 앞의 내용을 강하게 부정하며 오히려 그와 정반대의 상황임을 강조하는 "~는커녕"을 나타내는 문형이 됨
[치트키] "도코로카! 도코로(그럴 곳)가 카(아니라) 오히려" → どころか=도코로카→~는커녕
[장면] 살 빼려다 오히려 살이 더 찐 것을 확인하고 한숨 쉬는 장면
[예문] 痩せるどころか太った(야세루 도코로카 후톳타) = "살 빠지기는커녕 살쪘다"

ものだから
~때문에, ~라서(ものだから)
[읽기] 物(もの, 훈독) + だから → ものだから
[한자1] 物 (물건 물 / 물건, 것)
· 음독: ブツ, モツ
· 훈독: ★もの
· 분해: 牜(牛, 소) + 勿(말 물, 여러 색이 뒤섞인 깃발)
· 어원: 소(牜)를 여러 빛깔의 깃발(勿)로 구별하는 모습에서 물건, 것을 나타냄
· 예시 단어: 動物 (동물, どう+ぶつ)
[종합] 「もの(것)+だから(이니까)」가 결합해, 자신의 행동에 대한 이유나 변명을 다소 감정을 담아 설명할 때 쓰는 문형이 됨
[치트키] "모노다카라! 모노(그런 것)다카라(이니까) 어쩔 수 없이" → ものだから=모노다카라→~때문에
[장면] 늦잠을 잔 이유를 변명하며 미안해하는 장면
[예문] 電車が遅れたものだから遅刻した(덴샤가 오쿠레타 모노다카라 치코쿠시타) = "전철이 늦어서 지각했다"

かと思ったら
~했나 싶더니(かとおもったら)
[읽기] か + と + 思ったら(おもったら, 훈독) → かとおもったら
[한자1] 思 (생각 사 / 생각하다)
· 음독: シ
· 훈독: ★おも-う
· 분해: 田(밭, 정수리를 본뜬 모양) + 心(마음)
· 어원: 정수리(田)와 마음(心)으로 깊이 헤아리는 모습에서 생각하다를 나타냄
· 예시 단어: 思考 (사고, し+こう)
[종합] 「か(의문)+と思ったら(생각했더니)」가 결합해, 어떤 상황이라고 여긴 순간 곧바로 다른 상황으로 바뀌었음을 나타내는 문형이 됨
[치트키] "카토 오못타라! 카(그런가)토 오못타라(생각했더니) 바로" → かと思ったら=카토오못타라→~했나 싶더니
[장면] 맑았던 하늘이 갠 줄 알았더니 갑자기 다시 흐려지는 장면
[예문] 晴れたかと思ったらすぐ曇った(하레타카토 오못타라 스구 쿠못타) = "갰나 싶더니 바로 흐려졌다"

かねない
~할지도 모른다(かねない)
[읽기] 兼ねない(かねない, 훈독) — 앞서 나온 「〜ます+かねない」와 동일한 문형
[한자1] 兼 (겸할 겸 / 겸하다)
· 음독: ケン
· 훈독: ★か-ねる
· 분해: 秝(벼 두 포기) + 又(손)
· 어원: 손(又)으로 두 포기 벼(秝)를 한꺼번에 쥐는 모습에서 겸하다를 나타냄
· 예시 단어: 兼用 (겸용, けん+よう)
[종합] かねる(하기 어렵다)의 부정형으로, 부정적인 결과가 일어날 가능성이 충분히 있음을 우려하며 경고하는 문형(용법은 앞서 나온 「〜ます+かねない」와 동일)
[치트키] "카네나이! 카네(할 수도) 나이(없지 않다) 위험해" → かねない=카네나이→~할지도 모른다
[장면] 다리 위에서 위험하게 장난치다 사고가 날 뻔한 장면
[예문] そんなことをすると危険になりかねない(손나 코토오 스루토 키켄니 나리카네나이) = "그런 짓을 하면 위험해질지도 모른다"

はずがない
~할 리가 없다(はずがない)
[읽기] 筈(はず, 훈독) + が + ない → はずがない — 앞서 나온 항목과 동일한 문형
[한자1] 筈 (오늬 괄 / 화살 끝, 당연히 그럴 예정)
· 음독: カツ
· 훈독: ★はず
· 분해: 竹(대나무) + 舌(혀 설, 좁게 갈라진 모양)
· 어원: 화살대(竹) 끝이 시위에 걸리도록 좁게 갈라진(舌) 부분에서, 당연히 맞아 들어가야 할 예정, 당연함을 나타냄
· 예시 단어: 帳尻 (장부의 끝, ちょう+じり)
[종합] 筈(당연함, 예정)에 が+ない가 붙어, 상식적으로 절대 그럴 리 없다는 확신에 찬 부정을 나타냄(용법은 앞서 나온 はずがない와 동일)
[치트키] "하즈가나이! 하즈(당연)가 나이(없다) 그럴 리 없어" → はずがない=하즈가나이→~할 리가 없다
[장면] 완벽하게 준비했는데 실패할 리 없다며 자신하는 장면
[예문] この計画が失敗するはずがない(코노 케이카쿠가 싯파이스루 하즈가나이) = "이 계획이 실패할 리가 없다"

よりほかない
~할 수밖에 없다(よりほかない)
[읽기] より + 他(ほか, 훈독) + ない → よりほかない
[한자1] 他 (다를 타 / 다르다, 그 밖)
· 음독: タ
· 훈독: ★ほか
· 분해: 亻(사람) + 也(어조사 야, 뱀 모양)
· 어원: 사람(亻)과 다른(也) 대상을 가리키는 모습에서 다르다, 그 밖을 나타냄
· 예시 단어: 他人 (타인, た+にん)
[종합] 「より(~보다)+他(그 밖)+ない(없다)」가 결합해, 그것 말고는 다른 방법이 전혀 없어 그 하나를 택할 수밖에 없음을 나타내는 문형이 됨
[치트키] "요리호카나이! 요리(보다) 호카(다른 것) 나이(없다)" → よりほかない=요리호카나이→~할 수밖에 없다
[장면] 마지막 남은 선택지 하나를 붙잡을 수밖에 없는 절박한 상황
[예문] 諦めるよりほかない(아키라메루요리호카나이) = "포기할 수밖에 없다"

からには
~한 이상에는(からには)
[종합] 「から(원인·이유)+には(는)」가 결합한 문형으로, 어떤 상황이 이미 그러한 이상 그에 따른 당연한 결과·각오·의무가 뒤따름을 강조하는 표현. "일단 ~한 이상은 반드시 ~해야 한다"는 뉘앙스로 쓰이며, 한자 없이 조사만으로 이루어진 문형임
