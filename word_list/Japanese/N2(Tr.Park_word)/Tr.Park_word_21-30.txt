講師
강사(こうし)
[읽기] 講=コウ + 師=シ → こうし (음독)
[한자1] 講 (익힐 강 / 강의하다)
· 음독: ★コウ
· 훈독: 없음
· 분해: 言(말씀 언) + 冓(짤 구, 얽어 짬)
· 어원: 말을 엮어 짜서 가르친다는 뜻에서 강의하다를 나타냄
· 예시 단어: 講堂 (강당, こう+どう)
[한자2] 師 (스승 사 / 스승, 선생)
· 음독: ★シ
· 훈독: 없음
· 분해: 阜(언덕 부, 원래는 堆) + 帀(두를 잡, 군대가 둘러싸움)
· 어원: 언덕을 둘러싼 군대의 우두머리에서 스승, 지도자를 나타냄
· 예시 단어: 教師 (교사, きょう+し)
[종합] 강의하는(講) 스승(師)이라는 뜻에서 강사가 됨
[치트키] "코-시! 코-(강의)의 시(스승) 강사" → 講師=코-시→강사
[장면] 강단에 서서 열정적으로 가르치는 강사의 모습
[예문] 講師として招かれる(코-시토시테 마네카레루) = "강사로 초빙되다"

[읽기] 磁=ジ + 石=シャク → じしゃく (음독)
[한자1] 磁 (자석 자 / 자석)
· 음독: ★ジ
· 훈독: 없음
· 분해: 石(돌 석) + 茲(이 자, 발음요소)
· 어원: 쇠를 끌어당기는 신비한 돌에서 자석을 나타냄
· 예시 단어: 磁力 (자력, じ+りょく)
[한자2] 石 (돌 석 / 돌)
· 음독: セキ, ★シャク (여기선 특수 음독)
· 훈독: いし
· 분해: 厂(기슭 엄) + 口(입 구, 돌덩이)
· 어원: 언덕 아래 놓인 돌덩이 모양에서 돌을 나타냄
· 예시 단어: 石油 (석유, せき+ゆ)
[종합] 쇠를 끌어당기는 신비한(磁) 돌(石)이라는 뜻에서 자석이 됨
[치트키] "지샤쿠! 지(자석)의 샤쿠(돌) 자석" → 磁石=지샤쿠→자석
[장면] 자석에 클립들이 줄줄이 달라붙는 장면
[예문] 磁石にくっつく(지샤쿠니 쿳츠쿠) = "자석에 달라붙다"

支出
지출(ししゅつ)
[읽기] 支=シ + 出=シュツ → ししゅつ (음독)
[한자1] 支 (지탱할 지 / 지출하다)
· 음독: ★シ
· 훈독: ささ-える
· 분해: 十(열 십, 나뭇가지) + 又(또 우, 손)
· 어원: 손으로 나뭇가지를 잡아 지탱한다는 뜻에서 확장되어 지출을 나타냄
· 예시 단어: 収支 (수지, しゅう+し)
[한자2] 出 (날 출 / 나가다, 내다)
· 음독: ★シュツ, スイ
· 훈독: で-る, だ-す
· 분해: 屮(왼손 좌, 원래는 발) + 凵(입벌릴 감, 원래는 구멍)
· 어원: 발이 구멍 밖으로 나가는 모습에서 나가다, 내다를 나타냄
· 예시 단어: 出発 (출발, しゅっ+ぱつ)
[종합] 돈을 지탱해(支) 내보낸다(出)는 뜻에서 지출이 됨
[치트키] "시슈츠! 시(지탱)를 슈츠(내보냄)했어" → 支出=시슈츠→지출
[장면] 가계부에 이번 달 지출 내역을 적는 장면
[예문] 支出を抑える(시슈츠오 오사에루) = "지출을 줄이다"

姿勢
자세(しせい)
[읽기] 姿=シ + 勢=セイ → しせい (음독)
[한자1] 姿 (모양 자 / 모습, 자태)
· 음독: ★シ
· 훈독: すがた
· 분해: 次(버금 차, 발음요소) + 女(계집 녀)
· 어원: 여인의 모습, 자태를 나타냄
· 예시 단어: 姿見 (전신 거울, すがた+み)
[한자2] 勢 (기세 세 / 기세, 힘)
· 음독: ★セイ
· 훈독: いきお-い
· 분해: 力(힘 력) + 埶(재주 예, 심음)
· 어원: 힘써 심어 뻗어나가는 기세를 나타냄
· 예시 단어: 勢力 (세력, せい+りょく)
[종합] 몸의 모양(姿)과 기세(勢)가 합쳐져 자세라는 뜻이 됨
[치트키] "시세이! 시(모습)와 세이(기세) 자세" → 姿勢=시세이→자세
[장면] 요가 강사가 바른 자세를 시범 보이는 장면
[예문] 姿勢を正す(시세이오 타다스) = "자세를 바로잡다"

思想
사상(しそう)
[읽기] 思=シ + 想=ソウ → しそう (음독)
[한자1] 思 (생각 사 / 생각하다)
· 음독: ★シ
· 훈독: おも-う
· 분해: 田(밭 전, 원래는 머리) + 心(마음 심)
· 어원: 머리와 마음으로 생각한다는 뜻을 나타냄
· 예시 단어: 思考 (사고, し+こう)
[한자2] 想 (생각 상 / 생각하다)
· 음독: ★ソウ
· 훈독: 없음
· 분해: 相(서로 상) + 心(마음 심)
· 어원: 마음으로 서로 비교하며 생각한다는 뜻을 나타냄
· 예시 단어: 空想 (공상, くう+そう)
[종합] 생각(思)과 생각(想)이 합쳐져 체계화된 사상이라는 뜻이 됨
[치트키] "시소-! 시(생각)와 소-(생각) 사상" → 思想=시소-→사상
[장면] 철학자가 자신의 사상을 책으로 정리하는 장면
[예문] 独自の思想を持つ(도쿠지노 시소-오 모츠) = "독자적인 사상을 가지다"

吐く
구토하다, 뱉다(はく)
[읽기] 吐=は + く(오쿠리가나) → はく (훈독)
[한자1] 吐 (토할 토 / 토하다, 뱉다)
· 음독: ト
· 훈독: ★は-く
· 분해: 口(입 구) + 土(흙 토, 발음요소)
· 어원: 입에서 무언가를 밀어내는 모습에서 토하다, 뱉다를 나타냄
· 예시 단어: 吐息 (한숨, と+いき)
[종합] 한자 하나로 이루어진 훈독 동사로, 몸속의 것을 입 밖으로 밀어내는 행위를 뜻함
[치트키] "하쿠! 하(입)로 쿠욱 뱉었쿠" → 吐く=하쿠→뱉다
[장면] 멀미로 인해 속이 안 좋아 구토하는 장면
[예문] 息を吐く(이키오 하쿠) = "숨을 내쉬다"

慰める
위로하다, 달래다(なぐさめる)
[읽기] 慰=なぐさ + める(오쿠리가나) → なぐさめる (훈독)
[한자1] 慰 (위로할 위 / 위로하다)
· 음독: イ
· 훈독: ★なぐさ-める
· 분해: 尉(벼슬 위, 다림질) + 心(마음 심)
· 어원: 마음을 다림질하듯 어루만져 위로한다는 뜻을 나타냄
· 예시 단어: 慰安 (위안, い+あん)
[종합] 한자 하나로 이루어진 훈독 동사로, 슬프거나 힘든 사람의 마음을 어루만져 편안하게 해주는 것을 뜻함
[치트키] "나구사메루! 나구(눕혀) 사메(다독임)루" → 慰める=나구사메루→위로하다
[장면] 슬퍼하는 친구의 어깨를 토닥이며 위로하는 장면
[예문] 友達を慰める(토모다치오 나구사메루) = "친구를 위로하다"

どく
물러나다, 비키다(どく)
[종합] 순수 가나 동사로, 있던 자리에서 몸을 옮겨 길을 비켜주는 행위를 뜻함
[치트키] "도쿠! 도(길)를 쿠욱 비켜라도쿠" → どく=도쿠→물러나다
[장면] 좁은 길에서 다른 사람이 지나가도록 옆으로 비켜주는 장면
[예문] ちょっとどいてください(춋토 도이테쿠다사이) = "잠시 비켜주세요"

適する
적합하다, 알맞다(てきする)
[읽기] 適=てき + する(동사화 어미) → てきする (음독)
[한자1] 適 (맞을 적 / 알맞다, 적합하다)
· 음독: ★テキ
· 훈독: かな-う
· 분해: 辶(쉬엄쉬엄 갈 착) + 啇(밑동 적, 뿌리처럼 딱 맞음)
· 어원: 길을 가다 딱 맞는 곳에 이른다는 뜻에서 알맞다를 나타냄
· 예시 단어: 適用 (적용, てき+よう)
[종합] 適(맞을 적)에 する가 붙어 동사화된 형태로, 어떤 조건에 잘 들어맞는 상태를 뜻함
[치트키] "테키스루! 테키(적합)하게 스루(함)" → 適する=테키스루→적합하다
[장면] 딱 맞는 사이즈의 옷을 찾은 장면
[예문] この仕事に適する(코노 시고토니 테키스루) = "이 일에 적합하다"

めでたい
경사스럽다, 기쁘다 / 축하할 만하다(めでたい)
[종합] 순수 가나 형용사로, 축하할 만한 좋은 일이 생겨 경사스러운 상태를 뜻함
[치트키] "메데타이! 메데(눈에 띄게) 타이(경사스러워)" → めでたい=메데타이→경사스럽다
[장면] 아기가 태어나 온 가족이 축하하는 장면
[예문] めでたい話だ(메데타이 하나시다) = "경사스러운 이야기다"

消極的な
소극적인(しょうきょくてきな)
[읽기] 消=ショウ + 極=キョク + 的=テキ → しょうきょくてき (음독)
[한자1] 消 (사라질 소 / 사라지다, 소극적)
· 음독: ★ショウ
· 훈독: き-える, け-す
· 분해: 氵(물 수) + 肖(닮을 초, 작아짐)
· 어원: 물이 작아져 사라지는 모습에서 사라지다를 나타냄
· 예시 단어: 消費 (소비, しょう+ひ)
[한자2] 極 (다할 극 / 다하다, 극도)
· 음독: ★キョク
· 훈독: きわ-める
· 분해: 木(나무 목) + 亟(빠를 극)
· 어원: 나무 기둥의 끝, 다한 지점이라는 뜻에서 극도를 나타냄
· 예시 단어: 極端 (극단, きょく+たん)
[한자3] 的 (과녁 적 / ~적인)
· 음독: ★テキ
· 훈독: まと
· 분해: 白(흰 백) + 勺(구기 작)
· 어원: 흰 과녁의 모습에서 ~적인이라는 접미사를 나타냄
· 예시 단어: 積極的 (적극적, せっきょく+てき)
[종합] 사라지듯(消) 극도로(極) 물러서는 태도(的)라는 뜻에서 소극적인이 됨
[치트키] "쇼-쿄쿠테키나! 쇼-(사라짐) 쿄쿠(극도)테키나 소극적" → 消極的な=쇼-쿄쿠테키나→소극적인
[장면] 발표할 기회에도 손을 들지 않고 뒤로 물러서는 모습
[예문] 消極的な態度をとる(쇼-쿄쿠테키나 타이도오 토루) = "소극적인 태도를 취하다"

ちょっとした
약간의 / 상당한(ちょっとした)
[종합] 순수 가나 연체사로, 문맥에 따라 대수롭지 않은 정도(약간)와 무시할 수 없는 정도(상당한) 둘 다를 나타냄
[치트키] "춋토시타! 춋토(조금) 시타(했음)" → ちょっとした=춋토시타→약간의
[장면] 별거 아닌 것 같지만 은근히 도움이 되는 작은 배려를 받는 장면
[예문] ちょっとした問題(춋토시타 몬다이) = "사소한 문제 / 상당한 문제"

すっかり
죄다, 모두(すっかり)
[종합] 순수 가나 부사로, 남김없이 완전히, 모두를 강조하는 말
[치트키] "슷카리! 슷(전부) 카리(빌린)만큼 다" → すっかり=슷카리→죄다
[장면] 방을 완전히 깨끗하게 정리한 장면
[예문] すっかり忘れた(슷카리 와스레타) = "완전히 잊어버렸다"

パターン
패턴, 유형(パターン)
[유래] Pattern (패턴) = 유형, 무늬를 뜻하는 영어에서 유래
[종합] 반복되어 나타나는 일정한 형태나 방식, 유형을 뜻함
[치트키] "파타-엔! 파(펼쳐진) 타-엔 무늬 패턴" → パターン=파타-엔→패턴
[장면] 벽지에 반복되는 꽃무늬 패턴을 살펴보는 장면
[예문] 行動のパターンを分析する(코-도-노 파타-엔오 분세키스루) = "행동 패턴을 분석하다"

子孫
자손(しそん)

自体
자체(じたい)

辞退
사퇴(じたい)

[종합] 한자 하나로 이루어진 음독 명사로, 정해진 차례나 순서를 뜻함
[치트키] "쥰! 쥰(순서)대로" → 順=쥰→순서
[장면] 은행 창구에서 번호표 순서대로 대기하는 장면
[예문] 順に並ぶ(쥰니 나라부) = "순서대로 줄서다"

瞬間
순간(しゅんかん)
[읽기] 瞬=シュン + 間=カン → しゅんかん (음독)
[한자1] 瞬 (눈깜짝일 순 / 순간)
· 음독: ★シュン
· 훈독: またた-く
· 분해: 目(눈 목) + 舜(순임금 순, 발음요소)
· 어원: 눈을 깜빡이는 짧은 시간에서 순간을 나타냄
· 예시 단어: 瞬時 (순시, しゅん+じ)
[한자2] 間 (사이 간 / 사이, 시간)
· 음독: ★カン, ケン
· 훈독: あいだ
· 분해: 門(문 문) + 日(날 일)
· 어원: 문틈 사이로 햇빛이 새어드는 모습에서 사이, 시간을 나타냄
· 예시 단어: 時間 (시간, じ+かん)
[종합] 눈 깜짝일(瞬) 정도의 사이(間)라는 뜻에서 순간이 됨
[치트키] "슌칸! 슌(눈깜짝)의 칸(사이) 순간" → 瞬間=슌칸→순간
[장면] 사진작가가 결정적인 순간을 포착하는 장면
[예문] 決定的な瞬間だ(켓테이테키나 슌칸다) = "결정적인 순간이다"

順序
순서(じゅんじょ)
[읽기] 順=ジュン + 序=ジョ → じゅんじょ (음독)
[한자1] 順 (순할 순 / 순서)
· 음독: ★ジュン
· 훈독: 없음
· 분해: 川(내 천) + 頁(머리 혈)
· 어원: 물이 순리대로 흘러가듯 머리를 숙여 따른다는 뜻에서 순서를 나타냄
· 예시 단어: 順位 (순위, じゅん+い)
[한자2] 序 (차례 서 / 차례, 순서)
· 음독: ★ジョ
· 훈독: 없음
· 분해: 广(집 엄) + 予(나 여, 발음요소)
· 어원: 집안에서 정해진 차례로 앉는 모습에서 차례를 나타냄
· 예시 단어: 序論 (서론, じょ+ろん)
[종합] 순서(順)와 차례(序)가 합쳐져 순서라는 뜻이 됨
[치트키] "쥰죠! 쥰(순서)와 죠(차례) 순서" → 順序=쥰죠→순서
[장면] 정해진 순서대로 발표자가 나오는 장면
[예문] 順序を守る(쥰죠오 마모루) = "순서를 지키다"

使用
사용(しよう)
[읽기] 使=シ + 用=ヨウ → しよう (음독)
[한자1] 使 (하여금 사 / 부리다, 사용하다)
· 음독: ★シ
· 훈독: つか-う
· 분해: 亻(사람 인) + 吏(관리 리, 붓을 든 손)
· 어원: 사람에게 일을 시키는 관리의 모습에서 부리다, 사용하다를 나타냄
· 예시 단어: 使者 (사자, し+しゃ)
[한자2] 用 (쓸 용 / 쓰다)
· 음독: ★ヨウ
· 훈독: もち-いる
· 분해: 用 자체가 화살통 모양을 본뜬 상형자
· 어원: 화살통을 쓰는 모습에서 쓰다를 나타냄
· 예시 단어: 費用 (비용, ひ+よう)
[종합] 부려서(使) 쓰는(用) 것이라는 뜻에서 사용이 됨
[치트키] "시요-! 시(부림)와 요-(씀) 사용" → 使用=시요-→사용
[장면] 새로 산 기계의 사용법을 익히는 장면
[예문] 道具を使用する(도-구오 시요-스루) = "도구를 사용하다"

消火
소화(しょうか)
[읽기] 消=ショウ + 火=カ → しょうか (음독)
[한자1] 消 (사라질 소 / 사라지다, 끄다)
· 음독: ★ショウ
· 훈독: き-える, け-す
· 분해: 氵(물 수) + 肖(닮을 초, 작아짐)
· 어원: 물이 작아져 사라지는 모습에서 사라지다, 끄다를 나타냄
· 예시 단어: 消防 (소방, しょう+ぼう)
[한자2] 火 (불 화 / 불)
· 음독: ★カ
· 훈독: ひ
· 분해: 火 자체가 타오르는 불꽃 모양을 본뜬 상형자
· 어원: 불꽃 모양을 본떠 불을 나타냄
· 예시 단어: 火事 (화재, か+じ)
[종합] 불(火)을 사라지게(消) 한다는 뜻에서 소화가 됨
[치트키] "쇼-카! 쇼-(끔)의 카(불) 소화" → 消火=쇼-카→소화
[장면] 소방관이 소화기로 불을 끄는 장면
[예문] 消火器を使う(쇼-카키오 츠카우) = "소화기를 사용하다"
