# word_list_pure — 프롬프트 없는 순수 단어 목록

이 폴더의 txt 파일들은 **한자/히라가나 단어만** 한 줄에 하나씩 담은 목록입니다.
읽기·뜻·한자 분해·예문 같은 힌트 내용은 전혀 없습니다. 나중에
`word_test/prompt japanese 0829_1.txt` 형식으로 힌트를 붙이는 작업은 별도로 요청받으면
진행합니다.

## 출처 및 방법론 (N1, N2 공통)

**전체(100%) 기준**: JMdict에 해당 급수 태그(`jlpt-n1` 또는 `jlpt-n2`)가 붙은 단어 전체.

- 처음 태그 검색 결과를 그대로 쓰지 않았습니다. 예를 들어 N1 태그 검색 결과는
  3,440건(중복 표제어 정리 후 3,100개)이 나왔는데, 확인해보니 眼鏡(안경)·煙草(담배)·
  塩(소금)·黄色(노랑) 같은 **N5 수준 단어에도 jlpt-n1 태그가 같이 붙어있는 오염 사례**가
  많았습니다(예: 眼鏡 → `jlpt-n1, jlpt-n5` 둘 다 태그됨). JMdict의 이 JLPT 태그 데이터는
  2010년 개편 이전의 "구(舊) 1급~4급" 체계를 기준으로 만들어진 오래된 커뮤니티 태그라서,
  이런 다중 태그·과거 기준 오차가 있는 것으로 보입니다.
- 그래서 **해당 급수 태그만 있고 더 낮은 급수 태그가 함께 붙지 않은 단어만** 걸러서
  최종 목록을 확정했습니다.
- 이렇게 걸러도 완벽하지는 않습니다 — 옛 "구 급수" 기준이라 惑星(행성)·地獄(지옥)·
  仏像(불상)처럼 요즘 감각으론 오히려 구체적인 명사(중급 수준)로 느껴질 단어도 일부
  섞여 있습니다. "진짜 해당 급수 수준 어휘"만 정확히 원하시면 이 목록을 그대로 다
  쓰기보다 한 번 더 걸러내는 걸 권장합니다 (원하시면 이어서 진행하겠습니다).
- 이 태그 데이터 자체는 [JMdict](http://www.edrdg.org/jmdict/j_jmdict.html)
  (EDRDG, **CC BY-SA 3.0**) 소속이라 출처 표기 조건이 적용됩니다: "JLPT 급수 분류는
  JMdict/EDRDG(CC BY-SA 3.0) 데이터로 확인함".

## 2차 정제 — 난이도 필터링 (`_filtered_` 파일)

1차 목록(태그 오염만 제거한 것)도 실제로 열어보니, 순수 가타카나 외래어(オレンジ, データ 등),
숫자/기호 잡음(１０分, ＯＫ), 한 글자 대명사(私, 僕, 俺) 같은 명백한 잡음이 여전히 많이
섞여 있었습니다. 게다가 그런 잡음을 걷어내도, 惑星(행성)·地獄(지옥)·仏像(불상)·望遠鏡(망원경)
처럼 개념 자체는 초중급 수준인 구체명사, 형容詞(형용사)·代名詞(대명사) 같은 학교 문법
용어, 도구/신체부위/동식물 이름 등 "옛 구(舊)급수 태그" 특유의 오염이 대량으로 남아있었습니다.

그래서 2단계로 정제했습니다.
1. **자동 제거**: 순수 가타카나 외래어, 숫자/기호가 섞인 항목, 대표적인 1인칭 대명사를
   스크립트로 걸러냈습니다.
2. **직접 검토**: 자동으로 걸러지지 않는 나머지는 제가 하나하나 읽으면서, "구체적인
   사물/신체/동식물/학교급 문법·과목 용어"는 제외하고 "추상적·형식적·업무/문어체
   어휘"만 남기는 방식으로 판단했습니다. 사용자님이 예로 주신 N1(躊躇, 鬱陶しい 등)과
   N2(偏る, 契機, 催す, 把握, 著しい 등) 수준을 기준으로 삼았습니다.

**⚠️ 중요한 한계**: 이 기준으로 검토하던 중 사용자님이 예시로 주신 단어 중
**躊躇·彷徨う·錯綜·偏る·把握는 애초에 이 JMdict 태그 목록 안에 존재하지 않는다는 것을
발견했습니다.** 즉 JMdict의 jlpt 태그 데이터 자체가 "진짜 N1/N2 어휘 전체"를 담고 있는게
아니라, 예전에 일부 단어만 스팟체크로 태그해둔 불완전한 부분집합입니다. 아래 필터링
결과는 "이 태그 데이터 안에서 최대한 고른 것"이며, 이 데이터셋에 아예 없는 표준
N1/N2 어휘(위 5개 예시 등)는 여전히 빠져 있다는 점을 감안해 주세요.
