記憶
기억(きおく)
記 (기록할 기) = 言 (말씀 언) + 己 (몸 기) : 말(言)을 자기(己) 몸에 새기듯 잊지 않고 적어 둔다는 뜻입니다.
憶 (생각할 억) = 忄 (마음 심) + 意 (뜻 의) : 마음(忄)속에 뜻(意)을 품고 깊이 생각하며 되살린다는 의미입니다.
머릿속에 새겨두고(記) 마음속으로 생각하여(憶) 과거의 일이나 지식을 잊지 않고 간직하는 것을 의미합니다.

記録
기록(きろく)
記 (기록할 기) = 言 (말씀 언) + 己 (몸 기) : 말(言)을 잊지 않기 위해 자기(己) 것으로 새겨 둔다는 뜻입니다.
録 (기록할 록) = 金 (쇠 금) + 彔 (나무 깎을 록) : 쇠(金)에 글자를 새기거나 나무를 깎아(彔) 문서를 남기는 모습에서 유래했습니다.
오래 보존하기 위해 어떤 사실이나 상태를 글이나 매체에 남기는(記録) 행위를 뜻합니다.

機械
기계(きかい)
機 (틀 기) = 木 (나무 목) + 幾 (몇/기미 기) : 나무(木)로 만들어진 복잡하고 정교한(幾) 베틀 같은 장치를 뜻합니다.
械 (형틀/기계 계) = 木 (나무 목) + 戒 (경계할 계) : 나무(木)로 만들어 사람을 경계하게 하는(戒) 도구나 형틀에서 유래하여 도구를 뜻하게 되었습니다.
동력을 받아 특정한 일을 수행하도록 나무나 금속 등으로 정교하게 만들어진 장치를 의미합니다.

季節
계절(きせつ)
季 (계절 계) = 禾 (벼 화) + 子 (아들 자) : 벼(禾)의 싹이 트고 자라는(子) 주기에서 한 해의 시기를 나눈다는 의미입니다.
節 (마디 절) = 竹 (대죽) + 即 (곧 즉) : 대나무(竹)의 마디처럼 시간이 나뉘는 구분점을 의미합니다.
일 년을 기후나 자연 현상의 변화에 따라 나눈 한 마디, 즉 봄·여름·가을·겨울을 의미합니다.

規則
규칙(きそく)
規 (법 규) = 夫 (지아비 부) + 見 (볼 견) : 성인 남자(夫)가 올바른 기준을 바라보고(見) 따른다는 데서 법칙을 뜻합니다.
則 (법칙 칙) = 貝 (조개 패) + 刂 (칼 도) : 귀중한 재물(貝)을 칼(刂)로 공평하게 나누는 기준에서 법칙이나 규칙을 뜻하게 되었습니다.
여러 사람이 다 같이 지키기로 합의하여 정해 놓은 올바른 기준과 법칙을 의미합니다.

期待
기대(きたい)
期 (기약할 기) = 其 (그 기) + 月 (달 월) : 특정 달(月)이나 시기를 정해두고 그(其) 때를 기약한다는 뜻입니다.
待 (기다릴 대) = 彳 (조금 걸을 척) + 寺 (관청 사) : 관청(寺)에 볼일이 있어 가다(彳) 머물러서 기다린다는 뜻입니다.
어떤 일이 이루어지기를 정해진 시기(期)를 두고 바라고 기다리는(待) 마음을 의미합니다.

疑問
의문(ぎもん)
疑 (의심할 의) = 匕 (비수 비) + 矢 (화살 시) + 疋 (발 소) 등 복합 : 갈림길에서 어느 쪽으로 갈지 망설이며 의심하는 모습을 본뜬 글자입니다.
問 (물을 문) = 門 (문 문) + 口 (입 구) : 문(門) 밖에서 입(口)으로 소리를 내어 안에 묻는다는 의미입니다.
의심스럽거나(疑) 확실하지 않은 것에 대해 마음속으로 묻고(問) 궁금해하는 상태를 뜻합니다.

疑う
의심하다(うたがう)
疑 (의심할 의) = 匕 (비수 비) + 矢 (화살 시) + 疋 (발 소) 등 복합 : 갈림길에서 발걸음을 멈추고 망설이며 확신하지 못하는 모습입니다.
어떤 사실이나 사람에 대해 믿지 못하고 이상하게 여기거나 불확실하게 생각하는 행위를 의미합니다.

競争
경쟁(きょうそう)
競 (다툴 경) = 誩 (말다툼할 경) + 两人 : 두 사람이 나란히 서서 서로 앞서려고 다투는 모습을 나타냅니다.
争 (다툴 쟁) = 爪 (손톱 조) + 又 (또 우/손) : 두 손으로 하나의 물건을 서로 차지하려고 다투는 모습을 본뜬 글자입니다.
같은 목적을 두고 서로 이기거나 앞서려고 다투는(競争) 행위를 의미합니다.

区別
구별(くべつ)
区 (지경 구) = 匚 (상자 방) + メ (벨 예) : 상자나 테두리(匚) 안을 나누어(メ) 구역을 정한다는 뜻입니다.
別 (나눌 별) = 뼈 바를 과 + 刂 (칼 도) : 칼(刂)로 뼈와 살을 분리하여 나눈다는 뜻에서 구별하고 헤어짐을 의미합니다.
어떤 것들의 성질이나 종류에 따라 서로 차이가 나는 것을 나누어(区) 가르는(別) 것을 뜻합니다.

苦労
고생(くろう)
苦 (쓸 고) = 艹 (풀 초) + 古 (옛 고) : 잎이 쓴 풀(艹)에서 유래하여 맛이 쓰다, 괴롭다는 의미로 확장되었습니다.
労 (일할 로) = 𤇾 (불화가 변형된 모양) + 力 (힘 력) : 등불을 켜놓고 밤늦게까지 힘(力)을 들여 일한다는 뜻입니다.
어떤 일을 이루기 위해 육체적, 정신적으로 괴로움(苦)을 겪으며 힘써 일함(労)을 의미합니다.

計画を立てる
계획을 세우다(けいかくをたてる)
計 (셀 계) = 言 (말씀 언) + 十 (열 십) : 열(十) 가지를 하나하나 말(言)로 세어가며 셈하거나 헤아린다는 뜻입니다.
画 (그림 화/그을 획) = 聿 (붓 율) + 田 (밭 전) : 밭(田)의 경계를 붓(聿)으로 그어 구획을 정한다는 뜻입니다.
立 (설 립) = 사람이 땅 위에 서 있는 모습을 본뜬 상형자입니다.
앞으로 할 일의 절차나 방법, 규모 따위를 미리 헤아려(計) 구획을 짓고(画) 그 틀을 확고히 세우는(立てる) 것을 의미합니다.

経営
경영(けいえい)
経 (지날 경) = 糸 (실 사) + 巠 (물줄기 경) : 베틀의 세로실(糸)처럼 기준이 되어 곧게 나아간다는 뜻에서 다스리다는 의미가 파생되었습니다.
営 (경영할 영) = 宫 (집 궁)의 변형 : 큰 집을 짓기 위해 주위를 둘러싸고 일을 도모한다는 데서 짓다, 일하다를 뜻합니다.
조직이나 사업의 기준을 세워(経) 지속적으로 일을 도모하고 꾸려 나가는(営) 활동을 뜻합니다.

経験
경험(けいけん)
経 (지날 경) = 糸 (실 사) + 巠 (물줄기 경) : 세로실(糸)을 따라가듯 시간이나 공간을 거쳐 지나간다는 의미입니다.
験 (시험 험) = 馬 (말 마) + 僉 (다 첨) : 여러(僉) 말을 타보며 그 능력을 시험해 보고 검증한다는 뜻입니다.
자신이 실제로 겪어(経) 지나오면서 직접 확인하고 증명해 본(験) 지식이나 기능을 의미합니다.

経済
경제(けいざい)
経 (지날 경/다스릴 경) = 糸 (실 사) + 巠 (물줄기 경) : 기준이 되는 세로실처럼 나라와 사회를 올바르게 다스린다는 뜻입니다.
済 (건널 제/구제할 제) = 氵 (물 수) + 斉 (가지런할 제) : 물(氵)을 무사히 건너 평온하고 가지런하게(斉) 하여 백성을 구제한다는 의미입니다.
세상을 다스리고(経世) 백성을 구제한다(済民)는 뜻의 '경세제민'의 준말로, 재화나 용역을 생산·분배·소비하는 활동을 뜻합니다.

経由
경유(けいゆ)
経 (지날 경) = 糸 (실 사) + 巠 (물줄기 경) : 특정한 길이나 과정을 지나쳐 간다는 의미입니다.
由 (말미암을 유) = 열매가 맺힌 모양 또는 등잔 모양을 본떠, 어떤 것에서 비롯되거나 거쳐감을 뜻합니다.
목적지로 가는 도중에 어떤 장소나 과정을 거쳐서(経) 지나감(由)을 의미합니다.

結論
결론(けつろん)
結 (맺을 결) = 糸 (실 사) + 吉 (길할 길) : 실(糸)을 단단하게 묶어 좋은(吉) 상태로 마무리 짓는다는 뜻입니다.
論 (논할 론) = 言 (말씀 언) + 侖 (둥글 륜/조리 륜) : 조리(侖) 있게 말(言)로 따져서 의견을 나눈다는 뜻입니다.
논의하거나 생각한 끝에 하나로 묶여서(結) 최종적으로 내려진 판단이나 의견(論)을 의미합니다.

減少
감소(げんしょう)
減 (덜 감) = 氵 (물 수) + 咸 (다 함) : 물(氵)이 증발하여 그 양이 모두(咸) 줄어든다는 의미에서 덜다, 줄다를 뜻합니다.
少 (적을 소) = 小 (작을 소)의 변형으로, 작게 나뉘어 그 양이 적음을 나타냅니다.
어떤 것의 양이나 크기, 수량 등이 덜어져서(減) 적어지는(少) 현상을 뜻합니다.

代わる
대신하다(かわる)
代 (대신할 대) = 亻 (사람 인) + 弋 (주살 익) : 사람(亻)이 막대기(弋)를 교대로 번갈아 넘겨받으며 임무를 대신한다는 뜻입니다.
어떤 역할, 지위, 사물 등이 원래 있던 것을 물러나게 하고 다른 것으로 교체되거나 대신 채워지는 것을 의미합니다.

減る
줄다(へる)
減 (덜 감) = 氵 (물 수) + 咸 (다 함) : 물(氵)이 마르거나 퍼내어져 그 양이 줄어드는 모습을 나타냅니다.
수량, 무게, 정도 따위가 원래의 상태보다 적어지거나 깎여 나가는 자동사적 의미를 나타냅니다.

減ります
줄어듭니다(へります)
減 (덜 감) = 氵 (물 수) + 咸 (다 함) : 물(氵)이 마르거나 퍼내어져 그 양이 줄어드는 모습을 나타냅니다.
수량이나 정도가 원래보다 적어지는 현상(減る)을 정중하게 표현한 말입니다.

傷
상처(きず)
傷 (다칠 상) = 亻 (사람 인) + 昜 (볕 양/날릴 양의 변형) + 矢 (화살 시) : 사람(亻)이 화살(矢) 따위에 맞아 다치고 피를 흘린다는 뜻입니다.
몸을 다쳐서 상한 자국이나 마음의 아픔, 혹은 물건에 난 흠집을 의미합니다.

傷つけられる
상처받다(きずつけられる)
傷 (다칠 상) = 亻 (사람 인) + 昜 (변형) + 矢 (화살 시) : 화살(矢)에 맞아 사람(亻)이 다치는 모습에서 유래했습니다.
다른 사람의 말이나 행동으로 인해 마음이나 몸에 상처를 입게 되는 수동적 상태를 나타냅니다.

傷つく
상처입다(きずつく)
傷 (다칠 상) = 亻 (사람 인) + 昜 (변형) + 矢 (화살 시) : 화살 등에 맞아 피부나 몸이 다친 상태를 의미합니다.
물리적인 타격을 받거나 정신적으로 충격을 받아 마음이 상하게 되는 현상을 뜻하는 자동사적 표현입니다.

傷つける
상처입히다(きずつける)
傷 (다칠 상) = 亻 (사람 인) + 昜 (변형) + 矢 (화살 시) : 사람을 다치게 한다는 뜻입니다.
타인이나 물건에 물리적인 흠집을 내거나, 다른 사람의 감정을 상하게 하고 아픔을 주는 타동사적 표현입니다.

手首
손목(てくび)
手 (손 수) = 사람의 손가락과 손바닥 모양을 본뜬 상형자입니다.
首 (머리 수) = 머리카락과 얼굴을 본뜬 모양으로, 몸에서 중요한 부분이나 '목'을 뜻합니다.
손(手)과 팔을 이어주는 좁고 잘록한 목(首)과 같은 부위, 즉 손목을 의미합니다.

首になる
해고되다(くびになる)
首 (머리 수/목 수) = 사람의 머리와 목의 형태를 본뜬 상형자입니다.
목(首)이 잘린다는 비유적인 뉘앙스에서 유래하여, 직장에서 일자리를 잃거나 해고당하는 것을 빗대어 표현한 관용구입니다.

雨
비(あめ)
雨 (비 우) = 하늘(一) 아래 구름(冂)에서 물방울(점 네 개)이 떨어지는 모습을 본뜬 상형자입니다.
하늘의 구름에서 수증기가 응결되어 액체 상태로 땅에 떨어지는 강수 현상을 의미합니다.

雪
눈(ゆき)
雪 (눈 설) = 雨 (비 우) + 彗 (비 혜의 변형) : 비(雨)처럼 하늘에서 내리지만, 빗자루(彗)로 쓸어낼 수 있는 하얀 결정체를 뜻합니다.
기온이 빙점 이하로 떨어져 구름 속의 수분이 얼어 하얗게 떨어지는 눈을 의미합니다.

雲
구름(くも)
雲 (구름 운) = 雨 (비 우) + 云 (이를 운) : 비(雨)를 품고 있으며 하늘에서 뭉게뭉게 피어오르는(云) 수증기 덩어리를 뜻합니다.
대기 중의 수증기가 엉겨 뭉쳐서 하늘에 떠 있는 흰색 또는 회색의 물방울 덩어리를 뜻합니다.

震
떨림, 진동(しん/ふるえ)
震 (우레 진/떨 진) = 雨 (비 우) + 辰 (별 진/때 진) : 비(雨)가 내리고 벼락이 칠 때 천지가 크게 흔들리며 진동하는(辰) 모습을 나타냅니다.
두려움이나 추위로 몸이 떨리거나, 지진처럼 땅이 크게 흔들리는 진동 현상을 의미합니다.

霜
서리(しも)
霜 (서리 상) = 雨 (비 우) + 相 (서로 상) : 차가운 기운이 내려와(雨) 사물에 하얗게 달라붙어 얼어붙는(相) 현상을 의미합니다.
맑고 추운 밤에 대기 중의 수증기가 지면이나 물체의 표면에 얼어붙어 생기는 얇은 얼음 결정을 뜻합니다.

買い替える
새로 사서 바꾸다(かいかえる)
買 (살 매) = 罒 (그물 망) + 貝 (조개 패/재물) : 재물(貝)을 그물(罒)로 모으듯 끌어모아 물건을 산다는 뜻입니다.
替 (바꿀 체) = 夫 (지아비 부) 두 개 + 曰 (가로 왈) : 두 사람이 나란히 서서 번갈아 가며 역할을 교체한다는 뜻입니다.
낡거나 더 이상 쓰지 못하게 된 오래된 물건을 버리고 새로운 물건을 사서(買い) 교체하는(替える) 행위를 의미합니다.

替える
바꾸다, 교체하다(かえる)
替 (바꿀 체) = 夫 (지아비 부) + 夫 + 曰 (가로 왈) : 사람(夫)이 교대로 말(曰)을 하며 역할을 바꾼다는 의미에서 교체하다의 뜻이 되었습니다.
기존에 있던 것을 치우고 같은 종류의 다른 새로운 것으로 교체하거나 바꾸는 것을 의미합니다.

輝く
빛나다(かがやく)
輝 (빛날 휘) = 光 (빛 광) + 軍 (군사 군) : 군대(軍)의 무기나 깃발이 햇빛(光)을 받아 찬란하게 번쩍인다는 뜻입니다.
빛이 사방으로 눈부시게 퍼지거나, 어떤 사람의 성과나 미모 등이 훌륭하여 눈길을 강하게 끄는 상태를 뜻합니다.

囲む
둘러싸다(かこむ)
囲 (둘러쌀 위) = 囗 (에운담 위) + 井 (우물 정) : 테두리(囗) 안에서 우물(井)처럼 사방을 막아놓거나 지킨다는 의미입니다.
어떤 대상을 한가운데 두고 그 주변을 빙 둘러서 감싸거나 바깥을 막아 에워싸는 것을 뜻합니다.

重ねる
포개다, 거듭하다(かさねる)
重 (무거울 중) = 千 (일천 천/사람의 변형) + 里 (마을 리/동녘 동의 변형) : 무거운 짐을 진 사람의 모습이나 겹겹이 쌓여 두꺼워진 상태를 나타냅니다.
물건을 위로 차곡차곡 쌓아 올리거나, 같은 행동이나 경험, 시간을 반복하여 횟수를 늘려가는 것을 의미합니다.

飾る
장식하다(かざる)
飾 (꾸밀 식) = 食 (밥 식) + 人 + 巾 (수건 건)의 변형 : 사람을 아름답게 치장하거나 음식을 돋보이게 꾸민다는 데서 유래했습니다.
겉모양을 보기 좋게 치장하거나, 보기 좋은 물건을 놓아 화려하게 꾸며서 장식하는 행위를 뜻합니다.

貸す
빌려주다(かす)
貸 (빌릴 대/빌려줄 대) = 代 (대신할 대) + 貝 (조개 패/재물) : 다른 사람의 재물(貝)을 잠시 대신(代) 사용하도록 융통해 준다는 뜻입니다.
자신이 소유한 물건이나 돈을 다른 사람이 일시적으로 사용할 수 있도록 내어주는 것을 의미합니다.

数える
세다(かぞえる)
数 (셀 수/자주 삭) = 婁 (별 이름 루/포갤 루) + 攵 (칠 복) : 묶여진 끈이나 물건(婁)을 손으로 툭툭 치며(攵) 그 수를 하나씩 헤아린다는 데서 유래했습니다.
사물의 개수, 인원, 순서 등을 차례대로 헤아려 정확한 숫자를 파악하는 것을 뜻합니다.

教える
가르치다(おしえる)
教 (가르칠 교) = 孝 (효도 효) + 攵 (칠 복) : 자식(子)이 노인(老)을 모시는 효도(孝)를 하도록 회초리를 들고(攵) 지도한다는 뜻입니다.
지식, 기술, 이치 등을 상대방이 알도록 일깨워 주거나 구체적인 방법과 길을 알려주는 행위를 뜻합니다.

片付ける
정리하다, 치우다(かたづける)
片 (조각 편) = 나무를 반으로 쪼갠 모양을 본뜬 상형자로, 한쪽이나 일부분을 뜻합니다.
付 (붙을 부) = 亻 (사람 인) + 寸 (마디 촌/손) : 사람(亻) 곁에 손(寸)을 대어 바짝 다가붙게 한다는 뜻입니다.
어질러져 있는 물건들을 한쪽(片)으로 치워서 적절한 곳에 붙여두듯(付ける) 깔끔하게 정리하거나, 밀린 일을 마무리 짓는 것을 의미합니다.

乾く
마르다(かわく)
乾 (하늘 건/마를 건) = 𠦝 (해돋을 간의 변형) + 乙 (새 을) : 햇빛이 쨍쨍 내리쬐어 싹이 마르고 수분이 날아가 건조해지는 모습을 나타냅니다.
물기나 습기가 공기 중으로 날아가서 표면이 뽀송뽀송해지거나 완전히 건조한 상태가 되는 것을 뜻하는 자동사입니다.

枯れる
마르다, 시들다(かれる)
枯 (마를 고) = 木 (나무 목) + 古 (옛 고) : 나무(木)가 오래되어(古) 수분을 잃고 앙상하게 말라 죽어간다는 뜻입니다.
식물의 수분이 빠져서 생기를 잃고 시들거나, 사람의 감정이나 재주 등이 성숙하여 군더더기 없이 깊어지는(원숙해지는) 상태를 뜻합니다.

貴重だ
귀중하다(きちょうだ)
貴 (귀할 귀) = 臾 (삼태기 유/두 손 모을 국의 변형) + 貝 (조개 패) : 귀한 재물(貝)을 두 손으로 소중히 받들고 있는 모습에서 '귀하다'는 뜻이 되었습니다.
重 (무거울 중) = 사람(千의 변형)이 무거운 짐을 지고 있는 모습에서, 가볍지 않고 중대함을 뜻합니다.
물건이나 존재가 매우 귀하고(貴) 중요하여(重) 함부로 다룰 수 없이 소중하고 가치 있는 상태를 의미합니다.

結構だ
훌륭하다, 충분하다(けっこうだ)
結 (맺을 결) = 糸 (실 사) + 吉 (길할 길) : 실(糸)을 묶어 단단하고 좋게(吉) 마무리 짓는다는 뜻입니다.
構 (얽을 구) = 木 (나무 목) + 冓 (짤 구) : 나무(木)를 엮어서(冓) 집이나 건축물의 뼈대를 구축한다는 뜻입니다.
원래는 건축물의 뼈대를 얽어 짓는(結) 구조(構)의 짜임새가 훌륭하다는 의미였으나, 현대에는 흠잡을 데 없이 "훌륭하다"는 뜻과 함께, "이만하면 충분하니 더 이상 필요 없다"는 정중한 거절의 의미로 널리 쓰입니다.

きちんと
제대로, 깔끔히, 정확히(きちんと)
어원은 분명치 않으나, 사물이나 태도가 어긋남 없이 잘 정돈되거나 꽉 들어맞는 모양을 나타내는 일본어 고유의 부사어입니다. 한자는 사용하지 않습니다.
모양, 태도, 기준 따위가 흐트러짐이나 빈틈없이 정확하고 단정하게 갖추어진 상태를 의미합니다.

ぎっしり
빽빽이, 가득(ぎっしり)
틈이나 빈 공간이 없이 물건이나 일정이 가득 차 있는 모양을 나타내는 일본어 고유의 의태어입니다. 한자는 사용하지 않습니다.
상자 안에 물건이 틈새 없이 채워져 있거나, 스케줄이나 내용물이 여유 공간 없이 꽉 차서 빽빽하게 들어선 상태를 의미합니다.

決して
결코, 절대로(けっして)
決 (결단할 결) = 氵 (물 수) + 夬 (터놓을 쾌) : 막혀 있던 물(氵)의 둑을 터서(夬) 한 방향으로 세차게 쏟아지게 하듯, 마음을 확고히 정하고 결단한다는 뜻입니다.
뒤에 반드시 부정적인 표현(ない 등)과 함께 호응하여 쓰이며, 어떤 일이 있어도 '절대로 ~하지 않겠다' 또는 '결코 ~가 아니다'라는 단호한 결의나 강한 부정의 의미를 나타냅니다.

こっそり
남몰래, 살짝(こっそり)
일본어 고유의 부사 및 의태어로 한자를 사용하지 않습니다. 남의 눈을 피해 몰래 움직이는 모양을 나타내는 'こそこそ(살금살금, 몰래)' 등과 어원을 공유합니다.
다른 사람에게 들키지 않도록 소리나 기척을 숨기고 매우 조심스럽고 은밀하게 행동하는 모습을 의미합니다.

駐車場
주차장(ちゅうしゃじょう)
駐 (머무를 주) = 馬 (말 마) + 主 (주인 주) : 말(馬)이 주인(主)을 기다리며 한곳에 멈추어 머무른다는 뜻입니다.
車 (수레 차) = 바퀴가 달린 수레나 수레바퀴의 모양을 본뜬 상형자입니다.
場 (마당 장) = 土 (흙 토) + 昜 (볕 양) : 햇볕(昜)이 잘 드는 넓고 평평한 흙(土)바닥이라는 데서 마당을 뜻합니다.
수레나 자동차(車)를 운행하지 않을 때 한곳에 머무르게(駐) 세워 두는 일정한 넓은 공간(場)을 의미합니다.

ために
~를 위해, ~때문에(ために)
為 (할 위) = 원어인 'ため(為)'는 爪 (손톱 조)와 象 (코끼리 상)이 합쳐져 손으로 코끼리를 길들여 부린다는 뜻에서 '하다, 위하다'의 뜻이 되었습니다.
어떤 목적을 이루기 위한 행동의 목표를 나타내거나, 어떠한 결과가 발생하게 된 원인이나 이유를 나타내는 형식 명사 문형입니다. (보통 히라가나로 씁니다.)

代わりに
대신에(かわりに)
代 (대신할 대) = 亻 (사람 인) + 弋 (주살 익) : 사람(亻)이 막대기나 역할(弋)을 번갈아 넘겨받으며 임무를 대신한다는 뜻입니다.
원래 있던 사람이나 사물이 하던 역할을 물러나게 하고, 다른 사람이나 사물이 그 자리나 역할을 교체하여 맡는 상황을 의미합니다.

通りに
~대로, ~와 같이(とおりに)
通 (통할 통) = 辶 (쉬엄쉬엄 갈 착) + 甬 (솟을 용) : 솟아난 길을 막힘없이 쭉 지나간다는 뜻에서 뚫리다, 통하다를 뜻합니다.
어떤 기준, 규칙, 명령, 혹은 기대했던 바와 어긋남이 없이 똑같이 진행되거나 같은 상태임을 나타내는 표현입니다.

度に
~할 때마다(たびに)
度(법도 도)는 횟수나 때를 가리킵니다.

おかげで
덕분에(おかげで)
陰 (그늘 음) = 阝 (언덕 부) + 侌 (그늘 음) : 언덕에 가려진 그늘을 뜻합니다. (어원이 되는 한자)
원래 '신이나 부처의 가려진 그늘이나 가호(御陰)'를 뜻하던 단어에서 유래하여, 남의 도움이나 은혜로운 원인 덕분에 좋은 결과를 얻게 되었음을 감사하며 표현하는 문형입니다.

せいで
~탓에 (せいで)
所 (바 소) + 為 (할 위) : 한자 '所為(しょい)'에서 유래하여 'せい'가 되었습니다. 행동한 바, 즉 원인을 뜻합니다.
 어떤 나쁜 결과가 발생한 원인이나 이유를 남의 탓이나 특정 상황으로 돌려 불만을 나타낼 때 사용하는 표현입니다.

くせに
~주제에, ~임에도 불구하고(くせに)
癖 (버릇 벽) = 疒 (병들 녁) + 辟 (피할 피/치우칠 벽) : 고치기 힘든 병(疒)처럼 몸에 깊이 배어버린 나쁜 습관이나 치우친 성향을 뜻합니다.
명사 '癖(くせ)'에서 유래하여, 앞의 사실로부터 기대되는 것과는 정반대로 부정적인 행동이나 상태가 이어질 때, 상대를 비난하거나 경멸하는 뉘앙스를 담아 쓰는 문법 표현입니다.

ついでに
~하는 김에(ついでに)
序 (차례 서) = 广 (집 엄) + 予 (나 여/미리 여) : 집의 차례나 순서를 뜻하며, '序でに'로 표기하기도 합니다.
어떤 주된 목적을 위해 행동하는 김에, 그 기회를 이용하여 관련된 다른 부차적인 행동까지 순서대로 곁들여서 함께 하는 상황을 나타냅니다.

上に
~인 데다가, ~뿐만 아니라(うえに)
上 (윗 상) = 기준선(一) 위에 점을 찍어 위쪽을 나타낸 지사자입니다.
어떤 사실이나 상태가 이미 존재함(上)을 바탕으로, 거기에 또 다른 비슷한 성질의 장점이나 단점이 더해져 정도가 한층 심해짐을 나타내는 첨가의 문형입니다.

恐れがある
~할 우려가 있다(おそれがある)
恐 (두려울 공) = 心 (마음 심) + 巩 (안을 공/묶을 공) : 마음(心)이 오그라들며 단단히 묶이듯 두려움을 느낀다는 뜻입니다.
앞으로 나쁜 일이나 위험한 사태가 일어날 가능성이나 걱정거리(恐れ)가 존재함(ある)을 나타내는 격식 있는 문형으로, 주로 뉴스나 공적인 안내에서 사용됩니다.

潰れる
찌그러지다, 무너지다, 망하다(つぶれる)
潰 (무너질 궤) = 氵 (물 수) + 貴 (귀할 귀) : 귀한(貴) 물건이나 잘 쌓아둔 것이 물(氵)에 불어 형태가 허물어지고 무너진다는 뜻입니다.
원래 있던 입체적인 형태가 외부의 압력에 눌려 찌그러지거나 무너지는 것을 뜻하며, 비유적으로 회사나 가게가 파산하여 망하거나 체면과 계획이 수포로 돌아감을 의미하는 자동사입니다.

続く
계속되다, 이어지다(つづく)
続 (이을 속) = 糸 (실 사) + 売 (팔 매/잇닿을 육의 변형) : 실(糸)이 끊어지지 않고 쭉 길게 이어진다는 뜻입니다.
어떤 동작, 상태, 혹은 사물이 중간에 끊어지지 않고 길게 연결되어 유지되거나, 시간적으로 연속해서 일어나는 현상을 의미합니다.

居眠り
앉아 졺, 선잠(いねむり)
居 (살 거) = 尸 (주검 시/몸) + 古 (옛 고) : 사람의 몸(尸)이 한 장소에 오래(古) 앉아 머무른다는 뜻입니다.
眠 (잘 면) = 目 (눈 목) + 民 (백성 민/어두울 민) : 눈(目)을 감아 시야가 어두워지며(民) 잠에 든다는 뜻입니다.
본격적으로 자리에 눕지 않고, 앉아 있는(居) 자세 그대로 눈을 감고 꾸벅꾸벅 선잠을 자는(眠り) 행동을 의미합니다.

左に曲がる
왼쪽으로 돌다, 좌회전하다(ひだりにまがる)
左 (왼 좌) = 𠂇 (왼손 좌) + 工 (장인 공) : 왼손에 자나 도구(工)를 들고 작업하는 모습에서 왼쪽을 뜻합니다.
曲 (굽을 곡) = 대나무나 나무를 구부려 만든 굽은 자의 모양이나 바구니의 모양을 본뜬 상형자로, 굽히거나 꺾임을 뜻합니다.
길을 가다가 진행 방향을 굽혀서(曲がる) 왼쪽(左) 방향으로 꺾어 나아가는 행위를 뜻합니다.
