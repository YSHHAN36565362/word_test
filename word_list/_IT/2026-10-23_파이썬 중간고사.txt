프로그래밍 언어 (Programming Language)

인간이 일상적인 언어나 기호를 이용하여 하드웨어 지식 없이도 쉽게 작성할 수 있는 프로그래밍 언어는?

[치트키] 책 전체를 한 번에 번역하여 출판하는 번역가

고급 언어의 원시 코드를 한 줄씩 읽고 직접 해석하여 실행하는 가상의 컴퓨터 역할은?

[치트키] 옆에서 한 문장씩 즉각 통역해주는 동시통역사

프로그래밍 실행 시 서로 다른 컴퓨터 기종에서도 똑같은 결과를 도출해야 하는 프로그래밍 언어의 특성은?
기계 독립성 (Machine Independence)

100, 1.23, 파이썬 처럼 숫자나 문자열과 같이 소스 코드에 직접 표기한 데이터 상수 값은?
리터럴 (Literal)
[종합] 변수에 대입되는 변하지 않는 데이터 값 그 자체를 의미합니다.

참(True)이나 거짓(False)을 저장할 수 있으며, 조건문이나 반복문의 조건식 결과로 주로 사용되는 데이터 형식은?

특정 함수 내부에서 선언되어 해당 함수 내부에서만 생존하고 인식되는 변수는?
지역 변수
[헷갈리는 단어] 전역 변수 (함수 외부에서 선언되어 프로그램 전체에서 인식되는 변수)

리스트, 딕셔너리, 세트처럼 한 번 생성한 후에도 내부의 값을 추가, 삭제, 수정할 수 있는 데이터 형식은?
가변형 데이터 형식
[헷갈리는 단어] 불변형 데이터 형식 (문자열, 튜플처럼 한 번 저장하면 값을 변경할 수 없는 데이터 형식)

변수를 한 줄로 붙여 전체 이름을 지정하고, 각 값에 0부터 시작하는 첨자(인덱스)를 붙여 사용하는 가변형 자료구조는?
리스트 (List)
[종합] 꺾쇠 괄호로 생성하며, 접근 시 맨 뒤의 항목은 마이너스 1 인덱스를 사용하여 가져옵니다.

중괄호로 묶어 생성하며 고유한 키(Key)와 값(Value) 쌍으로 구성되는 가변형 자료구조는?
딕셔너리 (Dictionary)
[종합] 순서가 보장되지 않으며 키는 유일해야 합니다. 이미 존재하는 키에 새 값을 대입하면 기존 값이 덮어씌워집니다.

키만 모아 놓은 딕셔너리의 특수한 형태로, 중복된 값을 허용하지 않는 가변형 자료구조는?

리스트와 비슷하게 소괄호로 생성하지만, 값을 수정할 수 없고 읽기만 가능한 불변형 자료구조는?

파이썬에서 input() 함수로 키보드 입력을 받을 때 기본적으로 취급되는 데이터 타입은?

반복문 안에서 조건과 상관없이 무조건 반복문을 완전히 탈출하여 종료시키는 제어 키워드는?

[헷갈리는 단어] continue 문 (이하의 코드를 건너뛰고 반복문의 처음으로 다시 돌아가는 키워드)

global 예약어
[종합] 함수 내부에서 이 예약어 없이 변수 값을 대입하면 새로운 지역 변수가 생성됩니다.

딕셔너리에서 존재하지 않는 키를 호출할 때 시스템 오류 없이 아무것도 반환하지 않게 처리해주는 추출 함수는?

파이썬 리스트의 맨 뒤에 새로운 항목을 추가할 때 사용하는 함수는?

[치트키] "하나여도 쉼표는 꼭!" 쉼표가 튜플을 만든다.

시퀀스의 색인 방향 체계는 어떻게 되어 있나요?
좌측 0부터 시작하는 양수 색인, 우측 -1부터 시작하는 음수 색인
[종합] 양수 색인은 왼쪽에서 0, 1, 2 순서로, 음수 색인은 오른쪽에서 -1, -2 순서로 번호를 매겨 양방향 탐색이 가능.
[예문] 리스트의 맨 마지막 항목은 색인 -1로 접근.

set('hello')를 실행했을 때 결과와 그 이유는?
{'o','h','e','l'} (중복된 'l'이 삭제됨)
[종합] 세트는 중복을 허용하지 않으므로 문자열의 중복 문자가 하나로 합쳐짐. 순서도 보장되지 않음.
[치트키] 세트는 같은 글자를 한 번만 받아주는 깐깐한 바구니.

세트에서 특정 위치의 항목을 접근하거나 검색할 수 없는 이유는?
순서가 없어서 색인 정보를 사용할 수 없기 때문
[종합] 세트는 unordered 구조라 위치 번호 개념이 없음. 따라서 인덱스로 접근할 수 없음.
[헷갈리는 단어] 리스트와 튜플은 순서가 있어 색인이 가능하지만 세트는 불가능.

세트 자료형이 주로 활용되는 세 가지 용도는?
항목 존재 여부 파악, 중복 제거 필터, 수학적 집합 연산
[종합] 중복 불허와 무순서라는 특성 때문에 존재 확인, 자료형의 중복 제거 필터, 교집합, 차집합, 합집합 연산에 쓰임.
[예문] set([1, 2, 2, 3, 3, 3])의 결과는 {1, 2, 3}으로 중복 제거됨.

딕셔너리의 키(Key)로 사용할 수 있는 자료형과 없는 자료형은?
사용 가능: 정수, 실수, 문자열, 튜플 / 사용 불가: 리스트
[종합] 키는 한 번 정해지면 변경 불가(immutable)해야 하므로 변경 가능한 리스트는 키가 될 수 없음. 리스트를 키로 쓰면 TypeError가 발생.
[치트키] 이름표(키)는 바뀌면 안 된다. 바뀌는 리스트는 이름표 자격 박탈.
[헷갈리는 단어] 벨류(Value)에는 어떤 자료형이든 들어갈 수 있고 값 변경도 가능(mutable).

딕셔너리의 벨류(Value)에 관한 제약 조건은?
제약 없음: 어떤 자료형이든 가능하며 값 변경 가능(mutable)
[종합] 키와 달리 벨류에는 리스트를 포함한 모든 자료형이 들어갈 수 있고 나중에 바꿀 수 있음.
[헷갈리는 단어] 키는 immutable 필수, 벨류는 mutable 허용.

딕셔너리에서 존재하지 않는 키를 대괄호로 직접 호출하면 발생하는 예외와, 검색 방향의 제한은?
KeyError 예외 발생 / 키로 벨류만 검색 가능 (dic[벨류]로 키 검색은 불가)
[종합] dic["키"] 방식으로 값을 검색하며 없는 키를 호출하면 KeyError. 반대로 벨류로 키를 찾는 dic[벨류] 방식은 사용할 수 없음.
[헷갈리는 단어] 리스트 색인 범위 초과 시에는 IndexError, 딕셔너리 없는 키는 KeyError.

딕셔너리에 for문을 적용하면 반복 변수에 기본적으로 배정되는 것과 출력 순서의 특징은?
키(Key)값이 배정되며, 출력 순서는 만든 순서와 다를 수 있음
[종합] 딕셔너리는 비순서화된 시퀀스이므로 for문 순회 시 생성 순서와 출력 순서가 다를 수 있고, 기본적으로 키가 반복 변수에 배정됨.
[예문] for k in dic: 에서 k에는 키가 들어옴.

시퀀스 자료형에 공통으로 쓰이는 네 가지 연산자 공식은?
결합 seq + seq / 반복 seq 곱하기 정수 / 길이 len(seq) / 포함 확인 expr in seq
[종합] 결합은 더하기 기호, 반복은 곱셈 기호와 정수(정수가 앞에 와도 됨), 길이는 len(), 값 유무 확인은 in 연산자(불리언 반환).
[예문] 리스트에 3을 곱하면 내용이 3번 반복되고, 3 in 리스트는 True 또는 False를 반환.

시퀀스에서 일부 항목을 잘라내는 추출(Slice) 문법 세 가지는?
seq[start:end] / seq[start:end:n] / seq[:]
[종합] start 위치에서 시작해 end 위치 이전까지 추출. start:end:n은 매 n번째 항목만 추출. start나 end를 생략하면 처음 또는 끝을 의미하고 [:]는 전체를 의미.
[치트키] end는 포함 안 한다 (end 이전까지).
[예문] [10, 20, 30, 40][1:3]의 결과는 [20, 30].

리스트에 항목을 추가하는 세 가지 메소드와 그 차이는?
append(x), insert(i, x), extend(새 리스트)
[종합] append는 맨 끝에 x를 추가, insert는 i 위치에 x를 삽입, extend는 리스트 끝에 새 리스트를 결합해 추가.
[헷갈리는 단어] append는 항목 1개 추가, extend는 리스트의 항목들을 풀어서 이어 붙임.

리스트 항목 삭제 방식인 remove(x), pop(i), del list[i]의 차이는?
remove: 값 x 중 처음 한 개 삭제 / pop: i번째 삭제 후 값 반환 / del: i번째 단순 삭제
[종합] remove(x)는 값을 검색해 맨 처음 나타나는 항목만 제거. pop(i)는 i번째 항목을 삭제하며 그 값을 반환하고 i를 생략하면 맨 마지막 항목을 삭제 후 반환. del list[i]는 반환 없이 삭제만 함.
[치트키] remove는 값으로 찾기, pop은 번호로 빼서 돌려받기, del은 번호로 그냥 버리기.
[헷갈리는 단어] clear()는 한 번에 모든 항목을 삭제.

리스트 전체 항목을 한 번에 삭제, 역순 정렬, 오름차순 정렬, 내림차순 정렬하는 메소드는?
clear() / reverse() / sort() / sort(reverse=True)
[종합] clear는 모든 항목 삭제, reverse는 순서를 거꾸로 뒤집음, sort는 오름차순 정렬, sort(reverse=True)는 내림차순 정렬.
[헷갈리는 단어] reverse는 정렬이 아니라 단순히 순서를 뒤집는 것. 값 크기 정렬은 sort.

리스트에서 특정 값의 위치와 출현 횟수를 알려주는 메소드는?
index(x) / count(x)
[종합] index(x)는 x가 맨 처음 나타나는 곳의 위치 색인을 반환, count(x)는 리스트 내 x의 출현 횟수를 반환.
[예문] [1, 2, 2, 3].count(2)의 결과는 2, .index(2)의 결과는 1.

세트의 교집합, 합집합, 차집합을 구하는 기호와 함수는?
교집합 & 또는 intersection() / 합집합 | 또는 union() / 차집합 - 또는 difference()
[종합] 세트는 기호와 메소드 두 가지 방식 모두로 수학적 집합 연산을 지원.
[치트키] 앤드(&)는 둘 다 있는 것, 막대(|)는 전부 합치기, 마이너스(-)는 빼기.

딕셔너리의 키, 벨류, 키-벨류 쌍을 각각 반환하는 메소드와 반환 형태는?
keys() → dict_keys / values() → dict_values / items() → dict_items (튜플 (key, value) 시퀀스)
[종합] 반환값은 완전한 리스트가 아니므로 리스트로 저장하려면 list(dict.keys())처럼 list() 함수로 감싸야 함.
[예문] list(dic.items())의 결과는 [(키1, 값1), (키2, 값2)] 형태.

딕셔너리에 항목을 추가, 덮어쓰기, 삭제하는 방법과 KeyError 없이 값을 안전하게 얻는 메소드는?
dict[key] = value (추가 또는 덮어쓰기) / del dict[key] (삭제) / dict.get(key, default)
[종합] 새 키에 값을 대입하면 추가, 기존 키면 덮어씀. del은 키-값 쌍 전체를 제거. get(key, default)은 키가 있으면 벨류를, 없으면 에러 대신 지정한 default 값을 반환.
[치트키] get은 "없으면 이거라도 줘" 하는 안전장치.
[예문] dic.get("grape", "unknown")은 "grape" 키가 없으면 "unknown"을 반환.

컴퓨터 H/W(하드웨어)란 무엇인가요?
메인보드, CPU, RAM, 저장장치, 입출력 장치를 조립해 만드는 물리적 부품
[종합] 불량이 생기면 해당 부분만 수리 또는 교체하는 물리적 부품.
[치트키] 하드(Hard)는 손으로 만질 수 있는 딱딱한 부품.
[헷갈리는 단어] S/W는 부품이 아니라 실행 논리를 기술한 프로그램.

프로그램 S/W(소프트웨어)의 구성 방식은?
미리 만들어 둔 함수들을 조합해 만드는 커다란 프로그램
[종합] 자주 쓸 코드를 미리 만들어 두고 필요할 때 가져다 쓰며, 실행 논리를 기술한 함수들의 조합으로 구성됨.
[치트키] 소프트웨어는 레고 블록(함수)을 조립한 완성작.
[헷갈리는 단어] H/W는 물리적 부품, S/W는 부품 위에서 동작하는 프로그램.

어떤 목적의 작업을 수행하기 위한 명령어들의 집합은?
함수(Function)
[종합] 한 번 정의해 두면 언제든 호출해서 쓸 수 있는 명령어 묶음. 서브 프로그램(Sub-Program)이라고도 부름.
[치트키] 자판기. 버튼(입력)을 누르면 음료(결과)가 나옴.

프로그램 안에 있는 좀 더 작은 프로그램으로 함수를 가리키는 용어는?
서브 프로그램(Sub-Program)
[종합] 큰 프로그램 안에서 특정 작업을 맡는 작은 프로그램, 즉 함수의 다른 이름.

언어 설계 과정에서 미리 만들어졌고 성능이 검증되어 import가 필요 없는 함수는?
내장 함수(Built-in-function)
[종합] 파이썬이 기본으로 제공하며 검증이 끝난 함수. 목록은 docs.python.org/3/library/functions.html에서 확인 가능.
[예문] print(), int(), len() 등.
[헷갈리는 단어] 사용자 정의 함수는 사용자가 직접 만들고 검증이 미확인 상태.

내장 함수 이외에 사용자가 필요에 따라 만든 함수는?
사용자 정의 함수(User Defined Function)
[종합] 성능 검증은 미확인 상태이며, 사용자에 따라 공개 및 공유가 가능한 함수.
[치트키] 내장 함수는 공장 출고품, 사용자 정의 함수는 수제품.
[헷갈리는 단어] 내장 함수는 검증 완료이고 import 불필요.

함수가 필요한 이유(도입 배경)는?
동일한 코드를 여러 번 작성하는 문제를 해결하기 위해
[종합] a, b 비교 시 매번 if a > b: 를 반복 작성하는 대신 max(a, b) 함수를 만들어 값만 바꿔 여러 번 호출하면 효율적.
[예문] a=3, b=5이면 max = 5, a=9, b=6이면 max = 9를 같은 함수로 처리.

함수를 사용하면 얻는 장점 네 가지는?
코드 재활용, 중복 감소로 효율성 향상, 이해하기 쉬움, 유지보수 간편
[종합] 한 번 정의하면 언제든 호출 가능하고, 함수 이름으로 기능을 예측할 수 있어 프로그램 이해와 유지보수가 쉬워짐.
[예문] 함수 A(입력), B(처리), C(계산), D(출력)로 구성하면 오류 시 문제가 된 함수 C만 찾아 수정 가능.

함수 정의의 4가지 필수 요소는?
def 키워드와 함수 이름, 소괄호 안 매개변수, 들여쓰기된 함수 본체 블록, 필요 시 return 값
[종합] def로 이름을 기술하고, 소괄호 안에 0개 이상의 매개변수를 지정하며, 콜론 다음 줄부터 들여쓰기한 명령문을 나열하고, 필요 시 return으로 값을 반환.
[치트키] 정의 = def + 이름 + (매개변수) + 콜론 + 들여쓰기.

함수 정의 시 입력받을 변수를 선언한 것으로 함수 안에서만 쓰이는 지역변수는?
형식인자(Formal parameters)
[종합] 매개변수 혹은 인수로도 불리며, 0개 이상 정의 가능하고 쉼표로 구분. 함수가 종료되면 값은 삭제됨.
[헷갈리는 단어] 실제인자는 호출할 때 실제로 넘기는 값.

함수를 호출할 때 실제로 입력되는 값은?
실제인자(Actual parameters)
[종합] 호출 시 형식인자에 바인딩(binding)되며, 형식인자 개수와 맞지 않으면 오류 발생.
[예문] def sing(person): 에서 person은 형식인자, sing("Fred")의 "Fred"는 실제인자.
[헷갈리는 단어] 형식인자는 정의할 때 선언한 변수, 실제인자는 호출할 때 넘기는 값.

함수 호출의 4가지 유형은?
입력 유무와 반환 유무를 조합한 4가지
[종합] 입력 있음+반환 있음, 입력 있음+반환 없음, 입력 없음+반환 있음, 입력 없음+반환 없음.
[치트키] 입력 O/X와 출력 O/X의 2x2 조합으로 외우기.

함수 내에서 선언되어 외부에서 접근할 수 없고 함수 밖 변수와 별개로 취급되는 변수는?
지역 변수(Local Variable)
[종합] 매개변수를 포함해 함수 안에서 선언된 변수. 외부 변수와 이름이 같아도 서로 다른 변수.
[치트키] 지역 변수는 방 안에서만 쓰는 물건. 방을 나가면 사라짐.
[헷갈리는 단어] 전역 변수는 프로그램 어디서나 접근 가능.

프로그램 어디에서도 접근 가능하도록 전역으로 선언된 변수는?
전역 변수(Global Variable)
[종합] 함수 밖에서 선언되어 프로그램 전체에서 접근 가능한 변수.
[헷갈리는 단어] 지역 변수는 함수 내부에서만 유효.

x=50일 때 change_x(x) 함수 내부에서 x=0으로 바꾸면 함수 종료 후 외부 x 값은?
여전히 50
[종합] 함수 안의 x는 지역변수라 외부 x와 별개. 반환해서 받지 않는 한 외부 값과 무관.
[치트키] 복사본을 고쳤을 뿐 원본은 그대로.

함수 내부에서 외부 변수 값을 직접 바꾸고 싶을 때 사용하는 키워드는?
global
[종합] global x로 선언한 뒤 x=0을 대입하면 함수 종료 후 외부 x도 0으로 영구 변경됨.
[예문] def change_x(): global x; x = 0 호출 후 외부 x는 0.
[헷갈리는 단어] global 없이 대입하면 지역변수가 새로 만들어질 뿐 외부 값은 안 바뀜.

함수 호출 시 인자를 안 넘겨도 에러 없이 자동으로 쓰이도록 미리 설정해 두는 값은?
기본 인자(Default Parameter)
[종합] 함수 정의 시 반드시 상수로 지정하며, 필수 인자와 조합 가능.
[예문] def repeat_msg(msg, times=1): 에서 repeat_msg("Hello")는 기본값 1 적용, repeat_msg("Bye", 2)는 입력값 2 적용.

매개변수 이름을 직접 명시하여 매개변수이름=값 형태로 인자를 전달하는 방식은?
키워드 인수(Keyword Argument)
[종합] 인수 순서를 신경 쓰지 않고 바꿀 수 있고, 인수가 많을 때 가독성이 높아짐. 특정 매개변수만 값을 주고 나머지는 기본값으로 채울 수 있어 기본값과 자주 함께 쓰임.
[예문] keyword_function(a, b=0, c=0)에 대해 keyword_function(25, c=20), keyword_function(c=50, a=100) 호출 가능.
[헷갈리는 단어] 기본 인자는 정의할 때 설정, 키워드 인수는 호출할 때 이름을 명시.

매개변수를 원하는 만큼 무한히 받을 수 있는 함수 인자 형태는?
가변 매개변수(Variable Arguments)
[종합] 형식 인자 앞에 *를 붙여 def 함수이름(매개변수, ..., *가변매개변수): 로 선언.
[예문] def print_n_times(n, *values): 에 print_n_times(4, "Oh!", "Happy", "Day")처럼 호출.

가변 매개변수로 입력된 값들은 함수 내부에서 어떤 자료형으로 저장되나요?
튜플(tuple)
[종합] 입력값들이 튜플로 묶여 저장되어 반복문 적용이 가능함.
[헷갈리는 단어] 리스트가 아니라 튜플로 저장됨.

가변 매개변수는 한 함수에 몇 개까지 사용할 수 있나요?
단 하나만
[종합] 함수 정의에서 가변 매개변수는 한 개만 사용 가능.
[치트키] 가변은 만능 주머니 하나뿐.

함수가 내부 연산 결과를 호출된 위치로 돌려주는 값은?
반환 값(Return Value)
[종합] return을 만나면 즉시 값을 넘기고 함수가 완전 종료됨. 반환된 값은 호출 위치에서 다음 명령문이나 제어문에 사용됨. 입력값과 반환값의 자료형은 달라도 됨.
[예문] def add(a, b): return a + b

return 문을 사용하지 않은 함수가 반환하는 객체는?
None 객체
[종합] return을 생략하면 파이썬은 내부적으로 특별한 객체인 None을 반환함.
[예문] 값을 반환하지 않는 empty_return()을 print()로 감싸 출력하면 None이 출력됨.
[헷갈리는 단어] return 0이나 return ""와 달리, return 생략은 None.

return 구문으로 반환할 수 있는 항목은?
변수 및 수식 결과, 정수, 실수, 문자, Boolean, List, Dictionary, Tuple, Class 등 모든 자료형
[종합] 변수 값, 산술연산(a+b), 비교 및 관계 연산(1 < 2)의 결과와 모든 자료형을 반환할 수 있음.
[예문] return 0, return "Zero", return [1, 2, 3, 4, 5], return True

반환값이 있는 함수를 호출할 때 데이터 유실을 막으려면 어떻게 해야 하나요?
호출하는 쪽에서 반환값을 특정 변수에 저장
[종합] 반환값을 변수에 저장하지 않으면 결과가 사라짐.
[예문] amount = addInterest(amount, rate)
[치트키] 택배(return)가 오면 받을 곳(변수)이 있어야 한다.

Happy Birthday Song 실습에서 happy() 함수를 만든 이유는?
"Happy birthday to you!" 세 줄의 중복 코드를 하나로 묶기 위해
[종합] happy()가 동일 문장을 대체하고, singFred() 안에서 happy() 3번과 Fred를 부르는 문장을 조합함.
[예문] singFred()는 happy()를 3번 호출한 뒤 Fred 문장을 출력.

singFred(), singLucy()처럼 이름만 다른 함수가 중복될 때의 해결책은?
함수 인자를 도입해 def sing(person): 으로 일반화
[종합] 세 번째 줄의 이름만 다르고 나머지가 중복되므로, 지역변수 person에 sing("Fred"), sing("Lucy")처럼 실제 인수를 넘기면 하나의 함수로 모든 이름을 처리 가능.
[치트키] 달라지는 부분만 인자로 뽑아낸다.

은행 계좌 프로그램에서 addInterest(balance, rate)가 갱신된 원금을 반영하지 못한 원인과 해결책은?
return 누락 / return balance 추가 후 amount = addInterest(amount, rate)로 저장
[종합] 함수 내부에서는 newBalance = balance * (1 + rate)로 1050.0이 되었지만 return하지 않아 지역변수가 소멸하고 외부 amount는 1000으로 남음. return balance를 추가하고 반환값을 amount에 저장하면 1050.0이 유지됨.
[예문] amount=1000, rate=0.05이면 수정 후 1050.0.
[헷갈리는 단어] 지역변수 balance를 바꿔도 외부 amount는 자동으로 바뀌지 않음.

모듈 중 가장 먼저 외울, 함수보다 더 큰 단위의 코드 묶음이며 모듈명.py 파일 형태인 것은?
모듈(Module)
[종합] 파이썬의 클래스, 함수, 변수 등의 정의와 문장들을 담고 있는 파일.
[치트키] 함수가 레고 블록 하나라면, 모듈은 블록 상자 하나.
[헷갈리는 단어] 함수는 명령어 집합, 모듈은 그보다 큰 코드 묶음 파일.

파이썬 인터프리터와 함께 기본 제공되며 200개 이상이 존재하는 모듈은?
표준 모듈(Standard Module)
[종합] 파이썬 표준 라이브러리에 200개 이상 포함된 기본 제공 모듈.
[예문] os, sys, time, calendar, random, datetime, math.

모듈을 도입했을 때 얻는 두 가지 효과는?
효율성 증대, 재사용성 극대화
[종합] 용도에 따라 기능을 분리해 작성할 수 있어 효율성이 높아지고, 새로 작성하지 않고 기존 모듈을 가져다 쓸 수 있어 재사용성이 커짐.

모듈 전체를 가져오는 구문과 함수 호출 방식은?
import 모듈이름 / 모듈의이름.함수이름 형태로 호출
[종합] 모듈 안의 함수를 쓸 때 반드시 모듈 이름을 앞에 붙여야 함. 사용자가 만든 모듈은 실행하는 파일과 같은 위치에 있어야 함.
[예문] import math 후 math.pow(3, 3)
[헷갈리는 단어] from 방식은 모듈 이름 없이 함수 이름만으로 호출.

모듈의 특정 함수만 선택적으로 가져오는 구문은?
from 모듈이름 import 함수이름, ...
[종합] 1개 이상의 특정 함수만 가져오며 2개 이상이면 콤마로 구분. 모듈 이름 없이 함수이름만으로 바로 호출 가능.
[예문] from math import pow, ceil 후 pow(3, 3)

모듈 안의 모든 함수를 한 번에 가져오는 구문은?
from 모듈이름 import 별표(ALL)
[종합] 별표는 ALL을 의미하며 모든 함수를 가져와 모듈 이름 없이 함수 이름만으로 즉시 호출 가능.
[헷갈리는 단어] import 모듈이름은 모듈명을 붙여야 하고, from 모듈이름 import 별표는 붙이지 않음.

모듈 전체의 이름을 새로 지정해서 가져오는 구문은?
import 모듈이름 as 새이름
[종합] 호출할 때는 새이름.함수이름 형태로 사용.
[예문] import math as m 후 m.pi

모듈 안의 특정 함수 이름을 새로 지정해서 가져오는 구문은?
from 모듈이름 import 함수이름 as 새이름
[종합] 가져온 함수를 새 함수 이름만으로 즉시 사용 가능.
[헷갈리는 단어] import as는 모듈 이름을 바꾸고, from import as는 함수 이름을 바꿈.

파이썬이 import할 때 모듈을 검색하는 경로 3단계 순서는?
1 현재 디렉토리 → 2 환경변수 PYTHONPATH → 3 파이썬 설치 경로와 그 밑 라이브러리 경로
[종합] 세 경로를 취합해 시스템 경로 sys.path에 리스트 형태로 저장한 뒤 활용.
[치트키] 내 방(현재) → 내 환경변수 → 파이썬 본가(설치 경로) 순.

환경 변수, 디렉터리, 파일 등 운영체제 자원을 제어하는 기본 모듈은?
os 모듈
[종합] 운영체제 명령어들을 파이썬 상에서 실행할 수 있게 하는 모듈.
[헷갈리는 단어] sys 모듈은 파이썬 인터프리터 쪽 변수와 함수를 제어.

파이썬 인터프리터가 제공하는 변수와 함수를 제어하고 시스템 정보를 제공하는 기본 모듈은?
sys 모듈
[종합] 매개변수, 인자값 등 인터프리터 관련 변수와 함수를 직접 제어하고 시스템 관련 정보를 제공.
[헷갈리는 단어] os 모듈은 운영체제 자원 제어.

time, calendar, random 모듈은 각각 어떤 기능을 제공하나요?
time: 시간 관련 / calendar: 달력 보기 / random: 무작위 수 생성, 추출, 섞기
[종합] 모두 파이썬 기본 모듈이며 이름이 곧 기능을 암시함.

시스템의 시간과 날짜 정보를 제공하고 timedelta로 시간의 덧셈, 뺄셈을 지원하는 모듈은?
datetime 모듈
[종합] timedelta 클래스를 통해 시간 덧셈과 뺄셈 연산을 지원.
[헷갈리는 단어] time 모듈은 시간 관련 기능, datetime은 날짜와 시간 정보 및 연산.

수학 연산 함수와 자연 상수, 원주율 값을 제공하는 기본 모듈은?
math 모듈
[종합] pow, fabs, ceil, floor, log, 삼각함수 등과 math.pi, math.e를 제공.

os 모듈에서 운영체제 확인, 현재 폴더 경로 반환, 현재 폴더 내용 반환에 쓰는 것은?
os.name / getcwd() / listdir()
[종합] os.name은 현재 운영체제를 확인, getcwd()는 현재 작업 폴더 경로를 반환, listdir()는 현재 폴더 내부의 모든 요소를 반환.
[치트키] cwd = current working directory.

os 모듈에서 폴더를 만드는 함수와 폴더를 지우는 함수, 삭제 조건은?
mkdir("이름") 생성 / rmdir("이름") 삭제, 폴더가 비어있을 때만 가능
[종합] rmdir은 비어있는 폴더만 제거 가능하다는 제약이 있음.
[헷갈리는 단어] rmdir은 폴더 삭제, remove는 파일 삭제.

os 모듈에서 단일 파일을 삭제하는 함수는?
remove("이름") 또는 unlink("이름")
[종합] 폴더가 아니라 개별 파일을 삭제하며 두 함수는 같은 역할.
[헷갈리는 단어] 폴더는 rmdir로 삭제하며 비어있어야 함.

os 모듈에서 파일 이름 변경과 시스템 명령어 실행 함수는?
rename("기존이름", "새이름") / system("명령어")
[종합] rename은 파일명을 바꾸고, system은 시스템 명령어를 실행.
[예문] 윈도우에서 os.system("calc")는 계산기, os.system("notepad")는 메모장 실행.

sys 모듈에서 전달된 매개변수 출력, 파이썬 버전 출력, 저작권 정보 출력은 각각 무엇인가요?
sys.argv / sys.version / sys.copyright
[종합] argv는 시스템에 전달된 매개변수, version은 파이썬 버전, copyright는 저작권 정보를 출력. 윈도우 버전은 getwindowsversion.

sys 모듈에서 파이썬 설치 경로, 실행 파일 정보, 프로그램 강제 종료를 담당하는 것은?
sys.prefix / sys.executable / sys.exit
[종합] prefix는 설치 경로 정보, executable은 실행 파일 정보, exit은 프로그램을 즉시 강제 종료.

sys.path가 제공하는 정보는?
파이썬이 모듈을 검색하는 경로 정보 리스트
[종합] 현재 디렉토리, PYTHONPATH, 설치 경로를 취합한 리스트.
[치트키] path = 모듈 찾는 길.

random.random()과 random.uniform()의 차이는?
random(): 0.0 이상 1.0 미만 실수 난수 / uniform(a, b): 지정 범위 내 실수 난수
[종합] 둘 다 실수를 반환하며 uniform은 범위를 직접 지정.
[예문] random.uniform(2.5, 10.0)

random.randrange(시작, 끝, 간격)의 특징은?
범위를 지정해 정수 난수 생성, 세 번째 인자로 배수나 홀수/짝수 추출
[종합] 끝 값은 포함하지 않으며 세 번째 인자를 주면 간격대로 추출.
[예문] randrange(1, 100, 2)는 홀수, randrange(0, 10, 2)는 0, 2, 4, 6, 8 중 하나.
[헷갈리는 단어] randint는 양 끝 값을 모두 포함.

random.randint(a, b)의 특징은?
양 끝 값을 포함하는 임의의 정수 반환
[종합] 지정 범위의 시작과 끝을 모두 포함.
[예문] randint(1, 10)은 1 이상 10 이하 정수.
[헷갈리는 단어] randrange는 끝 값 미포함.

random 모듈의 choice, shuffle, sample은 각각 무엇을 하나요?
choice: 리스트에서 하나 추출 / shuffle: 리스트 원소 섞기 / sample: 리스트에서 k개 무작위 선택
[종합] choice는 원소 하나를 무작위로 추출, shuffle은 원소 위치를 랜덤하게 섞음, sample은 첫 번째 인자 리스트에서 두 번째 인자 k개를 고름.
[치트키] choice는 뽑기 1개, shuffle은 카드 섞기, sample은 k개 샘플링.

math 모듈의 pow와 fabs는 무엇을 하며 반환형은?
pow(밑, 지수): 제곱 연산 / fabs(값): 절대값, 둘 다 실수 반환
[예문] math.pow(3, 3)은 27.0, math.fabs(-99)는 99.0.

[치트키] filter는 커피 필터. 조건에 맞는 것만 통과.
[헷갈리는 단어] map은 모든 요소에 함수를 적용, filter는 조건에 맞는 요소만 남김.

[종합] 반환값은 리스트가 아니라 filter 객체이므로 형변환이 필요함. 형변환 없이 for문 범위로 직접 지정해 출력할 수도 있음.
[예문] list(filter(lambda x: x >= 19, ages))
[헷갈리는 단어] map도 map 객체를 반환하므로 같은 후처리가 필요.

반복가능한 객체의 모든 요소에 특정 함수를 일괄 적용하는 내장 함수는?
map()
[종합] 모든 요소에 무조건 함수를 적용하고 결과를 모아 map 객체로 반환하며 list(), tuple()로 형변환이 필요.
[치트키] map은 모든 요소에 같은 도장을 쾅쾅 찍는 것.
[헷갈리는 단어] filter는 일부만 남기고, map은 전부 변환.

map 함수의 공식과 사용 예는?
map(함수, 함수가 적용될 반복가능한 객체)
[종합] 일반 함수나 람다 함수를 첫 번째 인자로 넣을 수 있음.
[예문] list(map(square, n_list)) / 세제곱은 list(map(lambda x: x**3, a_list))

기존의 for문과 if문으로 리스트를 만드는 번거로움을 줄이는 파이썬 고급 문법은?
리스트 축약(List Comprehension)
[종합] 기존 리스트를 간결하게 생성하거나 조건을 걸어 새 리스트를 만드는 문법.
[치트키] 리스트를 한 줄로 압축해서 만드는 기술.

리스트 축약의 기본 공식과 조건부 공식은?
기본: [표현식 for 변수 in 시퀀스] / 조건부: [표현식 for 변수 in 시퀀스 if 조건문]
[종합] 조건부 공식은 뒤에 if 조건문을 붙여 조건에 맞는 항목만 포함.
[예문] [x * 2 for x in range(5) if x % 2 == 0]

리스트 축약의 장점과 단점은?
장점: 짧고 간결, 작성 시간 단축, 간단할 때 가독성 향상 / 단점: 복잡하면 가독성 저하
[종합] 복잡한 조건이나 중첩 루프가 들어가면 오히려 읽기 어려우므로 그럴 때는 기존 for문으로 풀어 쓰는 것이 좋음.

map()과 리스트 축약의 차이는?
map은 map 객체 반환(형변환 필요), 속도 우수 / 리스트 축약은 즉시 리스트 생성, 속도는 상대적으로 열세
[종합] 둘 다 리스트의 각 항목에 연산을 반복 적용할 수 있음.
[헷갈리는 단어] 형변환 필요 여부와 연산 속도가 핵심 차이.

문자열 'Hello World'에 [x.upper() for x in st]를 적용하면 어떤 결과가 나오나요?
각 글자가 대문자로 분리된 리스트
[종합] 문자열도 시퀀스이므로 글자 하나하나를 순회하며 upper()를 적용해 리스트로 만듦.
[예문] 'h'는 'H'로, 공백은 그대로 공백 요소로 남음.

input()으로 입력받은 여러 정수를 한 줄로 int 리스트로 만드는 코드는?
input_list1 = [int(x) for x in input().split()]
[종합] input()은 항상 문자열을 반환하므로 split()으로 분리한 뒤 각 원소에 int()를 적용.
[치트키] 입력, 쪼개기(split), 정수화(int)를 한 줄에.
[헷갈리는 단어] input()의 결과를 그대로 쓰면 숫자가 아니라 문자열.

리스트 축약에서 다중 for문과 복수 if 조건을 쓰는 방법은?
for와 if를 계속 중첩해 이어 씀
[종합] 이중 for문 표현과 여러 개의 if 조건식을 연속으로 붙여 거르는 것도 가능함.
[예문] [x * y for x in [1, 2, 3] for y in [2, 4, 6]] / if n % 2 == 0 if n % 3 == 0

여러 순회 가능한 객체의 같은 위치 원소끼리 튜플로 묶어 반환하는 내장 함수는?
zip()
[종합] 2개 이상의 iterable 객체를 인자로 받아 같은 인덱스 원소끼리 튜플로 묶어 zip 객체로 반환.
[치트키] zip은 지퍼. 양쪽 이빨이 같은 위치끼리 맞물림.
[예문] list(zip([1, 2, 3], ['a', 'b', 'c']))는 [(1, 'a'), (2, 'b'), (3, 'c')].

zip()이 반환한 zip 객체를 사용하려면 어떻게 해야 하나요?
list, tuple, dict로 형변환하거나 for문의 범위로 사용
[종합] zip 객체는 바로 쓸 수 없으므로 자료형 변환 또는 반복문 순회가 필요.
[헷갈리는 단어] filter, map, zip 모두 결과 객체를 형변환해야 확인 가능.

zip()에 길이가 다른 iterable을 넣으면 어떻게 처리되나요?
짧은 길이를 기준으로 묶고 나머지 긴 데이터는 무시
[종합] 인덱스 길이가 서로 맞지 않으면 예외 없이 짧은 쪽에 맞춰 묶음.
[예문] 원소 3개와 5개 리스트를 zip하면 튜플 3개가 반환됨.

내부에 원소들이 순서대로 존재해 하나씩 꺼낼 수 있는 객체는?
반복가능한 객체(iterable object)
[종합] 리스트, 튜플, 문자열 등이 해당하며 filter, map, zip의 입력으로 쓰임.
[예문] [1, 2, 3], (1, 2, 3), "abc"

zip, map, lambda를 결합해 words1과 words2를 하이픈으로 연결하는 코드는?
list(map(lambda x: x[0] + "-" + x[1], zip(words1, words2)))
[종합] zip이 두 리스트의 같은 위치 원소를 튜플로 묶고, map이 각 튜플에 람다를 적용해 x[0]과 x[1]을 하이픈으로 연결.
[치트키] zip으로 짝짓고, map으로 처리하고, list로 감싼다.

중간고사와 기말고사 점수 리스트를 합산해 평균을 구할 때 zip을 어떻게 활용하나요?
zip(midterm, final)로 같은 학생의 점수끼리 묶어 합산 후 평균 계산
[종합] 같은 인덱스끼리 튜플로 묶이므로 학생별 중간, 기말 점수를 함께 처리할 수 있음.
[예문] for m, f in zip(midterm, final): (m + f) / 2

filter, map, zip이 반환하는 객체의 공통점은?
모두 리스트가 아닌 별도 객체를 반환하므로 형변환 필요
[종합] filter는 filter 객체, map은 map 객체, zip은 zip 객체를 반환하며 list(), tuple() 등으로 변환하거나 for문에서 순회해 사용.
[헷갈리는 단어] 리스트 축약은 즉시 리스트를 생성하므로 형변환 불필요.

람다 함수에서 return 문 사용 여부는?
return 없이 콜론 우측에 반환 값을 바로 작성
[종합] 별도의 return 키워드 없이 표현식의 결과가 곧바로 반환값이 됨.
[헷갈리는 단어] 일반 def 함수는 return으로 값을 반환.
