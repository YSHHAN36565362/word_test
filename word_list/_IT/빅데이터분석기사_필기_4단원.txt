주성분 분석 (PCA, Principal Component Analysis)
상관성 높은 변수들을 선형결합해 차원을 축소하는 대표 기법
[구성] 주성분(Principal Component) + 분석(Analysis)
[의미] 고차원 데이터를 저차원으로 줄이면서도 데이터의 정보(분산)를 최대한 보존하는 방법. 변수들 간의 중복(상관관계)을 제거해 새로운 축(주성분)을 만들고 그 축에 데이터를 투영
[구분] 기출 함정: "정규분포를 반드시 가정해야 한다" → 틀림! PCA는 정규분포를 가정하지 않음
[구분] 기출 함정: "데이터 변동성이 가장 작은 방향으로 첫 번째 주성분을 설정한다" → 틀림! 반대로 "변동성(분산)이 가장 큰 방향"으로 첫 번째 주성분(PC1)을 설정함 (4월 기출 45번)
[구분] 요인분석과 차이: PCA는 "정방행렬" 대상, 변수 간 상관관계가 있을 때 유용, 직교변환(orthogonal transformation) 사용
[치트키] "PCA = 분산이 제일 큰 방향부터 축을 잡아서(PC1이 가장 중요), 정보를 최대한 안 잃게 압축"
[예문] 여러 재무지표들이 서로 상관관계가 높을 때 PCA로 차원을 축소해 다중공선성 문제를 완화할 수 있다

요인분석 (Factor Analysis)
변수들을 회전시켜 잠재 요인을 도출하는 차원축소 기법
[구성] 요인(Factor) + 분석(Analysis)
[의미] 다수 변수들의 상관관계를 분석해 소수의 잠재 요인으로 축약하는 기법. 독립/종속변수 구분이 없고, 공분산·상관계수 등 기술통계 기반. 각 요인끼리는 서로 독립적(직교)
[구분] 요인회전 방식
· 직각회전(Varimax): 요인들 사이 상관관계를 0으로 만들어 독립적으로 가정
· 사각회전(Promax, Oblimin): 요인들 사이 상관관계를 0이 아닌 값으로 유지
[구분] PCA와 차이: PCA는 "데이터 요약·차원축소" 목적, 요인분석은 "숨겨진 원인(요인) 해석" 목적. PCA는 단순 수학 변환, 요인분석은 통계 모형 기반
[치트키] "요인분석 = 보이는 변수들 뒤에 숨은 진짜 원인(요인)을 찾아내는 것"
[예문] 여러 설문 문항의 응답 패턴을 분석해 그 뒤에 숨은 '만족도'라는 공통 요인을 추출하는 것이 요인분석이다

다차원 척도법 (MDS, Multi-Dimensional Scaling)
개체 간 거리를 보존하며 시각적으로 표현하는 차원축소 기법
[구성] 다차원(Multi-Dimensional) + 척도법(Scaling)
[의미] 개체 사이의 유사성(거리)을 보존하면서 고차원 데이터를 저차원(2~3차원)으로 축소해 군집을 시각적으로 표현하는 방법
[구분] PCA는 "분산 보존"이 목적, MDS는 "개체 간 거리(유사성) 보존"이 목적이라는 차이
[치트키] "MDS = 멀리 있는 애들은 멀리, 가까운 애들은 가깝게 그림으로 그려주는 방법"
[예문] 여러 도시 간 이동 거리 데이터를 바탕으로 MDS를 적용하면 지도처럼 위치를 재구성할 수 있다

특이값 분해 (SVD, Singular Value Decomposition)
비정방행렬을 분해하는 행렬 분해 기법
[구성] 특이값(Singular Value) + 분해(Decomposition)
[의미] M×N 크기의 "비정방행렬"(행과 열의 크기가 다른 행렬)을 분해하는 기법. 텍스트 마이닝에서 단어-문서 행렬(TDM)에 SVD를 적용하면 LSA(잠재 의미 분석)가 됨
[구분] PCA는 "정방행렬" 대상, SVD는 "비정방행렬"도 가능하다는 차이
[치트키] "SVD = 정사각형이 아니어도(비정방) 쪼갤 수 있는 분해법"
[예문] 단어-문서 행렬에 특이값 분해(SVD)를 적용해 단어와 문서 간 잠재적 의미 관계를 분석하는 기법이 LSA다

요약변수 vs 파생변수
데이터 전처리에서 새롭게 만드는 두 종류의 변수
[구성] 요약변수(Summary Variable) / 파생변수(Derived Variable)
[의미]
· 요약변수: 수집된 정보를 종합하여 요약해 만든 변수 (예: 월평균 기온, 고객별 총구매금액). 주로 집계(aggregate) 형태, 재사용성 높음, 데이터 마트의 기본 변수
· 파생변수: 기존 변수를 변형·결합해 새로운 변수를 생성한 것 (예: 성별+연령='중년 남성', 나이=올해-출생연도)
[구분] 파생변수는 "논리적 타당성"이 중요(왜 만들었는지 설명 가능해야 함), 분석 목표에 따라 유연하게 달라짐. 요약변수는 다양한 분석에 공통으로 재사용 가능
[치트키] "요약변수 = 여러 개를 하나로 합침(집계), 파생변수 = 기존 걸 가공/조합해서 새로 만듦"
[예문] 고객의 최근 1년간 평균 구매금액은 파생변수의 대표적인 예시다(4월 기출 25번)

Z-score 정규화 vs 최소-최대 정규화
수치형 변수를 변환하는 두 가지 대표 방법
[구성] Z-score 정규화(표준화) / 최소-최대 정규화
[의미]
· Z-score: (현재값-평균)/표준편차 → 평균 0, 표준편차 1로 변환
· 최소-최대 정규화: (현재값-최소값)/(최대값-최소값) → 특정 범위(보통 0~1)로 변환
[구분] 기출 함정: "표준화한 값에는 단위가 없다"는 표준화(Z-score)의 특징으로 옳은 설명 (8회 기출 24번)
[구분] "두 개 이상의 데이터를 합쳐서 하나로 표현" = 표준화가 아니라 통합/집계에 관한 설명(오답 함정)
[치트키] "Z-score = 평균에서 얼마나 떨어졌나(편차 기준), 최소-최대 = 범위 안에서 어디쯤인가(비율 기준)"
[예문] 딥러닝 모델에서 이미지 데이터를 [0,1] 범위로 변환하는 것은 최소-최대 정규화(일반화)에 해당한다

레이블 인코딩 vs 원-핫 인코딩 vs 타깃 인코딩
범주형 변수를 수치로 변환하는 3가지 방법
[구성] 레이블 인코딩(Label Encoding) / 원-핫 인코딩(One-Hot Encoding) / 타깃 인코딩(Target Encoding)
[의미]
· 레이블 인코딩: 데이터를 단순 정수로 변환(0,1,2...). 컴퓨터가 정수를 크기로 오인할 위험 있음
· 원-핫 인코딩: 고유값 해당 칼럼만 1로 표시, 나머지는 0 (예: [0,0,1])
· 타깃 인코딩: 타깃(종속) 변수의 평균값으로 범주를 변환
[구분] 레이블 인코딩의 단점(순서 없는 범주에 크기가 부여되는 문제)을 원-핫 인코딩으로 해결 가능. 단, 원-핫은 칼럼 수가 급증하는 단점
[치트키] "레이블(그냥 숫자 붙임) - 원핫(있으면 1 없으면 0) - 타깃(평균으로 대체)"
[예문] 성별처럼 순서가 없는 범주형 변수는 레이블 인코딩보다 원-핫 인코딩이 적합한 경우가 많다

불균형 데이터 처리 (언더샘플링/오버샘플링/SMOTE)
클래스 불균형 문제를 해결하는 샘플링 기법들
[구성] 언더샘플링(Under-sampling) / 오버샘플링(Over-sampling) / SMOTE
[의미]
· 언더샘플링: 다수 클래스 데이터를 일부만 선택해 줄임
· 오버샘플링: 소수 클래스 데이터를 복사해서 수를 늘림
· SMOTE: 가상의 직선을 활용해 소수 클래스 데이터를 "합성"하는 오버샘플링 기법 (단순 복제가 아님!)
[구분] 기출 함정: "SMOTE는 소수 클래스 데이터를 단순히 복제하는 오버샘플링 기법이다" → 틀림! SMOTE는 복제가 아니라 기존 데이터 사이를 보간해 새로운 데이터를 "합성"함 (4월 기출 30번)
[구분] 비용민감학습: 소수 클래스에 더 많은 가중치를 줘서 예측 정확도 향상(모든 클래스 중요도가 다를 때 사용)
[치트키] "언더=줄이기, 오버=복제해서 늘리기, SMOTE=진짜 새로 만들어서 늘리기(합성)"
[예문] 사기 탐지 모델에서 사기 거래(소수 클래스) 데이터를 SMOTE로 합성해 데이터 불균형을 완화했다

EDA (탐색적 자료 분석, Exploratory Data Analysis)
데이터 분석 전 구조와 특징을 파악하는 과정 (암기: 저잔재현)
[구성] 저항성(Resistance) + 잔차 계산(Residual) + 자료변수의 재표현(Re-expression) + 그래프를 통한 현시성(Graphic representation)
[의미] 데이터 속에 숨겨진 의미나 패턴을 미리 확인하고 직관적으로 이해하는 과정. 통계요약+시각화를 함께 사용(평균, 분산, 히스토그램, 박스플롯 등)
[구분] 저항성: 이상치에 영향을 적게 받는 성질 / 잔차 계산: 모형에서 벗어난 정도 파악 / 재표현: 데이터를 변환해 보기 쉽게 / 현시성: 그래프로 시각화
[치트키] "저잔재현 = 저항성 있게, 잔차 보고, 재표현하고, 현시(그래프)로 보여줌"
[예문] 이상치 확인, 변수 간 관계 파악, 결측치 확인은 EDA의 대표적인 실전 활용 예다

피어슨 상관계수 vs 스피어만 상관계수
두 변수 간 상관관계를 측정하는 대표적인 두 지표
[구성] 피어슨(Pearson) / 스피어만(Spearman)
[의미]
· 피어슨: 연속형 수치 데이터, 선형(직선) 관계만 측정, 원래 값을 그대로 사용, 이상치에 매우 민감
· 스피어만: 서열형(순서형) 또는 연속형 데이터, 단조(monotonic) 관계 측정(선형·비선형 모두 가능), 데이터를 순위(rank)로 바꿔 계산, 이상치에 덜 민감
[구분] 기출 함정: "피어슨 상관계수는 이상치의 영향을 크게 받지 않아 안정적이다" → 틀림! 피어슨은 오히려 이상치에 "매우 민감"함 (4월 기출 34번)
[구분] "상관관계가 없다는 것이 반드시 독립을 의미하지는 않는다" → 옳은 지문(비선형 관계는 상관계수가 0이어도 독립이 아닐 수 있음)
[치트키] "피어슨 = 정확한 수치 그대로(키·몸무게), 스피어만 = 순위로 바꿔서(만족도 1~5)"
[예문] 만족도 점수처럼 순위 중심의 자료는 피어슨보다 스피어만 상관계수가 적합하다

첨도와 왜도
자료 분포의 모양을 나타내는 두 통계량
[구성] 첨도(Kurtosis) / 왜도(Skewness)
[의미]
· 첨도: 분포가 얼마나 뾰족한지. 0=정규분포 기준(3을 기준으로 정규분포 형태 판단하기도 함)
· 왜도: 분포의 비대칭 정도. 0보다 크면 오른쪽 꼬리(최빈값<중앙값<평균값), 0보다 작으면 왼쪽 꼬리(최빈값>중앙값>평균값)
[구분] 왜도의 부호와 대표값 순서를 정확히 암기: 양(+)의 왜도(오른쪽 꼬리) → 최빈값<중앙값<평균값 순
[치트키] "첨도=뾰족한 정도, 왜도=삐뚤어진 정도(왜곡)"
[기출 포인트] "단일봉이면서 우측으로 꼬리가 긴 분포"의 대표값 순서 = 최빈값<중앙값<평균 (8회 기출 29번)

표본 추출 방법 5가지
모집단에서 표본을 뽑는 대표적인 방법들
[구성] 랜덤(단순 무작위) / 계통 / 집락(군집) / 층화 / 복원·비복원
[의미]
· 랜덤 추출법: 완전 무작위
· 계통 추출법: 일정 간격으로 순서대로 추출
· 집락(군집) 추출법: 여러 군집으로 나눈 뒤 "군집을 선택"하여 랜덤 추출 → 군집 내부는 이질적, 군집 간에는 동질적이어야 효율적
· 층화 추출법: 유사한 요소끼리 층을 묶어 층별로 추출 → 군집 내부는 동질적, 군집 간에는 이질적
· 복원/비복원: 복원=뽑은 걸 다시 넣음, 비복원=안 넣음
[구분] 기출 함정: 집락추출과 층화추출의 "군집 내/군집 간" 동질성·이질성이 정반대이므로 헷갈리지 않게 주의! (4월 기출 29번)
[치트키] "집락(군집추출) = 군집끼리는 비슷(동질), 군집 안은 다양(이질) / 층화 = 층 안은 비슷(동질), 층끼리는 다름(이질)"
[예문] 학교를 무작위로 몇 개 뽑아 그 학교의 전교생을 모두 조사하는 것은 집락(군집) 추출법이다

표본추출 오차 (과잉대표/최소대표)
모집단과 표본 간 차이로 발생하는 오차
[구성] 과잉 대표 / 최소 대표
[의미] 전수조사가 어려워 표본을 추출할 때 발생하는, 모집단과 다른 차이. 표본의 "크기"보다 "대표성"이 더 중요함
· 과잉 대표: 어떤 특성이 너무 많이 뽑힘(예: 모집단 남녀 50:50인데 표본은 여자 90%)
· 최소 대표: 뽑아야 할 특성이 너무 적게 뽑힘(예: 모집단 고등학생 50%인데 표본 10%)
[구분] 표본 크기를 늘리는 것보다 대표성을 확보하는 것이 표본추출 오차를 줄이는 핵심
[치트키] "과잉대표=너무 많이 뽑힘, 최소대표=너무 적게 뽑힘 - 둘 다 모집단 비율과 어긋난 상태"
[예문] 설문조사에서 특정 연령대가 실제 비율보다 과도하게 많이 포함된 것은 과잉 대표의 예다

이산확률분포 5총사 (암기: 배포항항하)
값을 셀 수 있는 확률변수를 나타내는 5가지 분포
[구성] 베르누이분포 → 포아송분포 → 이항분포 → 기하분포 → 다항분포 (암기순서: 배포항항하)
[의미]
· 베르누이분포: 한 번 시행에 결과가 두 개(성공/실패)
· 이항분포: 베르누이 시행을 n번 반복, 분산=np(1-p), 공식 P(X=k)=nCk·p^k·(1-p)^(n-k)
· 기하분포: 처음 성공할 때까지 걸리는 시도 횟수
· 다항분포: 결과가 여러 개일 때(범주 3개 이상)
· 포아송분포: 단위 시간/공간에서 발생하는 사건 수 (희귀 사건), λ(람다) 사용
[구분] 기출 함정: "이항분포 B(n,p)의 분산은 np(1-p)"가 정답 (np나 n(1-p)는 오답, 8회 기출 22번)
[치트키] "베포항항하 = 베르누이-포아송-이항-기하-다항 순서로 외우기"
[예문] 동전을 10번 던져 앞면이 나온 횟수는 이항분포 B(10, 0.5)를 따른다

연속확률분포 5총사 (암기: 지수카이FT정규)
값을 셀 수 없는 연속적인 확률변수의 5가지 분포와 관련 검정
[구성] 정규분포 / t-분포 / 카이제곱분포 / F-분포 / 지수분포
[의미]
· 정규분포: 종 모양, 평균 중심 대칭 → Z-검정
· t-분포: 표본 적을 때 평균 비교 → t-검정(2집단 평균 차이 검정), 자유도 n-1
· 카이제곱분포: 한쪽으로 치우친 모양 → 범주형 변수 독립성 검정
· F-분포: 두 집단의 분산 비교 → 분산이 같나 다르나 확인(F-검정)
· 지수분포: 사건 사이의 시간 간격 → 기계 고장까지 걸리는 시간, 생존분석
[구분] t-분포는 표본 수가 커지면(n≥30) 정규분포와 거의 같아짐. Z-검정은 "모표준편차를 알고 있을 때"만 사용, 모르면 t-검정 사용
[치트키] "정규(대칭 종모양)-t(적은 표본)-카이제곱(범주형)-F(분산비교)-지수(사건간격)"
[예문] 표본 크기가 30 미만이고 모표준편차를 모를 때는 t-분포를 이용한 t-검정을 사용한다

중심극한정리 (Central Limit Theorem)
표본 크기가 충분히 크면 표본분포가 정규분포를 이룬다는 정리
[구성] 중심(Central) + 극한(Limit) + 정리(Theorem)
[의미] 표본 크기가 충분히 크면(보통 n≥30) 모집단의 분포 형태와 상관없이 표본평균의 분포가 정규분포에 가까워진다는 이론
[구분] 표본분포의 평균은 모집단의 평균과 같음, 표본분포의 분산은 모집단의 분산을 표본 크기로 나눈 것과 같음
[구분] 기출 함정: "N 크기가 커지면 표본평균의 분산은 커지고, 표준편차는 작아진다" → 틀림! N이 커지면 표본평균의 "분산도 작아짐"(표준오차=표준편차/√n이 감소, 4월 기출 38번)
[치트키] "표본을 많이 뽑을수록(n↑) 원래 모집단 모양과 상관없이 표본평균은 종모양(정규분포)이 된다"
[예문] 동일한 확률분포를 가진 독립확률변수 n개 평균의 분포는 n이 적당히 크면 정규분포에 가까워진다는 것이 중심극한정리다(8회 기출 39번)

불편추정량 vs 일치추정량
모수 추정량의 두 가지 성질
[구성] 불편추정량(Unbiased Estimator) / 일치추정량(Consistent Estimator)
[의미]
· 불편추정량: 추정량의 기댓값이 모수와 같음(편향=bias=0). 표본분산 계산 시 (n-1)로 나누면 불편추정량이 됨(S²=1/(n-1)Σ(Xi-X̄)²)
· 일치추정량: 표본 크기가 커질수록 추정량이 모수에 점점 가까워짐(수렴)
[구분] n으로 나눈 분산(S¹=1/n Σ)은 불편추정량이 아님(편향 있음), n-1로 나눈 분산(S²)이 불편추정량. 두 추정량 모두 표본 크기가 커지면 일치추정량이 될 수 있음
[치트키] "불편 = 기댓값이 딱 맞음(편향 없음), 일치 = 표본이 커질수록 점점 정답에 가까워짐"
[예문] 표본분산을 구할 때 n-1로 나누는 이유는 그래야 불편추정량이 되기 때문이다

가설검정 (귀무가설/대립가설/유의수준/기각역)
어떤 주장이 맞는지 데이터로 확인하는 통계적 절차
[구성] 귀무가설(H0) / 대립가설(H1) / 유의수준(α) / 기각역
[의미]
· 귀무가설(H0): 일반적으로 생각하는 기본 가설("차이 없다", "변화 없다")
· 대립가설(H1): 연구자가 증명하고 싶은 주장
· 유의수준(α): 귀무가설이 참인데 기각하게 될 확률 허용 한계(보통 5%)
· 기각역: 귀무가설을 기각하기로 한 검정통계량의 구간
[구분] 양측검정: 기각역이 양쪽에 있음("같지 않다") / 단측검정: 기각역이 한쪽에 있음("크다", "작다")
[치트키] "귀무=기본, 대립=증명하고 싶은 것, 유의수준=오류 허용치, 기각역=버리는 구간"
[예문] "불량률이 1.7%와 다르다"는 양측검정, "불량률이 1.7%보다 크다"는 단측검정에 해당한다

1종 오류 vs 2종 오류 vs 3종 오류
가설검정에서 발생할 수 있는 판단 오류 3가지
[구성] 1종 오류(Type I) / 2종 오류(Type II) / 3종 오류(Type III)
[의미]
· 1종 오류: 귀무가설이 "사실"인데 "거짓"이라고 판정(기각) → 판매자 오류(정상인데 반품 당함)
· 2종 오류: 귀무가설이 "거짓"인데 "사실"이라고 판정(채택) → 소비자 오류(불량인데 정상인 줄 앎)
· 3종 오류: 올바른 결론을 내렸지만, 잘못된 질문(가설)이나 방향으로 판단한 오류
[구분] 유의수준(α)은 1종 오류를 범할 확률의 허용 한계
[치트키] "1종=억울하게 기각(판매자 손해), 2종=속아서 채택(소비자 손해), 3종=답은 맞았는데 질문이 틀림"
[예문] 정상 제품을 불량품으로 오판하여 반품시키는 것은 1종 오류의 예다

가설검정 문제 풀이 5단계
가설검정 문제를 풀 때 따르는 표준 절차
[구성] ① 귀무/대립가설 설정 → ② 양측/단측검정 확인 → ③ 일표본/이표본 확인 → ④ 검정통계량 계산과 기각역 판단 → ⑤ (t검정인 경우) 단일/대응/독립표본 확인
[의미]
· 값이 "같지 않다" → 양측검정 / "크다", "작다" → 단측검정
· 일표본: 모집단이 하나 / 이표본: 모집단이 2개 이상
· t검정 세부구분: 단일표본(모집단 하나의 평균검정), 대응표본(동일 모집단의 평균비교), 독립표본(서로 다른 모집단의 평균비교)
[구분] 모표준편차를 알고 있으면 Z-검정, 모르면 t-검정 사용(자유도 n-1)
[치트키] "가설 세우고 → 양측인지 단측인지 → 몇 개 집단인지 → 통계량 계산 → (t검정이면) 단일/대응/독립 구분"
[예문] 동일 집단을 사전-사후로 비교하는 경우는 대응표본 t검정을 사용한다

공간 데이터 유형 (비공간/레스터/벡터/위상적)
공간 정보를 표현하는 4가지 데이터 타입
[구성] 비공간 타입 / 레스터(Raster) 공간 타입 / 벡터(Vector) 공간 타입 / 위상적 공간 타입
[의미]
· 비공간 타입: 위치 정보가 아예 없는 데이터(예: 전화번호)
· 레스터 공간 타입: 픽셀로 나눔, 객체 간 관계 표현이 약함
· 벡터 공간 타입: 객체 그 자체를 표현, 관계 표현은 X
· 위상적 공간 타입: 관계 중심으로 공간을 표현
[구분] 레스터는 "픽셀 단위"(이미지처럼), 벡터는 "객체 좌표 단위"(점·선·면)라는 차이를 구분
[치트키] "레스터=사진처럼 격자(픽셀), 벡터=도형처럼 좌표, 위상적=관계가 핵심"
[예문] 위성 이미지처럼 픽셀로 이루어진 데이터는 레스터 공간 타입에 해당한다

거리 측정 방법 (유클리디안/맨하튼/체비셰프/마할라노비스)
군집분석에서 사용하는 연속형 변수의 거리 계산법
[구성] 유클리디안 거리 / 맨하튼 거리 / 체비셰프 거리 / 표준화 거리 / 민코프스키 거리 / 마할라노비스 거리
[의미]
· 유클리디안 거리: 직선 거리, 차이의 제곱의 합의 루트 (가장 일반적)
· 맨하튼 거리: 계단식(격자) 거리, 차이의 절댓값의 합
· 체비셰프 거리: 최댓값, 차이의 절댓값 중 최댓값
· 표준화 거리: 유클리디안 거리를 표준편차로 나눔
· 민코프스키 거리: 일반화된 거리(유클리드/맨하튼을 포함)
· 마할라노비스 거리: 상관관계까지 반영, 변수의 상관성을 고려한 표준화 거리
[구분] 민코프스키 거리 공식 d(x,y)=(Σ|xj-yj|^p)^(1/p)에서 p=1이면 맨하튼, p=2이면 유클리디안이 됨 (8회 기출 50번)
[치트키] "유클리디안(직선 최단거리) - 맨하튼(바둑판 길) - 체비셰프(가장 큰 차이만) - 마할라노비스(상관관계까지 고려)"
[예문] 도시의 바둑판식 도로를 이동하는 거리를 계산할 때는 맨하튼 거리가 적합하다
