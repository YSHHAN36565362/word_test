## `word_app` 단어장 생성을 위한 프롬프트 설계 가이드 (설명서)

이 문서는 `word_app`(단어 암기 및 지식 학습 앱)에 최적화된 데이터를 생성하기 위해, 향후 LLM 프롬프트를 작성할 때 참고해야 할 구조와 규칙을 정리한 가이드입니다. 제시해주신 의견을 반영하여 콜론(:)으로 인한 오류 가능성을 배제하고, 오직 **줄 바꿈으로만 구분하는 방식**을 표준으로 삼았습니다.

### 1. 앱의 핵심 학습 로직 (프롬프트 설계 배경)

앱은 사용자가 정답을 확인한 후 스스로 4단계로 평가하는 시스템을 사용합니다. 생성된 데이터는 이 로직을 온전히 보조할 수 있어야 합니다.

* **4단계 자기 평가와 망각 곡선:** 카드를 뒤집어 정답과 해설을 확인한 뒤, 완벽함(100) / 조금 앎(60) / 헷갈림(40) / 모름(0)으로 평가합니다. 헷갈리거나 모르는 문제는 무작위 비율(20~40%, 5~15%)로 큐에 재삽입되어 세션 내에 다시 등장합니다.
* **간격 반복(SRS)과 영구 숙련도:** 완료한 문제도 점수가 영구 저장되며, 간격 반복(1일 → 3일 → 7일)에 따라 '오늘의 복습'에 다시 나타납니다.
* **목적:** 단순히 '정답'만 던져주는 것이 아니라, 사용자가 다음 번에 더 잘 기억할 수 있도록 돕는 '양질의 해설과 연상법(힌트)'을 함께 생성하는 것이 핵심입니다.

### 2. 파일 저장 경로 (카테고리 분류)

생성된 데이터는 앱이 연동된 GitHub 리포지토리의 `word_list/` 폴더 내에 저장되며, 폴더 구조가 곧 카테고리가 됩니다.

* **기본 구조:** `word_list/대분류(과목)/세부카테고리(단원)/YYYY-MM-DD.txt`
* (예: `word_list/History/Japanese_History/2026-10-22.txt`)

### 3. 데이터 입력 포맷 (줄 바꿈 구분 방식)

문제나 정답 안에 콜론(:)이 포함될 수 있는 범용 지식 학습의 특성을 고려하여, **줄 바꿈으로만 요소를 구분**합니다.

**[구조 규칙]**

* **1번째 줄:** 질문 (어학일 경우 단어, 역사/전공일 경우 문제)
* **2번째 줄:** 정답 (어학일 경우 뜻, 역사/전공일 경우 명답)
* **3번째 줄 이상:** 해설 및 힌트 (앱에서 `H`키를 누르거나 카드를 뒤집었을 때 표시됨)
* **블록 구분:** 각 문제와 문제 사이는 반드시 빈 줄(엔터 2번)로 띄워야 합니다.

**[작성 예시]**

```text
4세기부터 7세기까지 이어지며, 열쇠 구멍 모양의 거대한 전방후원분을 축조하고 한반도와 교류했던 최초의 통일 정권은?
야마토 정권 (고분 시대)
[종합] 유력 호족들의 연합체로 시작하여 오키미(대왕)를 중심으로 지배력을 넓혔으며, 백제를 통해 불교가 전래되어 아스카 문화를 꽃피움.

1946년 아이자와 다다히로가 이와주쿠 유적에서 창날을 발견하여 존재가 증명된, 기원전 13,000년 이전의 일본 역사 시대는?
구석기 시대
[종합] 이전까지 역사 학계에서는 일본에 구석기 시대가 없었다고 믿었으나, 이 발견으로 존재가 확정됨.

```

### 4. 해설(힌트) 영역 구성 가이드

해설 영역(3번째 줄 이하)은 주제에 따라 LLM이 유연하게 생성하되, 다음 요소들이 포함되도록 프롬프트를 설계해야 합니다.

* **어학(단어) 학습 시:**
* **어원/한자 분해:** 부수나 결합 원리를 쪼개서 설명.
* **암기 치트키:** 발음이나 모양을 활용한 직관적인 연상 문장 제공.


* **일반 지식(역사, 전공 등) 학습 시:**
* **맥락 요약 (`[종합]` 등 태그 활용):** 사건의 인과관계, 배경, 의의 등을 1~2줄로 요약.
* **연관 키워드:** 문제에 직접 나오지 않았더라도 함께 알아두면 좋은 필수 키워드 연결.



### 5. 프롬프트 작성 시 LLM에게 전달할 필수 제약 조건 목록

향후 실제 프롬프트를 만드실 때, 아래 조건들을 LLM에게 지시사항으로 넣으시면 됩니다.

* 출력 형식은 무조건 줄 바꿈 기반의 3단 구조(질문 - 정답 - 해설)를 따를 것.
* 질문(1열)과 정답(2열)은 단 한 줄로만 작성할 것.
* 해설(3열 이상)은 목적(어학/상식)에 맞게 연상법이나 배경지식을 풍부하게 작성하되 줄 바꿈을 허용할 것.
* 각 질의응답 블록 사이에는 반드시 **단 하나의 빈 줄**을 넣어 구분할 것.
* 마크다운 기호(예: `###`), 불필요한 인사말, 서론/결론 없이 순수한 텍스트 데이터만 출력할 것.
