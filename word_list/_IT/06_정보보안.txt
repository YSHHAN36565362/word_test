DoS
네트워크 구조의 취약점을 이용하거나 대량의 데이터를 보내 정상적인 서비스를 못 하게 하는 공격
[구성] 공격자 → 대량 요청·취약점 악용 → 대상 서버 자원 고갈 → 서비스 중단
[의미] 정보 보안 3요소 중 가용성을 침해하는 대표적인 공격
[구분] 대표 공격
· SYN Flooding
· 죽음의 핑(Ping of Death)
· 랜드 어택(Land Attack)
· 스머프(Smurf)
[치트키] "도스(DoS) = 서비스 도둑맞기, 정상 서비스를 거부당한다 → 가용성 침해"
[예문] DoS 공격은 대량의 데이터를 보내 정상적인 서비스를 제공하지 못하게 만들어 가용성을 침해한다
[헷갈리는 단어] DDoS - DoS는 단일 공격지, DDoS는 좀비 PC 여러 대를 이용한 분산 공격

DDoS
여러 대의 컴퓨터를 감염시켜(좀비 PC) 한 타겟 시스템을 집중 공격하는 방법
[구성] 공격자 → 마스터 → 좀비 PC 다수 → 타겟 시스템
[의미] 분산된 다수의 공격지에서 동시에 요청을 보내 대상 서비스를 마비시키는 DoS의 확장형
[구분] 대표 DDoS 공격 도구
· Trinoo: 많은 소스로부터 통합된 UDP Flood 서비스 거부 공격을 유발하는 도구
· TFN: Trinoo와 유사하며 UDP Flood뿐 아니라 TCP SYN flood, ICMP echo 요청, ICMP 브로드캐스트(스머프) 공격까지 수행
· Stacheldraht: 분산 서비스 거부 에이전트 역할을 하는 Linux·Solaris용 멀웨어 도구, ICMP Flood·SYN flood·UDP Flood·Smurf 등 수행
[치트키] "디(분산)도스 = 좀비 군단이 한 곳을 집중 공격"
[예문] DDoS는 좀비 PC를 이용해 하나의 타겟 시스템에 트래픽을 집중시켜 서비스를 마비시킨다
[헷갈리는 단어] DoS - 공격 주체가 하나이면 DoS, 여러 대의 좀비 PC이면 DDoS

죽음의 핑(Ping of Death)
ICMP 패킷을 정상보다 매우 크게 만들어 전송해 서비스를 마비시키는 공격
[구성] 큰 ICMP 패킷 전송 → 다수의 IP 단편화 발생 → 수신 측 부하·오버플로우 → 서비스 불가
[의미] 정상 크기를 초과한 ICMP 패킷의 단편화를 이용해 수신 측의 정상적인 서비스를 방해하는 DoS 공격
[치트키] "죽을 만큼 큰 핑(Ping) 하나 = 거대 ICMP 패킷"
[예문] 정상 크기보다 큰 ICMP 패킷으로 다수의 IP 단편화를 일으켜 수신 측을 마비시키는 공격은 Ping of Death이다

SYN Flooding
TCP의 취약점을 이용해 다량의 SYN 패킷을 보내 백로그 큐를 가득 채우는 DoS 공격
[구성] 다량의 SYN 전송 → 서버가 SYN/ACK 응답 후 ACK 대기 → 백로그 큐 가득 참 → 정상 연결 불가
[의미] TCP 3-way handshake의 연결 대기 자원을 고갈시켜 서비스를 거부하게 만드는 공격
[치트키] "SYN만 홍수처럼(Flooding) 보내서 대기실(백로그 큐)을 가득 채운다"
[예문] 다량의 SYN 패킷으로 서버의 백로그 큐를 가득 채워 새 연결을 막는 공격은 SYN Flooding이다
[헷갈리는 단어] Land Attack - SYN Flooding은 SYN 다량 전송, Land Attack은 출발지·목적지 주소를 같게 위조

랜드 어택(Land Attack)
출발지 IP와 목적지 IP를 같은 패킷 주소로 보내 시스템 가용성을 침해하는 공격
[구성] 출발지 IP = 목적지 IP로 위조한 패킷 전송 → 수신자가 자기 자신에게 응답 → 시스템 부하
[의미] 수신자가 자기 자신에게 패킷을 보내게 만들어 가용성을 침해하는 DoS 공격
[치트키] "랜드(Land) = 내 땅으로 되돌아오는 패킷, 보낸 곳과 받는 곳이 같다"
[예문] 출발지와 목적지 IP를 동일하게 위조한 패킷으로 시스템을 마비시키는 공격은 Land Attack이다

스머프(Smurf)
출발지 주소를 공격 대상 IP로 위조해 네트워크 전체에 ICMP Echo 패킷을 브로드캐스팅하여 마비시키는 공격
[구성] 출발지를 피해자 IP로 위조 → ICMP Echo를 브로드캐스트 → 다수 호스트가 피해자에게 응답 → 트래픽 폭주
[의미] 증폭 효과를 이용해 대상 서버를 ICMP 응답으로 마비시키는 DoS 공격
[치트키] "스머프 마을 전체에 소리쳐(브로드캐스트) 모두가 피해자에게 대답하게 만든다"
[예문] 피해자 IP로 위조한 ICMP Echo를 브로드캐스트하여 응답 트래픽을 몰아주는 공격은 Smurf이다
[헷갈리는 단어] Ping of Death - Smurf는 브로드캐스트 증폭, Ping of Death은 거대 패킷의 단편화

스니핑(Sniffing)
네트워크 중간에서 남의 패킷 정보를 도청하는 해킹 유형
[구성] 네트워크 패킷 수집 → 분석 → 정보 획득
[의미] 수동적으로 패킷을 엿보아 계정·비밀번호 등을 탈취하는 공격으로 기밀성을 침해
[치트키] "스니핑 = 킁킁 냄새 맡듯 몰래 엿듣기"
[예문] 스니핑은 네트워크 중간에서 패킷을 도청하여 정보를 탈취하는 공격이다
[헷갈리는 단어] 스푸핑 - 스니핑은 도청(수동적), 스푸핑은 위장(능동적)

IP 스푸핑
해커가 자신의 IP를 숨기고 다른 사람의 IP를 부당하게 취득해 합법적 사용자로 위장하여 공격하는 기법
[구성] 공격자 IP 은닉 → 신뢰받는 IP로 위조 → 대상 공격
[의미] 네트워크의 취약점을 이용해 신뢰 관계를 가진 호스트로 위장하는 공격
[치트키] "스푸핑 = 남의 얼굴로 위장하기, IP 스푸핑은 IP를 훔쳐 쓴다"
[예문] 공격자가 신뢰받는 호스트의 IP로 위장하여 접속하는 공격은 IP 스푸핑이다

ARP 스푸핑
공격자가 특정 호스트의 MAC 주소를 자신의 MAC 주소로 위조한 ARP Reply를 만들어 희생자에게 지속적으로 전송하는 공격
[구성] 위조 ARP Reply 지속 전송 → 희생자의 ARP 테이블 변조 → 패킷이 공격자에게 전달
[의미] IP와 MAC 주소 매핑 정보를 속여 통신 내용을 가로채는 공격
[치트키] "ARP = IP를 MAC으로 바꾸는 안내원, 안내원에게 거짓 주소를 계속 알려준다"
[예문] ARP 테이블을 위조된 ARP Reply로 오염시켜 패킷을 가로채는 공격은 ARP 스푸핑이다

DNS 스푸핑
DNS 서버로 보내는 질문을 가로채 변조된 결과를 보내주는 일종의 중간자 공격
[구성] DNS 질의 가로채기 → 변조된 응답 전송 → 가짜 사이트로 유도
[의미] 도메인 질의 결과를 위조하여 사용자를 의도하지 않은 사이트로 접속시키는 공격
[치트키] "DNS(전화번호부)에 가짜 번호를 끼워 넣는다"
[예문] 사용자의 DNS 질의에 변조된 응답을 보내 악성 사이트로 접속시키는 공격은 DNS 스푸핑이다

스위치 재밍(Switch Jamming)
위조된 MAC 주소를 지속적으로 흘려보내 스위치의 MAC 주소 테이블 저장 기능을 혼란시켜 더미 허브처럼 작동하게 하는 스니핑 기법
[구성] 위조 MAC 주소 대량 전송 → MAC 주소 테이블 포화 → 스위치가 허브처럼 동작 → 패킷 스니핑
[의미] 스위치 환경에서도 패킷을 도청할 수 있도록 스위치의 정상 동작을 방해하는 공격
[치트키] "스위치에 가짜 MAC을 가득 채워(재밍) 허브로 만든다"
[예문] MAC 주소 테이블을 가득 채워 스위치를 허브처럼 동작하게 만드는 스니핑 기법은 스위치 재밍이다

XSS(Cross-Site Scripting)
검증되지 않은 외부 입력 데이터가 포함된 웹페이지를 열람할 때 부적절한 스크립트가 실행되는 공격
[구성] 악성 스크립트 삽입 → 사용자가 해당 페이지 열람 → 사용자 PC(브라우저)에서 스크립트 실행
[의미] 웹 애플리케이션의 입력값 검증 미흡을 악용해 사용자 브라우저에서 악성 스크립트를 실행시키는 공격
[구분] CSRF와의 차이
· XSS: 공격 대상이 사용자 PC(클라이언트)
· CSRF: 공격 대상이 서버
[치트키] "XSS = 사용자 PC에서 스크립트가 터진다 (X-스크립트-S)"
[예문] 게시글에 삽입된 악성 스크립트가 열람자의 브라우저에서 실행되는 공격은 XSS이다
[헷갈리는 단어] CSRF - XSS는 사용자 PC에서 스크립트 실행, CSRF는 사용자 권한으로 서버에 위조 요청

CSRF(Cross-Site Request Forgery)
사용자가 자신의 의지와 무관하게 공격자가 의도한 행동을 하게 만들어 서버에서 수정·삭제 등을 수행시키는 공격
[구성] 로그인된 사용자 유도 → 위조된 요청 전송 → 사용자 권한으로 서버에서 실행
[의미] 사용자의 인증 상태를 악용해 서버에 원하지 않는 요청을 보내게 하는 웹 공격
[치트키] "CSRF = 사용자 이름으로 서버에 가짜 요청서(Request Forgery)를 제출"
[예문] 로그인 상태의 사용자가 모르는 사이 게시글 삭제 요청이 서버로 전송되는 공격은 CSRF이다
[헷갈리는 단어] XSS - CSRF는 서버에 위조 요청, XSS는 사용자 PC에서 스크립트 실행

SQL Injection
웹 프로그램에 악의적인 SQL 구문을 삽입·실행시켜 DB를 조작하는 공격
[구성] 입력값에 악성 SQL 삽입 → 서버가 그대로 실행 → DB 정보 노출·변조
[의미] 입력값 검증이 미흡한 웹 애플리케이션의 취약점을 이용한 대표적인 웹 공격
[치트키] "SQL을 주사기(Injection)로 몰래 주입"
[예문] 로그인 입력창에 악의적인 SQL 구문을 넣어 인증을 우회하는 공격은 SQL Injection이다

APT
지속적이고 지능적인 해킹 공격의 통칭
[구성] 침투 → 잠복 → 내부 확산 → 정보 탈취
[의미] 특정 대상을 목표로 장기간에 걸쳐 은밀하게 수행하는 지능형 지속 위협
[치트키] "APT = 끈질기게(Persistent) 똑똑하게(Advanced) 위협(Threat)"
[예문] 특정 기업을 장기간 노려 은밀하게 정보를 빼내는 지능적 해킹 공격은 APT이다

Rainbow Table Attack
단방향 해시 암호로 만들어낼 수 있는 값들을 대량으로 저장한 표(테이블)를 이용하는 공격
[구성] 평문과 해시값 쌍을 미리 계산해 표로 저장 → 탈취한 해시값을 표에서 검색 → 원문 복원
[의미] 해시 함수가 단방향이어도 해시값에서 원문을 찾을 수 있도록 미리 계산해 둔 표를 이용하는 공격
[치트키] "무지개(Rainbow) 표 = 해시값 답안지를 미리 만들어 둔 표"
[예문] 미리 계산해 둔 해시값 테이블로 비밀번호를 찾아내는 공격은 Rainbow Table Attack이다

디지털 저작권 관리(DRM) 구성요소
디지털 콘텐츠의 불법 복제와 무단 사용을 막기 위해 저작권을 보호·관리하는 기술의 구성요소
[구성] 콘텐츠 제공자 + 콘텐츠 분배자 + 패키저 + 보안 컨테이너 + DRM 컨트롤러 + 클리어링 하우스
[의미] 암호화된 콘텐츠를 안전하게 유통하고 이용 권한을 통제하기 위한 구성
[구분] 구성요소별 역할
· 콘텐츠 제공자: 콘텐츠를 제공하는 저작권자
· 콘텐츠 분배자: 쇼핑몰 등으로서 암호화된 콘텐츠를 분배·제공
· 패키저: 콘텐츠를 메타데이터와 함께 배포 가능한 단위로 묶음
· 보안 컨테이너: 원본을 안전하게 유통하기 위한 전자적 보안 장치
· DRM 컨트롤러: 배포된 콘텐츠의 이용 권한을 통제
· 클리어링 하우스: 소비자와 유통업자 사이의 거래에서 라이선스 발급·중계를 수행하는 정산소
[치트키] "제공자가 만들고 → 패키저가 포장하고 → 분배자가 팔고 → 컨트롤러가 권한 통제 → 클리어링 하우스가 정산"
[예문] 클리어링 하우스는 DRM에서 라이선스 발급과 거래 정산을 중계하는 역할을 한다

정보 보안의 3대 요소
정보 보안을 위해 보장해야 하는 세 가지 핵심 특성 (암기: 기무가)
[구성] 기밀성(Confidentiality) + 무결성(Integrity) + 가용성(Availability)
[의미] 정보 자산을 보호하기 위한 기본 목표로, 하나라도 침해되면 보안 사고로 이어짐
[구분] 요소별 의미
· 기밀성: 인가되지 않은 사용자에게 정보가 공개·노출되지 않도록 차단
· 무결성: 인가되지 않은 사용자가 데이터를 변경·파괴하지 못하게 보장
· 가용성: 인가된 사용자가 서비스를 지속해서 사용할 수 있도록 보장
[치트키] "기(기밀성) 무(무결성) 가(가용성) = 기무가, 기무가(기모노) 입고 보안 지킨다"
[예문] DoS 공격은 정보 보안의 3대 요소 중 가용성을 침해한다
[헷갈리는 단어] 무결성 - 무결성은 변조 방지, 기밀성은 노출 방지

접근 제어 방식
사용자의 자원 접근 권한을 통제하는 방식 3가지 (암기: MDR)
[구성] MAC + DAC + RBAC
[의미] 권한을 누가 어떤 기준으로 부여하는지에 따라 구분하는 접근통제 방식
[구분] 방식별 의미
· MAC(강제적 접근통제): 관리자가 지정·관리하는 대상에 권한을 부여
· DAC(임의적 접근통제): 접근 권한을 가진 사용자가 자신의 판단에 따라 권한을 허용
· RBAC(역할 기반 접근통제): 조직 내 개인의 역할에 따라 권한을 부여
[치트키] "M(관리자가 강제) D(소유자가 임의) R(역할에 따라)"
[예문] 조직 내 개인의 역할에 따라 접근 권한을 부여하는 방식은 RBAC이다

접근 통제 보호 모델
접근 통제를 위한 대표적인 보안 모델 (암기: BB)
[구성] BLP(벨라파듈라) + Biba
[의미] 기밀성을 강조하는 모델과 무결성을 강조하는 모델로 구분
[구분] 모델별 특징
· BLP: 미 국방부 지원 보안 모델로 기밀성을 강조하며 강제적 정책으로 접근을 통제, No Read Up, No Write Down
· Biba: 무결성을 보장하는 최초의 모델, No Read Down, No Write Up
[치트키] "기밀은 BLP(위를 읽지 마, 아래에 쓰지 마), 무결성은 Biba(아래를 읽지 마, 위에 쓰지 마)"
[예문] 무결성을 보장하는 최초의 접근 통제 모델로 No Read Down, No Write Up 속성을 갖는 것은 Biba이다
[헷갈리는 단어] BLP - BLP는 기밀성, Biba는 무결성

대칭키 암호 알고리즘
암호화와 복호화에 동일한 키를 사용하는 암호 방식 (블록 암호)
[구성] DES + AES + SEED + ARIA + IDEA + LFSR
[의미] 같은 키를 공유하므로 속도가 빠르지만 키 전달 문제가 있음
[구분] 알고리즘별 특징
· DES: 64bit 블록, 56bit 키 사용, Feistel 방식
· AES: DES를 대체, 128/192/256bit 키, SPN 방식
· SEED: 순수 국내 기술로 개발한 128/256bit 알고리즘
· ARIA: AES와 같이 128/192/256bit 키 제공
· IDEA: 스위스에서 PES를 개량하여 만든 블록 암호
· LFSR: 선형 피드백 시프트 레지스터, 스트림 암호에 사용되는 대칭키 방식 (RC4도 스트림 암호)
[치트키] "DES는 56 · AES는 128/192/256 · SEED·ARIA는 국산"
[예문] DES를 대체하며 128/192/256bit 키를 사용하는 대칭키 알고리즘은 AES이다
[헷갈리는 단어] 비대칭키 - 대칭키는 같은 키, 비대칭키는 서로 다른 키

비대칭키 암호 알고리즘
암호화와 복호화에 서로 다른 키를 사용하는 암호 방식
[구성] 공개키 + 개인키
[의미] 키 분배가 쉽지만 속도가 느림
[구분] 대표 알고리즘
· RSA: 소인수분해를 활용한 비대칭 암호화 알고리즘
· DSA: 미국의 전자 서명 표준
· ECC(타원 곡선), ElGamal, ECDSA도 비대칭키 계열 (ECDSA는 전자 서명)
[치트키] "RSA = 소인수 분해, DSA = 서명(Signature)"
[예문] 소인수분해의 어려움에 기반한 비대칭 암호 알고리즘은 RSA이다

해시 함수 특성
임의 길이 입력을 고정 길이 출력으로 변환하는 단방향 함수가 갖춰야 할 3가지 저항성
[구성] 역상 저항성 + 제2 역상 저항성 + 충돌 저항성
[의미] 해시값으로 원문을 알아내거나 같은 해시값을 만드는 입력을 찾기 어렵게 하는 성질
[구분] 특성별 의미
· 역상 저항성: 해시값이 주어졌을 때 그 해시값을 만드는 입력값을 알아내기 불가능
· 제2 역상 저항성: 어떤 입력값과 같은 해시값을 가지는 다른 입력값을 찾을 수 없어야 함
· 충돌 저항성: 해시값이 같은 서로 다른 두 입력을 찾을 수 없어야 함
· 대표 알고리즘: SHA는 미국 국가 표준, MD5는 MD4를 대체한 128bit 해시
[치트키] "하나 주고 원문 못 찾기(역상), 원문 주고 짝 못 찾기(제2역상), 둘 다 못 찾기(충돌)"
[예문] 서로 다른 두 입력이 같은 해시값을 가지지 않도록 하는 특성은 충돌 저항성이다

블루투스 공격
블루투스 장비의 취약점을 이용하는 공격 유형 4가지
[구성] 블루버그 + 블루스나프 + 블루재킹 + 블루프린팅
[의미] 블루투스 연결 관리와 검색 기능의 취약점을 악용한 공격
[구분] 공격별 의미
· 블루버그: 블루투스 장비 사이의 취약한 연결 관리를 악용한 공격
· 블루스나프: 블루투스 취약점을 활용해 장비의 파일에 접근하는 공격
· 블루재킹: 블루투스를 이용해 스팸처럼 명함을 익명으로 퍼뜨리는 공격
· 블루프린팅: 블루투스 공격 장치의 검색 활동
[치트키] "버그는 연결 취약점, 스나프는 파일 낚아채기, 재킹은 명함 뿌리기, 프린팅은 탐색"
[예문] 블루투스로 장비 내부의 파일에 접근하는 공격은 블루스나프이다

허니팟(Honeypot)
침입자를 속여 실제로 공격당하는 것처럼 보여줌으로써 크래커를 추적하고 공격 기법 정보를 수집하는 시스템
[구성] 가짜 시스템 + 공격 유인 + 정보 수집
[의미] 실제 시스템을 보호하면서 공격자의 행위를 분석
[치트키] "허니팟 = 꿀단지, 공격자를 꿀로 유인"
[예문] 공격자를 유인해 공격 기법 정보를 수집하는 가짜 시스템은 허니팟이다

DLP
내부 정보의 외부 유출을 방지하기 위한 솔루션
[구성] 정보 식별 + 유출 감시 + 차단
[의미] 회사의 데이터를 외부로 가져갈 수 없게 통제
[치트키] "DLP = 데이터 유출(Leak) 막이"
[예문] 내부 중요 정보의 외부 유출을 막는 보안 솔루션은 DLP이다

DB 암호화 방식
데이터베이스 안의 데이터를 암호화하는 4가지 방식 (암기: 애플티하)
[구성] API 방식 + Plug-in 방식 + TDE 방식 + Hybrid 방식
[의미] 암호화 모듈을 적용하는 위치에 따라 구분
[구분] 방식별 의미
· API 방식: 애플리케이션 레벨에서 암호 모듈을 적용하는 애플리케이션 수정 방식
· Plug-in 방식: 암호화·복호화 모듈이 DB 서버에 설치된 방식
· TDE 방식: DB 서버의 DBMS 커널이 자체적으로 암호화 기능 수행
· Hybrid 방식: API 방식과 Plug-in 방식을 결합
[치트키] "애(API) 플(Plug-in) 티(TDE) 하(Hybrid) = 애플티하"
[예문] DBMS 커널이 자체적으로 암호화 기능을 수행하는 방식은 TDE이다

SSL/TLS
4계층과 7계층 사이에서 클라이언트와 서버 간 웹 데이터 암호화, 상호 인증, 전송 데이터 무결성을 보장하는 보안 프로토콜
[구성] 암호화 + 상호 인증 + 무결성 / 443 포트
[의미] 웹 통신(HTTPS)의 보안을 담당
[구분] 비교
· S-HTTP: 네트워크 트래픽을 암호화하여 전송하는 보안 프로토콜
[치트키] "SSL/TLS = 전송 계층과 응용 계층 사이, 443번 포트"
[예문] 443 포트를 사용하며 웹 데이터 암호화와 상호 인증을 제공하는 프로토콜은 SSL/TLS이다

IPSec
3계층에서 무결성과 인증을 보장하는 인증 헤더(AH)와 기밀성을 보장하는 암호화(ESP)를 이용한 IP 보안 프로토콜
[구성] AH + ESP + IKE / 전송 모드 + 터널 모드
[의미] IP 계층에서 패킷 단위로 보안을 제공
[구분] 구성별 의미
· 전송 모드: IP 패킷의 페이로드를 보호
· 터널 모드: IP 패킷 전체를 보호
· AH: 인증과 무결성을 제공하며 기밀성은 보장하지 않음
· ESP: 송신처 인증과 기밀성까지 모두 제공
· IKE: 키를 주고받는 키 관리 프로토콜
[치트키] "AH는 인증만, ESP는 암호화까지, IKE는 키 교환"
[예문] 기밀성까지 제공하는 IPSec 프로토콜은 ESP이다

IDS(침입 탐지 시스템)
시스템에 대한 원치 않는 조작을 탐지해 주는 시스템 (Intrusion Detection System)
[구성] 모니터링 + 탐지 + 경고
[의미] 침입을 감지하여 알리지만 차단은 하지 않음
[치트키] "D = Detection, 탐지만 한다"
[예문] 침입을 탐지하고 경고하는 시스템은 IDS이다
[헷갈리는 단어] IPS - IDS는 탐지, IPS는 탐지와 차단

IPS(침입 방지 시스템)
네트워크 침입에 대한 차단 및 방지를 수행하는 시스템 (Intrusion Prevention System)
[구성] 탐지 + 차단
[의미] 침입을 탐지하는 데서 나아가 자동으로 막음
[치트키] "P = Prevention, 막아 버린다"
[예문] 침입을 탐지하고 실시간으로 차단하는 시스템은 IPS이다
[헷갈리는 단어] IDS - IPS는 차단까지, IDS는 탐지만

접근 통제 절차
사용자가 자원에 접근하기까지의 4단계 절차
[구성] 식별 → 인증 → 인가 → 책임 추적성
[의미] 누구인지 확인하고, 권한을 부여하고, 행위를 기록
[구분] 단계별 의미
· 식별(Identification): 나는 사용자입니다
· 인증(Authentication): 당신은 사용자가 맞습니다
· 인가(Authorization): 사용자에게 권한을 주겠습니다
· 책임 추적성(Accountability): 언제 누가 로그인했는지 기록
[치트키] "나야(식별) 맞네(인증) 들어와(인가) 기록해(책임추적)"
[예문] 인증된 사용자에게 권한을 부여하는 단계는 인가이다

포렌식
범죄 사실의 디지털 증거물에 대해 사법기관에 제출하기 위해 수집, 분석, 보고서를 작성하는 일련의 과정
[구성] 수집 → 분석 → 보고서 작성
[의미] 디지털 증거의 법적 효력을 확보하는 절차
[치트키] "포렌식 = 디지털 현장 감식"
[예문] 디지털 증거를 수집·분석하여 보고서로 작성하는 과정은 포렌식이다

방화벽(Firewall)
네트워크 트래픽을 규칙에 따라 필터링하여 허용하거나 차단하는 보안 장치
[구성] 접근 규칙 + 허용·차단
[의미] 내부 네트워크와 외부 네트워크 사이를 보호
[치트키] "방화벽 = 네트워크의 성벽 출입문"
[예문] 정해진 규칙에 따라 트래픽을 필터링하는 보안 솔루션은 방화벽이다
[헷갈리는 단어] WAF - 방화벽은 네트워크 필터링, WAF는 웹 공격 방어

WAF(웹 방화벽)
SQL 삽입, XSS 등 웹 기반 공격을 방어하기 위한 웹 애플리케이션 방화벽
[구성] HTTP 트래픽 검사 + 웹 공격 차단
[의미] 웹 서비스의 취약점을 노린 공격을 막음
[치트키] "WAF = 웹(Web)에 특화된 방화벽"
[예문] SQL Injection과 XSS 같은 웹 공격을 방어하는 방화벽은 WAF이다

NAC
네트워크에 접속하는 단말을 인증하고 보안 정책 준수 여부를 검사하여 접근을 제어하는 솔루션
[구성] 단말 인증 + 정책 검사 + 접근 제어
[의미] 허가되지 않거나 위험한 단말의 네트워크 접근을 막음
[치트키] "NAC = 네트워크 출입 심사대"
[예문] 단말의 보안 상태를 검사해 네트워크 접근을 제어하는 솔루션은 NAC이다

SIEM
보안 경고를 실시간으로 분석하고 빅데이터 기반으로 심층 분석하는 통합 보안 관제 솔루션
[구성] 로그 수집 + 실시간 분석 + 상관 분석
[의미] 여러 보안 장비의 로그를 통합해 위협을 탐지
[치트키] "SIEM = 보안 로그를 한곳에 모아 분석하는 관제센터"
[예문] 여러 보안 장비의 로그를 통합 분석해 위협을 탐지하는 솔루션은 SIEM이다

SSO(Single Sign-On)
한 번의 인증으로 여러 서비스를 이용할 수 있게 하는 인증 기술
[구성] 한 번 로그인 → 여러 서비스 이용
[의미] 사용자 편의와 계정 관리 효율을 높임
[치트키] "SSO = 한 번 열쇠로 모든 문"
[예문] 한 번 로그인으로 여러 시스템을 이용하는 인증 방식은 SSO이다

비트로커(BitLocker)
드라이브를 암호화하는 보안 기능으로 기본적으로 AES 128bit 암호화를 사용하며 USB나 외장하드도 암호화 가능
[구성] 드라이브 암호화 + AES 128bit
[의미] 분실·도난 시 저장 데이터의 유출을 막는 디스크 암호화 기능
[치트키] "비트(데이터)를 자물쇠(Locker)로 잠근다"
[예문] 드라이브 전체를 암호화하는 윈도우 보안 기능은 비트로커이다

공개키 암호화 활용
비대칭키 암호에서 어떤 키로 암호화하느냐에 따라 얻는 보안 속성이 달라지는 방식
[구성] 공개키 암호화 → 개인키 복호화 / 개인키 암호화 → 공개키 복호화
[의미] 기밀성과 인증·부인 방지(전자서명)를 구분해 구현
[구분] 활용
· 공개키로 암호화 → 개인키로 복호화: 기밀성
· 개인키로 암호화 → 공개키로 복호화: 인증, 부인 방지(전자서명)
[치트키] "남에게 비밀 보낼 땐 상대 공개키, 내가 서명할 땐 내 개인키"
[예문] 공개키로 암호화하면 보장되는 보안 요소는 기밀성이다

세션 하이재킹
인증된 세션을 가로채어 사용자인 것처럼 시스템에 접근하는 공격
[구성] 세션 ID 탈취 → 정상 사용자로 위장
[의미] 로그인 이후의 통신 세션을 탈취하는 네트워크 공격
[치트키] "하이재킹 = 이미 로그인된 세션을 납치"
[예문] 인증된 세션을 가로채는 공격은 세션 하이재킹이다

MITM(중간자 공격)
통신 사이에 끼어들어 내용을 가로채거나 변조하는 공격
[구성] 사용자 ↔ 공격자 ↔ 서버
[의미] 양쪽 모두 정상 통신으로 오인하게 만듦
[치트키] "중간에 끼어 몰래 엿보고 바꾼다"
[예문] 두 시스템의 통신 사이에 끼어들어 정보를 가로채는 공격은 중간자 공격이다

피싱·파밍·스미싱
사용자를 속여 정보를 탈취하는 사회공학 공격
[구성] 피싱 + 파밍 + 스미싱 + 스피어 피싱
[의미] 기술이 아닌 사람의 심리를 이용한 공격
[구분] 공격별 의미
· 피싱: 가짜 사이트나 메일로 개인정보를 낚음
· 파밍: DNS 등을 변조해 정상 주소로 접속해도 가짜 사이트로 유도
· 스미싱: 문자 메시지로 악성 링크를 보내 유도
· 스피어 피싱: 특정 대상을 겨냥한 맞춤형 피싱
· 큐싱(Qshing): QR코드를 이용한 피싱
[치트키] "피싱은 낚시, 파밍은 농장(주소 오염), 스미싱은 문자(SMS)"
[예문] 문자 메시지를 이용해 악성 링크로 유도하는 공격은 스미싱이다

악성코드 종류
사용자의 시스템에 해를 끼치는 악의적인 소프트웨어
[구성] 바이러스 + 웜 + 트로이 목마 + 랜섬웨어 + 백도어 + 루트킷 + APT
[의미] 감염 방식과 목적에 따라 구분
[구분] 종류별 의미
· 웜: 자기 복제 후 네트워크로 전파
· 트로이 목마: 정상 프로그램으로 위장
· 랜섬웨어: 파일을 암호화한 뒤 금전을 요구
· 백도어: 정상 인증 없이 접근할 수 있는 비밀 통로
· 루트킷: 침입 흔적을 숨기고 관리자 권한을 유지
[치트키] "웜은 퍼지고, 트로이는 위장하고, 랜섬은 인질"
[예문] 파일을 암호화한 후 금전을 요구하는 악성코드는 랜섬웨어이다

제로 트러스트
내부와 외부를 구분하지 않고 모든 접근을 신뢰하지 않으며 항상 검증하는 보안 모델
[구성] 지속적 인증 + 최소 권한 + 접근 검증
[의미] 경계 기반 보안의 한계를 보완
[치트키] "제로 트러스트 = 아무도 믿지 말고 매번 확인"
[예문] 모든 접근을 신뢰하지 않고 항상 검증하는 보안 모델은 제로 트러스트이다

그레이웨어
악성코드는 아니지만 사용자에게 불편이나 피해를 줄 수 있는 소프트웨어
[구성] 광고 + 정보 수집 + 성능 저하
[의미] 악성과 정상의 중간(회색) 영역에 있는 소프트웨어
[치트키] "그레이웨어 = 검지도 희지도 않은 회색 소프트웨어"
[예문] 악성코드는 아니지만 광고 노출 등 불편을 주는 소프트웨어는 그레이웨어이다

워터링 홀(Watering Hole) 공격
표적이 자주 방문하는 합법적인 웹사이트를 미리 감염시켜 두고 접속하는 순간 악성코드를 설치하게 하는 공격
[구성] 표적의 방문 사이트 파악 → 사이트에 악성코드 삽입 → 표적 접속 시 자동 감염
[의미] 불특정 다수가 아닌 특정 조직이나 인물을 겨냥하며, 접속자 IP·환경을 확인해 목표에게만 선택적으로 실행하기도 함 (2026년 1회 출제)
[치트키] "물웅덩이(워터링 홀)에서 사냥감이 물 마시러 오길 기다린다"
[예문] 표적이 자주 방문하는 정상 웹사이트를 감염시켜 접속 시 악성코드를 설치하는 공격은 워터링 홀이다
[헷갈리는 단어] 스피어 피싱 - 워터링 홀은 방문 사이트를 감염, 스피어 피싱은 표적에게 직접 메일 발송

심볼릭 링크 공격(레이스 컨디션)
프로그램이 임시 파일을 만드는 순간을 노려 임시 파일을 공격자가 만든 심볼릭 링크로 교체해 의도하지 않은 파일에 접근하게 하는 공격
[구성] 심볼릭 링크 준비 → 임시 파일 생성 시점에 교체 → 프로그램이 교체된 파일을 정상으로 인식
[의미] 경쟁 상태(Race Condition)와 TOCTOU 취약점을 악용하며 2026년 1회에서는 "심볼릭 링크"를 고르는 문제로 출제
[구분] 링크의 종류
· 심볼릭(소프트) 링크: 원본 파일의 경로를 가리키는 특수 파일
· 하드 링크: 원본 파일과 같은 데이터(inode)를 가리키는 또 다른 이름
[치트키] "경로를 가리키는 특수 파일 = 심볼릭(소프트) 링크"
[예문] 원본 파일의 경로를 가리키는 특수 파일로 임시 파일을 바꿔치기하는 공격에 쓰이는 것은 심볼릭 링크이다
[헷갈리는 단어] 하드 링크 - 하드 링크는 같은 데이터를 공유, 심볼릭 링크는 경로만 가리킴

스케어웨어(Scareware)
가짜 경고 메시지로 공포심을 유발해 악성 소프트웨어를 설치하거나 구매하게 만드는 공격
[구성] 가짜 바이러스 경고 → 해결책 설치·결제 유도 → 악성코드 감염 또는 금전 피해
[의미] 사용자의 불안을 이용하는 사회공학 공격
[치트키] "스케어(Scare) = 겁주기"
[예문] 컴퓨터가 감염되었다는 거짓 경고로 유료 프로그램을 설치하게 만드는 공격은 스케어웨어이다

타이포스쿼팅(Typosquatting)
사용자의 오타를 노려 유사한 도메인을 미리 등록해 가짜 사이트로 유도하는 공격
[구성] 유명 도메인과 비슷한 철자의 도메인 등록 → 오타 입력 시 접속 → 피싱·악성코드
[의미] 도메인 이름의 철자 오류를 악용
[치트키] "typo(오타) + squatting(무단 점거)"
[예문] naver를 nayver로 잘못 입력한 사용자를 가짜 사이트로 유도하는 공격은 타이포스쿼팅이다

템퍼 프루핑(Tamper Proofing)
소프트웨어가 임의로 위변조되는 것을 방지하고 변조를 감지하는 소프트웨어 보호 기술
[구성] 코드·실행 파일 무결성 검증 + 변조 감지 시 동작 차단
[의미] 크래킹과 리버스 엔지니어링으로부터 소프트웨어를 보호하는 기법 (2023년 2회 출제)
[구분] 관련 기술
· 난독화: 코드를 읽기 어렵게 변환
· 템퍼 프루핑: 변조 여부를 검사해 변조 시 실행 중단
[치트키] "템퍼(손댄 흔적) 프루핑(방지) = 위변조 방지"
[예문] 소프트웨어의 위변조를 감지하고 방지하는 기술은 템퍼 프루핑이다

ISMS와 ISMS-P
정보보호 관리체계(ISMS)와 개인정보 포함 정보보호 및 개인정보보호 관리체계(ISMS-P) 인증
[구성] ISMS = Information Security Management System / ISMS-P = ISMS + Personal Information
[의미] 기업이 정보자산을 보호하기 위해 수립한 관리체계를 심사하여 인증하는 제도 (2026년 1회: 정보보호 관리체계의 영문 약자 ISMS)
[치트키] "관리체계(M, Management System)가 약자의 핵심, 개인정보(P)를 더하면 ISMS-P"
[예문] 정보보호 관리체계의 영문 약자는 ISMS이다

패스워드 크래킹 유형
암호나 해시를 추측해 패스워드를 알아내는 공격 방식
[구성] 사전 대입 공격 + 무차별 대입 공격 + 패스워드 하이브리드 공격 + 레인보우 테이블 공격
[의미] 약한 패스워드를 찾아내는 공격으로, 솔트(Salt)와 복잡한 패스워드 정책으로 대응
[구분] 유형별 의미
· 사전 대입: 자주 쓰는 단어 목록(사전)을 대입
· 무차별 대입(브루트 포스): 가능한 모든 조합을 대입
· 하이브리드: 사전 단어에 숫자·기호 등을 조합
· 레인보우 테이블: 미리 계산해 둔 해시 테이블로 원문을 검색
[치트키] "사전 → 무차별 → 하이브리드 → 레인보우"
[예문] 가능한 모든 문자 조합을 대입하는 패스워드 공격은 무차별 대입 공격이다

네트워크 스캐너와 ICMP Redirect 공격
네트워크 취약점을 탐색하거나 패킷 경로를 바꿔 스니핑하는 공격 기법
[구성] 네트워크 스캐너(스니퍼) + ICMP Redirect 공격
[의미] 취약점 탐색과 패킷 흐름 조작에 활용
[구분] 공격별 의미
· 네트워크 스캐너: 네트워크 하드웨어·소프트웨어 구성의 취약점을 파악하기 위해 탐색하는 도구
· ICMP Redirect: 3계층에서 스니핑 시스템을 또 다른 라우터라고 속여 패킷의 흐름을 바꾸는 공격
[치트키] "스캐너는 탐색, ICMP Redirect는 길 바꾸기"
[예문] 가짜 라우터라고 알려 패킷 경로를 바꾸는 공격은 ICMP Redirect 공격이다

해시 암호화 알고리즘 종류
입력을 고정 길이 해시값으로 변환하는 단방향 알고리즘들
[구성] MD5 + SHA-1 + SHA-256/384/512 + HAS-160
[의미] 무결성 검증과 전자서명에 사용
[구분] 알고리즘별 의미
· MD5: 512bit 블록 단위로 128bit 해시값 생성
· SHA-1: 160bit 해시값 생성
· SHA-256/384/512: 각각 256/384/512bit 해시값 생성
· HAS-160: 국내 표준 서명 알고리즘 KCDSA를 위해 개발된 해시 함수 (160bit)
[치트키] "MD5는 128, SHA-1은 160, HAS-160도 160, SHA-2는 256 이상"
[예문] 국내 표준 전자서명 KCDSA를 위해 개발된 해시 함수는 HAS-160이다

애플리케이션 계층 DDoS 공격
웹 서버의 연결 유지 방식을 악용해 적은 트래픽으로 서비스를 마비시키는 응용 계층 DDoS
[구성] Slowloris + RUDY + Slow HTTP Read DoS
[의미] 대역폭이 아닌 서버의 연결 자원을 고갈시키는 방식
[구분] 공격별 의미
· Slowloris: HTTP 헤더를 아주 천천히 보내 연결을 오래 점유
· RUDY: POST 본문을 아주 천천히 전송
· Slow HTTP Read: 응답을 아주 천천히 읽어 연결을 유지
[치트키] "느리게(Slow) 보내거나 읽어서 연결을 붙잡는다"
[예문] HTTP 헤더를 천천히 전송해 연결을 오래 점유하는 공격은 Slowloris이다

보안 관련 용어
최근 기출에서 자주 등장하는 보안 용어
[구성] 이블 트윈 공격 + 난독화 + 랜섬웨어 + 사이버 킬체인
[의미] 무선 위장, 코드 보호, 악성코드, 공격 단계 모델
[구분] 용어별 의미
· 이블 트윈: 정상 AP와 같은 이름의 가짜 AP를 만들어 접속을 유도
· 난독화: 소스 코드를 읽기 어렵게 변환해 분석을 어렵게 함
· 랜섬웨어: 파일을 암호화하고 금전을 요구
· 사이버 킬체인: 공격을 정찰, 무기화, 전달, 악용, 설치, 명령·제어, 목표 달성 단계로 나눈 모델
[치트키] "이블 트윈 = 쌍둥이 와이파이"
[예문] 정상 AP와 같은 이름의 가짜 AP로 접속을 유도하는 공격은 이블 트윈이다

시스템 보안 공격 유형
운영체제와 프로그램의 취약점을 이용한 주요 시스템 공격
[구성] 포맷 스트링 공격 + 레이스 컨디션 공격 + 키로거 공격 + 루트킷
[의미] 메모리, 경쟁 상태, 키 입력 가로채기, 흔적 은닉 등을 활용
[구분] 공격별 의미
· 포맷 스트링: printf 계열 함수의 서식 지정자를 악용해 메모리를 읽거나 씀
· 레이스 컨디션: 두 프로세스가 공유 자원에 동시에 접근하는 틈을 악용
· 키로거: 키 입력을 기록해 정보를 탈취
· 루트킷: 침입 후 관리자 권한을 유지하고 흔적을 숨기는 도구
[치트키] "서식·경쟁·키입력·흔적 숨기기"
[예문] 키보드 입력을 몰래 기록해 탈취하는 공격은 키로거 공격이다

해킹 공격용 도구
공격자가 시스템 침투와 범죄에 사용하는 도구
[구성] 루트킷 + 크라임웨어
[의미] 흔적 은닉과 범죄 목적의 악성 소프트웨어
[구분] 도구별 의미
· 루트킷: 관리자 권한을 유지하고 침입 흔적을 숨김
· 크라임웨어: 금융 정보 탈취 등 범죄를 목적으로 만든 악성 소프트웨어
[치트키] "루트(뿌리)까지 숨고, 크라임(범죄)을 위해 만든다"
[예문] 침입 후 관리자 권한을 유지하며 흔적을 숨기는 도구는 루트킷이다

사회공학(Social Engineering)
사람의 심리와 신뢰를 이용해 보안 정보를 얻어내는 비기술적 공격
[구성] 피싱 + 스미싱 + 파밍 + 스피어 피싱 + 스케어웨어 + 어깨너머 훔쳐보기
[의미] 기술적 방어를 우회해 사람을 속이는 방식
[치트키] "시스템이 아니라 사람을 해킹한다"
[예문] 사람의 심리를 이용해 기밀 정보를 알아내는 공격 방식은 사회공학이다

네트워크 접근 제어 솔루션
네트워크 접근과 침입을 통제하는 보안 솔루션
[구성] 방화벽 + 웹 방화벽 + IDS + IPS + NAC + 무선 침입 방지 시스템 + 통합 보안 시스템 + VPN
[의미] 계층별로 다양한 위협을 방어
[구분] 솔루션별 의미
· 방화벽: 규칙에 따라 트래픽 허용·차단
· 웹 방화벽(WAF): 웹 공격 방어
· IDS: 침입 탐지
· IPS: 침입 탐지와 차단
· NAC: 접속 단말 인증과 정책 검사
· 무선 침입 방지(WIPS): 무선 구간 침입 방지
· 통합 보안 시스템: UTM/ESM 등으로 여러 기능을 통합
· VPN: 암호화된 가상 사설망
[치트키] "막고(방화벽) 탐지하고(IDS) 차단하고(IPS) 인증하고(NAC) 터널(VPN)"
[예문] 접속하는 단말을 인증하고 보안 정책 준수 여부를 검사하는 솔루션은 NAC이다

소프트웨어 개발 보안 용어
개발 보안에서 위험을 분석할 때 사용하는 기본 용어
[구성] 자산 + 위협 + 취약점 + 위험
[의미] 보호할 대상, 해를 끼칠 요인, 약점, 피해 가능성을 구분
[구분] 용어별 의미
· 자산: 보호해야 할 정보·시스템
· 위협: 자산에 피해를 줄 수 있는 요인
· 취약점: 위협이 악용할 수 있는 약점
· 위험: 위협이 취약점을 이용해 자산에 피해를 줄 가능성
[치트키] "자산을 위협이 취약점으로 공격하면 위험"
[예문] 위협이 악용할 수 있는 시스템의 약점은 취약점이다

SW 개발 보안의 3대 요소
안전한 소프트웨어 개발을 위해 보장해야 하는 세 가지 보안 요소
[구성] 기밀성(Confidentiality) + 무결성(Integrity) + 가용성(Availability)
[의미] 개발 단계부터 보안을 고려하는 Secure SDLC의 기본 목표
[치트키] "기무가 = 기밀성 무결성 가용성"
[예문] 인가된 사용자만 데이터를 수정할 수 있도록 하는 보안 요소는 무결성이다
