회귀분석 (Regression Analysis)
독립변수가 종속변수에 미치는 영향을 파악하는 예측 기법
[구성] 회귀(回歸, 돌아감) + 분석(分析) → 예측선 하나 그어놓고, 예측값과 실제값이 얼마나 차이 나는지 보는 것
[의미] 독립변수(연속형)와 종속변수(연속형) 간의 선형 관계를 파악하는 기법
[구분] 잔차: 예측값과 실제값의 차이(표본 기준, 모집단 기준은 오차) / 회귀계수: 기울기와 절편, 얼마나 영향을 주는지 나타냄 / 회귀계수 추정방법: 최소제곱법(잔차 제곱의 합이 최소가 되는 절편·기울기 찾기)
[구분] 회귀모형 평가: 결정계수 R-square(0~1 사이 값), 예측을 잘할수록 1에 가까워짐
[치트키] "회귀 = 데이터에 예측선(직선) 하나 딱 긋고, 그 선에서 얼마나 벗어났나(잔차) 확인"
[예문] 광고비 지출과 매출액 간의 관계를 회귀분석으로 파악해 매출을 예측할 수 있다

선형 회귀분석의 5가지 가정
회귀분석이 성립하기 위해 만족해야 하는 5가지 조건
[구성] 선형성 / 독립성 / 정상성(정규성) / 등분산성 / 비상관성
[의미]
· 선형성: 종속-독립변수는 선형관계(직선관계)
· 독립성: 잔차와 독립변수 간 상관관계가 없음(다중공선성: 독립변수끼리 강한 상관관계가 있으면 문제, 차원축소·상관계수 분해로 해결)
· 정상성(정규성): 잔차가 정규분포의 특성을 지님
· 등분산성: 잔차의 분산이 고르게 분포
· 비상관성: 잔차들끼리 상관이 없어야 함
[구분] 기출 함정: "독립변수들은 정규분포를 따라야 한다"는 잘못된 설명 → 정규성 가정은 "잔차"에 대한 것이지 "독립변수"에 대한 것이 아님(4월 기출 35번)
[치트키] "선형이고, 독립적이고(잔차-독립변수 무관), 정규분포 잔차, 분산 고르고, 잔차끼리 안 겹침"
[예문] 잔차가 정규분포를 따른다는 것이 회귀분석의 정상성(정규성) 가정이다

회귀 모형 변수 선택 방법 (전진/후진/단계별)
회귀모형에 포함할 변수를 선택하는 3가지 방법
[구성] 전진선택법 / 후진제거법(후진선택법) / 단계별 선택법
[의미]
· 전진선택법: 하나씩 넣어보면서(상관계수 절댓값이 큰 것부터) 성능이 좋아지면 유지
· 후진제거법: 모든 변수를 넣은 상태에서 상관계수 절댓값이 작은 것부터 하나씩 제거
· 단계별 선택법: 전진+후진을 결합해 보완
[구분] 기출 함정: "전진 선택법은 모든 변수를 포함한 모델에서 시작하여 중요도가 낮은 변수를 하나씩 제거하는 방식이다" → 틀림! 이건 후진선택법 설명. 전진선택법은 "빈 모델에서 하나씩 추가"하는 방식(4월 기출 37번)
[구분] 벌점 기준: 변수 추가 시 AIC, BIC 같은 벌점(낮을수록 좋음)을 고려
[치트키] "전진=아무것도 없는 데서 하나씩 추가, 후진=다 넣고 하나씩 빼기, 단계별=둘 다"
[예문] AIC 값이 낮아지는 방향으로 변수를 추가하거나 제거하며 최적 모델을 찾는다

다중공선성 (Multicollinearity)
독립변수들 간에 강한 상관관계가 나타나는 문제
[구성] 다중(多重, 여러 개) + 공선성(共線性, 같은 선 위에 있음)
[의미] 다중 회귀분석에서 독립변수들 간에 강한 선형 상관관계가 존재하는 현상. 회귀계수의 분산이 커져 모델이 불안정해짐
[구분] 기출 함정: "다중공선성을 해결하기 위해 상관관계가 높은 독립변수들을 추가로 모델에 포함시켜야 한다" → 틀림! 반대로 상관관계 높은 변수는 "제거하거나 차원축소(PCA 등)"해야 함(4월 기출 49번)
[구분] 진단 방법: 분산팽창계수(VIF), 보통 VIF≥10이면 문제가 있다고 판단
[치트키] "다중공선성 = 독립변수끼리 너무 닮아서 누가 진짜 영향 주는지 헷갈리는 문제, 해결은 '빼기'이지 '더하기'가 아님"
[예문] 키와 몸무게처럼 서로 상관이 높은 두 변수를 함께 독립변수로 넣으면 다중공선성 문제가 발생할 수 있다

결정계수 (R², R-squared)
회귀모형이 데이터를 얼마나 잘 설명하는지 나타내는 지표
[구성] 결정(決定) + 계수(係數) = R square
[의미] 독립변수가 종속변수를 설명하는 정도를 나타내는 지표. 범위는 보통 0~1 사이, 모델이 데이터를 잘 설명할수록 1에 가까움
[구분] 기출 함정: "독립변수가 종속변수에 의해 설명되는 오차의 비율을 나타낸다"는 설명은 반대로 됨 → 실제로는 "종속변수의 변동이 독립변수에 의해 설명되는 비율"(4월 기출 45번)
[구분] "다중선형회귀 모델에서는 1개만 존재한다" → 옳은 설명(R²는 모델 전체에 대해 하나만 계산됨, 독립변수 개수와 무관)
[치트키] "R² = 내가 만든 모델이 실제 데이터 변화를 얼마나 잘 설명하나(1에 가까울수록 잘 맞음)"
[예문] R-square가 0.98이면 모델이 종속변수 변동의 98%를 설명한다는 의미다

로지스틱 회귀분석 (Logistic Regression)
종속변수가 범주형(예/아니오)일 때 쓰는 회귀 기법
[구성] 로지스틱(Logistic) + 회귀(Regression) → 결과값이 예/아니오처럼 뚜렷할 때 쓰는 회귀
[의미] 종속변수가 범주형 데이터(0 또는 1)일 때 사용하는 회귀. 예측 결과는 0과 1 사이의 확률값으로 출력됨
[구분] 오즈(Odds): 성공확률과 실패확률의 비 / 로짓(logit) 변환: 오즈에 자연로그를 취해 선형처럼 바꿈(독립변수가 1 증가하면 오즈가 e^계수배만큼 증가)
[구분] 기출 함정: "다중공선성 문제를 해결하기 위해 독립변수 간 높은 상관관계는 확인해야 한다"는 표현은 다소 이상한 오답 함정 → 로지스틱 회귀도 선형회귀처럼 "독립변수들이 정규분포를 따라야 한다"는 가정은 없음
[치트키] "로지스틱 = 결과가 딱 둘 중 하나(예/아니오)일 때 확률로 예측, S자 곡선(시그모이드) 사용"
[예문] 시험점수로 합격 여부(0 또는 1)를 예측할 때는 로지스틱 회귀분석을 사용한다

의사결정나무 (Decision Tree)
여러 개 분리 기준으로 최종 분류값을 찾는 트리 구조 모델
[구성] 의사결정(意思決定) + 나무(Tree) → 질문하면서 나무처럼 가지를 쳐나가는 분류기
[의미] 분류와 회귀 문제 모두에 적용 가능한 비모수적 모델. 분석 결과를 시각적으로 표현할 수 있어 해석이 쉬움
[구분] 기출 함정: "데이터의 스케일링과 같은 전처리 과정이 전혀 필요 없다"는 것은 사실이지만, "정규성 가정이 필요하다"는 지문은 틀림(4월 기출 47번 나 선지) → 의사결정나무는 스케일링·정규성 가정이 불필요한 비모수 모델
[구분] 분할기준: 분류(CHAID-통계적유의성, CART-지니지수, C4.5/C5.0-엔트로피지수) / 회귀(CHAID, CART)
[구분] 정지규칙: 분리를 더 이상 수행하지 않게 함 / 가지치기(Pruning): 일부 가지를 제거해 과적합 방지
[치트키] "나무는 동질성이 커지는 방향으로 가지를 뻗음, 정규성 가정 불필요, 스케일링도 불필요"
[예문] 의사결정나무는 IF-THEN 규칙 형태로 표현되어 비전문가도 이해하기 쉽다

의사결정나무 분할기준 (CHAID/CART/C4.5)
의사결정나무가 가지를 나누는 기준이 되는 3가지 알고리즘
[구성] CHAID(카이제곱) / CART(지니지수) / C4.5, C5.0(엔트로피지수)
[의미]
· 분류 문제에서: CHAID는 통계적 유의성(카이제곱검정), CART는 지니지수, C4.5/C5.0은 엔트로피지수를 기준으로 분할
· 회귀 문제에서: CHAID, CART 사용
[구분] 지니지수와 엔트로피지수 모두 "불순도(Impurity)"를 측정하는 지표라는 공통점, 어떤 알고리즘을 쓰느냐에 따라 계산 방식이 다름
[치트키] "카이드(CHAID)=카이제곱, 카트(CART)=지니, C4.5/5.0=엔트로피"
[예문] CART 알고리즘은 지니지수를 기준으로 가장 순수한 분할을 찾는다

인공신경망 (ANN, Artificial Neural Network)
인간의 뇌 구조를 모방한 퍼셉트론 기반 모델
[구성] 퍼셉트론(입력→가중치→활성화함수→출력) → 다중 퍼셉트론(MLP, 은닉층 1개 이상)
[의미] 입력신호에 가중치를 곱하고 활성화 함수를 거쳐 출력하는 구조. 은닉층 수는 사용자가 직접 설정
[구분] 활성화 함수 4종
· 시그모이드: 0~1 사이 값, 로지스틱 회귀와 유사
· 소프트맥스: 목표 데이터가 다범주일 때 각 범주의 사후확률 제공
· 하이퍼볼릭 탄젠트: 시그모이드 중심을 0으로 이동 → -1~1 사이 값
· ReLU: 기울기 소실문제 극복(단, 0 이하 값에서는 dying ReLU 문제 가능)
[구분] 기출 함정: "입력값이 음수이면 그대로 출력, 양수이면 0을 출력"은 ReLU의 반대 설명(실제로는 음수는 0, 양수는 그대로 출력, 4월 기출 52번)
[치트키] "활성화함수 = 신호를 다음 뉴런에 넘길지 말지 결정하는 스위치"
[예문] 다범주 분류 문제의 출력층에서는 소프트맥스 함수를 사용해 각 클래스의 확률을 계산한다

인공신경망 과적합 방지 방안
신경망이 훈련데이터에 지나치게 맞춰지는 것을 막는 방법들
[구성] 라쏘(L1)규제 / 릿지(L2)규제 / 드롭아웃 / 조기종료 / 모델 복잡도 감소 / 데이터 증강 / 배치정규화
[의미]
· 라쏘(L1): 맨하탄 거리 기반(절댓값), 변수를 일부 아예 제거(변수선택 효과)
· 릿지(L2): 유클리드 거리 기반(제곱), 변수 영향을 0에 가깝게 만듦(제거는 안 함)
· 드롭아웃: 일부 퍼셉트론(뉴런)을 무작위로 비활성화
· 조기종료: 검증 성능이 나빠지기 전에 학습 중단
· 데이터 증강: 데이터를 더 많이 만듦(변형해서)
· 배치정규화: 중간중간 정규화해서 학습 안정화
[구분] 기출 함정: "손실 함수에 추가되는 패널티 항이 회귀 계수의 절댓값합 형태" = 라쏘(L1)의 희소(sparse) 효과 이유(4월 기출 77번 정답)
[치트키] "라쏘(L1, 절댓값)=아예 없애기, 릿지(L2, 제곱)=0에 가깝게만"
[예문] Lasso 회귀는 절댓값 패널티 때문에 일부 회귀계수를 정확히 0으로 만들어 변수 선택 효과를 가진다

XOR 문제와 활성화 함수
인공신경망의 선형성 한계를 극복하기 위한 배경 개념
[구성] XOR(배타적 논리합) + 활성화 함수(비선형 함수)
[의미] 단층 퍼셉트론은 XOR 같은 선형분리 불가능한 문제를 풀 수 없음. 활성화 함수(비선형)와 다층 구조(MLP)를 도입해 이 문제를 극복
[구분] 활성화 함수가 없으면(또는 선형함수만 쓰면) 여러 층을 쌓아도 결국 하나의 선형 모델과 동일해짐 → 비선형 활성화 함수가 필수인 이유(4월 기출 66번)
[치트키] "XOR = 직선 하나로 못 가르는 문제, 그래서 비선형 활성화함수+은닉층이 필요"
[예문] 은닉층에 비선형 활성화 함수가 없으면 여러 층을 쌓아도 단일 선형 모델과 다를 바 없다

역전파 알고리즘 & 경사하강법
인공신경망의 대표적인 두 가지 학습 방법
[구성] 역전파(Backpropagation) / 경사하강법(Gradient Descent)
[의미]
· 역전파 알고리즘: 가중치를 수정하여 오차를 줄임(출력층 → 입력층 방향으로 전파)
· 경사하강법: 기울기를 낮은 쪽으로 이동시켜 극값(최솟값)에 이를 때까지 반복
[구분] 역전파는 "오차를 뒤로(입력층 방향으로) 전달해 가중치를 수정하는 절차", 경사하강법은 "그 수정 방향(기울기)을 찾는 방법"이라는 관계
[치트키] "역전파 = 틀린 걸 뒤로 알려줌(출력→입력), 경사하강법 = 산을 내려가듯 최소점을 찾음"
[예문] 신경망 학습에서는 역전파로 오차를 계산하고, 경사하강법으로 가중치를 업데이트한다

경사하강법의 종류 (SGD/모멘텀/AdaGrad/Adam)
경사하강법을 개선한 다양한 옵티마이저
[구성] 확률적 경사하강법(SGD) / 모멘텀(Momentum) / AdaGrad / Adam
[의미]
· SGD: 전체 데이터가 아닌 미니배치를 사용해 파라미터 업데이트(계산 효율 높음), 기울기가 가장 작은 지점에 도달하도록 함
· 모멘텀: 관성(물리법칙) 적용, 빠른 최적점 수렴 가능
· AdaGrad: 기울기 크기에 따라 학습률 조정(처음엔 크게 → 점차 작게)
· Adam: 모멘텀+AdaGrad 결합, 좌우 흔들림이 덜함
[구분] 기출 함정: "확률적 경사하강법은 전미분을 사용한다" → 틀림, SGD는 미니배치(일부)만 사용 / "아다그라드는 이전 기울기 값과 관계없다" → 틀림, AdaGrad는 과거 기울기 누적을 반영함 / "Adam은 학습률을 고려하지 않는다" → 틀림, Adam도 학습률 개념을 사용(4월 기출 73번)
[구분] 기출 함정: "비볼록 함수에서도 항상 전역 최솟값을 찾는 것을 보장한다" → 틀림! 지역최솟값(local minimum)에 빠질 수 있음(4월 기출 65번)
[치트키] "SGD(기본)-모멘텀(관성 추가)-AdaGrad(학습률 자동조정)-Adam(모멘텀+AdaGrad 합체)"
[예문] Adam 옵티마이저는 모멘텀과 AdaGrad의 장점을 결합해 안정적으로 수렴한다

서포트벡터머신 (SVM, Support Vector Machine)
마진이 최대가 되는 초평면(경계선)을 찾아 분류하는 기법
[구성] 초평면(하이퍼플레인) + 서포트벡터 + 마진 → 데이터를 가장 똑 떨어지게 나눌 수 있는 '경계선' 찾기
[의미] 집단 사이의 마진이 최대화되는 초평면을 학습해 분류. 분류와 회귀 모두 사용 가능
[구분] 초평면(하이퍼플레인): 데이터를 구분하는 기준 경계선 / 서포트벡터: 초평면과 가장 가까운 데이터들 / 마진: 초평면과 서포트벡터 사이의 거리(최대화가 목표) / 커널함수: 저차원 데이터를 고차원 데이터로 변경해 비선형 분류를 가능하게 함
[구분] 기출 함정: "모델 훈련을 통한 최적화가 필요 없다"는 틀린 설명(4월 기출 49번) → SVM도 훈련(마진 최대화 최적화 과정)이 필요함
[구분] 유형: 하드마진분류(오류 비허용, 절대 안 틀림) / 소프트마진분류(마진 내 어느 정도 오류 허용)
[치트키] "SVM = 두 집단을 가장 넓게 벌려놓는 선(마진 최대화)을 찾는 것, 커널함수로 저차원→고차원 매핑해서 곡선도 분류 가능"
[예문] 선형으로 분리되지 않는 데이터는 커널함수를 이용해 고차원 공간으로 매핑한 뒤 SVM으로 분류한다

나이브베이즈 분류 (Naive Bayes)
베이즈 정리를 기반으로 한 분류 모델
[구성] 나이브(Naive, 독립 가정) + 베이즈(Bayes) 이론 → 나이브베이즈 = 나이브(독립)+베이즈(사전·사후확률)
[의미] 사전확률과 사후확률을 토대로 우도를 계산해 분류하는 모델. 독립변수들 간에 조건부 독립을 가정(나이브함)
[구분] 기출 함정: "모델이 복잡하고 계산속도가 느리다" → 틀림, 나이브베이즈는 오히려 "단순하고 계산속도가 빠름" / "독립변수들 간의 상관성을 가정한다" → 틀림, 반대로 "독립(비상관)을 가정" (4월 기출 56번)
[구분] 노이즈와 결측 데이터에 약한 편(정답 선지, 4월 기출 56번)
[치트키] "나이브 = 순진하게(독립이라고) 가정하고 베이즈 정리로 확률 계산 → 단순하고 빠름"
[예문] 스팸메일 필터링에서 단어 등장을 서로 독립이라 가정하고 확률을 계산하는 것이 나이브베이즈 분류다

베이즈 정리 & 베이지안 기법
사전확률에서 새로운 증거를 반영해 사후확률로 갱신하는 이론
[구성] 사전확률(Prior) → 새로운 증거(Evidence) → 사후확률(Posterior)
[의미] 새로운 정보(증거)가 생기면 기존의 확률(사전확률)을 갱신해 사후확률을 구하는 통계적 추론 방법
[구분] 나이브베이즈 분류는 베이즈 정리에 "조건부 독립 가정(나이브함)"을 추가한 것
[치트키] "새로운 정보가 생기면 믿음(확률)도 업데이트해야지"
[예문] 검사 결과라는 새로운 증거를 반영해 질병 확률(사후확률)을 다시 계산하는 것이 베이지안 기법이다
