[읽기] 凝=ギョウ + 縮=シュク → ぎょうしゅく (음독)
[한자1] 凝 (엉길 응 / 엉기다, 응축하다)
· 음독: ★ギョウ
· 훈독: こ-る, こ-らす
· 분해: 冫(얼음 빙) + 疑(의심할 의, 발음요소)
· 어원: 액체가 얼음처럼 엉겨 굳는 모습에서 응축하다를 나타냄
· 예시 단어: 凝固 (응고, ぎょう+こ)
[한자2] 縮 (다스릴 축 / 줄어들다)
· 음독: ★シュク
· 훈독: ちぢ-む
· 분해: 糸(실 사) + 宿(잘 숙, 몸을 웅크림)
· 어원: 실이 웅크리듯 줄어드는 모습에서 줄어들다를 나타냄
· 예시 단어: 短縮 (단축, たん+しゅく)
[종합] 엉겨서(凝) 줄어드는(縮) 것이라는 뜻에서 응축이 됨
[치트키] "교-슈쿠! 교-(엉김)와 슈쿠(줄어듦) 응축" → 凝縮=교-슈쿠→응축
[장면] 수증기가 차가운 유리에 물방울로 응축되는 장면
[예문] 経験が凝縮される(케이켄가 교-슈쿠사레루) = "경험이 응축되다"

厳正な
엄정한(げんせいな)
[읽기] 厳=ゲン + 正=セイ → げんせい (음독)
[한자1] 厳 (엄할 엄 / 엄하다)
· 음독: ★ゲン
· 훈독: きび-しい, おごそ-か
· 분해: 厂(기슭 엄) + 敢(감히 감)
· 어원: 감히 맞설 수 없는 엄격함에서 엄하다를 나타냄
· 예시 단어: 厳重 (엄중, げん+じゅう)
[한자2] 正 (바를 정 / 바르다)
· 음독: ★セイ, ショウ
· 훈독: ただ-しい
· 분해: 一(한 일, 기준) + 止(그칠 지)
· 어원: 정해진 기준에 발걸음을 멈춘다는 뜻에서 바르다를 나타냄
· 예시 단어: 正確 (정확, せい+かく)
[종합] 엄하고(厳) 바른(正) 태도라는 뜻에서 엄정한이 됨
[치트키] "겐세이나! 겐(엄함) 세이(바름)나 엄정해" → 厳正な=겐세이나→엄정한
[장면] 심사위원단이 엄정하게 채점하는 장면
[예문] 厳正に審査する(겐세이니 신사스루) = "엄정하게 심사하다"

拒む
거부하다(こばむ)
[읽기] 拒=こば + む(오쿠리가나) → こばむ (훈독)
[한자1] 拒 (막을 거 / 막다, 거부하다)
· 음독: キョ
· 훈독: ★こば-む
· 분해: 扌(손 수) + 巨(클 거)
· 어원: 손으로 크게 막아 물리친다는 뜻에서 막다, 거부하다를 나타냄
· 예시 단어: 拒否 (거부, きょ+ひ)
[종합] 한자 하나로 이루어진 훈독 동사로, 상대의 요구나 접근을 단호히 물리치는 것을 뜻함
[치트키] "코바무! 코바(거부의 손짓)로 막았무" → 拒む=코바무→거부하다
[장면] 부당한 요구를 단호히 거절하는 장면
[예문] 要求を拒む(요-큐-오 코바무) = "요구를 거부하다"

遂行
수행(すいこう)
[읽기] 遂=スイ + 行=コウ → すいこう (음독)
[한자1] 遂 (드디어 수 / 이루다, 완수하다)
· 음독: ★スイ
· 훈독: と-げる
· 분해: 辶(쉬엄쉬엄 갈 착) + 㒸(드디어 수, 발음요소)
· 어원: 길을 끝까지 가서 마침내 이룬다는 뜻에서 완수하다를 나타냄
· 예시 단어: 完遂 (완수, かん+すい)
[한자2] 行 (다닐 행 / 다니다, 행하다)
· 음독: ★コウ, ギョウ
· 훈독: い-く, おこな-う
· 분해: 行 자체가 사거리 모양을 본뜬 상형자
· 어원: 사람이 오가는 사거리 모양에서 다니다, 행하다를 나타냄
· 예시 단어: 実行 (실행, じっ+こう)
[종합] 완수하며(遂) 행하는(行) 것이라는 뜻에서 수행이 됨
[치트키] "스이코-! 스이(완수)와 코-(행함) 수행" → 遂行=스이코-→수행
[장면] 맡은 임무를 끝까지 완수해내는 장면
[예문] 任務を遂行する(닌무오 스이코-스루) = "임무를 수행하다"

健やかな
건강한(すこやかな)
[읽기] 健=すこ + やかな(형용동사 어미) → すこやかな (훈독)
[한자1] 健 (굳셀 건 / 굳세다, 건강하다)
· 음독: ケン
· 훈독: ★すこ-やか, すこ-とい
· 분해: 亻(사람 인) + 建(세울 건, 발음요소)
· 어원: 사람이 굳건히 세워진 모습에서 건강하다를 나타냄
· 예시 단어: 健康 (건강, けん+こう)
[종합] 한자 하나로 이루어진 훈독 형용동사로, 몸과 마음이 튼튼하고 병 없이 자라는 상태를 뜻함
[치트키] "스코야카나! 스코(조금씩) 야카나 건강해" → 健やかな=스코야카나→건강한
[장면] 아이가 건강하게 무럭무럭 자라는 장면
[예문] 健やかに育つ(스코야카니 소다츠) = "건강하게 자라다"

漂う
떠돌다, 감돌다(ただよう)
[읽기] 漂=ただよ + う(오쿠리가나) → ただよう (훈독)
[한자1] 漂 (떠다닐 표 / 떠다니다, 표류하다)
· 음독: ヒョウ
· 훈독: ★ただよ-う
· 분해: 氵(물 수) + 票(표 표, 발음요소)
· 어원: 물 위에 가벼운 것이 떠다니는 모습을 나타냄
· 예시 단어: 漂流 (표류, ひょう+りゅう)
[종합] 한자 하나로 이루어진 훈독 동사로, 정처 없이 물이나 공기 중을 떠다니는 것을 뜻함
[치트키] "타다요우! 타다(그저) 요우(떠다님)" → 漂う=타다요우→떠돌다
[장면] 은은한 향기가 방 안에 감도는 장면
[예문] いい香りが漂う(이이 카오리가 타다요우) = "좋은 향기가 감돌다"

中枢
중추(ちゅうすう)
[읽기] 中=チュウ + 枢=スウ → ちゅうすう (음독)
[한자1] 中 (가운데 중 / 가운데, 중심)
· 음독: ★チュウ
· 훈독: なか
· 분해: 口(입 구, 원래는 물건) + 丨(뚫을 곤)
· 어원: 사물의 한가운데를 관통하는 모습에서 가운데를 나타냄
· 예시 단어: 集中 (집중, しゅう+ちゅう)
[한자2] 枢 (지도리 추 / 지도리, 중추)
· 음독: ★スウ
· 훈독: 없음
· 분해: 木(나무 목) + 区(구역 구, 발음요소)
· 어원: 문을 여닫는 나무 지도리, 중요한 축을 나타냄
· 예시 단어: 中枢神経 (중추신경, ちゅうすう+しんけい)
[종합] 가운데(中)의 중요한 축(枢)이라는 뜻에서 중추가 됨
[치트키] "츄-스-! 츄-(중심)의 스-(축) 중추" → 中枢=츄-스-→중추
[장면] 정부의 중추 기관에서 정책을 결정하는 장면
[예문] 中枢を担う(츄-스-오 니나우) = "중추를 담당하다"

督促
독촉(とくそく)
[읽기] 督=トク + 促=ソク → とくそく (음독)
[한자1] 督 (감독할 독 / 감독하다, 독촉하다)
· 음독: ★トク
· 훈독: 없음
· 분해: 叔(아재비 숙) + 目(눈 목)
· 어원: 윗사람의 눈으로 아랫사람을 지켜보고 재촉한다는 뜻을 나타냄
· 예시 단어: 監督 (감독, かん+とく)
[한자2] 促 (재촉할 촉 / 재촉하다)
· 음독: ★ソク
· 훈독: うなが-す
· 분해: 亻(사람 인) + 足(발 족, 빨리 감)
· 어원: 사람의 발걸음을 재촉하는 모습에서 재촉하다를 나타냄
· 예시 단어: 促進 (촉진, そく+しん)
[종합] 감독하며(督) 재촉하는(促) 것이 합쳐져 독촉이라는 뜻이 됨
[치트키] "토쿠소쿠! 토쿠(감독)와 소쿠(재촉) 독촉" → 督促=토쿠소쿠→독촉
[장면] 미납된 요금을 독촉하는 고지서를 받는 장면
[예문] 支払いを督促する(시하라이오 토쿠소쿠스루) = "지불을 독촉하다"

臨む
임하다, (상황에) 직면하다(のぞむ)
[읽기] 臨=のぞ + む(오쿠리가나) → のぞむ (훈독)
[한자1] 臨 (임할 임 / 임하다, 대하다)
· 음독: リン
· 훈독: ★のぞ-む
· 분해: 臣(신하 신) + 品(입 여러 개, 원래는 물건) + 卜(점 복)
· 어원: 신하가 위에서 아래를 내려다보며 임하는 모습을 나타냄
· 예시 단어: 臨時 (임시, りん+じ)
[종합] 한자 하나로 이루어진 훈독 동사로, 어떤 중요한 상황이나 자리에 직접 참여하는 것을 뜻함
[치트키] "노조무! 노조(들여다봄)한 채 임했무" → 臨む=노조무→임하다
[장면] 결승전에 진지한 각오로 임하는 선수의 모습
[예문] 試合に臨む(시아이니 노조무) = "시합에 임하다"

躍進

· 음독: ★ヤク
· 훈독: おど-る
· 분해: 足(발 족) + 翟(꿩 적, 발음요소)
· 어원: 꿩이 발로 힘차게 뛰는 모습에서 도약하다를 나타냄
· 예시 단어: 活躍 (활약, かつ+やく)
[한자2] 進 (나아갈 진 / 나아가다)
· 음독: ★シン
· 훈독: すす-む

· 예시 단어: 進歩 (진보, しん+ぽ)
[종합] 뛰듯이(躍) 나아가는(進) 것이라는 뜻에서 약진이 됨
[치트키] "야쿠신! 야쿠(도약)과 신(나아감) 약진" → 躍進=야쿠신→약진
[장면] 신생 기업이 빠르게 성장하며 약진하는 장면
[예문] 業績が躍進する(교-세키가 야쿠신스루) = "업적이 약진하다"
