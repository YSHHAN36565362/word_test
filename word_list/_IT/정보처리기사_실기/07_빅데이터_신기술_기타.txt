클라우드 서비스 유형
클라우드로 제공하는 서비스의 범위에 따른 세 가지 유형 (암기: 인플소)
[구성] 인프라형(IaaS) → 플랫폼형(PaaS) → 소프트웨어형(SaaS)
[의미] 서버·플랫폼·소프트웨어 중 어디까지를 서비스로 제공하는지에 따라 구분
[구분] 유형별 설명
· IaaS: 서버 같은 시스템 자원을 클라우드로 제공
· PaaS: 소프트웨어를 개발할 수 있는 플랫폼을 제공
· SaaS: 소프트웨어와 데이터를 중앙에 호스팅하고 사용자는 웹 브라우저 등으로 접속해 이용
[치트키] "인(인프라) 플(플랫폼) 소(소프트웨어) = 인플소, 인플소(인형 풀소) 순서로 위로 올라간다"
[예문] 서버 같은 시스템 자원을 클라우드로 빌려 쓰는 서비스는 IaaS이다

하둡(Hadoop)
다수의 범용 컴퓨터를 연결해 하나의 시스템처럼 작동하도록 묶어 분산 처리하는 공개 소스 프레임워크
[구성] 범용 컴퓨터 클러스터 + 분산 저장 + 분산 처리
[의미] 대용량 데이터를 저렴한 장비로 분산 처리하기 위한 오픈소스 빅데이터 프레임워크
[치트키] "하둡 = 여럿이 힘을 모아 하나처럼 처리 (분산)"
[예문] 범용 컴퓨터 여러 대를 묶어 대용량 데이터를 분산 처리하는 오픈소스 프레임워크는 하둡이다

스쿱(Sqoop)
SQL To Hadoop, SQL과 하둡을 같이 쓸 수 있게 하는 도구
[구성] SQL + Hadoop
[의미] 관계형 데이터베이스와 하둡 사이에서 데이터를 옮겨 주는 도구
[치트키] "스쿱 = 관계형 DB 데이터를 하둡으로 퍼 담는 국자"
[예문] 관계형 데이터베이스의 데이터를 하둡으로 가져오는 도구는 스쿱이다

NoSQL
RDBMS와 다르게 설계된 비관계형 데이터베이스
[구성] Not Only SQL + 비관계형 + 유연한 스키마
[의미] 정형 데이터뿐 아니라 비정형 데이터도 다루며 대용량 분산 환경에 적합한 DB
[치트키] "노(No) SQL = 표(관계형)에 얽매이지 않는 DB"
[예문] 관계형이 아닌 방식으로 대용량 데이터를 유연하게 저장하는 DB는 NoSQL이다
[헷갈리는 단어] RDBMS - NoSQL은 비관계형, RDBMS는 관계형

OLAP
다수의 테이블을 효율적으로 검색할 수 있도록 하는 분석형 애플리케이션
[구성] 다차원 분석 + 데이터 웨어하우스 연계
[의미] 사용자가 다양한 관점에서 데이터를 대화식으로 분석하도록 지원
[치트키] "OLAP = 올라가며(Online) 분석(Analytical)"
[예문] 데이터 웨어하우스의 데이터를 다차원으로 분석하는 도구는 OLAP이다

데이터 웨어하우스(DW)
데이터베이스에 축적된 데이터를 공통으로 모아서 관리하는 데이터베이스
[구성] 여러 원천 데이터 + 통합 + 주제별 저장
[의미] 의사결정을 위해 기업 전체 데이터를 통합 저장한 대규모 저장소
[치트키] "웨어하우스 = 데이터 창고"
[예문] 여러 시스템의 데이터를 통합 저장해 분석에 활용하는 저장소는 데이터 웨어하우스이다
[헷갈리는 단어] 데이터 마트 - 웨어하우스는 전체, 마트는 특정 부서·주제의 일부

데이터 마트(Data Mart)
전체 데이터 웨어하우스의 일부 데이터를 가지고 특정 사용자가 관심 있는 데이터를 담은 비교적 작은 규모의 웨어하우스
[구성] 데이터 웨어하우스의 일부 + 특정 부서·주제
[의미] 특정 사용자 요구에 맞게 데이터를 분리해 접근성과 분석 효율을 높인 소규모 저장소
[치트키] "마트 = 창고에서 필요한 것만 꺼내 진열한 동네 마트"
[예문] 마케팅 부서가 사용하기 위해 데이터 웨어하우스에서 일부만 추출한 저장소는 데이터 마트이다

데이터 마이닝(Data Mining)
대규모 데이터 안에서 체계적이고 자동적으로 규칙이나 패턴을 찾아내는 기술
[구성] 대규모 데이터 + 규칙·패턴 탐색
[의미] 숨겨진 유용한 정보를 자동으로 발견하는 분석 기술
[구분] 유사 용어
· 텍스트 마이닝: 대규모 텍스트에서 의미 있는 정보를 추출
· 웹 마이닝: 웹의 대규모 정보 중 유용한 정보를 찾아내는 기법
[치트키] "마이닝 = 데이터 광산에서 금(패턴)을 캔다"
[예문] 대규모 데이터에서 규칙이나 패턴을 자동으로 찾아내는 기술은 데이터 마이닝이다

메타 데이터(Meta Data)
데이터에 대한 데이터, 다른 데이터를 설명해 주는 구조화된 데이터
[구성] 데이터 + 설명 정보
[의미] 데이터의 구조·의미·출처를 설명하여 검색과 관리에 활용
[치트키] "메타 = 한 단계 위, 데이터를 설명하는 데이터"
[예문] 사진 파일의 촬영일과 크기 정보처럼 데이터를 설명하는 데이터는 메타 데이터이다

CAP 이론
일관성, 가용성, 분할 내성 세 가지 속성 중 두 가지만 가질 수 있다는 이론
[구성] Consistency(일관성) + Availability(가용성) + Partition tolerance(분할 내성)
[의미] 분산 시스템에서 세 속성을 동시에 모두 만족할 수 없음을 설명
[치트키] "C·A·P 중 두 개만 고르세요"
[예문] 분산 시스템에서 일관성, 가용성, 분할 내성을 모두 만족할 수 없다는 이론은 CAP 이론이다

블록체인
관리 대상 데이터를 블록이라는 소규모 데이터로 만들어 P2P 방식으로 체인 형태로 연결한 기술
[구성] 블록 + 체인 연결 + P2P 분산 저장
[의미] 중앙 서버 없이 참여자가 거래 기록을 공동으로 보관하고 검증
[치트키] "블록을 쇠사슬처럼 이어 모두가 장부를 나눠 갖는다"
[예문] 거래 정보를 블록으로 묶어 P2P 방식으로 연결한 분산 기술은 블록체인이다

NFT(Non-fungible token)
블록체인 기술을 이용해 디지털 자산의 소유주임을 증명하는 가상의 토큰
[구성] 블록체인 + 고유 토큰 + 소유권 증명
[의미] 대체 불가능한 고유한 디지털 자산을 구분하게 함
[치트키] "NFT = 복사해도 원본임을 증명하는 디지털 소유 증서"
[예문] 디지털 자산의 소유권을 블록체인으로 증명하는 토큰은 NFT이다

하이퍼바이저
하나의 컴퓨터에서 동시에 다수의 운영체제를 구동시킬 수 있게 하는 소프트웨어 가상화 플랫폼
[구성] 물리 서버 → 하이퍼바이저 → 가상 머신 여러 개
[의미] 하드웨어 자원을 추상화하여 여러 운영체제가 공유
[치트키] "하이퍼바이저 = 한 컴퓨터를 여러 대처럼 나누는 감독관"
[예문] 한 대의 서버에서 여러 운영체제를 동시에 구동시키는 가상화 소프트웨어는 하이퍼바이저이다

SDN(Software Defined Networking)
하드웨어에 의존하는 네트워크 체계에서 안전성, 보안, 속도 등을 소프트웨어로 제어·관리하기 위해 개발된 기술
[구성] 제어부 + 데이터부 분리 + 소프트웨어 제어
[의미] 네트워크를 소프트웨어로 중앙에서 유연하게 관리
[치트키] "SDN = 네트워크를 소프트웨어로 조종"
[예문] 네트워크 장비를 소프트웨어로 제어·관리하는 기술은 SDN이다

소프트웨어 정의 기술
하드웨어에 종속된 자원을 소프트웨어로 분리해 제어하는 기술
[구성] SDN + SDS + SDC + SDDC
[의미] 인프라를 소프트웨어로 유연하게 관리
· SDDC의 구성요소로 SDC, SDN, SDS와 프로비저닝이 거론됨
[구분] 기술별 의미
· SDN: 네트워크를 소프트웨어로 제어
· SDS: 하드웨어에서 스토리지 소프트웨어를 분리하는 스토리지 아키텍처
· SDC: 소프트웨어 정의 컴퓨팅 (IaaS)
· SDDC: 모든 하드웨어를 가상화하여 가상 자원 풀을 구성하고 소프트웨어가 동적으로 할당·관리하는 데이터 센터
[치트키] "네트워크 N, 스토리지 S, 컴퓨팅 C, 데이터센터 DC"
[예문] 모든 하드웨어를 가상화해 자원 풀로 운영하는 데이터 센터는 SDDC이다

NFC
13.56MHz 주파수를 이용한 자기 유도결합 기반의 근접 무선 통신 기술
[구성] 근거리 + 13.56MHz + 자기장 통신
[의미] 스마트폰 결제나 출입 인증 등에 쓰이는 짧은 거리 통신
[치트키] "NFC = 가까이(Near Field) 대면 통신"
[예문] 13.56MHz 주파수를 이용해 가까운 거리에서 통신하는 기술은 NFC이다

RFID
전파 신호를 통해 비접촉식으로 사물에 부착된 얇은 평면 형태의 태그를 식별해 정보를 처리하는 기술
[구성] 태그 + 리더기 + 전파 식별
[의미] 물류, 출입 관리 등에서 사물을 자동으로 식별
[치트키] "RFID = 전파로 태그 읽기"
[예문] 전파를 이용해 비접촉으로 태그를 식별하는 기술은 RFID이다

도커(Docker)
컨테이너 응용 프로그램의 배포를 자동화하는 오픈소스 엔진
[구성] 컨테이너 + 이미지 + 자동 배치
[의미] 응용 프로그램을 컨테이너 안에 넣어 어디서나 동일하게 실행
[치트키] "컨테이너도 커~ = 도커"
[예문] 소프트웨어 컨테이너 안에 응용 프로그램을 배치하는 일을 자동화하는 오픈소스는 도커이다

머신러닝·딥러닝 라이브러리
인공지능 개발에 널리 사용되는 도구
[구성] 딥러닝 + 사이킷런 + 텐서플로 + 파이토치
[의미] 모델 구축과 학습을 쉽게 해 주는 프레임워크
[구분] 도구별 의미
· 딥러닝: 머신러닝 알고리즘 중 인공신경망을 기반으로 한 방법의 통칭
· 사이킷런: 가장 널리 사용되는 머신러닝 패키지 중 하나
· 텐서플로: 구글이 만든 딥러닝 라이브러리, CPU와 GPU로 인공신경망 모델을 효율적으로 훈련
· 파이토치: 페이스북에서 개발해 2016년에 공개한 파이썬 기반 오픈소스 머신러닝 라이브러리
[치트키] "텐서플로는 구글, 파이토치는 페이스북"
[예문] 구글이 만든 딥러닝 라이브러리는 텐서플로이다

빅데이터 3V
빅데이터의 대표 특성 3가지
[구성] Volume(규모) + Velocity(속도) + Variety(다양성)
[의미] 기존 방식으로 처리하기 어려운 대규모 데이터의 특징
[구분] 특성별 의미
· Volume: 데이터의 양이 매우 큼
· Velocity: 생성과 처리 속도가 빠름
· Variety: 정형·비정형 등 형태가 다양함
[치트키] "양(Volume) 속도(Velocity) 다양성(Variety) = 3V"
[예문] 빅데이터의 3V는 규모, 속도, 다양성이다

DevOps
개발(Development)과 운영(Operations)을 통합하여 개발 주기를 단축하고 지속적으로 배포하는 방법론
[구성] 개발 + 운영 + 자동화(CI/CD)
[의미] 개발과 운영 간 협업으로 빠르고 안정적인 배포를 지원
[치트키] "DevOps = 개발팀과 운영팀의 벽을 허문다"
[예문] 개발과 운영을 통합하여 빠르게 배포하는 방법론은 DevOps이다

마이크로서비스(MSA)
하나의 큰 애플리케이션을 독립적으로 배포 가능한 작은 서비스 단위로 나누어 구성하는 아키텍처
[구성] 작은 서비스 + 독립 배포 + API 통신
[의미] 서비스별로 독립적으로 개발·확장·배포할 수 있어 유연성이 높음
[치트키] "MSA = 큰 덩어리를 작은 서비스로 쪼개기"
[예문] 서비스를 독립적으로 배포 가능한 작은 단위로 나누는 아키텍처는 마이크로서비스이다

메타버스
3차원 가상 세계에서 실제 생활과 같은 직업, 금융, 학습 등이 연결된 가상 세계
[구성] 3차원 가상 공간 + 사용자 아바타 + 경제 활동
[의미] 현실과 가상이 융합되어 사회·경제 활동이 이루어지는 공간
[치트키] "메타(초월) + 유니버스(세계) = 메타버스"
[예문] 3차원 가상 공간에서 경제·사회 활동이 이루어지는 세계는 메타버스이다

스크레이피(Scrapy)
웹 사이트를 크롤링하여 구조화된 데이터를 수집하는 파이썬 기반의 애플리케이션 프레임워크
[구성] 파이썬 + 크롤러 + 데이터 추출
[의미] 웹에서 필요한 정보를 자동으로 수집
[치트키] "스크레이프 = 긁어모으다, 웹 데이터를 긁어 오는 프레임워크"
[예문] 파이썬으로 웹 크롤링을 수행하는 프레임워크는 Scrapy이다

피코넷(Piconet)
소규모 무선 통신망을 형성하는 무선 네트워크 기술
[구성] 근거리 무선 단말 + 소규모 망 형성
[의미] 개인 영역에서 장치들을 무선으로 연결하는 소규모 네트워크
[치트키] "피코(아주 작은) + 넷 = 아주 작은 무선망"
[예문] 근거리 무선 단말들이 구성하는 소규모 무선 네트워크는 피코넷이다
[헷갈리는 단어] WPAN - 피코넷은 소규모 망 형성, WPAN은 개인 영역 무선 네트워크

UWB(초광대역)
낮은 전력으로 넓은 주파수 대역을 사용하여 대용량 정보를 전송하는 무선 통신 기술
[구성] 초광대역 + 저전력 + 대용량 전송
[의미] 근거리에서 고속 통신과 정밀 위치 측정에 활용
[치트키] "UWB = 아주 넓은(Ultra Wide) 대역"
[예문] 낮은 전력으로 대용량 정보를 전송하는 초광대역 무선 통신 기술은 UWB이다

GIS
지리 정보 시스템, 지도에 관한 속성 정보를 컴퓨터를 이용해 해석하는 시스템
[구성] 지도 + 속성 정보 + 분석
[의미] 위치 기반 정보를 저장·분석·시각화
[치트키] "GIS = 지리(Geographic) 정보 시스템"
[예문] 지도와 속성 정보를 컴퓨터로 해석하는 시스템은 GIS이다

WPAN
무선을 이용하는 개인 영역 네트워크
[구성] 무선 + 개인 영역 + 근거리
[의미] 개인 주변 기기들을 무선으로 연결하는 소규모 네트워크
[치트키] "W 무선 + PAN 개인 영역 = 내 주변 무선망"
[예문] 개인 영역에서 무선으로 기기를 연결하는 네트워크는 WPAN이다

매시업(Mashup)
웹에서 제공하는 정보 및 서비스를 융합하여 새로운 소프트웨어나 서비스, 데이터베이스 등을 만드는 기술
[구성] 여러 웹 서비스 + 결합 + 새로운 서비스
[의미] 공개 API를 조합해 새로운 가치를 만듦
[치트키] "매시업 = 여러 서비스를 한 그릇에 섞기"
[예문] 지도 API와 맛집 정보를 결합해 새로운 서비스를 만드는 기술은 매시업이다

MQTT
IoT 환경에서 사용되는 경량 메시지 전송 프로토콜
[구성] 발행(Publish) + 구독(Subscribe) + 브로커
[의미] 낮은 대역폭과 제한된 자원을 가진 기기에 적합
[치트키] "MQTT = IoT용 가벼운 발행-구독 우체국"
[예문] 사물 인터넷에서 경량으로 메시지를 주고받는 프로토콜은 MQTT이다

디지털 트윈
현실 세계의 사물이나 시스템을 가상 세계에 똑같이 구현해 시뮬레이션하는 기술
[구성] 현실 사물 + 센서 데이터 + 가상 모델
[의미] 시뮬레이션으로 문제를 미리 예측하고 최적화
[치트키] "트윈 = 쌍둥이, 가상 세계의 쌍둥이"
[예문] 현실의 공장을 가상 모델로 만들어 시뮬레이션하는 기술은 디지털 트윈이다

CSS
HTML과 함께 웹을 구성하는 기본 요소로, 색상, 크기, 이미지 위치, 배치 등 웹 문서의 디자인 요소를 담당하는 언어
[구성] 스타일 + 레이아웃 + 디자인
[의미] 구조(HTML)와 표현(CSS)을 분리
[치트키] "HTML은 뼈대, CSS는 옷"
[예문] 웹 문서의 색상과 배치를 담당하는 언어는 CSS이다

다차원 데이터베이스 유형
OLAP 분석에서 데이터를 저장하는 방식에 따른 3가지 유형
[구성] MOLAP + ROLAP + HOLAP
[의미] 다차원 큐브 저장 방식과 관계형 DB 저장 방식을 구분
[구분] 유형별 의미
· MOLAP: 다차원 큐브에 저장하여 빠른 분석
· ROLAP: 관계형 DB에 저장하여 대용량 처리
· HOLAP: MOLAP와 ROLAP를 혼합
[치트키] "M 큐브, R 관계형, H 혼합"
[예문] 관계형 데이터베이스에 데이터를 저장하여 OLAP 분석을 수행하는 방식은 ROLAP이다

안드로이드(Android)의 특징
구글이 개발한 리눅스 기반의 모바일 운영체제로, 미들웨어와 사용자 인터페이스, 표준 응용 프로그램을 포함한 소프트웨어 스택
[구성] 리눅스 커널 + 자바·코틀린 언어 + 런타임 라이브러리 + 소프트웨어 개발 키트(SDK)
[의미] 휴대용 장치를 위한 운영체제로 앱 개발에 필요한 도구와 API를 제공
[구분] 특징별 의미
· 리눅스 기반: 리눅스 커널 위에서 동작
· 자바와 코틀린: 고수준 언어로 응용 프로그램을 작성
· 런타임 라이브러리: 컴파일된 바이트 코드를 구동
· SDK: 앱 개발에 필요한 각종 도구와 API 제공
[치트키] "안드로이드 = 리눅스 위에 자바·코틀린"
[예문] 리눅스 커널 위에서 동작하며 자바와 코틀린으로 앱을 개발하는 모바일 운영체제는 안드로이드이다

블록체인 합의 알고리즘
블록체인 참여자들이 새로운 블록의 생성과 승인에 합의하는 방식
[구성] PoW(작업 증명) + PoS(지분 증명)
[의미] 중앙 관리자 없이 신뢰를 확보하기 위한 합의 규칙
[구분] 알고리즘별 의미
· PoW(Proof of Work): 어려운 문제를 가장 빨리 해결한 참여자가 블록을 생성 (연산 능력 중심)
· PoS(Proof of Stake): 화폐를 더 많이 보유한 승인자가 우선하여 블록을 생성 (이더리움이 채택)
[치트키] "PoW는 일(연산)로, PoS는 지분(재산)으로"
[예문] 보유 화폐량이 많은 승인자가 블록 생성에 우선권을 갖는 알고리즘은 PoS이다

하둡(Hadoop)의 구성
오픈 소스 기반의 분산 컴퓨팅 플랫폼을 구성하는 핵심 요소
[구성] 하둡 분산 파일 시스템(HDFS) + 맵리듀스(MapReduce)
[의미] 일반 PC급 컴퓨터로 대형 스토리지를 형성하고 거대한 데이터 세트를 병렬 처리
[구분] 구성요소별 의미
· HDFS: 대용량 파일을 분산된 서버에 저장하고 빠르게 처리
· 맵리듀스: 대용량 데이터 세트를 분산 병렬 컴퓨팅으로 처리·생성하는 소프트웨어 프레임워크
[치트키] "저장은 HDFS, 계산은 맵리듀스"
[예문] 하둡에서 대용량 데이터를 분산 병렬 처리하는 프레임워크는 맵리듀스이다

클라우드 관련 기술
여러 클라우드를 연계·통합해 활용하는 기술
[구성] 인터클라우드 컴퓨팅 + 메타클라우드 + 멀티클라우드
[의미] 단일 클라우드의 종속성과 한계를 넘어 서비스를 연계
[구분] 용어별 의미
· 인터클라우드: 서로 다른 클라우드 서비스를 연동하여 상호 운용
· 메타클라우드: 여러 클라우드를 통합 관리하는 상위 계층의 클라우드
· 멀티클라우드: 둘 이상의 클라우드 서비스를 함께 사용하는 방식
[치트키] "인터는 연동, 메타는 통합 관리, 멀티는 여러 개 사용"
[예문] 둘 이상의 클라우드 서비스를 함께 사용하는 방식은 멀티클라우드이다

스마트 그리드와 Wi-SUN
전력과 정보통신을 결합한 지능형 전력망과 이를 위한 무선 통신 기술
[구성] 스마트 그리드 + Wi-SUN
[의미] 전력 사용 정보를 양방향으로 주고받아 에너지 효율을 높임
[구분] 용어별 의미
· 스마트 그리드: 전력망에 IT를 접목해 공급자와 소비자가 실시간으로 정보를 교환
· Wi-SUN: 스마트 미터링과 스마트 그리드에 사용되는 저전력 장거리 무선 통신 기술
[치트키] "스마트한 전력망(Grid) + 무선(Wi) SUN"
[예문] 전력 공급자와 소비자가 정보를 양방향으로 주고받는 지능형 전력망은 스마트 그리드이다

LOD(Linked Open Data)
웹상의 데이터를 개별 URI로 식별하고 링크 정보를 부여하여 상호 연결된 웹을 지향하는 개방형 데이터
[구성] URI 식별 + 링크 정보 + 개방 데이터
[의미] 데이터를 공개하고 서로 연결해 활용도를 높임
[치트키] "링크로 연결된(Linked) 열린(Open) 데이터"
[예문] 웹상의 데이터를 URI로 식별하고 서로 연결한 개방형 데이터는 LOD이다

DRM 패키징 도구 구성
디지털 콘텐츠를 안전하게 배포하기 위해 패키징할 때 사용하는 기술 구성
[구성] 암호화 + 식별 기술 + 저작권 표현 + 암호화 파일 생성 + 정책 관리 + 크랙 방지 + 인증
[의미] 콘텐츠를 암호화하고 이용 정책을 포함해 유통
[구분] 항목별 대표 기술
· 암호화: 공개키 기반 구조, 대칭·비대칭 암호화, 전자서명
· 식별 기술: DOI, URI
· 저작권 표현: XrML, MPEG-21
· 암호화 파일 생성: Pre-packaging, On-the-fly Packaging
· 정책 관리: XML, CMS
· 크랙 방지: 코드 난독화, Secure DB
· 인증: SSO
[치트키] "암호화·식별·표현·생성·정책·크랙방지·인증"
[예문] 콘텐츠를 사전에 암호화하여 패키징하는 방식은 Pre-packaging이다
