講師
강사(こうし)
[읽기] 講=コウ + 師=シ → こうし (음독)
[한자1] 講 (익힐 강 / 강의하다)
· 음독: ★コウ
· 훈독: 없음
· 분해: 言(말씀 언) + 冓(짤 구, 얽어 짬)
· 어원: 말을 엮어 짜서 가르친다는 뜻에서 강의하다를 나타냄
· 예시 단어: 講堂 (강당, こう+どう)
[한자2] 師 (스승 사 / 스승, 선생)
· 음독: ★シ
· 훈독: 없음
· 분해: 阜(언덕 부, 원래는 堆) + 帀(두를 잡, 군대가 둘러싸움)
· 어원: 언덕을 둘러싼 군대의 우두머리에서 스승, 지도자를 나타냄
· 예시 단어: 教師 (교사, きょう+し)
[종합] 강의하는(講) 스승(師)이라는 뜻에서 강사가 됨
[치트키] "코-시! 코-(강의)의 시(스승) 강사" → 講師=코-시→강사
[장면] 강단에 서서 열정적으로 가르치는 강사의 모습
[예문] 講師として招かれる(코-시토시테 마네카레루) = "강사로 초빙되다"

[치트키] "다이야! 다이(크게) 야(빛나는) 보석" → ダイヤ=다이야→다이아몬드
[장면] 반짝이는 다이아몬드 반지를 살펴보는 장면
[예문] 電車のダイヤが乱れる(덴샤노 다이야가 미다레루) = "전철 시간표가 어지러워지다"

高層
고층(こうそう)
[읽기] 高=コウ + 層=ソウ → こうそう (음독)
[한자1] 高 (높을 고 / 높다)
· 음독: ★コウ
· 훈독: たか-い
· 분해: 高 자체가 높이 솟은 누각 모양을 본뜬 상형자
· 어원: 누각이 높이 솟은 모습에서 높다를 나타냄
· 예시 단어: 高校 (고등학교, こう+こう)
[한자2] 層 (층 층 / 층, 겹)
· 음독: ★ソウ
· 훈독: 없음
· 분해: 尸(주검 시, 몸) + 曽(일찍 증, 겹쳐 쌓음)
· 어원: 여러 겹으로 쌓인 층을 나타냄
· 예시 단어: 階層 (계층, かい+そう)
[종합] 높이(高) 겹겹이 쌓인 층(層)이라는 뜻에서 고층이 됨
[치트키] "코-소-! 코-(높음)의 소-(층) 고층" → 高層=코-소-→고층
[장면] 하늘을 찌를 듯 높이 솟은 빌딩의 모습
[예문] 高層ビルが並ぶ(코-소-비루가 나라부) = "고층빌딩이 늘어서다"

構造

· 음독: ★コウ

· 분해: 木(나무 목) + 冓(짤 구, 얽어 짬)

· 예시 단어: 構成 (구성, こう+せい)
[한자2] 造 (지을 조 / 짓다, 만들다)
· 음독: ★ゾウ (연탁)
· 훈독: つく-る
· 분해: 辶(쉬엄쉬엄 갈 착) + 告(고할 고, 발음요소)

[종합] 얽어(構) 만들어진(造) 형태라는 뜻에서 구조가 됨
[치트키] "코-조-! 코-(얽음)와 조-(만듦) 구조" → 構造=코-조-→구조
[장면] 건물 설계도에서 내부 구조를 살펴보는 장면
[예문] 建物の構造を調べる(타테모노노 코-조-오 시라베루) = "건물의 구조를 조사하다"

[읽기] 交=コウ + 替/代=タイ → こうたい (음독)
[한자1] 交 (사귈 교 / 사귀다, 교차하다)
· 음독: ★コウ
· 훈독: まじ-わる
· 분해: 交 자체가 사람이 다리를 꼬고 있는 모습을 본뜬 상형자
· 어원: 사람의 다리가 교차한 모습에서 사귀다, 바꿈을 나타냄
· 예시 단어: 交換 (교환, こう+かん)
[한자2] 替 (바꿀 체 / 바꾸다) / 代 (대신할 대 / 대신하다)
· 음독: ★タイ
· 훈독: か-える, か-わる
· 분해: 夫(지아비 부)×2 + 日(날 일) / 亻(사람 인) + 弋(주살 익)

· 예시 단어: 交代 (자기 반복, こう+たい)
[종합] 서로 바꾸어(交) 대신하는(替/代) 것이라는 뜻에서 교체, 교대가 됨
[치트키] "코-타이! 코-(바꿈)와 타이(대신) 교대" → 交替=코-타이→교대
[장면] 야간 근무자와 주간 근무자가 자리를 바꾸는 장면
