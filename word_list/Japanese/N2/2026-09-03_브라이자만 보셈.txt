依然として
여전히(いぜんとして)
[읽기] 依=イ + 然=ゼン + として → いぜんとして (음독)
[악센트] 0형(평판형)
[한자1] 依 (의지할 의 / 의지하다, 여전하다)
· 음독: ★イ, エ
· 훈독: よ-る
· 분해: 亻(사람 인) + 衣(옷 의)
· 어원: 사람(亻)이 옷(衣)에 몸을 감싸고 기대어 의지한다는 데서 의지하다, 기대다, 그대로다를 뜻함
· 예시 단어: 依存 (의존, い+ぞん)
[한자2] 然 (그러할 연 / 그러하다, 틀림없다)
· 음독: ★ゼン, ネン
· 훈독: しか-り, しか-し
· 분해: 月(고기 육) + 犬(개 견) + 灬(불 화)
· 어원: 개(犬) 고기(月)를 불(灬)에 굽는다는 뜻에서 파생되어, 불타는 것이 당연하다, 그러하다라는 상태를 나타내는 어조사로 쓰임
· 예시 단어: 自然 (자연, し+ぜん)
[종합] 예전부터 기대어 온(依) 상태 그대로(然) 변함없이 유지한다는 뜻에서 여전히를 의미함
[치트키] "이젠토시테! 이(이)젠(전)이나 지금이나 토(똑)같이 여전히 그대로다" → 依然として=이젠토시테→여전히
[장면] 10년이 지나 다시 찾은 옛 동네 식당이 간판 하나 바뀌지 않고 예전 모습 여전히 그대로 영업하고 있는 장면
[예문] 依然として人気がある(이젠토시테 닌키가 아루) = "여전히 인기가 있다"

반도체(はんどうたい)
[읽기] 半=ハン + 導=ドウ + 体=タイ → はんどうたい (음독)
[악센트] 3형(중고형)
[한자1] 半 (반 반 / 반, 절반)
· 음독: ★ハン
· 훈독: なか-ば
· 분해: 八(여덟 팔/나누다) + 牛(소 우)
· 어원: 소(牛)를 칼로 정확히 반으로 나눈다(八)는 데서 절반을 뜻함
· 예시 단어: 半分 (절반, はん+ぶん)
[한자2] 導 (이끌 도 / 이끌다, 전도하다)
· 음독: ★ドウ
· 훈독: みちび-く
· 분해: 道(길 도) + 寸(마디 촌/손)
· 어원: 길(道)을 잃은 사람의 손(寸)을 잡고 올바른 방향으로 이끌어간다는 데서 이끌다, 전기를 통하게 하다를 뜻함
· 예시 단어: 指導 (지도, し+どう)
[한자3] 体 (몸 체 / 몸, 형태)
· 음독: ★タイ, テイ
· 훈독: からだ
· 분해: 亻(사람 인) + 本(근본 본)
· 어원: 사람(亻)을 구성하는 근본(本)이 되는 뼈대와 덩어리, 즉 몸을 뜻함
· 예시 단어: 身体 (신체, しん+たい)
[종합] 전기가 완전히 통하는 도체와 안 통하는 부도체의 중간, 즉 절반(半)만 전기를 이끄는(導) 물체(体)라는 뜻
[치트키] "한도-타이! 한(한)국이 주도(도-)하여 타(타)국에 수출하는 반도체" → 半導体=한도-타이→반도체
[장면] 미세한 회로가 복잡하게 그려져 있는 은빛의 작은 칩을 핀셋으로 조심스럽게 들어 올리는 연구원의 모습
[예문] 半導体の工場を作る(한도-타이노 코-죠-오 츠쿠루) = "반도체 공장을 짓다"

[치트키] "교-카이! 교-(교)묘하게 카(카)이(이익)를 챙기는 치열한 업계" → 業界=교-카이→업계
[장면] 같은 종류의 상품을 파는 여러 회사의 임원들이 모여 눈치 싸움을 벌이는 연회장 모습
[예문] 業界のトップになる(교-카이노 톱푸니 나루) = "업계의 톱이 되다"

[장면] 거대한 회사가 사장 아래로 여러 부서를 톱니바퀴처럼 조직적으로 엮어 움직이는 피라미드 형태의 조직도

· 예시 단어: 連続 (연속, れん+ぞく)

[장면] 초록색 컴퓨터 기판 위에 전기가 통하는 은색 선들이 미로처럼 복잡하게 얽혀서 빙빙 돌아가는 구조

不動
부동, 움직이지 않음(ふどう)

· 음독: ★フ, ブ
· 훈독: 없음
· 분해: 새가 하늘로 날아오르지 못하고 땅으로 향해 꺾인 날개 모양
· 어원: 위로 비상하지 못하고 꺾였다는 데서 부정, 아니다를 뜻함

· 예시 단어: 運動 (운동, うん+どう)
[종합] 무거운 것을 밀어내듯 움직이는(動) 일이 전혀 없이(不) 제자리에 꽉 박혀 고정되어 있다는 뜻
[치트키] "후도-! 후(후) 불어도 도-(도)통 꿈쩍도 안 하는 부동의 바위" → 不動=후도-→부동
[장면] 강한 태풍이 불어 나무들이 꺾이는데도 끄떡없이 흔들림 없이 우뚝 서 있는 거대한 산의 바위
[예문] 不動の地位を築く(후도-노 치-오 키즈쿠) = "부동의 지위를 구축하다"

DRAM
다이내믹 램(ダイナミック・ラム)
[유래] Dynamic Random Access Memory (다이내믹 램) = 전원이 끊어지면 정보가 지워지는 기억 장치, 영어에서 유래
[종합] 컴퓨터의 주 기억 장치로 쓰이며, 처리 속도가 뛰어나지만 전원이 꺼지면 데이터가 날아가는 휘발성 메모리를 의미함
[치트키] "디램! 디(디)지털 램(램) 기억 장치" → DRAM=디램→기억 장치
[장면] 컴퓨터 메인보드에 꽂혀 있는 초록색의 길쭉한 직사각형 메모리 칩
[예문] パソコンにDRAMを増設する(파소콘니 디-라무오 조-세츠스루) = "컴퓨터에 DRAM을 증설하다"

[읽기] プリント(가타카나) + 配=ハイ + 線=セン + 基=キ + 板=バン → プリントはいせんきばん (음독 + 가타카나 결합)
[악센트] 6형(중고형)

· 예시 단어: 配達 (배달, はい+たつ)
[한자2] 線 (선 선 / 줄, 선)
· 음독: ★セン
· 훈독: 없음
· 분해: 糸(실 사) + 泉(샘 천/물줄기)
· 어원: 가늘고 길게 이어지는 샘의 물줄기(泉)처럼 물레에서 길게 뽑아낸 실(糸)을 뜻하며, 가느다란 줄이나 선을 의미함
· 예시 단어: 直線 (직선, ちょく+せん)

· 훈독: もと, もとい

· 어원: 흙(土)을 반듯하게 다져 세운 건축의 기초, 바탕을 뜻함
· 예시 단어: 基本 (기본, き+ほん)
[한자4] 板 (널 판 / 널빤지, 판자)
· 음독: ★バン, ハン
· 훈독: いた
· 분해: 木(나무 목) + 反(돌이킬 반/평평하게 펴다)
· 어원: 나무(木)를 넓고 평평하게(反) 깎아 만든 판자나 널빤지를 뜻함
· 예시 단어: 看板 (간판, かん+ばん)
[종합] 구리 선(線)을 복잡하게 배열(配)하여 인쇄(プリント)하듯 찍어낸, 전자 부품을 꽂기 위한 바탕(基)이 되는 판자(板)라는 뜻 (PCB)

· 분해: 广(집 엄) + 廿(스물 입) + 又(또 우/손)
· 어원: 집을 지을 때 손(又)으로 자를 잡고 여러 번(廿) 길이를 잰다는 데서 일정한 한도, 정도, 마음의 도량을 뜻함
· 예시 단어: 程度 (정도, てい+ど)
[한자2] 胸 (가슴 흉 / 가슴, 마음)
· 음독: ★キョウ
· 훈독: むね, むな
· 분해: 月(고기 육/몸) + 匈(오랑캐 흉/가슴)
· 어원: 사람 몸(月)에서 심장이 있는 앞부분, 즉 흉곽이나 가슴을 뜻하며 나아가 마음속의 생각을 의미함
· 예시 단어: 胸部 (흉부, きょう+ぶ)
[종합] 가슴(胸)속에 품은 마음의 크기나 정도(度)가 대단하여, 어떤 일에도 겁내지 않고 당당히 맞서는 배짱을 뜻함
[치트키] "도쿄-! 도쿄(도쿄) 한복판에서 노래를 부르는 대단한 배짱" → 度胸=도쿄-→배짱
[장면] 낭떠러지 위에서 번지점프를 할 때 눈 하나 깜짝하지 않고 두 팔을 벌려 웃으며 뛰어내리는 강심장의 모습
[예문] 彼には度胸がある(かれには どきょうがある) = "그에게는 배짱이 있다"

信じる
믿다(しんじる)
[읽기] 信=シン + じる → しんじる (음독)
[악센트] 3형(중고형)
[한자1] 信 (믿을 신 / 믿다)
· 음독: ★シン
· 훈독: 없음
· 분해: 亻(사람 인) + 言(말씀 언)
· 어원: 사람(亻)이 뱉은 말(言)은 마땅히 거짓이 없이 진실해야 한다는 데서 믿다, 신뢰하다를 뜻함
· 예시 단어: 信用 (신용, しん+よう)
[종합] 사람이 하는 말이 진실하다고 확신하며(信) 상대를 의심하지 않고 확실하게 여긴다는 뜻의 타동사
[치트키] "신지루! 신(신)의 존재를 진심으로 믿다" → 信じる=신지루→믿다
[장면] 친구가 억울하게 누명을 썼을 때, 모두가 손가락질해도 나는 네가 안 그랬다는 걸 알아라며 눈을 맞추고 굳게 믿어주는 모습
[예문] 先生の言葉を信じる(せんせいの ことばを しんじる) = "선생님의 말을 믿다"
[활용] ます형: しんじます · ない형: しんじない · て형: しんじて · た형: しんじた

かどうか
~인지 어떤지(かどうか)
[종합] 명사, 형용사, 동사의 보통형 뒤에 붙어(な형용사와 명사는 だ 생략), 앞의 내용이 사실인지(か) 아니면 그렇지 않은지(どうか)를 불확실하게 나타내는 구어체 문법 표현
[치트키] "카도-카! 카(가)스 불을 껐는지 안 껐는지 도-카(통) 모르겠네" → かどうか=카도-카→~인지 어떤지
[장면] 집을 나와서 문을 잠그고 가다가, 내가 현관문을 잠갔나? 안 잠갔나? 하고 고개를 갸우뚱하며 확신하지 못하는 모습
[예문] 本当かどうか確かめる(ほんとう かどうか たしかめる) = "정말인지 어떤지 확인하다"

かいなか
~인지 아닌지(かいなか)
[읽기] か + 否=いな + か → かいなか (훈독 혼합)
[한자1] 否 (아닐 부 / 아니다, 거절하다)
· 음독: ヒ
· 훈독: ★いな, いや
· 분해: 不(아닐 불) + 口(입 구)
· 어원: 상대방의 말에 대해 입(口)으로 아니라고(不) 단호하게 부정하고 거절한다는 뜻
· 예시 단어: 否定 (부정, ひ+てい)
[종합] 문어체적 표현으로, 앞의 사실이 맞는가(か) 아니면 틀린가(否か)를 묻는 딱딱하고 격식 있는 표현 (どうか의 문어체)
[치트키] "카이나카! 카(가)짜인지 이(이)상하게 진짜인지 아(아)닌가(나카)를 면밀히 조사하다" → かいなか=카이나카→~인지 아닌지
[장면] 법정에서 재판장이 피고인의 증언을 들으며 저 말이 진실인가 아닌가를 엄격한 표정으로 저울질하는 모습
[예문] 出席するかいなかを知らせる(しゅっせきする かいなかを しらせる) = "출석할지 어떨지(아닌지)를 알리다"

と呼ばれる
~라고 불리다, 일컬어지다(とよばれる)
[읽기] と + 呼=よ + ばれる → とよばれる (훈독, 수동태)
[악센트] 4형(미고형)
[한자1] 呼 (부를 호 / 부르다)
· 음독: コ
· 훈독: ★よ-ぶ
· 분해: 口(입 구) + 乎(어조사 호, 부르다)
· 어원: 입(口)을 벌려 숨을 내쉬거나 큰 소리로 남의 이름을 부른다(乎)는 뜻
· 예시 단어: 呼吸 (호흡, こ+きゅう)
[종합] 명사 뒤에 조석 と가 붙고 呼ぶ(부르다)의 수동태가 결합하여, 세상 사람들에게 특정한 명칭이나 별명으로 불리고 일컬어진다는 뜻
[치트키] "토요바레루! 토(토)끼라고 요(요)란하게 불리다" → と呼ばれる=토요바레루→~라고 불리다
[장면] 도쿄의 아키하바라 거리에 수많은 전자 상가들이 모여 있어, 외국인 관광객들이 이곳을 가리키며 전자제품의 천국이라고 부르는 장면
[예문] 機械音痴と呼ばれる(きかいおんちと よばれる) = "기계치라고 불리다"

おかげ
덕분(おかげ)
[읽기] お + 陰=かげ → おかげ (훈독)
[악센트] 0형(평판형)
[한자1] 陰 (그늘 음 / 그늘, 숨다)
· 음독: イン
· 훈독: ★かげ, かげ-る
· 분해: 阝(언덕 부) + 侌(그늘 음)
· 어원: 언덕(阝)에 가려 해가 비치지 않는 어두운 그늘(侌)을 뜻하며, 나아가 남의 눈에 띄지 않게 뒤에서 도와주는 은덕을 뜻하게 됨
· 예시 단어: 陰気 (음기, いん+き)
[종합] 미화어 お에 그늘(陰)이 붙은 형태로, 보이지 않는 그늘 뒤에서 도와준 은덕이나 도움이라는 뜻에서 ~의 덕분을 의미함. 좋은 결과의 원인을 나타냄. (반어법으로 나쁜 결과에 탓으로 쓸 때도 있음)
[치트키] "오카게! 오(오)늘 카(카)페 게(개)업을 무사히 한 것은 다 네 덕분이야" → おかげ=오카게→덕분
[장면] 무사히 대학에 합격한 학생이, 부모님과 선생님의 보이지 않는 뒷바라지(그늘)에 감사하며 두 손을 모아 고개를 숙이는 모습
[예문] 先生のおかげで合格しました(せんせいの おかげで ごうかくしました) = "선생님 덕분에 합격했습니다"
