万事休す
다 끝났다(ばんじきゅうす)
[읽기] 万=ばん + 事=じ + 休=きゅう + す → ばんじきゅうす (음독)
[한자1] 万 (일만 만 / 일만)
· 음독: ★マン, バン
· 훈독: なし
· 분해: 원자 萬의 간략형으로 세부 분해는 이설 있음
· 어원: 전갈 모양을 본뜬 萬에서 간략화되어 숫자 일만을 뜻함. 신자체로 원자 萬의 간략형
· 예시단어(음독): 万国 (만국, ばん+こく)
[한자2] 事 (일 사 / 일)
· 음독: ★ジ, ズ
· 훈독: こと, つか-える
· 분해: 一(한 일) + 口(입 구) + ヨ(손의 변형) + 亅(갈고리 궐)
· 어원: 손(ヨ)에 깃발을 든 모습에서 일, 사건을 뜻함
· 예시단어(음독): 事故 (사고, じ+こ)
· 예시단어(훈독): 事 (일, こと)
[한자3] 休 (쉴 휴 / 쉬다)
· 음독: ★キュウ
· 훈독: やす-む, やす-まる, やす-める
· 분해: 亻(사람 인) + 木(나무 목)
· 어원: 사람(亻)이 나무(木) 그늘에 기대어 쉰다는 뜻에서 쉬다를 뜻함
· 예시단어(음독): 休憩 (휴식, きゅう+けい)
· 예시단어(훈독): 休む (쉬다, やす+む)
[종합] 모든(万) 일(事)이 멈췄다(休す)는 뜻에서 더 이상 손쓸 방법이 없다는 관용구
[치트키] "반지큐-스! 반지(반지)큐-스(큐-스) 다 끝났어" → 万事休す=반지큐-스→다 끝났다
[장면] 궁지에 몰려 손을 놓고 주저앉는 모습
[예문] もはや万事休すだ(모하야 반지큐-스다) = "이제는 다 끝났다"
[헷갈리는 단어] 一巻の終わり(いっかんのおわり) - 一巻の終わり는 끝장, 万事休す는 방법이 다 사라짐

納まる
다 들어가다(おさまる)
[읽기] 納=おさ + まる → おさまる (훈독)
[한자1] 納 (들일 납 / 거두다)
· 음독: ノウ, ナッ, ナ, トウ, ナン
· 훈독: ★おさ-まる, おさ-める
· 분해: 糸(실 사) + 内(안 내)
· 어원: 실(糸)을 안(内)으로 거두어들인다는 뜻에서 들이다를 뜻함
· 예시단어(음독): 納得 (납득, なっ+とく)
· 예시단어(훈독): 納める (거두다, おさ+める)
[종합] 알맞은 곳에 들어가 자리를 잡는다는 뜻의 동사
[치트키] "오사마루! 오사(오사)마루(마루) 쏙 들어가" → 納まる=오사마루→다 들어가다
[장면] 짐이 상자에 딱 맞게 들어가는 모습
[예문] 箱に納まる(하코니 오사마루) = "상자에 들어간다"
[활용] ます형: おさまります · ない형: おさまらない · て형: おさまって · た형: おさまった
[헷갈리는 단어] 収まる(おさまる) - 収まる는 일정한 범위 안에 들어감, 納まる는 알맞은 곳에 정돈됨

満たない
다 차지 않다(みたない)
[읽기] 満=み + たない → みたない (훈독, 満たす의 부정형)
[한자1] 満 (찰 만 / 차다)
· 음독: マン
· 훈독: ★み-たす, み-ちる
· 분해: 氵(물 수) + 満의 오른쪽 부분(艹 + 両), 원자 滿의 간략형
· 어원: 물(氵)이 가득 차오른다는 뜻에서 차다를 뜻함. 신자체로 원자 滿의 간략형
· 예시단어(음독): 満足 (만족, まん+ぞく)
· 예시단어(훈독): 満ちる (차다, み+ちる)
[종합] 정해진 수나 양에 차지(満たす) 못한다는 뜻의 표현
[치트키] "미타나이! 미타(미타)나이 다 안 차" → 満たない=미타나이→다 차지 않다
[장면] 컵에 물이 반도 못 차 있는 모습
[예문] 100人に満たない(햐쿠닌니 미타나이) = "100명에 차지 못한다"
[활용] ない형: みたない · て형: みたなくて · た형: みたなかった
[헷갈리는 단어] 足りない(たりない) - 足りない는 모자람, 満たない는 기준에 미치지 못함

吹っ切れる

[한자1] 吹 (불 취 / 불다)

· 훈독: ★ふ-く
· 분해: 口(입 구) + 欠(하품 흠)
· 어원: 입(口)을 벌려(欠) 바람을 내보낸다는 뜻에서 불다를 뜻함
· 예시단어(음독): 吹雪 (눈보라, ふ+ぶき)
· 예시단어(훈독): 吹く (불다, ふ+く)
[한자2] 切 (끊을 절 / 자르다)
· 음독: セツ, サイ
· 훈독: ★き-れる, き-る
· 분해: 七(일곱 칠, 베는 선의 모양) + 刀(칼 도)
· 어원: 칼(刀)로 가로 선(七)을 그어 자른다는 뜻에서 자르다를 뜻함
· 예시단어(음독): 切実 (절실, せつ+じつ)
· 예시단어(훈독): 切れる (끊어지다, き+れる)
[종합] 바람에 날리듯(吹っ) 마음의 응어리가 끊겨(切れる) 사라진다는 뜻의 동사
[치트키] "훗키레루! 훗(훗)키레루(키레루) 털어내" → 吹っ切れる=훗키레루→다 털어내다
[장면] 고민을 떨치고 환하게 웃는 모습
[예문] 迷いが吹っ切れる(마요이가 훗키레루) = "망설임을 털어낸다"
[활용] ます형: ふっきれます · ない형: ふっきれない · て형: ふっきれて · た형: ふっきれた
[헷갈리는 단어] 割り切る(わりきる) - 割り切る는 딱 잘라 정리함, 吹っ切れる는 응어리를 떨쳐 냄

詰め寄る
다가서다(つめよる)
[읽기] 詰=つ + め + 寄=よ + る → つめよる (훈독, 詰める의 연용형 + 寄る)
[한자1] 詰 (물을 힐 / 채우다, 따지다)
· 음독: キツ
· 훈독: ★つ-める, つ-まる, つ-む
· 분해: 言(말씀 언) + 吉(길할 길)
· 어원: 말(言)로 따져 길(吉)을 막는다는 뜻에서 따지다, 막히다를 뜻함
· 예시단어(음독): 詰問 (힐문, きつ+もん)
· 예시단어(훈독): 詰める (채우다, つ+める)
[한자2] 寄 (부칠 기 / 가까이하다)
· 음독: キ
· 훈독: ★よ-る, よ-せる
· 분해: 宀(집 면) + 奇(기이할 기, 大(큰 대) + 可(옳을 가))
· 어원: 집(宀)에 기이한(奇) 손님이 찾아와 몸을 맡긴다는 뜻에서 가까이하다, 맡기다를 뜻함
· 예시단어(음독): 寄付 (기부, き+ふ)
· 예시단어(훈독): 寄る (다가가다, よ+る)
[종합] 거리를 좁혀(詰め) 바짝 다가선다(寄る)는 뜻에서 따지듯 다가서다가 됨
[치트키] "츠메요루! 츠메(츠메)요루(요루) 바짝 다가서" → 詰め寄る=츠메요루→다가서다
[장면] 기자가 해명을 요구하며 바짝 다가가는 모습
[예문] 詰め寄って問い質す(츠메욧테 토이타다스) = "바짝 다가서서 따져 묻는다"
[활용] ます형: つめよります · ない형: つめよらない · て형: つめよって · た형: つめよった
[헷갈리는 단어] 近寄る(ちかよる) - 近寄る는 가까이 감, 詰め寄る는 따지며 바짝 다가섬

何はさておき
다른 것은 제쳐두고(なにはさておき)
[읽기] 何=なに + は + さて + おき → なにはさておき (何는 훈독)
[한자1] 何 (어찌 하 / 무엇)
· 음독: カ
· 훈독: ★なに, なん
· 분해: 亻(사람 인) + 可(옳을 가)
· 어원: 사람(亻)이 짐을 어깨에 메는(可) 모양에서 짊어지다, 무엇을 뜻함
· 예시단어(음독): 幾何 (기하, き+か)
· 예시단어(훈독): 何 (무엇, なに)
[종합] 무엇(何)보다도 우선이라며 다른 것은 제쳐 둔다(さておき)는 뜻의 관용구
[치트키] "나니와 사테오키! 나니와(나니와)사테오키(사테오키) 먼저 하자" → 何はさておき=나니와 사테오키→다른 것은 제쳐두고
[장면] 만나자마자 일단 밥부터 먹자고 말하는 모습
[예문] 何はさておき食事にしよう(나니와 사테오키 쇼쿠지니 시요-) = "무엇보다도 먼저 식사하자"
[헷갈리는 단어] とりあえず(우선) - とりあえず는 우선 급한 대로, 何はさておき는 다른 모든 것보다 먼저

出会い頭
다른 길로 접어드는 순간(であいがしら)
[읽기] 出=で + 会=あ + い + 頭=がしら → であいがしら (훈독, 頭의 かしら가 탁음화/연탁으로 がしら)
[한자1] 出 (날 출 / 나다, 나가다)
· 음독: シュツ, スイ
· 훈독: ★で-る, だ-す
· 분해: 屮(싹 철) + 凵(입 벌릴 감)
· 어원: 싹(屮)이 땅 구덩이(凵)에서 돋아 나온다는 뜻에서 나다를 뜻함
· 예시단어(음독): 出発 (출발, しゅっ+ぱつ)
· 예시단어(훈독): 出る (나가다, で+る)
[한자2] 会 (모일 회 / 모이다)
· 음독: カイ, エ
· 훈독: ★あ-う
· 분해: 人(사람 인)의 변형 亼 + 云(이를 운), 원자 會의 간략형
· 어원: 사람들이 모여(亼) 말한다(云)는 뜻에서 모이다를 뜻함. 신자체로 원자 會의 간략형
· 예시단어(음독): 会社 (회사, かい+しゃ)
· 예시단어(훈독): 会う (만나다, あ+う)
[한자3] 頭 (머리 두 / 머리, 우두머리)
· 음독: トウ, ズ, ト
· 훈독: ★かしら, あたま
· 분해: 豆(콩 두, 굽 달린 제기 모양) + 頁(머리 혈, 사람 머리를 본뜬 독립 부수)
· 어원: 제기(豆)처럼 둥글게 얹힌 사람의 머리(頁)에서 머리, 맨 앞을 뜻함
· 예시단어(음독): 先頭 (선두, せん+とう)
· 예시단어(훈독): 頭 (머리, あたま)
[종합] 나가다(出) 마주치는(会い) 첫 순간(頭)이라는 뜻에서 모퉁이를 돌자마자 마주치는 순간이 됨
[치트키] "데아이가시라! 데아이(데아이)가시라(가시라) 마주친 순간" → 出会い頭=데아이가시라→다른 길로 접어드는 순간
[장면] 골목 모퉁이에서 자전거와 사람이 부딪치는 모습
[예문] 出会い頭にぶつかる(데아이가시라니 부츠카루) = "모퉁이에서 마주쳐 부딪친다"
[헷갈리는 단어] 出会い(であい) - 出会い는 만남, 出会い頭는 마주치는 바로 그 순간

相部屋
다른 사람과 같이 사용하는 방(あいべや)
[읽기] 相=あい + 部屋=べや → あいべや (훈독, 部屋의 へや가 탁음화/연탁으로 べや)
[한자1] 相 (서로 상 / 서로)
· 음독: ソウ, ショウ
· 훈독: ★あい
· 분해: 木(나무 목) + 目(눈 목)
· 어원: 나무(木)를 눈(目)으로 살펴 서로 마주 본다는 뜻에서 서로를 뜻함
· 예시단어(음독): 相互 (상호, そう+ご)
· 예시단어(훈독): 相手 (상대, あい+て)
[한자2] 部 (떼 부 / 부분, 부서)
· 음독: ★ブ
· 훈독: なし
· 분해: 咅(침 뱉을 부) + 阝(고을 읍)
· 어원: 고을(阝)을 나누어 맡는 부분이라는 뜻에서 부분, 부서를 뜻함
· 예시단어(음독): 部分 (부분, ぶ+ぶん)
[한자3] 屋 (집 옥 / 집)
· 음독: オク
· 훈독: ★や
· 분해: 尸(주검 시, 지붕) + 至(이를 지)
· 어원: 지붕(尸) 아래 사람이 이르러(至) 머무는 집을 뜻함
· 예시단어(음독): 屋上 (옥상, おく+じょう)
· 예시단어(훈독): 屋 (집, や)
[종합] 서로(相) 나누어 쓰는 방(部屋)이라는 뜻에서 남과 같이 쓰는 방이 됨
[치트키] "아이베야! 아이(아이)베야(베야) 같이 쓰는 방" → 相部屋=아이베야→다른 사람과 같이 사용하는 방
[장면] 병원에서 여러 환자가 한 병실을 나눠 쓰는 모습
[예문] 相部屋に泊まる(아이베야니 토마루) = "같이 쓰는 방에 묵는다"
[헷갈리는 단어] 個室(こしつ) - 個室는 혼자 쓰는 방, 相部屋는 같이 쓰는 방

人伝
다른 사람을 통해 전함(ひとづて)
[읽기] 人=ひと + 伝=づて → ひとづて (훈독, 伝て의 つて가 탁음화/연탁으로 づて)
[한자1] 人 (사람 인 / 사람)
· 음독: ジン, ニン
· 훈독: ★ひと
· 분해: 독립 부수, 사람이 서서 팔을 늘어뜨린 옆모습을 본뜬 상형자
· 어원: 두 다리로 서 있는 사람의 옆모습에서 사람을 뜻함
· 예시단어(음독): 人類 (인류, じん+るい)
· 예시단어(훈독): 人 (사람, ひと)
[한자2] 伝 (전할 전 / 전하다)
· 음독: デン
· 훈독: ★つた-える, つた-わる, つた-う, つて
· 분해: 亻(사람 인) + 云(이를 운), 원자 傳의 간략형
· 어원: 사람(亻)이 말(云)을 옮겨 전한다는 뜻에서 전하다를 뜻함. 신자체로 원자 傳의 간략형

[치트키] "히토즈테! 히토(히토)즈테(즈테) 사람을 통해" → 人伝=히토즈테→다른 사람을 통해 전함

[예문] 人伝に聞く(히토즈테니 키쿠) = "인편으로 전해 듣는다"
[헷갈리는 단어] 伝言(でんごん) - 伝言는 전할 말, 人伝는 남을 통해 전해진 것

潰しが利く
다른 일을 잘할 수 있다(つぶしがきく)
[읽기] 潰=つぶ + し + が + 利=き + く → つぶしがきく (훈독, 潰す의 연용형 + 利く)
[한자1] 潰 (무너질 궤 / 부수다, 표외한자)
· 음독: カイ
· 훈독: ★つぶ-す, つぶ-れる
· 분해: 氵(물 수) + 貴(귀할 귀)
· 어원: 물(氵)에 귀한(貴) 것을 담가 무너뜨린다는 뜻에서 무너지다, 부수다를 뜻함. 상용한자가 아닌 표외한자
· 예시단어(음독): 潰滅 (궤멸, かい+めつ)
· 예시단어(훈독): 潰す (부수다, つぶ+す)
[한자2] 利 (이로울 리 / 이롭다)
· 음독: リ
· 훈독: ★き-く
· 분해: 禾(벼 화) + 刂(칼 도)
· 어원: 칼(刂)로 벼(禾)를 잘 베듯 날이 잘 들어 이롭다는 뜻에서 이롭다를 뜻함
· 예시단어(음독): 利益 (이익, り+えき)
· 예시단어(훈독): 利く (효과가 있다, き+く)
[종합] 쓰던 물건을 부숴서(潰し) 다른 용도로 쓸 수 있다(利く)는 뜻에서 다른 일도 잘할 수 있다는 관용구
[치트키] "츠부시가 키쿠! 츠부시가(츠부시가)키쿠(키쿠) 다른 일도 가능" → 潰しが利く=츠부시가 키쿠→다른 일을 잘할 수 있다
[장면] 이직해서도 능숙하게 일하는 모습
[예문] 手に職があれば潰しが利く(테니 쇼쿠가 아레바 츠부시가 키쿠) = "기술이 있으면 다른 일도 할 수 있다"
[활용] ます형: ききます · ない형: きかない · て형: きいて · た형: きいた
[헷갈리는 단어] 融通が利く(ゆうずうがきく) - 融通が利く는 융통성이 있음, 潰しが利く는 다른 일에도 쓸모가 있음

[읽기] 引=ひ + き + 締=し + まる → ひきしまる (훈독, 引く의 연용형 + 締まる)
[한자1] 引 (끌 인 / 끌다)
· 음독: イン
· 훈독: ★ひ-く, ひ-ける
· 분해: 弓(활 궁) + 丨(뚫을 곤)
· 어원: 활(弓)의 시위를 곧게(丨) 당기는 모양에서 끌다를 뜻함
· 예시단어(음독): 引退 (은퇴, いん+たい)
· 예시단어(훈독): 引く (끌다, ひ+く)
[한자2] 締 (맺을 체 / 조이다)
· 음독: テイ
· 훈독: ★し-まる, し-める
· 분해: 糸(실 사) + 帝(임금 제)
· 어원: 실(糸)을 임금(帝)의 명처럼 단단히 묶는다는 뜻에서 조이다를 뜻함
· 예시단어(음독): 締結 (체결, てい+けつ)
· 예시단어(훈독): 締まる (조여지다, し+まる)
[종합] 팽팽히 당겨지고(引き) 조여져(締まる) 몸이나 분위기가 단단히 긴장된다는 뜻의 동사
[치트키] "히키시마루! 히키(히키)시마루(시마루) 다부져" → 引き締まる=히키시마루→다부지다
[장면] 단련된 몸이 탄탄하게 조여진 모습
[예문] 引き締まった体(히키시맛타 카라다) = "다부진 몸"
[활용] ます형: ひきしまります · ない형: ひきしまらない · て형: ひきしまって · た형: ひきしまった
[헷갈리는 단어] 引き締める(ひきしめる) - 引き締める는 타동사로 조임, 引き締まる는 자동사로 조여짐
